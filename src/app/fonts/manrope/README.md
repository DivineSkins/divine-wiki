# Manrope

Source: [Google Fonts, revision b31870a](https://github.com/google/fonts/tree/b31870aff700ab7a1d74fa0c6887d95beb9e0037/ofl/manrope).

`Manrope-Variable.woff2` is the full `Manrope[wght].ttf` converted to WOFF2
with FontTools 4.64.0, without subsetting or changing the outlines. It retains
the 200 to 800 weight axis and all source glyphs, including Vietnamese.
The font is distributed under the included SIL Open Font License.

Loading this file through `next/font/local` avoids the intermittent Google Fonts
URL parsing failure in [Next.js #99114](https://github.com/vercel/next.js/issues/99114).
