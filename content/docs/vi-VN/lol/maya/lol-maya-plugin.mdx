## Cài plugin LoL-Maya

Để bắt đầu làm việc với model LMHT trong Maya, bạn cần **plugin LoL-Maya** của **Tarngaina**.

## Tải plugin

Tải **LoL-Maya (bản mới nhất)**
Hãy chắc chắn bạn dùng bản phát hành mới nhất.

---

## Cài plugin

1. Giải nén nội dung file `.zip`.
2. Chép tất cả file plugin vào thư mục Maya của bạn.

Đặt các thư mục sau vào:

```text
Documents\maya\2023\
```

- `plug-ins`
- `prefs`
- `scripts`

---

## Bật plugin trong Maya

1. Mở **Maya**
2. Vào:
   **Windows → Settings/Preferences → Plug-in Manager**
3. Tìm **lol_maya** trong danh sách
4. Bật cả hai:
   - **Loaded**
   - **Auto Load**

5. Bấm **Close**, rồi khởi động lại Maya

Nếu thành công, bạn sẽ thấy tab **LoLMaya** và **LoLMaya_MAPGEO** trên thanh công cụ chính của Maya.

### Plugin không xuất hiện trong Plug-in Manager

**Nguyên nhân:**

- File không nằm đúng thư mục
- Sai thư mục phiên bản Maya

**Cách sửa:**

1. Kiểm tra file có nằm trong `Documents\maya\[PHIEN_BAN_CUA_BAN]\` không
2. Đảm bảo cả ba thư mục (`plug-ins`, `prefs`, `scripts`) đều có mặt
3. Khởi động lại Maya hoàn toàn

</Tab>
<Tab value="Thiếu tab">

### Tab không hiện sau khi nạp

**Nguyên nhân:**

- Plugin đã nạp nhưng giao diện chưa làm mới
- Maya cần khởi động lại

**Cách sửa:**

1. Đóng Maya hoàn toàn
2. Mở lại Maya
3. Kiểm tra lại Plug-in Manager
4. Đảm bảo cả **Loaded** và **Auto Load** đều đang bật

</Tab>
