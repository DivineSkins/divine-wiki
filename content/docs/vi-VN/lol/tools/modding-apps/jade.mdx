Jade là trình chỉnh BIN tập trung của **RitoShark**. Đây là điểm khởi đầu
được khuyên dùng nếu bạn chủ yếu làm việc với file `.bin`.

[Tải bản phát hành mới nhất](https://github.com/RitoShark/Jade-League-Bin-Editor/releases)

> Jade vẫn đang được phát triển tích cực. Đừng ngạc nhiên nếu còn vài chỗ
> thô, và báo lỗi trên GitHub nếu bạn gặp phải.

---

## Jade làm được gì

- **Trình chỉnh BIN trực quan** có tô màu cú pháp (trình Monaco, cùng cái
  mà VS Code dùng).
- **Hai engine phân tích**: engine riêng của Jade (Rust) và trình phân tích
  LTK. Chuyển qua lại trong phần cài đặt.
- **Quản lý file hash** với tự tải về từ CommunityDragon, nên bạn không
  phải tự theo dõi file.
- **Xem trước texture** khi rê chuột. Thấy được texture được tham chiếu
  trông thật ra thế nào.
- **Trình chỉnh particle** để tinh chỉnh hệ thống particle trực quan.
- **Tab** kèm kéo và thả. Chỉnh nhiều file cạnh nhau.
- **Kết nối Quartz**. Jade nhận ra khi Quartz đổi một file bạn đang chỉnh.

---

## Cài đặt

1. Vào [trang releases](https://github.com/RitoShark/Jade-League-Bin-Editor/releases).
2. Tải bộ cài Windows.
3. Chạy nó. Xong.

Sau khi cài, nhấp đúp một file `.bin` là mở nó trong Jade.

---

## Khi nào dùng Jade so với các tool khác

- **Dùng Jade** nếu chỉnh BIN là việc chính của bạn. Đây là đường nhanh
  nhất từ mở file → chỉnh → lưu.
- **Dùng [Flint](/docs/lol/tools/modding-apps/flint)** nếu bạn còn cần trích xuất,
  xem trước và đóng gói mod trong cùng một ứng dụng.
- **Dùng [RitoBin](/docs/lol/tools/modding-apps/ritobin)** nếu bạn cần một công cụ
  dòng lệnh cho script hoặc tác vụ hàng loạt.

<Callout type="info" title="Jade bên trong Flint">
  [Flint](/docs/lol/tools/modding-apps/flint) có thể dùng thẳng engine BIN của
  Jade. Chọn nó trong phần cài đặt của Flint. Bên trong Flint, hash đến từ một
  cơ sở dữ liệu LMDB tự tải, nên không có thư mục hashes nào để quản lý. Jade
  chạy độc lập vẫn dùng mô hình thư mục CommunityDragon mô tả ở trên.
</Callout>

## Phím tắt

| Hành động          | Phím tắt           |
| ----------------- | ------------------ |
| Mở file           | `Ctrl + O`         |
| Lưu               | `Ctrl + S`         |
| Lưu thành         | `Ctrl + Shift + S` |
| Tìm               | `Ctrl + F`         |
| Thay thế          | `Ctrl + H`         |
| So sánh hai file  | `Ctrl + D`         |
| Trình chỉnh particle | `Ctrl + P`      |
| Tab kế tiếp       | `Ctrl + Tab`       |
| Đóng tab          | `Ctrl + W`         |

---

## Mẹo

- File hash nằm ở `%APPDATA%\LeagueToolkit\Requirements\Hashes`. Bạn có thể
  cho nạp sẵn khi khởi động trong phần cài đặt.
- Bật thu nhỏ xuống khay nếu bạn để Jade mở trong lúc test trong game.
