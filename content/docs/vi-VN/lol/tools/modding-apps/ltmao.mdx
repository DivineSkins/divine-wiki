**LtMAO** là một bộ tool cho việc mod Liên Minh Huyền Thoại của tarngaina. Nó thêm một menu chuột phải để chuyển đổi file và ghép nó với một loạt tool GUI cho đóng gói WAD, file 3D, âm thanh, texture, và nhiều thứ khác.

<Callout type="info" title="Bộ tool đời cũ">
  LtMAO vẫn chạy được và bao phủ rất nhiều thứ. Các ứng dụng mới hơn của RitoShark
  giờ làm phần lớn những việc này với ít thiết lập hơn. Dùng
  [Flint](/docs/lol/tools/modding-apps/flint) để trích xuất, chỉnh và đóng gói,
  [Quartz](/docs/lol/tools/modding-apps/quartz) cho VFX và âm thanh, và
  [Jade](/docs/lol/tools/modding-apps/jade) cho chỉnh BIN. Giữ LtMAO làm phương án
  dự phòng cho tác vụ hàng loạt, trình dựng no-skin, và làm soundbank đầy đủ.
</Callout>

## Menu chuột phải làm được gì

LtMAO thêm một menu chuột phải vào Windows Explorer. Từ đó bạn có thể:

### Chuyển đổi file

| Từ     | Sang   | Tác dụng                                  |
| ------ | ------ | ----------------------------------------- |
| `.dds` | `.tex` | Chuyển texture để dùng trong game         |
| `.tex` | `.dds` | Trích xuất texture để bạn chỉnh được      |
| `.wem` | `.wav` | Chuyển file âm thanh sang định dạng chỉnh được |
| `.bin` | `.py`  | Chuyển file nhị phân sang Python đọc được |
| `.py`  | `.bin` | Đóng gói file Python đã chỉnh lại thành nhị phân |

### Làm việc với file WAD

- Giải nén file `.wad.client` dùng hash bạn tự trích xuất.
- Mở WAD từ mod đã repath hoặc mod bị chỉnh mạnh.
- Trích xuất một file lẻ hoặc cả kho lưu trữ WAD.

### In thông tin file

In chi tiết về:

- File `.bin`: cấu trúc và thuộc tính.
- File `.skn`: dữ liệu mesh skin.
- File `.skl`: dữ liệu khung xương và rig.

## Cài đặt

1. Tải [LtMAO-hai.zip](https://github.com/tarngaina/LtMAO/archive/refs/heads/hai.zip).
2. Giải nén file zip.
3. Chạy `LtMAO-hai/start.bat`. Ứng dụng mở lên.

## Cập nhật

LtMAO-hai kiểm tra phiên bản mới mỗi lần bạn mở ứng dụng. Khi có bản mới, một thông báo cập nhật hiện ở thanh tiêu đề.

Để cập nhật đầy đủ:

1. Tải lại ứng dụng từ GitHub.
2. Giải nén nó vào cùng vị trí, ghi đè file cũ.

Để cập nhật cách nhanh:

1. Mở ứng dụng.
2. Vào trang cài đặt.
3. Nhấn **Redownload LtMAO**. Đây không phải cách được khuyên dùng, nhưng nó thường chạy được.

## Tài liệu

### Shortcut

Lần đầu bạn chạy ứng dụng, một file shortcut `LtMAO.lnk` hiện ra trong cùng thư mục với `start.bat`.

Để tạo shortcut trên desktop, mở tab cài đặt và tạo một cái từ đó.

### Theme

Bạn có thể tự làm theme riêng. Thêm một thư mục mới bên trong `LtMAO-hai/res/themes`.

Quy tắc:

- Kích thước ảnh của bạn phải cùng tỷ lệ với ảnh gốc.
- Màu nhấn của ứng dụng lấy từ màu chủ đạo trong `background.gif` của bạn.
- Nếu tên theme có dấu `_`, màu nhấn là một dải màu giữa hai màu chủ đạo nhất.

### hash_helper

<img
  src="/wiki-images/ltmao-screenshot-1-34fc8725.webp"
  alt="Giao diện hash_helper"
  width={700}
/>

<Callout type="warning">
  Chờ đồng bộ, cập nhật và nạp hash xong trước khi bạn chạy bất kỳ chức năng
  `LtMAO` nào khác.
</Callout>

Ba nguồn hash đổ vào LtMAO:

1. **CDTB Hashes**: tự đồng bộ từ [CommunityDragon](https://github.com/CommunityDragon/CDTB/tree/master/cdragontoolbox). Bạn cũng có thể tự tải chúng bằng tay từ cùng đường link.
2. **Extracted Hashes**: hash bạn tự trích xuất. Bạn có thể trích những cái này:
   - binentries:
     - VfxSystemDefinitionData → particlePath trong BIN.
     - StaticMaterialDef → name trong BIN.
   - binhashes:
     - Joint hashes → tên joint trong SKL.
     - Submesh hashes → tên submesh trong SKN.
   - game:
     - Đường dẫn file bắt đầu bằng `assets/` hoặc `data/` trong BIN. Nếu kiểu file là `.dds`, dds 2x và 4x cũng được trích luôn.
3. **Custom Hashes**: bộ hash mà mọi chức năng LtMAO dùng (ritobin, wad_tool, no_skin, và các cái khác).
   - Custom Hashes = CDTB Hashes + Extracted Hashes + hash bạn tự thêm bằng tay.

`hash_helper` cũng có trình tạo hash cho WAD và BIN. Bạn có thể đẩy hash đã tạo vào Custom Hashes chỉ bằng một nút.

### no_skin

Làm ra một mod NO SKIN đưa **gần như** mọi skin League về lại vẻ ngoài mặc định.

<img
  src="/wiki-images/ltmao-afqyzfn-1fa63a3f.webp"
  alt="Giao diện tool no_skin"
  width={700}
/>

`SKIPS.json` là danh sách các skin làm crash League khi bị đưa về base. Tool đọc nó và bỏ qua những skin đó.

Có hai chế độ:

1. **Full**: dựng một `NO SKIN.fantome` đầy đủ từ mọi tướng bên trong `League of Legends/Game/DATA/FINAL/Champions`.

   <img
     src="/wiki-images/ltmao-screenshot-4-034c9802.webp"
     alt="Output chế độ Full của no_skin"
     width={700}
   />

2. **Lite**: biến mỗi `skinx.bin` được chọn thành `skin0.bin`.

   <img
     src="/wiki-images/ltmao-screenshot-7-5c41e3b6.webp"
     alt="Kết quả chế độ Lite của no_skin"
