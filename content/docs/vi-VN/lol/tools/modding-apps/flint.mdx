Flint là ứng dụng desktop của **RitoShark**, gói gần như cả quy trình mod
vào một chỗ. Nếu bạn không muốn nhảy qua nhảy lại giữa nhiều tool riêng lẻ
để trích xuất, chỉnh BIN, làm VFX và đóng gói, thì đây là cách bắt đầu dễ
nhất.

[Tải bản phát hành mới nhất](https://github.com/RitoShark/Flint/releases)

Phiên bản mới nhất: **v2.1.0**.

---

## Flint làm được gì

- **Trích xuất** skin tướng và asset thẳng từ file game.
- **Xem trước** mô hình 3D, texture, file BIN, animation, particle
  và âm thanh (BNK / WPK kèm dạng sóng) mà không cần export gì cả.
- **Chỉnh** file BIN, LuaBin và TroyBin có tô màu cú pháp.
- **Chỉnh file WAD ngay trong bộ nhớ** thẳng từ explorer, rồi export.
- **Chuyển đổi** texture giữa `.tex` và `.dds`.
- **Đổi màu** texture bằng hue shift, colorize, hoặc grayscale + tint.
- **Port sang chroma**: chọn một chroma, port bản mod skin gốc lên nó.
- **Checkpoint** dự án của bạn: chụp lại, so sánh và khôi phục thay đổi
  như một phiên bản git gọn nhẹ.
- **So sánh và khôi phục** bất kỳ file nào với chunk WAD gốc nếu bạn
  làm hỏng thứ gì đó.
- **Export** mod dạng `.fantome`, `.modpkg`, hoặc đồng bộ chúng sang LTK Manager.
- **Kiểm tra và sửa** mod bằng bộ luật Hematite tích hợp sẵn (bắt được
  shader thiếu, tham chiếu hỏng, và nhiều lỗi khác).

<Callout type="info" title="Hash tự động">
  Flint tự tải sẵn cơ sở dữ liệu hash LMDB (bộ `lmdb-hashes` của RitoShark).
  Không có thư mục hashes nào để tải hay quản lý, và nó tự làm mới.
</Callout>

## Cài đặt

1. Vào [trang releases](https://github.com/RitoShark/Flint/releases).
2. Tải bộ cài mới nhất cho Windows.
3. Chạy nó. Xong.

## Khi nào dùng Flint so với các tool khác

- **Dùng Flint** nếu bạn muốn một ứng dụng cho cả quy trình (trích xuất,
  chỉnh, đóng gói).
- **Dùng [Jade](/docs/lol/tools/modding-apps/jade)** nếu bạn chỉ chỉnh file BIN
  và muốn một trình chỉnh gọn, tập trung.
- **Dùng [LtMAO](/docs/lol/tools/modding-apps/ltmao)** như phương án dự phòng cho
  các tác vụ hàng loạt và chuyển đổi bằng chuột phải.

---

## Kết nối với các tool khác

Flint phối hợp tốt với hai tool khác mà cộng đồng hay dùng:

- **Jade**: Flint có thể dùng engine BIN của Jade thay cho trình phân tích
  LTK của chính nó. Chọn cái nào tùy bạn trong phần cài đặt.
- **Quartz**: đưa một texture sang chế độ paint của Quartz, rồi quay lại.
  Flint phát hiện khi Quartz đổi một file bạn đang mở và mời bạn làm mới.

## Mẹo

- Mở nhiều tab dự án cùng lúc. Mỗi tab giữ trạng thái riêng.
- Trình tạo màn hình tải trận động biến một file MP4 hoặc WebM thành
  spritesheet mà game chấp nhận.
- Đánh chỉ mục nền là tùy chọn. Bật nó lên nếu bạn muốn tìm kiếm toàn văn
  trong kho lưu trữ WAD.
- Kéo thả file vào cây thư mục để nhập chúng.
- Lần đầu dùng Flint? Trình hướng dẫn chạy lần đầu dẫn bạn qua đường dẫn
  League, đường dẫn PBE và kết nối với các tool.
- Bí không tìm ra asset? Mở bảng tra đường dẫn WAD từ trình explorer WAD
  để có bản đồ nhanh về nơi mọi thứ nằm ở đâu.
- Đặt Flint làm ứng dụng "Open with" của Windows cho file League như `.wad`
  và `.bin`, để nhấp đúp là mở chúng trong Flint.
