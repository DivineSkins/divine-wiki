LTK Tex Thumb Handler là shell extension cho Windows của nhóm
**LeagueToolkit**. Nó hiện file `.tex` thành ảnh xem trước trong Windows Explorer.

Nó làm đúng việc mà [Tex Thumbnail Provider](/docs/lol/tools/texturing/tex-thumbnail-provider)
của RitoShark làm. Chọn một cái thôi, đừng dùng cả hai.

[Tải bản phát hành mới nhất](https://github.com/LeagueToolkit/ltk-tex-utils/releases)

---

## Nó làm gì

- Hiện file `.tex` thành ảnh thumbnail xem trước trong Windows Explorer.
- Chạy trên mọi thư mục có texture `.tex` (file game, file xuất, asset của bản mod).
- Chạy dưới dạng một COM DLL đã đăng ký. Không có app nào để mở. Không có tiến trình chạy nền.

## Trước khi bắt đầu

- Windows 10 hoặc 11.
- Quyền quản trị viên (bộ cài đăng ký một DLL hệ thống).
- PowerShell.

---

## Cài đặt

1. Đóng mọi cửa sổ Windows Explorer đang hiện file `.tex`.
2. Chuột phải vào PowerShell rồi chọn **Run as administrator**.
3. Dán lệnh này vào rồi nhấn Enter:

   ```powershell
   iwr -useb https://raw.githubusercontent.com/LeagueToolkit/ltk-tex-utils/main/scripts/install-thumbnail-handler.ps1 | iex
   ```

4. Chờ bộ cài chạy xong. Nó tải `ltk-tex-thumb-handler.dll`,
   chép vào `%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler`, rồi
   đăng ký với Windows.
5. Khởi động lại Windows Explorer (hoặc khởi động lại máy).

{/* SCREENSHOT: PowerShell window showing the install script output with success message */}

---

## Cách kiểm tra đã chạy chưa

Mở bất kỳ thư mục nào có file `.tex`. Các icon biến thành ảnh xem trước. Nếu
chúng vẫn trông như icon trắng, khởi động lại Explorer hoặc khởi động lại máy.

---

## Gỡ cài đặt

1. Chuột phải vào PowerShell rồi chọn **Run as administrator**.
2. Chạy:

   ```powershell
   regsvr32.exe /u "%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler\ltk_tex_thumb_handler.dll"
   ```

3. Xóa thư mục tại `%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler`.

---

## Khi nào dùng cái này thay vì Tex Thumbnail Provider

Cả hai công cụ làm cùng một việc: hiện ảnh xem trước `.tex` trong Explorer. Chỉ
chạy một cái mỗi lúc.

| Công cụ                    | Do ai làm     | Cách cài                        |
| -------------------------- | ------------- | ------------------------------- |
| **LTK Tex Thumb Handler**  | LeagueToolkit | Một dòng lệnh PowerShell (admin) |
| **Tex Thumbnail Provider** | RitoShark     | Một dòng lệnh PowerShell (theo từng user) |

Chọn LTK Tex Thumb Handler nếu bạn đã dùng các công cụ LeagueToolkit khác.
Chọn bản của RitoShark nếu bạn muốn cài theo từng user mà không cần quyền admin.

> **Cảnh báo.** Đừng cài cả hai. Hai thumbnail handler cho cùng một loại
> file có thể xung đột với nhau và làm bạn chẳng thấy ảnh xem trước nào cả.
> Gỡ cái này trước khi cài cái kia.

## Xử lý sự cố

### Thumbnail không hiện ra

Khởi động lại Windows Explorer. Mở Task Manager, tìm **Windows Explorer**,
chuột phải rồi chọn **Restart**. Mở lại thư mục.

### Vẫn không có thumbnail sau khi khởi động lại

Kiểm tra xem DLL có nằm tại
`%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler\ltk_tex_thumb_handler.dll` không.
Nếu nó không có ở đó, chạy lại lệnh cài đặt.

### DLL Tex Thumbnail Provider cũ vẫn còn đăng ký

Gỡ thumbnail provider kia trước. Xem
[trang Tex Thumbnail Provider](/docs/lol/tools/texturing/tex-thumbnail-provider)
để biết cách cài và gỡ nó.

### Script cài đặt bị lỗi

Chắc chắn rằng PowerShell đang chạy dưới quyền quản trị viên. Script cần quyền
admin để đăng ký DLL với Windows.
