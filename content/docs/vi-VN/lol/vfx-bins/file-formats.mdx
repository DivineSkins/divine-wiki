## File .bin: Dữ liệu & logic

File `.bin` lưu **toàn bộ logic** trong League: hệ particle, định nghĩa skin, animation, âm thanh và nhiều thứ khác.

| Chứa gì            | Ví dụ                       |
| ------------------ | --------------------------- |
| Dữ liệu particle   | Màu, kích thước, thời điểm VFX |
| Định nghĩa skin    | Đường dẫn model, texture    |
| Cấu hình animation | Tên animation, blending     |
| Cấu hình âm thanh  | Kích hoạt âm thanh, âm lượng |

### Quy trình

1. Trích xuất `.bin` bằng [Flint](/docs/lol/tools/modding-apps/flint)
2. Chuyển sang `.py` bằng [Ritobin](/docs/lol/tools/modding-apps/ritobin) (hoặc chỉnh thẳng trong [Jade](/docs/lol/tools/modding-apps/jade))
3. Chỉnh trong trình soạn thảo văn bản như VS Code hoặc Notepad++
4. Chuyển ngược lại thành `.bin`
5. Thêm vào thư mục mod của bạn

> 💡 File `.py` đọc được bằng mắt thường. Bạn có thể tìm kiếm và chỉnh sửa chúng.

## File .dds: Texture

`.dds` (DirectDraw Surface) là **định dạng texture chuẩn**, dùng cho:

| Dùng ở đâu      | Ví dụ                  |
| --------------- | ---------------------- |
| Model tướng     | Texture skin, khuôn mặt |
| Particle        | Sprite VFX, ánh sáng   |
| UI/HUD          | Icon, bảng kỹ năng     |

### Công cụ chỉnh sửa

<ToolCard name="Photoshop" href="https://www.adobe.com/products/photoshop.html">
  Lựa chọn tốt nhất khi đi kèm plugin DDS của NVIDIA.
</ToolCard>

<ToolCard name="GIMP" href="https://www.gimp.org/">
  Lựa chọn miễn phí, hỗ trợ DDS.
</ToolCard>

<ToolCard name="Paint.NET" href="https://www.getpaint.net/">
  Nhẹ nhàng, có plugin DDS.
</ToolCard>

### Cài đặt xuất file

| Cài đặt     | Giá trị        |
| ----------- | -------------- |
| Định dạng   | `.dds`         |
| Nén         | **BC3 / DXT5** |
| Mipmaps     | ✅ Bật         |

> ⚠️ Nén sai kiểu = texture vỡ hình trong game!

## File .tex: Định dạng của Riot

`.tex` là **định dạng texture riêng của Riot**, nằm trong các file `.wad.client`.

| Trạng thái              | Thông tin              |
| ----------------------- | ---------------------- |
| ❌ Không chỉnh trực tiếp được | Đây là định dạng đã biên dịch |
| ✅ Phải chuyển đổi trước | Dùng tex2dds           |
| ✅ Chuyển ngược lại sau  | Trước khi import lại   |

Bạn có hai cách làm việc với `.tex`:

1. **Mở trực tiếp** bằng plugin TEX cho phần mềm chỉnh ảnh của bạn. Không cần bước chuyển đổi.
2. **Chuyển đổi** `.tex` sang `.dds` rồi ngược lại bằng Flint hoặc LtMAO.

## Bảng quy trình đầy đủ

| Tác vụ                  | File   | Công cụ                            | Kết quả         |
| ----------------------- | ------ | ---------------------------------- | --------------- |
| Chỉnh VFX/particle      | `.bin` | Jade (hoặc Ritobin)                | `.bin`          |
| Chỉnh skin tướng        | `.dds` | Photoshop/GIMP                     | `.dds`          |
| Chỉnh texture trực tiếp | `.tex` | RitoTex, Paint.NET, hoặc plugin GIMP | `.tex`        |
| Chuyển đổi texture      | `.tex` | Flint hoặc LtMAO                   | `.dds`          |
| Import lại texture      | `.dds` | Flint hoặc LtMAO                   | `.tex`          |
| Duyệt file game         | `.wad` | Flint                              | File đã trích xuất |
