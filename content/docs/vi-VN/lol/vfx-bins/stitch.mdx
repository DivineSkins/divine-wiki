**Stitch** là một tính năng trong Hacksaw cho phép bạn mượn particle system từ file `.bin` này và chèn vào file khác. Nhờ vậy bạn có thể trộn và ghép hiệu ứng giữa các tướng, skin và kỹ năng mà không cần dựng particle từ đầu!

**[Quartz](https://github.com/RitoShark/Quartz)** được khuyên dùng, vì nó tự port luôn các file texture.

## Stitch giúp bạn làm được gì

- Import particle system có sẵn từ bất kỳ tướng hay skin nào
- Dựng hiệu ứng hình ảnh mới bằng cách kết hợp nhiều nguồn khác nhau
- Mod nhanh hơn mà không phải chỉnh tay logic particle
- Tạo skin theo chủ đề mới bằng cách pha trộn nhiều bộ VFX
