Material atlas gom mọi texture của model vào một ảnh duy nhất, nên League chỉ cần load một texture. [Bản CATS của hướng dẫn này](/docs/lol/blender/material-atlas) chỉ chạy trên Blender 5.0. Bản này dùng add-on Material Combiner, chạy được trên mọi phiên bản Blender.

## Cài add-on

1. Cài file `.zip`:
   - **Blender 4.2 trở lên:** kéo thả file `.zip` vào cửa sổ Blender.
   - **Phiên bản cũ hơn:** vào **Edit → Preferences → Add-ons**, nhấn **Install**, chọn file `.zip` rồi bật **Material Combiner**.
2. Nhấn `N` trong viewport để mở sidebar rồi mở tab **MatCombiner**.
3. Nhấn **Install Pillow** để tải thư viện mà add-on cần, sau đó khởi động lại Blender.

## Tạo atlas

1. Chọn model rồi mở lại tab **MatCombiner**.
2. Nhấn **Generate Material List**. Mọi material của model sẽ hiện trong danh sách. Bỏ tick những cái bạn muốn loại ra.

<img
  src="/wiki-images/atyayaya.png"
  alt="Tab MatCombiner trong sidebar của Blender với nút Generate Material List được gạch chân"
/>

3. Nhấn **Save Atlas to..** (ở các bản mới hơn tên là **Generate Texture Atlas**) rồi chọn một thư mục. Add-on sẽ lưu texture đã gộp vào đó và chuyển model sang dùng một material duy nhất.

Vậy là xong. Model của bạn giờ chỉ dùng một texture thay vì mỗi material một texture.

<Callout type="info" title="Atlas bị thiếu texture?">

- Nếu texture được đóng gói trong file `.blend`, hãy lưu file rồi dùng **File → External Data → Unpack Resources** trước.
- Add-on tìm node theo tên tiếng Anh. Nếu atlas ra trống, hãy chuyển ngôn ngữ Blender sang tiếng Anh rồi import lại model.

</Callout>

Không muốn dùng add-on? Xem [Material Atlas (No Plugin)](/docs/lol/blender/material-atlas-no-plugin).
