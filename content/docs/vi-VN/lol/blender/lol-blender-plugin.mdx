## Tính năng chính

| Tính năng       | Mô tả                                          |
| --------------- | ---------------------------------------------- |
| **SKL + SKN**   | Nhập/Xuất model nhân vật kèm khung xương       |
| **ANM**         | Nhập/Xuất animation                            |
| **SCB / SCO**   | Nhập/Xuất vật thể tĩnh                         |
| **Bone Limit**  | Giới hạn tối đa 4 xương ảnh hưởng mỗi vertex   |
| **UV Tools**    | Công cụ snap góc UV                            |
| **Drag & Drop** | Xử lý file gọn nhẹ                             |

## Yêu cầu

| Yêu cầu     | Chi tiết                                |
| ----------- | --------------------------------------- |
| Blender     | **4.0+** (chỉ Windows)                  |
| Thiết lập FPS | Nên để **30 FPS** cho animation        |

## Cài đặt

1. Tải [`Aventurine.zip`](https://github.com/RitoShark/Aventurine-League-Tools/releases): **Đừng giải nén!**
2. Mở Blender → `Edit` → `Preferences` → `Add-ons` → `Install…`
3. Chọn file `.zip` → Nhấn **Install Add-on**
4. Bật **Aventurine: League Tools**

> ✅ **Kiểm tra:** Tùy chọn Import/Export sẽ xuất hiện trong **menu File**, và tab **Aventurine LoL** trong thanh bên (phím `N`)

---

### Hướng dẫn sử dụng

<Tabs items={["Import", "Export"]}>
<Tab value="Import">

### Nhập model

1. Vào `File → Import → LoL SKN+SKL`
2. Chọn file `.skn` của bạn (chắc chắn file `.skl` nằm cùng thư mục)
3. Chỉnh scale (mặc định: `0.01`) → Nhấn **Import**

### Nhập animation

1. Nhập model trước (SKL+SKN)
2. Vào `File → Import → LoL ANM Animation`
3. Chọn file `.anm` của bạn

</Tab>
<Tab value="Export">

### Xuất model

1. Chọn **mesh + armature** trong viewport
2. Vào `File → Export → LoL SKN+SKL`
3. Dùng **Limit to 4 Influences** nếu cần trước khi xuất

### Xuất animation

1. Chọn **armature** có chứa animation
2. Vào `File → Export → LoL ANM Animation`
3. Chọn nơi lưu file

</Tab>
</Tabs>

## Thanh bên LoL Tools

Nhấn `N` để mở thanh bên, rồi tìm tab **LoL Tools**:

| Công cụ               | Chức năng                     |
| --------------------- | ----------------------------- |
| Import/Export         | Lối tắt truy cập nhanh        |
| Limit to 4 Influences | Sửa trọng số xương để xuất    |
| UV Corners            | Snap vertex UV                |

---

## 💡 Mẹo nhanh

- Scale nhập mặc định = **0.01** (đơn vị của LMHT rất lớn)
- Bắt buộc tối đa **4 xương ảnh hưởng** mỗi vertex khi xuất
- Luôn đặt FPS = **30** cho animation
- Giữ file `.skl` và `.skn` trong **cùng một thư mục**
