File `.modpkg` là file bạn tải lên Divine và người chơi cài vào. Creator Hub đóng gói [dự án mod](/docs/lol/mod-format/mod-project) của bạn, cùng với mọi [lớp](/docs/lol/mod-format/layers), vào file này.

Trước khi xuất:

- Repath mod tướng. Bài [Repath mod của bạn](/docs/lol/getting-started/repath-your-mod) chỉ cách làm.
- Điền thông tin mod, và tăng **Phiên bản** nếu bạn đang đăng bản cập nhật.
- Test mod trong game từ Creator Hub.

## Xuất file

1. Bấm chuột phải vào thẻ của mod.
2. Trong mục **Export**, bấm **Modpkg**.
3. Kiểm tra danh sách: mỗi WAD hiện lớp của nó, số file và dung lượng.
4. Bấm **Export** rồi chọn nơi lưu file.

Tên file được gợi ý sẵn theo tên mod, phiên bản và tác giả. Đây là file bạn tải lên Divine.

  alt="Cửa sổ Export .modpkg liệt kê Aatrox.wad.client trong lớp base với 257 file, nút Export được khoanh tròn"
/>

**Add another project to this package** gộp thêm một dự án Creator Hub khác vào cùng file này.

## Cài file .modpkg

Người chơi cài mod từ Divine bằng Celestial. Để tự cài một file bằng tay:

1. Mở **Thư viện** trong Celestial.
2. Kéo file thả vào Thư viện, hoặc bấm **Nhập**, rồi **Import Files**.

<img
  src="/wiki-images/lol-mod-format-4.webp"
  width={360}
  alt="Menu Nhập của Thư viện đang mở, mục Import Files được khoanh tròn"
/>

Lúc đầu chỉ có lớp `base` được bật. Bấm vào huy hiệu lớp trên thẻ của mod để bật hoặc tắt từng lớp.
