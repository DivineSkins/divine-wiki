Ai cũng có thể góp thêm vào wiki này. Mỗi hướng dẫn là một file văn bản lưu trên GitHub, một website miễn phí nơi mọi người cùng nhau làm việc trên các file. Bạn đề xuất một thay đổi. Một người bảo trì kiểm tra rồi đăng nó.

## Trước khi bắt đầu

Bạn cần một tài khoản GitHub miễn phí. Tạo một cái ở [github.com/signup](https://github.com/signup). Đó là toàn bộ khâu chuẩn bị.

Ba từ bạn sẽ gặp rất nhiều:

- **Fork** là bản sao riêng của bạn cho các file của wiki trên GitHub.
- **Commit** là một thay đổi đã được lưu vào các file đó.
- **Pull request** (hay **PR**) là lời đề nghị người bảo trì đăng thay đổi của bạn.

## Viết một hướng dẫn mới

Wiki có trình chỉnh sửa trực quan. Bạn viết trong trình duyệt và xem bản xem trước ngay lập tức. Không tải gì, không code.

{/* Screenshot: the Contribute picker with the Visual editor and Manual on GitHub cards */}

1. Nhấn **Contribute** trên thanh trên cùng. Một cửa sổ với hai lựa chọn mở ra.
2. Chọn **Visual editor**. Trình chỉnh sửa mở ra.
3. Điền **Title**, **Category** và **Description**.
4. Viết hướng dẫn của bạn ở bên trái. Bên phải cho thấy trang đã đăng sẽ trông ra sao.

{/* Screenshot: the draft editor with the live preview on the right */}

<Callout type="info" title="Mẹo dùng trình chỉnh sửa">
  Thanh công cụ chèn sẵn các component như callout và nhúng video. Gõ `@` để liên
  kết tới một hướng dẫn khác. Xem [trang
  component](/docs/lol/contributing/components) để biết mọi thứ bạn dùng được.
</Callout>

Sẵn sàng gửi đi chưa?

5. Nhấn **Contribute** ở góc trên bên phải.
6. Trình chỉnh sửa có thể gợi ý các liên kết tới hướng dẫn khác mà nó tìm thấy trong văn bản của bạn. Nhấn những cái bạn muốn, rồi nhấn **Continue to GitHub**.
7. Cửa sổ **Publish your guide** mở ra. Nó có ba bước. Giữ tab này mở tới khi bạn xong.
8. Gõ tên người dùng GitHub của bạn vào ô. Các nút bên dưới dùng nó để tìm fork của bạn.
9. Nhấn **Fork on GitHub**. GitHub mở trang **Create a new fork**. Nhấn nút **Create fork** màu xanh. Việc này tạo bản sao wiki của riêng bạn. Bạn chỉ làm một lần. Đã có fork rồi? Bỏ qua bước này.

     alt="Trang Create a new fork của GitHub. Một mũi tên chỉ vào nút Create fork màu xanh ở góc dưới bên phải."
   />

10. Quay lại tab wiki. Nhấn **Create the file on GitHub**.

    <img
      src="/wiki-images/contribute-step-create-file.jpg"
      alt="Cửa sổ Publish your guide. Một mũi tên chỉ vào nút Create the file on GitHub dưới bước 2."
    />

11. GitHub mở một file mới trên fork của bạn với hướng dẫn đã điền sẵn. Kiểm tra tên file và văn bản. Rồi nhấn nút **Commit changes...** màu xanh ở góc trên bên phải.

    <img

    />

12. Một cửa sổ nhỏ mở ra. Giữ lựa chọn đầu tiên, **Commit directly to the main branch**. Nhấn **Commit changes**.

    <img
      src="/wiki-images/contribute-commit-changes.png"
      alt="Cửa sổ Commit changes của GitHub. Commit directly to the main branch đang được chọn và một mũi tên chỉ vào nút Commit changes màu xanh."
    />

13. Quay lại tab wiki. Nhấn **Open the pull request on GitHub**.

    <img
      src="/wiki-images/contribute-step-open-pr.jpg"
      alt="Cửa sổ Publish your guide. Một mũi tên chỉ vào nút Open the pull request on GitHub dưới bước 3."
    />

14. GitHub hiện các thay đổi của bạn và một biểu mẫu. Điền vào biểu mẫu. Để nguyên **Allow edits by maintainers** đã tick. Nhấn **Create pull request**.

    <img
      src="/wiki-images/contribute-create-pull-request.png"
      alt="Trang Open a pull request của GitHub với biểu mẫu pull request của wiki. Một mũi tên chỉ vào nút Create pull request màu xanh."
    />

Xong rồi. Một người bảo trì duyệt hướng dẫn của bạn và đăng nó. Hướng dẫn của bạn có dùng hình ảnh không? Còn một bước nữa: xem [Thêm hình ảnh](#thêm-hình-ảnh) bên dưới.

<Callout type="info">
  Bản nháp dài? GitHub không điền sẵn được file rất dài. Bước 2 sẽ hiện nút **Copy
  MDX** thay vào đó. Sao chép bản nháp của bạn, rồi dán nó vào file trống mà
  GitHub mở ra.
</Callout>

## Chỉnh sửa một hướng dẫn có sẵn

1. Mở hướng dẫn bạn muốn thay đổi.
2. Cuộn xuống dưới cùng. Nhấn **Edit on GitHub**. Trình chỉnh sửa trực quan mở ra với hướng dẫn đã nạp sẵn.
3. Chỉnh sửa của bạn.
4. Nhấn **Contribute**.
5. Nhấn **Copy MDX**. GitHub không điền sẵn được bản chỉnh, nên bạn tự dán vào.
6. Nhấn **Open guide on GitHub**.
7. Nhấn biểu tượng bút chì ở góc trên bên phải của file.
8. Chọn hết văn bản cũ. Dán bản sao của bạn đè lên.
9. Nhấn **Commit changes...**, rồi **Propose changes**, rồi **Create pull request**.

## Thêm hình ảnh

Trong trình chỉnh sửa, nhấn **Upload image** để đưa một tấm ảnh vào hướng dẫn của bạn. Ảnh hiện ngay trong bản xem trước. Nhưng file ảnh không đi cùng văn bản lên GitHub. Bạn tự tải nó lên, sau khi commit hướng dẫn.

### Tải ảnh lên sau khi bạn commit

Khi bản nháp của bạn dùng ảnh, cửa sổ Contribute liệt kê đúng những tên file cần tải lên. Giữ danh sách đó bên cạnh.

<img
  src="/wiki-images/contribute-upload-images-reminder.jpg"
  alt="Cửa sổ Publish your guide với thẻ One more step: upload your images được tô sáng. Nó liệt kê file ảnh cần tải lên và một nút Upload on GitHub."
/>

1. Commit hướng dẫn của bạn trước (các bước ở trên), để pull request của bạn tồn tại.
2. Quay lại tab wiki. Trong cửa sổ Contribute, nhấn **Upload on GitHub**. Thư mục ảnh của fork của bạn mở ra.
3. Kéo ảnh của bạn vào. Giữ tên file y hệt như hướng dẫn của bạn dùng.
4. Nhấn **Commit changes**. Giữ lựa chọn đầu tiên, commit vào main.

{/* Screenshot: GitHub's Upload files page inside public/wiki-images */}

Ảnh sẽ tự nhập vào pull request của bạn. Chúng hiện trên wiki khi pull request của bạn được merge.

<Callout type="info">
  Chỉnh một hướng dẫn có sẵn thay vì viết mới? GitHub đặt thay đổi của bạn lên một
  branch có tên kiểu như `patch-1`. Mở pull request của bạn, nhấn tên branch đó
  gần trên cùng, mở `public/wiki-images`, rồi nhấn **Add file** và **Upload
  files**. Commit vào cùng branch đó.
</Callout>

### Quy tắc về hình ảnh

- Dùng tên file chữ thường có gạch nối: `my-screenshot.png`, không phải `My Screenshot.png`.
- Cho mỗi ảnh một dòng alt text mô tả nó. Người duyệt sẽ kiểm tra.
- Giữ mỗi file dưới 500 KB. File lớn hơn làm trang chậm đi.
- Dùng PNG cho ảnh chụp màn hình, JPG cho ảnh thường. WebP cũng được.

## Chuyện gì xảy ra sau khi bạn mở một pull request

1. Một liên kết xem trước xuất hiện dưới dạng bình luận trên pull request của bạn. Mở nó để xem thay đổi của bạn trực tiếp.
2. Một người bảo trì duyệt văn bản, liên kết và hình ảnh của bạn. Họ có thể yêu cầu vài chỉnh sửa nhỏ.
3. Khi được duyệt, thay đổi của bạn được merge. Nó lên sóng trên wiki trong vài phút.

## Làm việc trên máy của bạn (nâng cao)

Với các danh mục mới, viết lại lớn, hoặc nhiều file cùng lúc, hãy làm việc trên máy của bạn. Bạn cần Node 22+, Git và một trình soạn thảo code.

```bash
git clone https://github.com/<your-username>/divine-wiki.git
cd divine-wiki
npm install
npm run dev
```

Fork repo ở [github.com/DivineSkins/divine-wiki](https://github.com/DivineSkins/divine-wiki) trước, rồi clone fork của bạn. Mở `http://localhost:3000` để kiểm tra trang có tải được không. Tạo một branch, chỉnh các file dưới `content/docs/en/lol/`, thả ảnh vào `public/wiki-images/`, rồi push và mở một pull request tới `main`.

## Cần trợ giúp?

- Kẹt với GitHub hay trình chỉnh sửa? Hỏi ở `#wiki-feedback` trên Discord.
- Đang lên kế hoạch cho một thay đổi lớn, như một danh mục mới hay tái cấu trúc? Đăng ở `#wiki-proposals` trước. Nó giúp bạn khỏi làm công việc rồi bị từ chối.
