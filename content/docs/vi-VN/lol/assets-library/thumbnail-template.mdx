## Bạn cần gì

1. **Template thumbnail (.PSD) và font** - [Tải từ Google Drive](https://drive.google.com/drive/folders/1U211qsFT13Th91ACx6W4GLaEfCta_h1q?usp=sharing)
2. **Một trình chỉnh sửa ảnh** mở được file PSD:
   - [Adobe Photoshop](https://www.adobe.com/products/photoshop.html) (trả phí)
   - [Photopea](https://www.photopea.com/) (miễn phí, chạy ngay trên trình duyệt)
   - [GIMP](https://www.gimp.org/) (miễn phí, ứng dụng máy tính)

## Thiết lập

1. Tải template PSD và file font từ link Google Drive ở trên.
2. Cài font vào máy trước khi mở template (nhấp đúp file font và bấm Install).
3. Mở template `.psd` trong trình chỉnh sửa bạn chọn.
