<Callout type="warning" title="Pick your resource quality">
  Since version 3.7, Wuthering Waves installs at one resource quality: UHD, HD
  or SD. In XXMI Launcher, set **Client Resource Quality** to the one you
  installed. A tier you did not install crashes the game while it loads, and
  texture mods made on another tier may not show. The install guide shows where
  to set it.
</Callout>

## Play with mods

XXMI Launcher installs WWMI, the tool that loads Wuthering Waves mods, and starts the game with it. These guides show how to add a mod you downloaded and keep your game working. A Resonator is the game's name for a playable character.

## Tools

Kuro Games has not released modding tools for Wuthering Waves. These community tools fill the gap.

<ToolCard
  name="XXMI Launcher"
  href="/docs/wuthering-waves/tools/xxmi-launcher"
  badge="Required"
  icon={<Icon name="XXMILauncher" />}
>
  Installs and updates WWMI, starts the game with mods, and sets the graphics
  options that keep mods visible.
</ToolCard>

<ToolCard
  name="WWMI Tools for Blender"
  href="/docs/wuthering-waves/tools/blender-add-on"
  badge="Models"
  icon={<Icon name="Blender" />}
>
  Pulls objects out of a frame dump, imports them into Blender, and exports your
  edits as a mod with its mod.ini.
</ToolCard>

<ToolCard
  name="Paint.NET"
  href="/docs/wuthering-waves/tools/texture-editors"
  badge="Textures"
  icon={<Icon name="PaintNET" />}

</ToolCard>

<ToolCard

## Want to help?

These guides are new, and some steps are not yet tested on version 3.8. If a step doesn't match what you see, tell us on [Discord](https://discord.gg/divineskins).

Every page on this wiki has an **Edit on GitHub** button. Spotted something wrong? Fix it. Tested a guide on the current update? Tell us what worked. Got a guide in your head? Head to [/contribute](/contribute). The visual editor opens a pull request for you.
