A Wuthering Waves mod needs a few free tools. Each row below says what a tool does. Click it for the full guide.

**New here?** Install XXMI Launcher first. It is the only tool a player needs.

<Callout type="info" title="Every tool here is community-made">

The tools on these pages come from community creators, and all of them are free. XXMI Launcher is free too: never pay for it.

</Callout>

## How the tools fit together

<img
  src="/wiki-images/wuthering-waves-tools-index-1.webp"
  alt="Five stages in a row: get the original from your frame dump with F8 and Extract Objects From Dump, edit in Paint.NET or Blender, export the buffers and mod.ini with WWMI Tools, put the mod in the WWMI Mods folder, and press F10 in game"
/>

Every mod passes through the same stages: frame dump, extract, edit, export, `Mods`, `F10`. A texture-only mod goes through WWMI Tools too, because WWMI Tools writes the `mod.ini` for you. [How Wuthering Waves mods work](/docs/wuthering-waves/basics/how-mods-work) explains what WWMI does with these files.

## Tools to skip

| Skip this                                                             | Why                                                                      | Use instead                           |
| --------------------------------------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------- |
| `WWMI Loader.exe` and WWMI zips you install by hand                   | Outdated. WWMI is now installed and updated by the launcher.             | XXMI Launcher                         |
| XXMI Tools                                                            | The Blender add-on for other games. It does not support Wuthering Waves. | WWMI Tools                            |
| Guides and tools that write lines into the game's config files        | Stale since version 3.2. The game ignores or removes such lines.         | The launcher's WWMI settings          |
| Fix tools for old versions                                            | Outdated. Old fixers break newer mods.                                   | The newest release of a current fixer |
| A `d3d11.dll` from any source but the launcher                        | Real fixes never swap XXMI files.                                        | XXMI Launcher's **Repair WWMI**       |
| GitHub "mod menus", "mod launchers", and skin packs with farmed stars | Tools for unfair play, or malware.                                       | Nothing. Never download them.         |
| Tools that unpack the game's files                                    | Not covered by this wiki.                                                | Your own frame dump                   |
| Lookalike 3DMigoto or XXMI download sites                             | Not official.                                                            | XXMI Launcher from GitHub             |

## How to spot a real tool

- Real tools come from known community authors, most often on GitHub. A few live only on their GameBanana tool page.
- Download each tool from the link on its wiki page, not from a search result or a video comment.
- A tool can be an `.exe`. A mod never is: it holds a `mod.ini`, `.buf` and `.dds` files. [What's allowed and how to stay safe](/docs/wuthering-waves/getting-started/stay-safe) explains how to check a mod download.
