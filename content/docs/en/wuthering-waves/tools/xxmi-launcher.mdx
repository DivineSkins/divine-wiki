XXMI Launcher is the only app you need to load Wuthering Waves mods. It downloads WWMI and the XXMI DLL, keeps them up to date, and starts the game with your mods. This page explains every setting. For the first install, follow [Install mods with XXMI Launcher](/docs/wuthering-waves/getting-started/install-with-xxmi-launcher).

Written for XXMI Launcher 2.5.0, XXMI DLL 1.3.3, and WWMI 1.2.2 on Wuthering Waves 3.8.

## Get the real launcher

Download it only from the [GitHub releases page](https://github.com/SpectrumQT/XXMI-Launcher/releases/latest). Each release has two files:

- `XXMI-Launcher-Installer-Online-v2.5.0.msi`: the normal installer. Pick this one.
- `XXMI-Launcher-Portable-v2.5.0.zip`: a portable copy. Install the Microsoft Visual C++ Redistributable (x64) first, extract it outside Program Files, and run `Resources\Bin\XXMI Launcher.exe`.

## Where everything lives

The installer puts the launcher in `%AppData%\XXMI Launcher`. WWMI and your mods sit in a `WWMI` folder inside it.

<Files>
  <Folder name="XXMI Launcher" defaultOpen>
    <Folder name="Backups" />
    <Folder name="Resources" />
    <Folder name="WWMI" defaultOpen>
      <Folder name="Core" />
      <Folder name="Mods" />
      <Folder name="ShaderFixes" />
      <File name="d3dx.ini: written by the launcher" />
      <File name="d3dx_user.ini: your saved mod toggles" />
    </Folder>
    <File name="XXMI Launcher Config.json: your settings" />
    <File name="XXMI Launcher Log.txt: the log for bug reports" />
  </Folder>
</Files>

- `WWMI\Mods` is where your mods go. Updates never touch it.
- `WWMI\Core` holds WWMI itself. Do not edit it: the next update replaces it.
- `WWMI\ShaderFixes` is for shader files. Never put your own files there. If you did, remove only those files and run **Repair WWMI**.
- `Backups` keeps a copy of your settings and of `d3dx.ini` before each WWMI update.

Nothing goes into the game folder. The launcher refuses to run if its own folder or the `WWMI` folder sits inside the game folder.

## What Start does

Each time you press **Start**, the launcher:

1. Closes Wuthering Waves if it is already running.
2. Puts the XXMI DLL in the `WWMI` folder and checks its signature.
3. Writes your settings into `WWMI\d3dx.ini`.
4. Checks your `Mods` folder for files that break or slow down other mods (the Mod Optimizer, below).
5. Applies the game settings mods need, if **Configure Game Settings For WWMI** is on.
6. Starts the game the way **Game Launch** says, with your **Client Resource Quality**, and loads WWMI into it.
7. Closes itself, unless you changed that.

Start does not update the game. Update Wuthering Waves in Kuro's launcher, Steam or Epic Games first, then press **Start**.

## The 3-dots menu

The button with three dots next to **Start** opens these tools:

| Item                     | What it does                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------ |
| **Repair WWMI**          | Downloads WWMI and the XXMI DLL again and reinstalls them. Your mods stay.           |
| **Check For Updates**    | Looks for new versions now. Shows "No updates available!" if there are none.         |
| **Add Desktop Shortcut** | Adds a `WWMI Quick Start` shortcut that starts the game without the launcher window. |
| **Optimize Mods**        | Runs the Mod Optimizer by hand. It also runs on every Start.                         |
| **Open Mods Folder**     | Opens `WWMI\Mods` in File Explorer.                                                  |

The Mod Optimizer turns off a stray `d3dx.ini` inside `Mods` and lines in mods that slow the game down. It turns off a file by adding a `DISABLED_` prefix to its name, and a heavy line by making it a comment. Add, turn off, and remove mods, linked below, explains what it checks.

## The settings window

Click the gear in the top-right corner to open the settings. The window has four tabs: **General**, **Launcher**, **WWMI**, and **Advanced**. Your changes save when you close the window.

### General tab

| Setting                              | Default       | What to do                                                                                                                                                     |
| ------------------------------------ | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Game Launch**                      | `Direct`      | Pick where you got the game: `Direct` for Kuro's launcher, `Steam`, or `Epic Games`. See the table below.                                                      |
| **Game Folder**                      | found for you | The `Wuthering Waves Game` folder, the one that holds `Wuthering Waves.exe` and the `Client` and `Engine` folders. Use **Browse...** if it is empty.           |
| **Launch Options**                   | off           | Leave it unticked. The launcher's own tooltip warns that the game may crash with it on.                                                                        |
| **Game Executable Run Method**       | set for you   | Keep the default.                                                                                                                                              |
| **Game Process Launch Wait Timeout** | `30` seconds  | Raise it on a slow PC if the launcher says the game did not start in time.                                                                                     |
| **Client Resource Quality**          | `HD`          | Pick the quality you installed: `UHD`, `HD` or `SD`. A wrong choice crashes the game while it loads. With one quality installed, it is picked for you.         |
| **Configure Game Settings For WWMI** | on            | Keep it on. It turns ray tracing off, handles the Wounded Effect, and keeps the full character model on screen at normal camera distance.                      |
| **Disable Wounded Effect**           | asks once     | Make sure it is ticked. The Wounded Effect swaps character textures when you take hits, which breaks modded textures. If the launcher asks, click **Disable**. |
| **Mesh LOD Base FOV**                | `165`         | Leave it at `165`. It keeps the modded model on screen when the camera zooms out.                                                                              |
| **Manual Game Config Edit**          | none          | Do not use it. Hand edits to the game's config files are not covered here, and the game ignores or removes many of them.                                       |

[What's allowed and how to stay safe](/docs/wuthering-waves/getting-started/stay-safe) explains what it means that the launcher changes game settings.

Set **LOD Bias** to **Ultra High** yourself, in <MenuPath path="Settings > Graphics" /> in game, and keep frame generation off.

{/* NEEDS HANDS-ON TEST: on XXMI Launcher 2.5.0, the default of Disable Wounded Effect on a fresh install, the exact buttons of its dialog (Disable, Keep Enabled), and the label and button text of Manual Game Config Edit. */}

**Game Launch** decides how **Start** opens the game:

| Store           | Game Launch  | What happens                                                                                                                                                                                                                |
| --------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Kuro's launcher | `Direct`     | XXMI Launcher starts the game itself, in DirectX 11. Kuro's launcher stays closed.                                                                                                                                          |
| Steam           | `Steam`      | XXMI Launcher sets the game's launch options in Steam, then starts the game through Steam. Keep **Configure Launch Options on Steam** and **Skip Kuro Games Launcher** ticked. Steam restarts if its launch options change. |
| Epic Games      | `Epic Games` | Kuro's launcher opens. Tick its **DirectX 11** box, then press **Start** there. A one-time reminder shows this.                                                                                                             |

`Custom` and `Manual` also exist for special setups. You do not need them.

### Launcher tab

| Setting                             | Default           | What to do                                                                              |
| ----------------------------------- | ----------------- | --------------------------------------------------------------------------------------- |
| **Close Launcher After Game Start** | on                | Turn off to keep the window open.                                                       |
| **UI Theme**, **Window Scale**      | `Default`, `Auto` | Change the look and size.                                                               |
| **Auto Update**                     | on                | Keep it on. Turned off, an up-arrow button appears next to **Start** when updates wait. |
| **Overwrite d3dx.ini**              | on                | Keep it on. Updates replace `d3dx.ini` after a backup.                                  |
| **GitHub Token**                    | empty             | Add one only if you see "GitHub API requests limit reached".                            |
| **Verify SSL**, **Use Proxy**       | on, off           | Change only if your network blocks GitHub.                                              |

### WWMI tab

| Setting                                         | Default                     | What to do                                                                                                                                 |
| ----------------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| **WWMI Folder**                                 | `WWMI/` inside the launcher | Where `Mods`, `Core` and `d3dx.ini` live. It must be outside the game folder.                                                              |
| **XXMI DLL Injection Mode**                     | set for you                 | Keep the default.                                                                                                                          |
| **Manage XXMI DLL Config**                      | on                          | Keep it on. Off, the launcher stops writing `d3dx.ini`.                                                                                    |
| **Configure XXMI DLL for WWMI**                 | on                          | Keep it on. It sets what WWMI needs to work.                                                                                               |
| **XXMI DLL Initialization Delay**               | `500` ms                    | Leave it at the default unless [Crashes and launch errors](/docs/wuthering-waves/errors/game-crashes#initialization-delay) sends you here. |
| **Mute Warnings**                               | on                          | Turn off while you look for a broken mod. Error text then shows on screen after `F10`.                                                     |
| **Clear Unknown Mod Settings**                  | on                          | Removes saved toggles of mods you deleted.                                                                                                 |
| **Enable By Default**, **Input Disabling Mode** | on, `Mods`                  | Mod hotkeys work from the start. `Ctrl+Alt+Shift+End` turns them on or off.                                                                |
| **Enable Hunting**                              | off                         | Turn on only to make mods. It allows hunting mode on `Numpad 0` and frame dumps with `F8`.                                                 |
| **Dump Shaders**                                | off                         | For creators. Copying a hash also saves the shader.                                                                                        |
| **Log File Output Verbosity**                   | `Disabled`                  | Keep `Disabled`. Detailed logging slows the game and can fill your disk with a huge log file.                                              |

### Advanced tab

This tab runs extra commands or loads extra files with the game. Leave every option off. Mods do not need any of them. The one common exception is starting a mod manager with the game, which [Mod managers compared](/docs/wuthering-waves/tools/mod-managers) explains.

## Update, repair, move, and uninstall

<Steps>
<Step>

### Update

With **Auto Update** on, the launcher updates itself, the XXMI DLL, and WWMI when you open it. To check by hand, open the 3-dots menu and click **Check For Updates**. An update replaces `Core` and `d3dx.ini`, and never touches `Mods`.

The launcher takes the newest full release of each part from GitHub and skips test versions. On November 26, 2026, that was WWMI 1.2.2 and XXMI DLL 1.3.3. WWMI 1.2.2 needs XXMI DLL 1.3.3 or newer for mods exported with WWMI Tools 1.9.4. With an older DLL, a **WWMI Integrity Error** box says `Installed XXMI DLL version is below minimally required!` in the first seconds of the game. Click **Check For Updates**, then restart the game. `X` hides the box.

{/* NEEDS HANDS-ON TEST: on XXMI Launcher 2.5.0, that an install with an XXMI DLL older than 1.3.3 shows the WWMI Integrity Error box with WWMI 1.2.2, and that Check For Updates or Repair WWMI installs XXMI DLL 1.3.3 */}

After a game update, waiting one to three days for a launcher or WWMI update is normal. Open the launcher every day or two so you get it.

</Step>
<Step>

### Repair

Open the 3-dots menu and click **Repair WWMI**. Do this after you repair the game in Kuro's launcher, or when WWMI files are missing. If you added your own files to `ShaderFixes`, remove only those first, then repair.

</Step>
<Step>

### Move your mods

1. Close the launcher.
2. Copy the whole `WWMI` folder to the new place, for example `C:\Games\WWMI`.
3. Open the settings, go to the **WWMI** tab, and set **WWMI Folder** to the new path.

{/* NEEDS HANDS-ON TEST: whether changing WWMI Folder moves the files by itself, or expects you to copy the folder first as written. */}

</Step>
<Step>

### Uninstall

1. Back up `WWMI\Mods`, and `WWMI\d3dx_user.ini` if you want to keep your toggles.
2. Open <MenuPath path="Windows Settings > Apps" />, find XXMI Launcher, and click **Uninstall**. For the portable copy, delete its folder and shortcuts.
3. Delete the leftover `WWMI` folder if you no longer want your mods.
4. If you used Game Launch `Steam`, clear the game's launch options in Steam.

The game settings the launcher changed stay as they are until you change them in game.

</Step>
</Steps>

## Hand edits to config files

Use the launcher settings when one exists. Edits to files in `Core` are lost at the next WWMI update. Edits to `d3dx.ini` are lost too, unless you turn off **Overwrite d3dx.ini**, and the launcher rewrites some lines on every Start. The old file goes to `Backups\WWMI <date>` before each update. When you ask for help, the WWMI author wants your original `d3dx.ini`, not an edited copy from a mod page.

## Command line

The `WWMI Quick Start` shortcut runs the launcher with options. You can use them in your own shortcut:

```text
"%AppData%\XXMI Launcher\Resources\Bin\XXMI Launcher.exe" --nogui --xxmi WWMI
```

- `--nogui --xxmi WWMI` starts Wuthering Waves with mods, with no launcher window.
- `--update` checks for updates first.

## Common problems

Antivirus alerts, GitHub connection errors, and a launcher that will not open are on XXMI Launcher problems, linked above. If the game starts but your mods do not show, see [Mods not loading](/docs/wuthering-waves/errors/mods-not-loading).
