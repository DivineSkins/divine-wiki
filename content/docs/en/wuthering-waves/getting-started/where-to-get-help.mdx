## What to put in your question

Helpers can fix a problem much faster when they have these details.

1. **What you see.** Copy the exact error text, or post a screenshot or a phone photo of the text on screen.
2. **Your versions.** XXMI Launcher shows them in its bottom-left corner, for example `LAUNCHER 2.5.0`, `XXMI 1.3.3`, and `WWMI 1.2.2`. Add your game version, such as 3.8.
3. **The banner.** Say whether `WWMI 1.2.2 (PRESS F12 TO SHOW GUIDE)` showed in the first 30 seconds of the game.
4. **Your settings.** Name your **Client Resource Quality** (UHD, HD or SD) and say whether the game runs in DirectX 11.
5. **What changed last.** A game update, a new mod, or a file you edited.
6. **Hidden errors.** If a mod fails with no message, untick **Mute Warnings** on the launcher's **WWMI** tab, press `F10` in game, and share the text that shows.

Creators: also post the full error text from Blender's System Console, your WWMI Tools and Blender versions, the Resonator you are working on, and whether you imported it with the **Merged** or **Per-Component** skeleton. A Resonator is a playable character.

Crop your UID out of every picture before you post it.

## Report a real bug

| Problem                                            | Where it goes                                                                                                                                                                    |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| XXMI Launcher fails before the game's login screen | The XXMI Launcher issue tracker, with your `XXMI Launcher Log.txt`. [Report a launcher bug](/docs/wuthering-waves/errors/launcher-problems#report-a-launcher-bug) has the steps. |
| A problem in game, or with one mod                 | Divine's Discord or the AGMG Discord, not the launcher tracker.                                                                                                                  |
| A bug in WWMI itself                               | The [WWMI-Package issue page](https://github.com/SpectrumQT/WWMI-Package/issues) on GitHub, or the AGMG Discord.                                                                 |
| A bug in WWMI Tools                                | The [WWMI-Tools issue page](https://github.com/SpectrumQT/WWMI-Tools/issues) on GitHub, or the AGMG Discord.                                                                     |

The GitHub issue pages are for bugs only. The author sends "how do I" questions to Discord.

### Spot an outdated guide

Wuthering Waves modding changes with almost every game update. A guide, video, or document is out of date if it:

- installs WWMI by hand or starts `WWMI Loader.exe`. Use XXMI Launcher instead.
- tells you to type lines into the game's config files. Since version 3.2 the game ignores or removes them. Use the launcher's WWMI settings.
- explains how to start the game by hand, or was written before version 3.7 (September 30, 2026). The way the game starts changed then.
- says "Blender 3.6 only", or sets rotation `(0, 0, 180)` and scale `0.01` after import. Use Blender 4.5 LTS and work on the model as it imports.
- uses `F1` for the in-game guide. The key is `F12`.
- shows extracted textures named like `Components-0 t=<hash>.dds`. WWMI Tools 1.9.4 names them `c=0 f=<format> t=<hash> d=<dhash>.dds`, and finds textures by how they look. Steps that change texture hashes in a `mod.ini` fit only mods from older versions.

## Skip fake help

- **Lookalike sites.** XXMI Launcher comes only from `github.com/SpectrumQT/XXMI-Launcher`. Sites with "XXMI" in their name, such as `xxmilauncher.com`, are not official and host old copies.
- **Fake fixers.** A "fix" from a new account, in a password-protected archive, that asks for admin rights or replaces `d3d11.dll`, is a red flag. Fake fixers carrying malware have been reported.
- **Mod menus and glitches.** GitHub pages that offer Wuthering Waves "mod menus", skin packs or currency "glitches" are tools for unfair play, or malware.
- **Login requests.** No helper, mod, or tool needs your Kuro Games account login.

[What's allowed and how to stay safe](/docs/wuthering-waves/getting-started/stay-safe) explains how to check a download.
