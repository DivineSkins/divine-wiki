Almost every Wuthering Waves update breaks some mods for a few days. Updates come about every six weeks, and small patches in between can break mods too. This page shows what to do, in order, so you fix the broken mods without breaking the ones that still work. Written for Wuthering Waves 3.8 with WWMI 1.1.0.

## What usually breaks in Wuthering Waves

Wuthering Waves runs on a customised Unreal Engine 4, and its updates break mods in four ways:

- **The game loads lower-detail models and textures.** At a distance, or in the open world, the game swaps in simpler versions that the mod does not know. Textures look white, patchy or wrong, or the mod turns back to the original look when the camera zooms out. XXMI Launcher updates and the right settings fix most of this.
- **A Resonator's model or texture data changes.** A Resonator is a playable character. The mod no longer matches, so you see the original look or broken parts. Rover breaks most often. This needs a fix tool or a new version of the mod.
- **The way the game starts changes.** In 3.7 the game got UHD, HD and SD resource packages, and in 3.8 Steam installs moved to Kuro's launcher. An XXMI Launcher update fixes this for everyone.
- **The way the game draws characters changes.** This is rare. WWMI gets an update through the launcher, and sometimes creators must export their mods again.

| Eyes and lips glitch right after the update                       | The game rebuilt its shaders                        | Restart the game                              |
| A red `Mod Loading Error` box                                     | The mod and WWMI versions do not match              | Update WWMI (step 2), or wait for the creator |

## Fix your mods

<Steps>
<Step>

### Back up your Mods folder before the update

1. Open `%AppData%\XXMI Launcher\WWMI\Mods`.
2. Zip the whole folder with your archive tool.
3. Keep the zip outside the `Mods` folder.

Fix tools change model files that you cannot undo by hand. The zip is your way back.

</Step>
<Step>

### Update the game, then XXMI Launcher

1. Update Wuthering Waves in Kuro's launcher, Steam or Epic Games. XXMI Launcher does not update the game.
2. Open XXMI Launcher. It checks for updates when it starts and installs new versions of itself and of WWMI.
3. To check by hand, click the 3-dots button next to **Start**, then **Check For Updates**.
4. Check the versions in the bottom-left corner, for example `LAUNCHER 2.5.0` and `WWMI 1.1.0`.

Waiting one to three days for launcher, WWMI and fix tool updates is normal. SpectrumQT, who makes WWMI, posts what broke and what to do in the updates of the [WWMI page on GameBanana](https://gamebanana.com/tools/17252). Open the launcher every day or two so you get the fixes.

{/* NEEDS HANDS-ON TEST: the exact update prompt XXMI Launcher 2.5.0 shows when a new WWMI version is out, and whether it installs it without asking. */}

</Step>
<Step>

### Check the settings mods need

In XXMI Launcher, open the settings with the gear icon, then the **General** tab:

1. **Client Resource Quality** matches the quality you installed: `UHD`, `HD` or `SD`.
2. **Game Folder** and **Game Launch** still match your install. Updates that move the game to another launcher change them.
3. **Configure Game Settings For WWMI** and **Disable Wounded Effect** are ticked.
4. **Mesh LOD Base FOV** is `165`.

In the game, open <MenuPath path="Settings > Graphics" /> and check that **LOD Bias** is **Ultra High**. On an NVIDIA card, keep Smooth Motion and frame generation off.

Many "all my mods broke" reports are one of these settings, or a launcher that is not updated yet.

{/* NEEDS HANDS-ON TEST: after the 3.8 move of Steam installs to Kuro's launcher, whether Game Folder and Game Launch must be changed by hand in XXMI Launcher 2.5.0. */}

</Step>
<Step>

### Test your mods

1. Start the game with **Start** in XXMI Launcher.
2. Switch to a different Resonator so the modded one is off screen.
3. Press `F10` to reload.
4. Switch back and check each modded Resonator, up close and from a distance.

Write down which mods are still broken. Only those need a fix tool.

</Step>
<Step>

### Run one fix tool on the broken mods only

<Callout type="warning" title="Get fix tools only from these two pages">
  Fake fixers carrying malware have been uploaded after game updates. Download
  only from the GitHub pages below. Never use a "fix" that replaces `d3d11.dll`,
  asks for admin rights, or comes in a password-protected archive.
</Callout>

Two community fix tools are in use. The WWMI author names both. Neither is better in every case: use the one that has a release for your game version. On November 24, 2026, Woju's fixer had a 3.8 release (v3.8.1.1) and Moonholder's newest release was v3.7.0, made for 3.7.

<Tabs items={["Wuwa_Mod_Fixer", "WuWa_MOD_WojuFixer"]}>
<Tab value="Wuwa_Mod_Fixer">

<ToolCard
  name="Wuwa_Mod_Fixer"
  href="https://github.com/Moonholder/Wuwa_Mod_Fixer/releases/latest"
  icon={<Icon name="GitHub" />}
>
  By Moonholder. Finds changed model and texture data in a mod and updates it.
  Keeps backups. Open source (GPL-3.0) and code-signed.
</ToolCard>

1. Download the latest release. Check that its version number matches your game version, or is newer.
2. Make a copy of the broken mod's folder outside `Mods`.
3. Open the fixer.
4. Select the broken mod's folder, or drag it into the window.
5. Leave the optional fixes off for a first try, then click **Start Fix**.
6. Press `F10` in game and check the Resonator.

The fixer keeps backups, and its rollback option puts a mod back as it was. The real file is code-signed: a copy without a signature is not the real one.

1. Download the latest release. Check that its version number matches your game version.
2. Make a copy of the broken mod's folder outside `Mods`.

5. Run it on the broken mod's folder only.
6. Press `F10` in game and check the Resonator.

Run each tool once per mod, and never run both tools on the same mod. Running a tool twice, or an older version after a newer one, can break the mod for good. If that happens, restore the mod from your copy and start again.

Antivirus programs sometimes flag fix tools, because they rewrite many files at once. Add an exception for that one file if you trust it. Never turn your antivirus off.

</Step>
<Step>

### Still broken? Wait for the creator

Some breaks no tool can fix. Mods made for the first WWMI versions, from mid 2024, must be exported again by their creator. Check the page where you got the mod for an update, and give creators a few days after a big update.

To find which mod breaks things:

1. Turn off half of your mods with the `DISABLED` prefix.
2. Press `F10` and check whether the problem is still there.
3. Keep halving the group that has the problem until one mod is left.

</Step>
</Steps>

## Common problems

<Accordions type="multiple">
<Accordion title="A guide or video says to add lines to the game's config files" id="config-lines">

Skip that step. Those guides are stale since version 3.2, and the game ignores or removes such lines. Use the launcher's WWMI settings and **LOD Bias** in the game instead.

</Accordion>
<Accordion title="Someone shared a new d3d11.dll that fixes everything" id="random-dll">

Never use it. WWMI and the XXMI DLL come only through XXMI Launcher. A loader file from anywhere else can carry malware.

</Accordion>
<Accordion title="The game runs at 10 to 20 FPS after the update" id="low-fps">

Open the launcher settings, then the **WWMI** tab, and set **Log File Output Verbosity** to **Disabled**. Detailed logging slows the game and fills your disk with a huge log file.

{/* NEEDS HANDS-ON TEST: confirm that the WWMI tab of XXMI Launcher 2.5.0 shows Log File Output Verbosity (Disabled, Warning, Info, Debug), with Disabled as the default, in place of the older Calls Logging and Debug Logging boxes. */}

</Accordion>
<Accordion title="I use a mod manager" id="mod-manager">

Some managers edit mod `.ini` files. Use the manager's restore option on a mod before you run a fix tool on it.

</Accordion>
</Accordions>
