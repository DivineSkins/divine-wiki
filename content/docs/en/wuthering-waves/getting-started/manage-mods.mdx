<LevelPill level="beginner" />

Every Wuthering Waves mod is a folder inside WWMI's `Mods` folder. This page shows how to add more, turn them off, reload them in game, and clean up. Written for XXMI Launcher 2.5.0 and WWMI 1.1.0.

## What you need

<Requirements>
  <Requirement
    icon="XXMILauncher"
    href="/docs/wuthering-waves/getting-started/install-with-xxmi-launcher"
    note="with WWMI installed"
  >
    XXMI Launcher
  </Requirement>
  <Requirement icon="FileArchive" note="such as 7-Zip">
    An archive tool
  </Requirement>
</Requirements>

Your `Mods` folder is here:

```text
%AppData%\XXMI Launcher\WWMI\Mods
```

To open it, click the 3-dots button next to **Start** in XXMI Launcher, then **Open Mods Folder**.

## How WWMI reads your Mods folder

<img
  src="/wiki-images/wuthering-waves-getting-started-manage-mods-1.webp"
  alt="A Mods folder tree: two mod folders and one RabbitFX folder load, a DISABLED folder is skipped, a .zip is ignored, and a second RabbitFX copy and a d3dx.ini are marked for deletion"
/>

- WWMI loads every `.ini` file in `Mods` and in every folder inside it, at any depth.
- A file or folder whose name starts with `DISABLED` is skipped, with everything inside it.
- A `.zip`, `.7z` or `.rar` file does nothing. Always extract it.

So you can sort mods into folders however you like, for example `Mods\Resonators\Zani\Zani Outfit`.

## Add a mod

1. Open the mod you downloaded with your archive tool. Check that it holds only a `mod.ini`, `.buf` and `.dds` files, and sometimes `.hlsl`.
2. Extract the mod's folder into `Mods`. You should get `Mods\<mod name>\mod.ini`.
3. If the archive holds several versions in separate folders, keep only the one you want. The others load too unless you turn them off.
4. Turn off any other mod for the same Resonator, the game's name for a playable character.
5. In game, switch to a different Resonator so the modded one is off screen.
6. Press `F10`. Switch back to see the mod.

If the Resonator looks wrong after `F10`, it was probably on screen during the reload. Switch away, press `F10` again, or restart the game.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check it on Wuthering Waves: what a Resonator looks like when F10 is pressed while it is on screen, and whether switching away and pressing F10 again fixes it. */}

### One mod per Resonator

Only one mod per Resonator, or per outfit, can be on at a time. Two mods for the same Resonator fight each other and you get a mix of both. A merged mod counts as one: it switches between several mods with a key.

A mod made for one outfit does not change the Resonator's other outfits.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check it on Wuthering Waves: a mod for a Resonator's default outfit does not show when the Resonator wears another outfit. */}

## Turn a mod off or on

<Tabs items={["Turn one mod off", "Turn all mods off"]}>
<Tab value="Turn one mod off">

1. Rename the mod's folder so its name starts with `DISABLED`, for example `DISABLED_Yinlin Dress`.
2. Press `F10` in game.

To turn it back on, remove `DISABLED` from the name and press `F10`.

You can do the same to one `.ini` file inside a mod, for example `DISABLED_mod.ini`.

</Tab>
<Tab value="Turn all mods off">

- Press `F6` to turn all mods off. The top of the screen shows `Mods Display: Disabled`. Press it again to turn them back on.
- Hold `F9` to see the original game while the key is down.

Neither key changes any files. Your mods come back as they were.

</Tab>
</Tabs>

Turning a mod off with `DISABLED` also forgets the options you picked in it, such as which outfit part was showing.

## Keys you will use

| Key                  | What it does                                                          |
| -------------------- | --------------------------------------------------------------------- |
| `F10`                | Reload all mods and save their settings                               |
| `F6`                 | Turn all mods off or on                                               |
| `F9` (hold)          | Show the original game while held                                     |
| `F12`                | Show or hide the WWMI user guide                                      |
| `Ctrl+Alt+F10`       | Reset the saved settings of every mod, then reload                    |
| `Alt+F12`            | Turn compatibility mode for very old mods on or off, then press `F10` |
| `X`                  | Hide a WWMI error message                                             |
| `Ctrl+Alt+Shift+End` | Turn all mod keys off or on, so typing does not trigger them          |

Some download pages still list `F1` for the user guide. That is outdated: the key is `F12`.

Many mods add their own keys to switch parts, colors or outfits. The mod's page lists them. WWMI saves your choices when you press `F10` and every 60 seconds.

To give a mod different keys, see [Change a mod's keys and saved settings](/docs/wuthering-waves/ini/change-mod-keys).

## Keep your Mods folder clean

### One copy of RabbitFX

Many Wuthering Waves mods need RabbitFX, a shared texture and glow library by caverabbit. It is a separate download, not part of WWMI. The version for this game is called **RabbitFX for WWMI**. A mod that needs it says so on its page. Add it only then.

1. Install RabbitFX once, in its own folder in `Mods`.
2. If a mod ships its own copy inside its folder, delete that copy.
3. Never keep two RabbitFX folders. Two copies cause crashes and strange behavior.

[Make textures survive game updates](/docs/wuthering-waves/textures/stable-textures) explains how creators use it.

### Files that do not belong in Mods

WWMI's own files live in `WWMI\Core\WWMI` and update with the launcher. Never edit them and never copy them into `Mods`.

1. Delete any `d3dx.ini` or `d3d11.dll` that came with a mod. XXMI Launcher refuses to start with a `d3dx.ini` in `Mods`.
2. Never put mod files into `WWMI\ShaderFixes`. If you added files there, remove them, then click the 3-dots button next to **Start** and choose **Repair WWMI**.

### Optimize Mods

Each time you click **Start**, XXMI Launcher checks `Mods` for common problems. It offers to turn off stray `d3dx.ini` files and `.ini` lines that cost a lot of FPS. It turns off a file by adding `DISABLED_` to its name, and a heavy line by making it a comment.

To run the same check by hand, click the 3-dots button next to **Start**, then **Optimize Mods**. The details go to `XXMI Launcher Log.txt` in the launcher folder.

{/* NEEDS HANDS-ON TEST: on a test WWMI Mods folder with a stray d3dx.ini and a heavy ShaderRegex mod, record exactly what Optimize Mods changes and the wording of each prompt in XXMI Launcher 2.5.0. */}

### Many mods

Each mod that is on makes `F10` and the first load slower. Keep on only the mods you use, and turn the rest off with `DISABLED`. A few badly made mods also lower your FPS: **Optimize Mods** finds the worst of them.

Zip your whole `Mods` folder before every game update. Then you can always go back.

## Use a mod manager or not

You do not need a mod manager. Folders and the `DISABLED` prefix do everything above, and fix tools expect this plain setup.

If you want buttons instead of renaming folders, two maintained managers support Wuthering Waves. Both are source available.

  icon={<Icon name="GitHub" />}

  By jpbhatt21. A desktop app that lists your mods and tracks updates.
</ToolCard>

Use one manager at most on a `Mods` folder. Managers can edit mod `.ini` files, so restore your mods with the manager before you share one or run a fix tool. [Mod managers compared](/docs/wuthering-waves/tools/mod-managers) has the details.

## Remove all mods

To play without mods for a while, start Wuthering Waves from Kuro's launcher, Steam or Epic Games instead of XXMI Launcher.

To remove everything:

1. Uninstall XXMI Launcher from <MenuPath path="Settings > Apps" /> in Windows. If you used the portable version, delete its folder.
2. Delete the desktop shortcuts `XXMI Launcher` and `WWMI Quick Start` if they are still there.
3. Delete `%AppData%\XXMI Launcher\WWMI` if you no longer want your mods.
4. If you used Game Launch `Steam`, clear the game's launch options in Steam, under **Properties**.

The game settings the launcher changed, such as ray tracing and the Wounded Effect, stay as they are. Change them back in the game's settings if you want.

## Common problems

<Accordions type="multiple">
<Accordion title='"Mod is incompatible with current WWMI version! Enable Compatibility Mode"' id="compatibility-mode">

The mod uses a very old WWMI format. Press `Alt+F12`, then `F10`, to load it. A version re-exported by its creator is better: compatibility mode costs some FPS.

</Accordion>
<Accordion title={`"Mod is incompatible with current WWMI version! Please check out the mod's page for any updates!"`} id="incompatible-mod">

The mod was made for the first versions of WWMI and can no longer load. Look for an updated version of the mod. Press `X` to hide the message.

</Accordion>
<Accordion title='"Installed WWMI version is below minimally required!"' id="wwmi-too-old">

The mod needs a newer WWMI. Open XXMI Launcher and let it update. Click the 3-dots button, then **Check For Updates**, if it does not update by itself.

</Accordion>
<Accordion title="Two copies of the same modded Resonator glitch" id="two-copies">

When the same modded Resonator is on screen twice, for example in co-op or photo mode, the mod glitches. This is a known limit of WWMI and will not be fixed. Turn the mod off with `F6` for that moment.

</Accordion>
<Accordion title="A mod's options reset after a restart" id="options-reset">

The mod does not save that option. This is a choice of the mod's creator. Pick the option again after each start.

</Accordion>
</Accordions>

More fixes are in [Mods not loading](/docs/wuthering-waves/errors/mods-not-loading) and [Mods look broken](/docs/wuthering-waves/errors/mods-look-broken).
