Your mod loads, but the Resonator looks wrong. A Resonator is a playable character. Find what you see in the table, then open the matching fix below. Written for Wuthering Waves 3.8 with XXMI Launcher 2.5.0, XXMI DLL 1.3.3 and WWMI 1.2.2.

No mod shows at all? Go to [Mods not loading](/docs/wuthering-waves/errors/mods-not-loading).

## Try this first

These steps fix many broken mods. Do them before anything else.

1. Close the game and open XXMI Launcher. It updates itself and WWMI.
2. In the launcher's **General** settings, make sure **Configure Game Settings For WWMI** and **Disable Wounded Effect** are ticked, and **Mesh LOD Base FOV** is at `165`.
3. In game, open <MenuPath path="Settings > Graphics" /> and set **LOD Bias** to **Ultra High**.
4. Switch to another Resonator, press `F10`, and switch back.

## Fixes

<Accordions type="multiple">
<Accordion title="White or patchy textures" id="white-or-patchy-textures">

The model is right, but its textures look white, patchy, blurry or wrong. Often they look fine in menus and break in the open world. This is the most common problem after a game update.

{/* SCREENSHOT: wuthering-waves-errors-mods-look-broken-2.webp, a modded Resonator in the Wuthering Waves 3.8 open world with white or patchy textures, next to the same mod looking right in the Resonators menu. No usable current image exists in any source. */}

**Cause:** the game loads lower-detail versions of textures, mostly in the open world. A mod exported with WWMI Tools 1.8.0 or older knows only the hashes of the full-detail textures, so it no longer matches. Mods exported with WWMI Tools 1.9.4 find textures by how they look, so they should break less often here. Nobody has tested that on this game yet. Updates also change texture data: version 2.6 changed the textures of every Resonator, weapon and glider. Since version 3.5, the launcher can no longer stop this for every mod.

**Fix, in this order:**

1. Set **LOD Bias** to **Ultra High** in the game's graphics settings.
2. Close the game and open XXMI Launcher, so it updates.
3. Check the mod's page for an update. Many creators now bind textures through RabbitFX texture slots, or export with WWMI Tools 1.9.4. Both should survive updates better.
4. If the mod is still broken, run one fix tool on a copy of it. [Fix your mods after a game update](/docs/wuthering-waves/getting-started/fix-mods-after-an-update) shows both tools and the steps.
5. Still broken? Wait for the mod's creator.

Guides and videos that tell you to type lines into the game's config files are stale since version 3.2. Skip those steps and use the settings above.

{/* NEEDS HANDS-ON TEST: on Wuthering Waves 3.8 with XXMI Launcher 2.5.0, whether LOD Bias at Ultra High alone stops open-world texture breaks for a mod made without RabbitFX, and whether a mod exported with WWMI Tools 1.9.4 keeps its textures in the open world on WWMI 1.2.2. */}

</Accordion>
<Accordion title="WWMI Integrity Error" id="wwmi-integrity-error">

A mod shows its shape but keeps the original textures, and a box in the middle of the screen starts with `WWMI Integrity Error:`.

**Cause:** your XXMI DLL is older than 1.3.3. Mods exported with WWMI Tools 1.9.4 need it to find their textures. Older mods are not affected.

**Fix:** close the game and open XXMI Launcher, so it updates. Then start the game again. Press `X` to hide the box.

{/* NEEDS HANDS-ON TEST: on WWMI 1.2.2 with an XXMI DLL older than 1.3.3, whether a mod exported with WWMI Tools 1.9.4 draws its mesh with the original textures, and whether the WWMI Integrity Error box shows */}

</Accordion>
<Accordion title="Textures break in a fight" id="textures-break-in-a-fight">

The mod looks right until the Resonator takes a few hits. Then its textures break.

**Cause:** the Wounded Effect. When a Resonator is hurt, the game swaps in damaged versions of its textures, which the mod does not know.

**Fix:**

1. In XXMI Launcher, open the settings with the gear icon, then the **General** tab.
2. Tick **Disable Wounded Effect**. If the launcher asks about it when you start, click **Disable**.
3. Start the game from XXMI Launcher again.

</Accordion>
<Accordion title="Original look at a distance" id="original-look-at-a-distance">

The mod shows up close, but the Resonator turns back to the original look when the camera zooms out.

**Cause:** at a distance, the game swaps in a simpler model of the Resonator. The mod is made for the full model, so it no longer matches.

**Fix:**

1. In XXMI Launcher, open the **General** settings tab.
2. Check that **Configure Game Settings For WWMI** is ticked.
3. Set **Mesh LOD Base FOV** to `165` or higher. `165` is the default.
4. Update XXMI Launcher if it offers an update.

Some mods come with a second `.ini` file for the distance model. Keep it in the mod's folder. [Make mods show at a distance](/docs/wuthering-waves/models/lods) explains how this works.

{/* NEEDS HANDS-ON TEST: on XXMI Launcher 2.5.0 with Wuthering Waves 3.8, at which camera distance a mod still turns to the original look with Mesh LOD Base FOV at 165. */}

</Accordion>
<Accordion title="Old mod after an update" id="old-mod-after-an-update">

**Cause:** a game update changed the Resonator's model or texture data, so the mod no longer matches. Rover breaks most often. Version 3.8 broke Rover mods and facial expressions again.

**Fix:**

1. Check the mod's page for an update first.
2. Zip a copy of the mod folder and keep it outside `Mods`.
3. Run one fix tool on the broken mod, with a release made for version 3.8 or newer.
4. Run it once. Never run a tool twice on the same mod, and never run both tools on it.
5. Press `F10` in game.

Mods made for the first WWMI versions, from mid 2024, show a `Mod Loading Error` box instead. No tool fixes those: they need a new export from their creator.

Fake fixers carrying malware have been uploaded after game updates. Get fix tools only from their GitHub pages. Warning signs: the file asks for admin rights, comes in a password-protected archive, or wants to replace `d3d11.dll`.

</Accordion>
<Accordion title="Several Resonators look wrong" id="several-resonators">

After an update, the faces or shading of several Resonators look wrong, even ones you never modded.

**Cause:** some textures, such as face shadow and light maps, are shared by many Resonators. One outdated mod, exported with WWMI Tools 1.8.0 or older, that still ships the old shared texture breaks all of them. Mods exported with WWMI Tools 1.9.4 swap a texture only on their own parts, so they should not cause this.

**Fix:** find that mod and update it, run a fix tool on it, or turn it off. To find it, use the halves method:

1. Rename half of your mod folders so they start with `DISABLED_`.
2. Press `F10` and check whether the problem is still there.
3. Keep halving the group that has the problem until one mod is left.

</Accordion>
<Accordion title="Two mods on one Resonator" id="two-mods-on-one-resonator">

**Cause:** two mod folders change the same Resonator or outfit. Or a download holds several versions of one mod in subfolders, and all of them load.

**Fix:**

1. Keep one mod for each Resonator or outfit.
2. Rename the other mod folders so they start with `DISABLED_`.
3. For a download with several versions, keep one version folder and disable the rest.
4. Press `F10`.

</Accordion>
<Accordion title="Missing or stretched parts" id="missing-or-stretched-parts">

Parts are missing, or spikes stretch out of the body, the first time a mod loads.

**Cause:** the Resonator was on screen when WWMI reloaded the mod.

**Fix:** switch to another Resonator, press `F10`, and switch back. If that does not help, restart the game.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check it on Wuthering Waves: what a Resonator looks like when F10 is pressed while it is on screen, and whether switching away and pressing F10 again fixes it. */}

If a part always looks wrong, the mod itself is broken. See [Model problems in game](/docs/wuthering-waves/errors/model-problems).

</Accordion>
<Accordion title="Other problems" id="other-problems">

**Eyes and lips glitch right after an update:** the game rebuilt its shaders. Restart the game.

**Two copies of the same modded Resonator glitch**, for example in co-op, photo mode or a story scene: this is a known limit of WWMI and will not be fixed. Turn mods off with `F6` for that moment.

**Half of the model is see-through from behind:** version 3.0 changed how the game hides the back side of some models. The mod needs a fix in its `.ini` from its creator. Check the mod's page for an update.

**Skin looks pale in the open world only:** usually the mod itself, or another mod or shader file that clashes with it. Turn every other mod off with a `DISABLED_` prefix, remove any files you added to `WWMI\ShaderFixes`, and press `F10`. If the skin is still pale, ask the mod's creator.

**Crashes or strange looks with several mods:** you may have more than one copy of RabbitFX, the shared texture and glow library. Keep exactly one copy in `Mods`. [Make textures survive game updates](/docs/wuthering-waves/textures/stable-textures) explains it.

**The screen or map flickers on an RTX 50 card:** this is a driver problem in DirectX 11, and some players see it without mods too. No reliable fix is known yet.

</Accordion>
</Accordions>
