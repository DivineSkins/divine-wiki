<LevelPill level="intermediate" />

Each component of a Resonator uses several textures, and each color channel in them does its own job. A Resonator is the game's name for a playable character. This page shows how to tell the textures apart and what is known about each one, so you change only what you mean to. Read [Your first mod: recolor a character](/docs/wuthering-waves/textures/recolor-a-character) first if you have not edited a texture yet.

<Accordions>
<Accordion title="Coming from another game?" id="from-another-game">

**From Genshin Impact, Honkai: Star Rail or Zenless Zone Zero.** Wuthering Waves texture files have no readable names like `BodyDiffuse.dds`. A name tells you only which components use the texture and its hash. `TextureUsage.json` tells you which slot each texture filled. WWMI binds textures with `this =` per texture hash, and has no library like ORFix or SlotFix. RabbitFX is an optional library for binding textures by role.

Other game sections: [Genshin Impact](/docs/genshin-impact), [Honkai: Star Rail](/docs/honkai-star-rail), [Zenless Zone Zero](/docs/zenless-zone-zero).

</Accordion>
</Accordions>

## The one rule

Copy every channel you do not mean to change from the original. No WWMI source documents what each channel means. The meanings below come from creators' guides and a fan shader project, and they may be incomplete. A channel you leave alone cannot break.

## The textures of a component

An extracted object folder, or the `Textures` folder of a mod, holds every texture of the object in one place. Find a component's textures by its number in the file name: `Components-3 t=<hash>.dds` and `Components-0-1-2-3 t=<hash>.dds` both belong to component 3. [Character names and parts](/docs/wuthering-waves/basics/character-names-and-parts) explains the names.

| Type            | What to know                                                               | Usual format                                               |
| --------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Diffuse         | A normal colored picture: skin, cloth, patterns                            | `BC7_UNORM_SRGB`. A few small textures are BC3 sRGB or BC1 |
| Normal map      | The same layout in green and grey, or dark yellow                          | `BC7_UNORM`                                                |
| Light map       | Like the diffuse, in loud colors: orange, green, yellow                    | `BC7_UNORM` in most files                                  |
| Material map    | An extra map on Resonators released after 3.0. Not described in the guides | Read it from the dump                                      |
| Face shadow map | Used for face shadows. Not described in the guides                         | Read it from the dump                                      |
| Glow map        | Mostly black, only the glowing parts show                                  | Read it from the dump                                      |

Some Resonators, such as Hiyuki, also have cut-out or special effect maps. [Save DDS textures the right way](/docs/wuthering-waves/textures/save-dds-files) shows how to read any texture's format from the dump.

## Tell them apart

Creators describe the colors of these maps differently: one guide calls the normal map dark yellow, another green and grey. So never decide by color alone. Use `TextureUsage.json`, the format and a test.

<Steps>
<Step>

### Read TextureUsage.json

WWMI Tools writes `TextureUsage.json` into every extracted object folder. Open it in a text editor. Here is component 3 of Aalto, from the WWMI-Assets repository:

```text
"Component 3": {
    "ps-t0": [
        "98a883e4-vs=2974476ed7fe47bc-ps=b62f7a5cd90e47a1",
        "3dcf2a5e-vs=3a4d50f2f9828565-ps=ca134b7ad59cdf8c"
    ],
    "ps-t1": [
        "184f22fd-vs=2974476ed7fe47bc-ps=b62f7a5cd90e47a1",
        "4eba0ca3-vs=3a4d50f2f9828565-ps=ca134b7ad59cdf8c"
    ],
    "ps-t2": [
        "f47bc395-vs=2974476ed7fe47bc-ps=b62f7a5cd90e47a1"
    ]
}
```

- Each `ps-t` line is a texture slot of the pixel shader. Under it is every texture that filled the slot.
- Each entry is the texture hash, then the two shaders of that draw: `vs=` and `ps=`.
- Entries with the same `ps=` hash belong to one draw. Here `98a883e4`, `184f22fd` and `f47bc395` are read together by shader `b62f7a5cd90e47a1`: that is one material set.
- The texture hash is the `t=` part of a file name. `184f22fd` is the file `Components-3 t=184f22fd.dds`.

A hash with no file in the folder was skipped by the texture filters at extraction.

</Step>
<Step>

### Check the format

Within one material set, the `BC7_UNORM_SRGB` texture usually holds the colors: that is the diffuse. The linear ones hold data: the normal map and the light map. In Aalto's set above, `184f22fd` is BC7 sRGB and `98a883e4` is BC7 Linear.

Slot numbers do not tell you the type. In Aalto's folder, the BC7 sRGB texture of the main draw sits in `ps-t1` for component 3, but in `ps-t2` for component 2. Checked in WWMI-Assets on 2026-11-24.

</Step>
<Step>

### Confirm in game

1. Back up the texture you think is the diffuse.
2. Paint a bright color over one area and save it in its own format.
3. Press `F10` in game. If that area changes color, you found the diffuse.
4. Put the backup back.

</Step>
</Steps>

## Diffuse

- **RGB:** the colors you see. This is what a recolor changes.
- **Alpha:** shading data, not see-through areas. The Wuthering Waves beginner guide says the game uses it for forced shadows. A fan shader project reads it as an emission or mask channel. Keep it as it is.

## Light map

The light map looks like the diffuse, in loud colors. The beginner guide reads it by area:

- **Orange:** skin.
- **Green:** clothes and everything else that is not skin.
- **A mix of both:** skin under thin cloth, such as tights.

What each single channel controls is not documented. To give a new area the same shading as an existing one, pick the light map color from an area that already looks right, alpha included, and paint with it. Save light maps as Linear.

{/* NEEDS HANDS-ON TEST: on Wuthering Waves 3.8, that painting a new area with the light map color of existing skin, alpha included, gives it skin shading */}

## Normal map

- **R and G:** the direction of the surface, for small bumps and folds. This is how a fan shader project reads them.
- **B and A:** the same project reads them as shine or metal terms. The beginner guide says blue areas of the normal map give a metallic look.

Keep every channel of the original. Paint new areas by copying a matching area of the normal map, not with a made-up color.

## Other textures

- **Material map.** Resonators released after 3.0 have it. RabbitFX can bind it by role.
- **Face shadow map.** Many Resonators have one, used for face shadows. WWMI Tools' default texture filters may skip it. [Make a frame dump](/docs/wuthering-waves/basics/frame-dump) shows how to extract it anyway.
- **Glow map.** Mostly black, with only the glowing parts showing. [Add glow and see-through parts](/docs/wuthering-waves/effects/glow-and-transparency) covers glow.

Vertex colors in the mesh, not textures, decide outlines and which parts count as skin. [UV maps, vertex colors, and outlines](/docs/wuthering-waves/models/uvs-and-vertex-colors) covers them.

## Look at one channel

In Paint.NET, duplicate the layer, then open <MenuPath path="Adjustments > Modify Channels" />. Set line 1 to `Greyscale`, `Identity`, and the channel you want as the source. Add line 2: `Alpha`, `Constant`, `255`. Tick `Enabled`. The layer now shows that one channel in black and white. Delete the layer when you are done.

In Photoshop, open the **Channels** panel and click one channel. With Intel Texture Works, tick **Load Transparency as Alpha Channel** when you open the file, or the alpha does not show.

## Common problems

<Accordions type="multiple">
<Accordion title="Shading on skin or clothes looks wrong after an edit" id="wrong-shading">

The light map was edited, saved as sRGB, or comes from another Resonator. Copy the channels back from the original and save as `BC7 (Linear, DX 11+)`.

</Accordion>
<Accordion title="A texture listed in TextureUsage.json has no file" id="missing-file">

The texture filters skipped it at extraction, usually because it is small. Extract again with **Skip Small** and **Skip .jpg** unticked.

</Accordion>
<Accordion title="Two textures in a set look like a diffuse" id="two-diffuse">

Check the format of both in the dump: only one is usually sRGB. If both are, do the in-game test above on each.

</Accordion>
</Accordions>
