ReShade is a separate tool that filters the whole picture: colors, sharpness, and depth effects, including the UI. It is not a mod, because it changes no single model or texture. This page covers only how to run it next to XXMI Launcher without breaking your mods. It does not teach presets or effects.

<Callout type="warning" title="Third-party software, not tested here">
  ReShade is one more program that hooks into the game, next to the mod loader.
  The account risk on [What's allowed and how to stay
  safe](/docs/wuthering-waves/getting-started/stay-safe) applies to it too.
  Nobody has tested ReShade with WWMI 1.1.0 for this wiki.
</Callout>

## Rules that keep your mods working

1. **Keep ReShade files out of `Mods`.** That includes presets. A ReShade preset in the `Mods` folder can crash the game, or leave only ReShade running.
2. **Leave XXMI DLL Initialization Delay at its default.** The WWMI default is `500`. The setting's tooltip in XXMI Launcher names `150` as the lowest value for use with ReShade, so the default already covers it. If you lowered it below `150`, raise it again.
3. **Keep the game in DirectX 11.** WWMI mods load only in DirectX 11, with or without ReShade.
4. **Keep the launcher's injection settings at their defaults.** This wiki does not cover changing them.
5. **Keep presets cosmetic.** Change colors and light only. Skip any preset or ReShade add-on that removes fog, filters or outlines, or shows anything the normal game hides.

## If something breaks

1. Move every ReShade file out of `%AppData%\XXMI Launcher\WWMI\Mods`.
2. Turn ReShade off, and start the game from XXMI Launcher's **Start** button.
3. If your mods load now, the ReShade setup is the problem. Check the delay in rule 2, then the tool's own page.
4. If they still do not load, ReShade is not the cause. Go to [Mods not loading](/docs/wuthering-waves/errors/mods-not-loading).

Crashes with ReShade or overlays are also covered on [Crashes and launch errors](/docs/wuthering-waves/errors/game-crashes#overlays-and-reshade).

## What to skip

| Skip this                                                | Why                                                            |
| -------------------------------------------------------- | -------------------------------------------------------------- |
| Unofficial DirectX 12 loaders, including ReShade add-ons | Not supported and not covered here. WWMI mods need DirectX 11. |
| Presets or add-ons that remove fog, filters or outlines  | They change what the game shows on purpose. Not covered here.  |
