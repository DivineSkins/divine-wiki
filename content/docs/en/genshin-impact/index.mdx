## Tools

HoYoverse has not released modding tools for Genshin Impact. These community tools fill the gap.

<ToolCard
  name="XXMI Launcher"
  href="/docs/genshin-impact/tools/xxmi-launcher"
  badge="Required"
  icon={<Icon name="XXMILauncher" />}
>
  Installs and updates GIMI, starts the game with mods, and opens your Mods
  folder.
</ToolCard>

<ToolCard
  name="XXMI Tools for Blender"
  href="/docs/genshin-impact/tools/blender-add-on"
  badge="Models"
  icon={<Icon name="Blender" />}
>
