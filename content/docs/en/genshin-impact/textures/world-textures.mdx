<LevelPill level="intermediate" />

You will put your own image on an object in the world, like a sign, a painting, a wall or a prop. It is a texture-only mod: you find the object's texture in a frame dump, edit it, and write a short `.ini`. Written for XXMI Launcher 2.5.0 and GIMI 8.9.4 on Genshin Impact 7.2.

<Callout type="warning" title="Looks only">
  A world texture mod changes how things look, never what the game shows you.
  This guide does not cover mods that mark chests or collectibles, remove fog,
  or make walls or hidden things see-through. Those give an unfair advantage.
</Callout>

## Make the mod

<Steps>
<Step>

### Set up

1. In XXMI Launcher, click the gear, open the **GIMI** tab and tick **Enable Hunting**.
2. Turn off any mod that changes this object. Rename its folder so it starts with `DISABLED`. Otherwise you dump the mod's texture, not the original.
3. In your `Mods` folder, make a folder such as `MyWorldMod`, with a text file renamed to `MyWorldMod.ini`.

</Step>
<Step>

### Hunt the object's pixel shader

A full dump of a busy scene can take more than 20 GB. Find the shader that draws your object first, so you can dump only that.

1. Start the game and walk up to the object. Turn the camera so it fills the screen.
2. Press `Numpad 0` for hunting mode.
3. Press `Numpad 1` and `Numpad 2` until the object, or its surface, disappears.
4. Press `Numpad 3` to copy the shader hash.

[Find a hash with hunting mode](/docs/genshin-impact/basics/find-a-hash) explains the keys and the overlay.

</Step>
<Step>

### Dump only that shader

1. Add this section to your `.ini`, with your shader hash in place of `0123456789abcdef`:

   ```ini
   [ShaderOverrideDumpMyObject]
   hash = 0123456789abcdef
   analyse_options = dump_rt dump_tex dump_cb dump_vb dump_ib buf txt dds
   ```

2. Press `F10`, then `F8`. Wait until the game moves again.

The word `dds` makes the dump save textures as `.dds` files you can edit. [Make a frame dump](/docs/genshin-impact/basics/frame-dump) explains dump folders and file names.

</Step>
<Step>

### Find the texture

1. Open the new `FrameAnalysis-...` folder in `%AppData%\XXMI Launcher\GIMI`, then `deduped`.
2. Search for `unorm_srgb` to list the color textures.
3. Look for your object's texture. The `o0` images in the main dump folder show what each draw put on screen, which helps you find the right draw.
4. Read the file name, for example `1a2b3c4d-BC7_UNORM_SRGB.dds` (a placeholder). The start is the hash. The end is the format.
5. Copy the file into your mod folder and give it a clear name, like `MyPainting.dds`.

</Step>
<Step>

### Edit the image

1. Open the copy in Paint.NET.
2. Paint or paste your art. Keep the exact size of the original.
3. Keep the alpha channel as it was.
4. Save in the format from the file name: `BC7_UNORM_SRGB` is `BC7 (sRGB, DX 11+)`, `BC7_UNORM` is `BC7 (Linear, DX 11+)`. Tick **Generate Mip Maps**.

[Save DDS textures the right way](/docs/genshin-impact/textures/save-dds-files) has every option.

</Step>
<Step>

### Write the override

Delete the dump section, and write one pair of sections per texture, with your own hash and file name:

```ini
[TextureOverrideMyPainting]
hash = 1a2b3c4d
this = ResourceMyPainting

[ResourceMyPainting]
filename = MyPainting.dds
```

Never write a note after the hash on the same line. Each section name must be unique in the file.

</Step>
<Step>

### Test it

1. Press `F10` in game.
2. Look at the object by day and by night, from close up and from far away.
3. Untick **Enable Hunting** when you are done.

A texture override changes every object that uses that texture. If your art shows up on other props too, they share the texture.

</Step>
</Steps>

## If the texture does not change, or vanishes at night

Some shaders draw a texture without checking for overrides. Others draw the same object only at night, or in another place. Tell those shaders to check for your texture.

1. Search the main dump folder, not `deduped`, for your texture hash.
2. Each match names its draw, its slot and its shaders. In this example, from a Zenless Zone Zero dump, the slot is `ps-t3`, and the pixel shader hash follows `ps=` further along the name:

<img
  src="/wiki-images/genshin-impact-textures-world-textures-2.webp"
  alt="Two search results for the hash 17ad2a44: the deduped file 17ad2a44-BC7_UNORM_SRGB.dds, and the dump file 000315-ps-t3=17ad2a44-vs=..., which shows the slot ps-t3"
/>

3. Add one section per pixel shader that reads your texture, with your own shader hash and slot:

   ```ini
   [ShaderOverrideMyPaintingCheck]
   hash = fedcba9876543210
   allow_duplicate_hash = true
   checktextureoverride = ps-t3
   ```

4. Press `F10` and look again.

`allow_duplicate_hash = true` lets this section share its shader hash with another section, such as one in another mod. If the object vanishes only at night, make a second dump at night and add the night shader the same way. If you cannot tell which shader it is, step through pixel shaders with `Numpad 1` and `Numpad 2` until the object disappears.

{/* NEEDS HANDS-ON TEST: whether Genshin Impact 7.2 draws world objects with a separate night shader that needs its own checktextureoverride */}

## If it disappears from far away

From a distance, the game can draw a simpler version of the object with its own texture. Make another dump from that distance, find the second texture hash, and add an override for it too. Dumps from far away are much bigger, so use the shader dump above.

## Common problems

<Accordions type="multiple">
<Accordion title="Nothing changes at all" id="no-change">

Check the hash and the `filename =` line. Make sure no other mod for that object is on. Then add the `checktextureoverride` section above.

</Accordion>
<Accordion title="The colors look washed out or too dark" id="wrong-colors">

The format does not match the original. Save again with the sRGB or Linear choice the original file name shows.

</Accordion>
<Accordion title="My art is upside down or mirrored" id="flipped">

Some game textures are stored flipped. Flip your image in Paint.NET and save again.

</Accordion>
<Accordion title="It worked, then stopped after a game update" id="after-update">

Updates can change texture and shader hashes. Hunt and dump again, and put the new hashes in your `.ini`.

</Accordion>
</Accordions>
