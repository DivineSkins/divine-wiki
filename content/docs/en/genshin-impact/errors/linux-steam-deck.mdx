<LevelPill level="intermediate" />

Genshin Impact and XXMI Launcher are made for Windows. Some players run both on Linux or a Steam Deck through Wine or Proton, which translate the Windows game. This page says what is known to work, what is not known yet, and where to ask for help.

<Callout type="warning" title="Unofficial, and not tested here">
  XXMI Launcher's author offers Linux support "as is", in the hope that Wine and
  Proton do the job. The launcher's issue tracker does not take Linux bug
  reports. Nobody has tested the steps on this page with Genshin Impact 7.2 for
  this wiki.
</Callout>

## The risk is the same as on Windows

Mods break the Terms of Service of Genshin Impact. HoYoverse can ban any account that uses third-party software. Genshin Impact's anti-cheat detects the mod loader, and its "Illegal tool detected" kicks have hit Linux players too, since August 2025. Linux is not a way around them. Use mods only on an account you can afford to lose.

["Illegal tool detected" and 4001 errors](/docs/genshin-impact/errors/illegal-tool-detected) explains the error and your choices.

## What is known to work

<img
  src="/wiki-images/genshin-impact-errors-linux-steam-deck-1.webp"
  alt="A Wine prefix folder tree that holds both the official HoYoPlay launcher with Genshin Impact and the portable XXMI Launcher with its GIMI Mods folder, next to four rules for Linux"
/>

One rule matters most: XXMI Launcher must run in the same Wine or Proton prefix as the game. A prefix is the folder where Wine keeps one fake Windows install. Two routes do this.

<TabsList>
<TabsTrigger value="official-launcher"><Icon name="AppWindow" className="size-4" />Official launcher in Wine</TabsTrigger>
<TabsTrigger value="twintail"><Icon name="Linux" className="size-4" />Twintail Launcher</TabsTrigger>
</TabsList>
<TabsContent value="official-launcher">

Run the official HoYoPlay launcher and the portable XXMI Launcher in one prefix. A Wine manager such as Lutris makes this easier.

1. Install HoYoPlay into a Wine prefix, then install Genshin Impact through it. Start the game once.
2. Download `XXMI-Launcher-Portable-vX.X.X.zip` from the [XXMI Launcher releases](https://github.com/SpectrumQT/XXMI-Launcher/releases/latest) on GitHub.
3. Extract it to a folder inside the same prefix. Keep it out of `Program Files`, and use no `{` or `}` in the path.
4. Install the Microsoft Visual C++ Redistributable (x64) in that prefix. The portable build needs it.
5. Add `Resources\Bin\XXMI Launcher.exe` as a second program in the same prefix. In Lutris, duplicate the HoYoPlay entry and change its executable.
6. Start XXMI Launcher, pick Genshin Impact, and install GIMI. If it does not find the game, set **Game Folder** to the folder that holds the game's `.exe`.
7. Put your mods in `GIMI\Mods` inside the launcher folder. Start the game from XXMI Launcher.

The steps after the install are the same as on Windows: [Install mods with XXMI Launcher](/docs/genshin-impact/getting-started/install-with-xxmi-launcher).

  id="7vaMUdY1E6E"

This video is from early 2025 and shows XXMI Launcher 1.3.4, so the labels differ today. It puts the launcher in `Program Files`: the launcher's own README says to avoid those folders. The creator's pinned comment updates the Wine advice: Wine Staging-Tkg 10.0, not Wine 10.1. The "Illegal tool detected" kicks reached Linux players after this video was made.

</TabsContent>
<TabsContent value="twintail">

Twintail Launcher installs and starts the game on Linux and has a built-in XXMI option. It downloads XXMI and GIMI itself and starts them in the game's prefix.

1. Install Twintail from Flathub (`app.twintaillauncher.ttl`), or from Copr, AUR or Nix.
2. Install or import Genshin Impact inside Twintail.
3. Turn on the game's XXMI option.
4. If Twintail says your runner does not support modding, pick another runner.
5. Put your mods in the `GIMI\Mods` folder that Twintail made, and start the game from Twintail.

In September 2026 a player reported mods loading under Twintail in another XXMI game. We found no such report for Genshin Impact yet.

## Steam Deck

Genshin Impact is not on Steam. On a Steam Deck, switch to Desktop Mode and use one of the routes above. The video above runs on a Steam Deck and adds shortcuts you can start from Game Mode.

XXMI's folder picker does not show hidden folders, such as `.local`. Type the path into the picker's address bar instead.

## Common problems

<Accordions type="multiple">
<Accordion title='"d3d11.dll is missing expected entry point"' id="entry-point">

**Cause:** on Linux, this error comes from the graphics layers of Wine or Proton, VKD3D or NVAPI.

**Fix:** turn off VKD3D and NVAPI in your Wine runner's settings, then start again. If it stays, ask in the AGMG Discord's Linux channel.

{/* NEEDS HANDS-ON TEST: that turning off VKD3D and NVAPI clears this error for GIMI on Linux */}

</Accordion>
<Accordion title="XXMI Launcher cannot find the game" id="game-not-found">

1. Check that the launcher and the game run in the same prefix.
2. In the launcher settings, set **Game Folder** to the folder that directly holds the game's `.exe`.
3. If the folder sits under a hidden folder such as `.local`, type its path by hand.

</Accordion>
<Accordion title='The game kicks me with "Illegal tool detected"' id="kicked">

This is the same kick that Windows players get. There is no supported fix on any system. Read the page linked in [The risk is the same as on Windows](#the-risk-is-the-same-as-on-windows).

</Accordion>
</Accordions>
