XXMI Launcher will not install, open, update, or find Genshin Impact. Find the message you see below and follow its fix. This page was written for XXMI Launcher 2.5.0 and GIMI 8.9.4.

XXMI Launcher needs admin rights to add the mod loader to the game. A Windows permission prompt each time you open it is normal.

## Start with the real launcher

Many problems come from a wrong download. Get XXMI Launcher only from [its GitHub releases page](https://github.com/SpectrumQT/XXMI-Launcher/releases/latest), made by SpectrumQT. The installer is named `XXMI-Launcher-Installer-Online-v2.5.0.msi`. Lookalike sites with similar names exist: avoid them.

Install it with **Quick Installation**, to `%AppData%\XXMI Launcher`. Never install it inside the game folder or in Program Files.

## Antivirus warnings

Your antivirus may flag or delete `d3d11.dll`, `3dmloader.dll`, the installer, or the launcher itself. A common name is `Trojan:Win32/Bearfoos.A!ml`. The launcher may then say:

```text
Data Corruption Detected
XXMI Libraries package is corrupted by antivirus
Failed to start ...msi! Was it blocked by Antivirus software or security settings?
```

**Cause:** the launcher's files are not signed, so antivirus programs guess. The XXMI team marks these reports as false positives on its issue tracker.

**Fix:**

1. Check that you downloaded the launcher from the GitHub releases page.
2. Open your antivirus and restore the file from quarantine.
3. Add an exclusion for the two paths the launcher's message names, inside your launcher folder: `Resources\Packages\XXMI` and `GIMI\d3d11.dll`.
4. In XXMI Launcher, click the 3-dots button next to **Start**, then **Repair GIMI**.

<Callout type="warning" title="Never turn your antivirus off">
  Exclude only the two paths above. A fake launcher or fake "fix" can carry real
  malware, so keep your antivirus on for everything else.
</Callout>

## The launcher will not open

<Accordions type="multiple">
<Accordion title="VCRUNTIME140.dll not found, or Visual C++ is damaged" id="vc-runtime">

You see `VCRUNTIME140.dll not found`, or the launcher says:

```text
Microsoft Visual C++ Redistributable is damaged or not installed!
```

**Fix:**

1. Download the [Visual C++ Redistributable for x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
2. Run it. If it is already installed, choose **Repair**.
3. Restart your PC.

If the launcher still shows nothing at all, Windows files may be damaged. Run `sfc /scannow` in a Command Prompt opened as administrator, or try the portable version.

</Accordion>
<Accordion title="The launcher takes minutes to open" id="slow-start">

**Cause:** a slow game search in launcher versions 2.4.1 to 2.4.6.

**Fix:** update to version 2.4.7 or newer. Version 2.5.0 is current.

</Accordion>
<Accordion title="Failed to load configuration" id="config-load">

**Cause:** the launcher's settings file, `XXMI Launcher Config.json`, is damaged.

**Fix:** click **Load Backup**. If that fails too, click **Load Default** and set your options again.

</Accordion>
<Accordion title="Failed to write Read Only file" id="read-only-file">

**Cause:** a file the launcher needs has the read-only flag.

**Fix:** click **Remove Flag** in the message.

</Accordion>
</Accordions>

## Updates and downloads fail

<Accordions type="multiple">
<Accordion title="Failed to establish HTTPS connection to GitHub" id="github-connection">

You see this, or "Max retries exceeded", or "SSL wrong version number":

```text
Failed to establish HTTPS connection to GitHub! Please check your Antivirus, Firewall, Proxy and VPN settings.
```

**Cause:** something blocks GitHub: a firewall, your internet provider, a VPN, or a proxy.

**Fix:**

1. Allow XXMI Launcher through your firewall.
2. Turn off a VPN or proxy that does not work, then try again.
3. If you need a proxy, open the launcher settings, then the **Launcher** tab, tick **Use Proxy**, and enter its address.

Turn **Verify SSL** off only if a proxy you trust breaks the connection.

</Accordion>
<Accordion title="GitHub API requests limit reached" id="github-api-limit">

```text
Unauthorized GitHub API requests limit reached for your IP!
```

**Cause:** too many update checks from your internet address. This is common on shared proxies.

**Fix:** wait an hour and try again. If it keeps happening, add a GitHub token: in the **Launcher** tab, click **Create...** next to **GitHub Token**, and make a "classic" token on GitHub.

</Accordion>
</Accordions>

## The launcher cannot find the game

<Accordions type="multiple">
<Accordion title="Game Installation Not Found" id="game-not-found">

You see "Game Installation Not Found", "Game executable ... not found!", or "Found 2 copies of game executable".

**Cause:** **Game Folder** is empty, points at the wrong level, or two copies of the game exist.

**Fix:**

1. Open the launcher settings, then the **General** tab.
2. Click **Detect Installations**, or click **Browse...**.
3. Pick the folder that directly holds `GenshinImpact.exe`. It also holds the `GenshinImpact_Data` folder, and is usually named `Genshin Impact game`.
4. If you have an old second copy of the game, delete it.

</Accordion>
<Accordion title="Genshin Impact registry key is not found" id="registry-key-not-found">

```text
Genshin Impact registry key is not found! Please start the game via original launcher to create the key and try again.
```

**Cause:** the launcher turns **Dynamic Character Resolution** off through a Windows registry value. The game creates that value the first time it runs.

**Fix:**

1. Start Genshin Impact once from HoYoPlay or Epic Games, without mods.
2. Close the game.
3. Click **Start** in XXMI Launcher again.

If you see "Graphics Settings record is not found in GI registry!", do the same. If it keeps coming back, untick **Configure Game Settings For GIMI** in the **General** tab. Then set **Dynamic Character Resolution** to **Off** in the game's graphics settings yourself.

</Accordion>
</Accordions>

## The launcher warns about your Mods folder

The launcher checks your `Mods` folder each time you press **Start**.

- **"Cannot start with d3dx.ini in Mods folder!"** A mod came with its own `d3dx.ini`. Click **Disable Ini Files** when the "Stability Warning" shows.
- **"Your Mods folder contains some libraries that are already included into GIMI!"** Copies of libraries such as ORFix sit in `Mods`. Accept the offer to disable them.

Both fixes rename the files to start with `DISABLED_`. Your mods keep working.

## Report a launcher bug

The XXMI Launcher issue tracker takes only launcher bugs that happen before the game's login screen.

1. Find `XXMI Launcher Log.txt` in your launcher folder, `%AppData%\XXMI Launcher`.
2. Upload its text to Pastebin.
3. Open a report on the [XXMI Launcher issue tracker](https://github.com/SpectrumQT/XXMI-Launcher/issues) and add the Pastebin link.

Problems in game, or with a mod, do not go there. Ask in the [Divine Skins Discord](https://discord.gg/divineskins) or the [AGMG Discord](https://discord.gg/agmg) instead.
