A frame dump saves every buffer, texture and shader the game used to draw one frame. With gui_collect you turn it into a character folder that XXMI Tools imports into Blender. You need a dump when the asset repo lacks your character or outfit, or when you want the current hashes after an update. Written for XXMI Launcher 2.5.0, GIMI 8.9.4 and gui_collect 1.4.2.

## Get ready

1. Tick **Enable Hunting** in the **GIMI** tab of XXMI Launcher's settings, before you start the game.
2. Turn off every mod for your target: rename its folder so it starts with `DISABLED`. Otherwise you dump the mod, not the original.
3. Lower the game's resolution. A smaller frame makes a smaller dump.
4. Download gui_collect from its GitHub page and unzip it anywhere. Start it with `launch.bat`.

## Dump a character

<Steps>
<Step>

### Copy each part's IB hash

1. In gui_collect, click the Genshin Impact icon in the left bar.
2. Type the character's name in **Extract Name**, for example `Furina`.
3. In game, open the character screen with your character. It draws little else.
4. Press `Numpad 0`, then `Numpad 8` until a part disappears. Press `Numpad 9` to copy its hash.
5. Paste the hash into an **IB Hash** field in gui_collect.
6. Type a component name next to it, like `Ponytail`. Use only English letters and numbers, and give each one a different name. Leave it empty for the character's main body IB.
7. Repeat for every part you want.

Do not dump the face mesh. Face meshes need separate face tools, and a changed face loses its expressions. For the face texture only, copy the face's hash as usual and turn off the 3D part of that entry in gui_collect.

{/* NEEDS HANDS-ON TEST: the exact gui_collect 1.4.2 labels Extract Name and IB Hash, and the toggle that turns off the 3D part for a texture-only entry */}

{/* SCREENSHOT: genshin-impact-basics-frame-dump-3.webp, gui_collect 1.4.2 with the Genshin Impact page open, an Extract Name and two IB hashes with component names filled in */}

</Step>
<Step>

### Press F8

Press `F8` with hunting on. The game freezes while it writes the dump. Wait until it moves again.

The dump is a new folder next to GIMI's `d3dx.ini`:

```text
%AppData%\XXMI Launcher\GIMI\FrameAnalysis-YYYY-MM-DD-HHMMSS
```

</Step>
<Step>

### Extract with gui_collect

1. In gui_collect, click the folder button at the top and pick the new `FrameAnalysis-...` folder.
2. Choose where the result goes. Any folder works.
3. Click **Extract**.

If gui_collect reports a missing shader hash, make a targeted dump (below) and dump again.

</Step>
<Step>

### Label the textures

gui_collect shows the textures it found for each part. Click each one and pick its type:

| Type        | How it looks                                          |
| ----------- | ----------------------------------------------------- |
| `Diffuse`   | The colors you see in game.                           |
| `LightMap`  | Simple, flat colors, one per material (metal, cloth). |
| `NormalMap` | Grey, blue or muted, with a bumpy, shaded look.       |

Then click **Done**.

</Step>
</Steps>

## What you get

A folder named after your Extract Name, with one set of files per part:

<Files>
  <Folder name="Furina" defaultOpen>
    <File name="FurinaBody-ib=<hash>.txt: the triangles of one part" />
    <File name="FurinaBody-vb0=<hash>.txt: its vertices" />
    <File name="FurinaBodyDiffuse.dds" />
    <File name="FurinaBodyLightMap.dds" />
    <File name="FurinaBodyNormalMap.dds" />
    <File name="hash.json: every component, part and hash" />
  </Folder>
</Files>

This is the same kind of folder as the ones in the asset repo. XXMI Tools imports it into Blender.

<Callout type="warning" title="Keep the folder as it is">
  Never rename the folder or delete `hash.json`. XXMI Tools needs both to export
  your mod.
</Callout>

## Make smaller, targeted dumps

A full dump holds everything on screen and can take several gigabytes, more in busy scenes. A targeted dump saves only your character. One creator's dump went from 3.4 GB to 840 MB.

1. In gui_collect's settings, tick **Targeted Frame Analysis (Advanced)**.
2. Let gui_collect generate the targeting `.ini` for your IB hashes.
3. Put that `.ini` in a folder inside `Mods`.
4. Press `F10` in game, then `F8`.
5. Remove the `.ini` from `Mods` when you are done.

Never add it to `d3dx.ini`. XXMI Launcher rewrites that file.

## Read a dump by hand

You do not need this for a character. It helps for icons, effects and world objects that gui_collect does not cover.

<img
  src="/wiki-images/genshin-impact-basics-frame-dump-2.webp"
  alt="The dump file name 000123-ib=1a2b3c4d-vs=0123456789abcdef-ps=fedcba9876543210.txt split into draw number, resource type, hash, shader hashes and file type"
/>

- **Find a mesh:** search the dump folder for `-ib=` plus your hash. Every match is a draw of that mesh.
- **Find its parts:** open the `-ib=...txt` file. Each different `first index` value is one part.
- **Find its textures:** files with the same draw number and `-ps-t0=`, `-ps-t1=` and so on are the textures of that draw.
- **Find a texture file:** the `deduped` folder holds each texture once, named `<hash>-<FORMAT>.dds`. Search for `BC7_UNORM_SRGB` to find color textures.

By default a dump does not save textures as plain `.dds`, because full DDS dumps can need hundreds of gigabytes. To save them for one object only, hunt its pixel shader, then add a section like this to an `.ini` inside `Mods`. Replace `0123456789abcdef` with your shader hash:

```ini
[ShaderOverrideMyTarget]
hash = 0123456789abcdef
analyse_options = dump_rt dump_tex dump_cb dump_vb dump_ib buf txt dds
```

Press `F10`, then `F8`. Remove the section when you are done.

## Delete old dumps

Each dump can take many gigabytes. When you have extracted what you need, delete the `FrameAnalysis-...` folders in `%AppData%\XXMI Launcher\GIMI`.

## Common problems

<Accordions type="multiple">
<Accordion title="The game crashes when I press F8" id="crash-on-f8">

Busy places make huge dumps and can crash the game. Go to the character screen, lower the resolution, or make a targeted dump.

</Accordion>
<Accordion title="The textures in the dump are the mod's, not the original" id="dumped-the-mod">

A mod for that character was still on. Rename its folder so it starts with `DISABLED`, press `F10`, and dump again. `F6` alone does not turn off shader mods.

</Accordion>
<Accordion title="Export later fails with no hash.json" id="no-hash-json">

The folder was renamed or `hash.json` was deleted. Extract the dump again with gui_collect and leave the result as it is.

</Accordion>
</Accordions>
