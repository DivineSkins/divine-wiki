After a Genshin Impact update, some mods stop working. Two community tools repair most of them: Fix All Character Mods and the ORFix Applier. This page explains which one each mod needs, how to make sure you have the real tool, and what no tool can fix.

Written for Genshin Impact 7.2 and GIMI 8.9.4.

## Most breaks need no tool

Many "all my mods broke" moments fix themselves. Check these two things first:

1. **`Dynamic Character Resolution` is Off.** Game updates and GPU driver updates can turn it back on.
2. **GIMI is up to date.** Open XXMI Launcher and let it update. The game's load banner should read `GIMI 8.9.4 F12 TO SHOW GUIDE`.

GIMI ships ORFix, the library that fixes outlines and reflections. When a new version turns characters green, yellow, or too bright, an ORFix update inside GIMI usually fixes every mod at once. Since 2024 this is the most common kind of break. Hash changes are rare: the 7.2 update changed the hashes of only two characters, Odette and Vesna.

The ORFix Applier is not for mods with complex toggles or merged mods. Those need a fix by hand or an update from the creator.

## Run them in this order

1. Back up: zip your whole `Mods` folder.
2. Turn `Dynamic Character Resolution` off, and update GIMI in XXMI Launcher.
3. Press `F10` in game and see which mods are still broken.
4. Run the ORFix Applier on broken mods made before 6.1. Put it in the broken mod's folder and run it.
5. Run Fix All Character Mods only on mods that still look unmodded. Put `gifixversion72.exe` in the broken mod's folder and run it.
6. Press `F10` and test again.

Three rules keep this from going wrong:

- **Use only the newest fixer.** Running an old fixer after a newer one breaks mods.
- **Fix only broken mods.** Running a fixer on working mods can cause conflicts.
- **Never run a fixer twice** on the same mod. Start again from your backup instead.

If you use a mod manager that edits `.ini` files, restore your mods in it first. Fix them, then add them back.

## What no tool can fix

- **Normal maps from before 5.4.** Version 5.4 (February 2025) changed normal maps into "heightmaps". No script converts them. The creator must make new ones from a fresh dump.
- **Complex and merged mods.** Scripts often miss parts of them. Expect a fix by hand or a creator update.
- **"Illegal tool detected".** Fixers only repair mod files. For that error, see ["Illegal tool detected" and 4001 errors](/docs/genshin-impact/errors/illegal-tool-detected).

If a tool cannot fix a mod, check the mod's page for an update from its creator. Creators who fix their own mods use [Update your mod after a game update](/docs/genshin-impact/publishing/update-your-mod).

## Spot a fake fixer

<Callout type="danger" title="Fake fixers have carried malware">

After the 6.0 update in September 2025, a new account uploaded a fake "6.0 Fix all Character Mods!". It copied the real title. Its script asked for admin rights and downloaded a malicious program. Fake fixers show up after game updates, when players are in a hurry.

</Callout>

Before you run any fixer, check:

1. **The link.** Use the links on this page, or the one in the GIMI team's news post for that version. Not a link from a video comment or a search result.
2. **The author.** The real Fix All page lists SilentNightSound and Gustav0\_ as authors. It has a long update log and hundreds of thousands of downloads.

<img
  src="/wiki-images/genshin-impact-tools-update-fixers-1.webp"
  alt="The real Fix All Character Mods page on GameBanana, titled 7.2 Fix All Character Mods!, with Key Authors Gustav0_ and SilentNightSound and about 647 thousand downloads"
/>

3. **The checksum.** GameBanana shows an MD5 checksum and a scan result for each file. Compare the MD5 of your download with it.
4. **The source.** Prefer the version you can read, such as the `.py` script or source `.zip`.

Red flags: a "fix" that replaces `d3d11.dll` or other XXMI files, asks for admin rights, comes in a password-protected archive, or comes from a new account with one upload. Also a "fix" that appears before the community has announced one.

Antivirus apps sometimes flag real fixers, because they rewrite many files at once. Add an exclusion for that one file. Never turn your antivirus off.

## Tools to skip

| Skip this                                         | Why                                              |
| ------------------------------------------------- | ------------------------------------------------ |
| Fix pages for 4.1, 4.3, and 4.4                   | Outdated. The 7.2 Fix All covers them.           |
| Any old fixer version                             | It breaks mods that a newer fixer already fixed. |
| HOYO-SHA hash updater                             | Not trusted. Do not run it.                      |
| A `d3d11.dll` "fix" from anyone but XXMI Launcher | Real fixes never replace XXMI files.             |

## Common problems

<Accordions type="multiple">
<Accordion title="Green skin or a multicolored face after a fix" id="green-face">

ORFix was added to a face part. Remove the `run = CommandList\global\ORFix\ORFix` line from the face sections of the `.ini`, or run the ORFix Applier again on a fresh copy.

</Accordion>
<Accordion title="Every mod broke after I ran a fixer" id="all-broke">

An outdated fixer, or a fixer run twice, can do this. Restore your `Mods` backup and follow the order above with the newest fixer.

</Accordion>
<Accordion title="The launcher warns about duplicate libraries" id="duplicate-orfix">

An old mod or fixer left `ORFix.ini`, `ORFixAPI.ini`, `Region.ini` or `Offset.ini` in `Mods`. GIMI already has them. Delete the copies.

</Accordion>
</Accordions>
