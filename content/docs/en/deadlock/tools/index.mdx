A Deadlock mod takes a few free tools. Each row below says what a tool does. Click it for the full guide.

**New here?** Install the two **Required** tools first. They cover sounds, recolors, textures, icons, and item art.

<Callout type="info" title="There is no official SDK">

Valve has not released modding tools for Deadlock. The Valve Developer Community wiki lists its mod support as "Unsupported" and its SDK as "None". The game ships a resource compiler, but no editors.

So creators use community tools. The main one, CSDK 12, is Valve's Counter-Strike 2 tools adapted for Deadlock. Every tool on these pages is unofficial, and most of them run on Windows only.

</Callout>

## How the tools fit together

<img
  src="/wiki-images/deadlock-tools-index-1.webp"

Every mod passes through the same five stages. The tool changes with the file type, but the order stays the same. [How Deadlock mods work](/docs/deadlock/basics/how-mods-work) explains why compiled files and VPKs matter.

## Tools to skip

| Skip this                                                        | Why                                                                          | Use instead                                                    |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------- |
| CSDK 10                                                          | Outdated. Its own page points to CSDK 12. Some older tutorials still use it. | CSDK 12                                                        |
| The original Blender Source Tools                                | Lacks the Source 2 fixes Deadlock models need.                               | BlenderSource2Tools, a Source 2 fork                           |
| Valve's `vpk.exe`                                                | Has no Source 2 docs. No Deadlock guide uses it.                             | [Source 2 Viewer or CSDK 12](/docs/deadlock/basics/pack-a-vpk) |
| Valve tools repacked by unknown uploaders                        | You cannot check what is inside.                                             | The official CS2 Workshop Tools                                |
| Anything sold as a "mod menu", ESP, or a "Deadlock 2026" toolkit | These are tools for unfair play, or they carry malware.                      | Nothing. Never download them.                                  |

## How to spot a real tool

- Real creator tools are open-source GitHub projects from known authors, or tool pages in [GameBanana's Deadlock tools section](https://gamebanana.com/tools/games/20948).
- Download each tool from the link on its wiki page, not from a search result or a video comment.
- A tool can be an `.exe`. A mod never is. [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) explains how to check a mod download.
