A Deadlock mod takes a few free tools. This page shows what each one does, which ones to install first, and how they fit together. To install the basics step by step, follow [Set up your creator tools](/docs/deadlock/getting-started/creator-setup).

## There is no official SDK

Valve has not released modding tools for Deadlock. The Valve Developer Community wiki lists its mod support as "Unsupported" and its SDK as "None". The game ships a resource compiler, but no editors.

So creators use community tools. The main one, CSDK 12, is Valve's Counter-Strike 2 tools adapted for Deadlock. Every tool on these pages is unofficial, and most of them run on Windows only.

## How the tools fit together

Every mod passes through the same five stages. The tool changes with the file type, but the order stays the same. [How Deadlock mods work](/docs/deadlock/basics/how-mods-work) explains why compiled files and VPKs matter.

## Beginner toolchain

Install these first. They cover sounds, recolors, textures, icons, and item art.

<ToolCard
  name="Source 2 Viewer"
  href="/docs/deadlock/tools/source-2-viewer"
  badge="Required"
>
  Opens the game's files. Previews, exports, and decompiles them, and packs your
  mod into a VPK.
</ToolCard>
<ToolCard name="CSDK 12" href="/docs/deadlock/tools/csdk-12" badge="Required">
  Community build of Valve's Source 2 tools. Compiles your edited files so the
  game can read them.
</ToolCard>
<ToolCard
  name="Make mods without installing tools"
  href="/docs/deadlock/tools/browser-builders"
  badge="No install"
>
  Deadlock Forge and DeadMod build simple sound, icon, and texture mods in your
  browser.
</ToolCard>
<ToolCard name="Mod managers" href="/docs/deadlock/tools/mod-managers">
  Deadlock Mod Manager and Grimoire install and switch mods. Use one to test
  your own.
</ToolCard>

You also need editors for your files. Any editor that saves the right file type works:

- **Images:** [GIMP](https://www.gimp.org/) (free) or Photoshop.
- **Sounds:** [Audacity](https://www.audacityteam.org/) (free).
- **Text:** [Notepad++](https://notepad-plus-plus.org/) or [VS Code](https://code.visualstudio.com/), for small edits to tool files.

## Advanced toolchain

Add these when you move on to models and animations.

<ToolCard
  name="Blender and add-ons"
  href="/docs/deadlock/tools/blender-add-ons"
>
  Edit 3D models. BlenderSource2Tools exports DMX, SourceIO imports game models,
  and PulseSrcOps handles animations.
</ToolCard>
<ToolCard
  name="CS2 Workshop Tools"
  href="/docs/deadlock/tools/cs2-workshop-tools"
  badge="Advanced"
>
  Valve's free Counter-Strike 2 tools. Hero model swaps use them for the
  AnimGraph 2 setup that CSDK 12 cannot do.
</ToolCard>
<ToolCard
  name="Helper tools and scripts"
  href="/docs/deadlock/tools/helper-tools"
  badge="Advanced"
>
  Build scripts, VPK merging, AnimGraph 2 helpers, and a tracker that shows what
  each update changed.
</ToolCard>

Two more extras live on the tool pages above. The Source 2 Viewer command line handles batch exports. CSDK 12 can take the full game files, which you need only for maps, posing, and in-engine previews.

## Tools to skip

| Skip this                                                        | Why                                                                          | Use instead                                                            |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| CSDK 10                                                          | Outdated. Its own page points to CSDK 12. Some older tutorials still use it. | [CSDK 12](/docs/deadlock/tools/csdk-12)                                |
| The original Blender Source Tools                                | Lacks the Source 2 fixes Deadlock models need.                               | [A Source 2 fork](/docs/deadlock/tools/blender-add-ons)                |
| Valve's `vpk.exe`                                                | Has no Source 2 docs. No Deadlock guide uses it.                             | [Source 2 Viewer or CSDK 12](/docs/deadlock/basics/pack-a-vpk)         |
| Valve tools repacked by unknown uploaders                        | You cannot check what is inside.                                             | [Official CS2 Workshop Tools](/docs/deadlock/tools/cs2-workshop-tools) |
| Anything sold as a "mod menu", ESP, or a "Deadlock 2026" toolkit | These are tools for unfair play, or they carry malware.                      | Nothing. Never download them.                                          |

## How to spot a real tool

- Real creator tools are open-source GitHub projects from known authors, or tool pages in [GameBanana's Deadlock tools section](https://gamebanana.com/tools/games/20948).
- Download each tool from the link on its wiki page, not from a search result or a video comment.
- A tool can be an `.exe`. A mod never is. [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) explains how to check a mod download.
