<LevelPill level="intermediate" />

CSDK 12 compiles your edited files into files Deadlock can read. Every current guide uses it for materials, sounds, UI images, and models. The first install is in [Set up your creator tools](/docs/deadlock/getting-started/creator-setup). This page is the reference for everything after that.

<Callout type="warning" title="CSDK 12 is an unofficial community tool">
  Valve did not make CSDK 12 and does not support it. Community members built it
  from Valve's Counter-Strike 2 Workshop Tools, Deadlock files, and their own
  fixes. It has no named maintainer and no license. Download it only through its
  community page.
</Callout>

## What you need

<ToolCard name="Source 2 Viewer" href="/docs/deadlock/tools/source-2-viewer">
  Gets files out of the game.
</ToolCard>

- A Windows PC. CSDK 12 runs on Windows only.
- Steam, running whenever you use the tools.

## At a glance

| Detail         | CSDK 12                                                                                                     |
| -------------- | ----------------------------------------------------------------------------------------------------------- |
| Full name      | Community Source Development Kit 12                                                                         |
| Version to get | Reduced CSDK 12. It leaves out the full game files and still edits models, sounds, textures, UI, and vdata. |
| Get it         | The CSDK 12 page on Deadlock Modding Notes                                                                  |
| Built for      | The "6 Heroes" update of 2025-08-19. The page was last updated 2026-08-10.                                  |
| Cost           | Free                                                                                                        |

CSDK 12 is pinned to an older game build. Newer formats, such as AnimGraph 2 animation clips, compile in an outdated form. Hero model swaps use the [CS2 Workshop Tools](/docs/deadlock/tools/cs2-workshop-tools) for that part.

## Get started

<Steps>
<Step>

### Download and unzip

1. Open the [CSDK 12 page](https://deadlockmodding.pages.dev/modding-tools/csdk-12).
2. Use the **Download** link in its Installation section. The archive holds a `Reduced_CSDK_12` folder.
3. Unzip it to a short path, such as `C:\Reduced_CSDK_12`.

Do not unzip it on the Desktop or in Documents. OneDrive often syncs those folders, and that breaks the tools. Keep it out of the Deadlock game folder too.

Windows may show a SmartScreen warning for the CSDK 12 programs. Continue only if you got the archive from the community page.

### Open the launcher

1. Start Steam.
2. Open `csdkcfg.exe` in the `Reduced_CSDK_12` folder. This is the launcher, also called the Configuration Tool.
3. Select an addon and click **Launch Tools**. A VConsole window opens first, then the Asset Browser.

Older CSDK 12 downloads start from `game\bin\win64\Deadlock_with_tools.exe` instead. Some guides call it the "Project8 CFG Tool".

### Pick a binary

The binary picker sits in the top left of the launcher. Each choice starts a different build of the tools.

| Binary       | Use it for                                                                     | Watch out                                               |
| ------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------- |
| `bin`        | Almost everything. Start here.                                                 | Can crash when it previews some projected particles.    |
| `bin_tools`  | Previewing projected particle effects                                          | Crashes when it compiles AnimGraph 1 models.            |
| `bin_server` | Starting Deadlock in server mode to preview mods. Compiles VData and Panorama. | Needs the full game files. Will not start without them. |
| `bin_cs2`    | The GUI Map Compiler, for map lighting                                         | Maps only.                                              |

</Step>

## Addons and templates

An addon is one mod project. CSDK 12 gives each addon two folders, and your paths must match the game's paths.

<img
  src="/wiki-images/deadlock-tools-csdk-12-3.webp"
  alt="An addon's content folder holds the source file example_sound.wav. Recompile Full writes example_sound.vsnd_c to the same path in the game folder. You copy the compiled file from there into your VPK."
/>

- Click **Create New Addon** in the launcher. Name it in lowercase with no spaces or special characters, or the launcher hides it.
- Right-click an addon for its menu: **Explore Content Folder**, **Explore Game Folder**, **Duplicate**, **Compile All Assets**, **Create VPK**, and **Delete**.
- CSDK 12 ships template addons: `hero_image_template` for portraits and icons, and the **Billy Audio Template** for sounds. Duplicate a template to start from it.

We do not use **Create VPK** yet. The packing guide in Next steps explains why.

## Compile

You have three ways to compile:

<Tabs items={["Automatic", "One file", "The whole addon"]}>
<Tab value="Automatic">

While the tools run, they watch the content folder and compile new files into the game folder.

</Tab>
<Tab value="One file">

In the Asset Browser, right-click the file and choose **Recompile > Full**.

</Tab>
<Tab value="The whole addon">

In the launcher, right-click the addon and choose **Compile All Assets**.

</Tab>
</Tabs>

To find the result, right-click the asset and choose **File '...' > Open Folder**, or use **Explore Game Folder**. Compiled files end in `_c`.

To see only your files, click the "x/y mods" counter in the Asset Browser. Pick **Only** next to your addon.

When a compile fails, read the VConsole window. Compile errors show up there.

### From the command line

Every compile runs `resourcecompiler.exe`. Build scripts call it from `game\bin_tools\win64\`:

```
resourcecompiler.exe -i "<full path to your source file>"
```

## The tools inside

| Tool                        | What Deadlock creators use it for                                              |
| --------------------------- | ------------------------------------------------------------------------------ |
| Asset Browser               | The hub. Browse, preview, open editors, and recompile.                         |
| Material Editor             | Make and fix `.vmat` materials. A purple checkerboard means a missing texture. |
| ModelDoc                    | Build hero and prop models from your exported meshes.                          |
| Particle Editor             | Recolor ability particles.                                                     |
| VConsole                    | Read compile errors and logs.                                                  |
| Resource Compiler           | Compiles everything. The Asset Browser uses it for you.                        |
| CS2 Workshop Manager        | A packing trick. The packing guide in Next steps shows it.                     |
| Multichunk Workshop Manager | Packs mods over 2 GB in parts.                                                 |
| Hammer, S2FM                | Maps, posing, and renders. Both need the full game files.                      |

No AnimGraph editor exists for Deadlock yet. CSDK 12 cannot author animation graphs.

## Full game files (advanced, optional)

Skip this if you are new. You need the full game files only for `bin_server`, Hammer, and S2FM. Want only to study how heroes are built? Use the lighter option.

<Tabs items={["Full game files", "Lighter option: hero models"]}>
<Tab value="Full game files">

- The [CSDK 12 page](https://deadlockmodding.pages.dev/modding-tools/csdk-12) has the steps. They use [DepotDownloader](https://github.com/SteamRE/DepotDownloader) to fetch an older Deadlock build, then Source 2 Viewer to unpack it into the CSDK folder.
- A `401` error means Valve blocks that old build for your account, which happens if you got Deadlock later. The page offers a workaround. If that fails too, skip the full game files.

</Tab>
<Tab value="Lighter option: hero models">

Export only the hero model folders into CSDK 12. You get hero models for reference.

1. In Source 2 Viewer, open `pak01_dir.vpk` and go to `models`.
2. Right-click `heroes_staging` and choose **Export as is**.
3. Pick `Reduced_CSDK_12\game\citadel` as the target folder.
4. Repeat for `heroes_wip`.
5. Open CSDK 12 and filter the Asset Browser for `vmdl`. The heroes now show with their materials.

Both folders together take about 4 to 5 GB, and CSDK 12 starts slower with more files.

</Tab>
</Tabs>

## Common problems

<Accordions>
<Accordion title="Your addon is missing from the launcher">

The name has a capital letter, a space, or a special character. Rename the folder in both `content/citadel_addons` and `game/citadel_addons`. Then click **Refresh addons list**.

</Accordion>
<Accordion title="The tools do not start">

Start Steam first. Move the `Reduced_CSDK_12` folder out of OneDrive folders.

</Accordion>
<Accordion title="CSDK 12 crashes when it opens a decompiled hero model">

Newer Source 2 Viewer builds add AnimGraph 2 nodes. CSDK 12 cannot read them. [Hero swap part 2](/docs/deadlock/models/hero-swap-modeldoc) shows how to remove them.

</Accordion>
<Accordion title="Hero materials are missing in the tools">

Export the hero model folders, as shown in the lighter option tab above.

</Accordion>
<Accordion title="The game will not find a match">

The game refuses to queue while Tools mode runs. Close CSDK 12 before you play online.

</Accordion>
</Accordions>

More fixes are in [Errors when making mods](/docs/deadlock/errors/creator-errors).
