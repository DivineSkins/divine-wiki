Counter-Strike 2 Workshop Tools are Valve's free creator tools for CS2. Deadlock creators use them for one job: the final compile of a hero model. You only need them for a [hero model swap](/docs/deadlock/models/hero-model-swap) and some [animation work](/docs/deadlock/animations/replace-an-animation).

- A Windows PC. The tools run on Windows only.
- A Steam account with Counter-Strike 2 in your library. CS2 is free.

## Why CSDK 12 is not enough

Almost every Deadlock hero animates with AnimGraph 2 (AG2). Your hero model must point to the hero's original AG2 skeleton and animation graphs. Without these references, the hero stands in an A-pose or does not turn with the camera.

CSDK 12 cannot compile these references into a model. CS2 Workshop Tools can. So you build the model in CSDK 12, then do the last compile in CS2.

The Deadlock Modding Notes animation guide also uses CS2 tools for animation clips. CSDK 12 has no AG2 Clip Viewer, and it writes clips in an older format.

## Get the tools from Steam

1. Add [Counter-Strike 2](https://store.steampowered.com/app/730/CounterStrike_2/) to your Steam library.
2. Install Counter-Strike 2 Workshop Tools. Valve's Workshop Tools page, in the row at the top, has the install steps.
3. Start Counter-Strike 2 Workshop Tools from your Steam library.

Neutral's guide says CS2 does not need to be fully downloaded for the tools to start. This may differ on your PC.

## Do the final compile in CS2

<Steps>
<Step>

### Move your model into a CS2 addon

CS2 Workshop Tools keep their addons inside your Counter-Strike 2 install folder. Like CSDK 12, each addon has two folders:

| Folder                         | What goes there                          |
| ------------------------------ | ---------------------------------------- |
| `content/csgo_addons/<addon>/` | Source files you copy in from CSDK 12    |
| `game/csgo_addons/<addon>/`    | Compiled files, including your `.vmdl_c` |

1. Close CSDK 12.
2. Start CS2 Workshop Tools and create a new addon. Give it the same name as your CSDK 12 addon.
3. Open your CSDK 12 content folder: `Reduced_CSDK_12/content/citadel_addons/<addon>/`.
4. Copy its `models` folder into the CS2 addon's content folder. Keep the same folder structure.
5. Launch the tools for your CS2 addon.
6. Open your hero's `.vmdl` in ModelDoc.

{/* SCREENSHOT: deadlock-tools-cs2-workshop-tools-3.webp, File Explorer showing the copied models folder inside content/csgo_addons/<addon> */}

</Step>
<Step>

### Add AnimGraph 2 and compile

In ModelDoc you add the AG2 skeleton and graph references, then compile. Hero swap part 4, in Next steps, lists the nodes and where to find each value.

</Step>
<Step>

### Take only the model back

CS2 does not have Deadlock's shaders, so it cannot build your materials. Your mod mixes files from both tools.

1. Compile the model in CS2 Workshop Tools.
2. Open the CS2 addon's game folder: `game/csgo_addons/<addon>/`.
3. Copy only the compiled `.vmdl_c`.
4. Build your staging folder from CSDK 12's game folder, as in [Pack your mod into a VPK](/docs/deadlock/basics/pack-a-vpk#build-a-staging-folder).
5. Delete the CSDK 12 `.vmdl_c` in the staging folder.
6. Paste the `.vmdl_c` from CS2 in its place. Check that it has the original model's file name, as Source 2 Viewer shows it.
7. Pack the staging folder.

</Step>
</Steps>

## Red checkerboards are normal

CS2 Workshop Tools show Deadlock materials as red checkerboards. CS2's shaders differ from Deadlock's. You may also see an error when you open the model. Ignore both, and compile your materials and textures in CSDK 12 only.

## Other ways

- **DeadlockTools** (community tool, unofficial) writes the AG2 references into a model you already compiled in CSDK 12. Then you skip CS2 entirely. Its author warns that its file-writing features are experimental. [Helper tools and scripts](/docs/deadlock/tools/helper-tools) covers it.
- **Dota 2 Workshop Tools** are named in some guides as another option. No guide we found shows the steps, so this wiki uses CS2.

## Common problems

<Accordions>
<Accordion title="The hero A-poses or does not turn in game">

The AG2 references are missing. Compile the final model in CS2, as in Hero swap part 4.

</Accordion>
<Accordion title="Materials are red checkerboards in CS2">

This is normal. Take only the `.vmdl_c` from CS2.

</Accordion>
<Accordion title="LODs break after the CS2 compile">

Pugzilla's fix: export your DMX files from Blender straight into the CS2 addon's content folder. Then compile again.

</Accordion>
</Accordions>
