Source 2 Viewer opens Deadlock's game files. Use it to find the file you want to change, preview it, and export a copy you can edit. It also packs mods into VPKs. To install it with the rest of your tools, follow [Set up your creator tools](/docs/deadlock/getting-started/creator-setup).

## What you need

<Requirements>
  <Requirement icon="Monitor" note="for the app">
    Windows PC
  </Requirement>
  <Requirement icon="Steam">Deadlock on Steam</Requirement>
</Requirements>

The app runs on Windows. Its site lists Windows 11 and OpenGL 4.6. The command-line version also runs on macOS and Linux.

## Download the dev build

1. Open s2v.app with the **Download** button at the top of this page.
2. Click **Download dev build**, under the big download button.
3. Put the file in its own folder. There is no installer.

Every current Deadlock guide uses the dev build, because Deadlock fixes land there first. If you prefer a normal release, use **Download v20.0** or newer. Older releases have bugs with hero models. See [Known issues by version](#known-issues-by-version).

## Open the game files

1. Open the **Explorer** tab. Source 2 Viewer finds your Steam games on its own. Expand Deadlock.
2. Or click <MenuPath path="File > Open" /> and pick `Deadlock/game/citadel/pak01_dir.vpk`.
3. Open only the `_dir` file. Source 2 Viewer loads the numbered `pak01_000.vpk` parts with it.

## Export as is, or decompile

Right-click any file or folder to export it. There are two modes.

<img
  src="/wiki-images/deadlock-tools-source-2-viewer-5.webp"
  alt="Export as is gives the same compiled file. Decompile and export gives editable files: a model becomes a vmdl with DMX or glTF, a material becomes a vmat with PNG images, a texture becomes PNG, a sound becomes WAV or MP3."
/>

| You export                | Save it to                                                                  |
| ------------------------- | --------------------------------------------------------------------------- |
| One file                  | The matching folder of your addon, inside `content/citadel_addons/<addon>/` |
| A folder or several files | The addon's root folder. Source 2 Viewer rebuilds the subfolders for you.   |
| Reference copies          | A work folder outside `content/`. Keep glTF files and test exports there.   |

## Export by file type

<Tabs items={["Models", "Textures and sounds"]}>
<Tab value="Models">

- For a model swap, export the hero model twice. The `.vmdl` export is the ModelDoc project, with DMX meshes, attachments, and hitboxes. The glTF export is the easiest file to open in Blender.
- Pick `.gltf`, not `.glb`. A `.glb` file breaks above 2 GB.
- glTF holds only the most detailed version of the model (LOD0). It has no hitboxes, and cloth bones come out stiff.
- Hero animations sit in a `clips` folder next to the model. Decompile that folder to get `.vnmclip` and DMX files.

The Blender import guide in Next steps has the full steps.

{/* SCREENSHOT: deadlock-tools-source-2-viewer-7.webp, the export type dropdown for a model with vmdl and gltf options */}

</Tab>
<Tab value="Textures and sounds">

- Textures export as PNG. HDR textures export as EXR. Only the largest size is saved.
- An export comes from the compressed game file, not the artist's original. Paint at full size instead of saving the same export over and over.
- Masks and normal maps look wrong in plain color. Check each channel in the viewer.
- Sounds export as WAV or MP3.
- Right-click a folder to export everything in it at once.

</Tab>
</Tabs>

## Create a VPK

Source 2 Viewer can pack a folder into a VPK with <MenuPath path="File > Create VPK from folder" />. Its own docs call the packing screen basic, but most Deadlock guides use it. The packing guide in Next steps has the full steps.

Some older releases had bugs when building VPKs. Use the dev build for packing too.

## Command line (optional)

`Source2Viewer-CLI` runs on Windows, macOS, and Linux. Use it for batch exports and scripts. These examples follow the official docs, with Deadlock paths filled in:

```
# List every file in a hero folder
Source2Viewer-CLI -i "<Deadlock>/game/citadel/pak01_dir.vpk" --vpk_list -f "models/heroes_wip/<codename>/"

# Export every hero texture as PNG
Source2Viewer-CLI -i "<Deadlock>/game/citadel/pak01_dir.vpk" -o "exported/" -d --vpk_extensions "vtex_c" --vpk_filepath "models/heroes_wip/"

# Pack a folder into a VPK
Source2Viewer-CLI -i "mymod" --vpk_create "pak05_dir.vpk"
```

## Known issues by version

<Accordions>
<Accordion title="19.1 (2026-04-09): decompiled hero models include AnimGraph 2 nodes">

CSDK 12 can crash when it opens them. The model guides delete those nodes first.

</Accordion>
<Accordion title="Builds before 2026-08-04: attachment values drifted on decompile">

Modded heroes got a camera stuck in the center of the screen. Fixed in 20.0.

</Accordion>
<Accordion title="20.0 (2026-08-17): glTF export handles axes differently">

Blender steps written before August 2026 may tell you to rescale or rotate bones you no longer need to.

</Accordion>
<Accordion title="Still open: some AnimGraph 2 clip and skeleton exports get the wrong name or folder">

Check the paths after you decompile clips.

</Accordion>
</Accordions>
