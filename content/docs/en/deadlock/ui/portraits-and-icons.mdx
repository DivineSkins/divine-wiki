<LevelPill level="beginner" />

Replace hero portraits, minimap icons, ability icons, or item art with your own: compile your images with CSDK 12's image template, rename them, and pack them as a mod. First set up your tools with [Set up your creator tools](/docs/deadlock/getting-started/creator-setup).

## What you need

<ToolCard name="Source 2 Viewer" href="/docs/deadlock/tools/source-2-viewer">
  Shows the original images, their names, and their sizes.
</ToolCard>
<ToolCard name="CSDK 12" href="/docs/deadlock/tools/csdk-12">
  Compiles your images with its image template.
</ToolCard>

- An image editor that saves PNG with transparency, such as GIMP or Photoshop.
- Your own art. Draw it yourself or use art you have permission to share.
- The hero's codename.

## Keep it fair

Icon mods change art only. Other players see the normal game.

- Keep icons at their normal size and about as easy to read as the originals.
- Never make objective or enemy icons brighter, bigger, or glowing.
- Never add information the game hides, such as timers or health numbers. The full list is in [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe).

## Which image is which

Hero images live in `panorama/images/heroes/`. Each file name starts with the hero's image codename, which can differ from the hero's other codenames in [Hero names and file paths](/docs/deadlock/basics/hero-codenames). For Haze it is `haze`:

| File                             | Where it shows                          |
| -------------------------------- | --------------------------------------- |
| `haze_card_psd.vtex_c`           | Hero portrait at the top of the HUD     |
| `haze_card_critical_psd.vtex_c`  | Portrait when the hero is low on health |
| `haze_card_gloat_psd.vtex_c`     | Kill streak portrait                    |
| `haze_sm_psd.vtex_c`             | Small icon, used in the kill feed       |
| `haze_mm_psd.vtex_c`             | Minimap icon                            |
| `haze_vertical_psd.vtex_c`       | Tall portrait on hero select            |
| `backgrounds/haze_bg_psd.vtex_c` | Hero background                         |

Other images:

| Images        | Folder                                                   |
| ------------- | -------------------------------------------------------- |
| Ability icons | `panorama/images/hud/abilities/<codename>/`              |
| Item art      | `panorama/images/upgrades/` and `panorama/images/items/` |

## Make the mod

Pick a route. The full workflow works for every image. The quick option builds the mod in your browser, with no CSDK 12.

<Step>

### Check the original size

Your image must be the exact same size as the original.

1. Open `Deadlock/game/citadel/pak01_dir.vpk` in Source 2 Viewer.
2. Go to `panorama/images/heroes/`.
3. Double-click the image you want to replace. Write down its width and height.
4. Repeat this for every image you plan to replace. Each image type has its own size.
5. Optional: right-click the image and choose **Decompile & export** to get a PNG to use as a guide.

</Step>
<Step>

### Duplicate the image template

CSDK 12 comes with a ready-made image addon called `hero_image_template`.

1. Open the CSDK 12 launcher. Keep Steam running.
2. Right-click **hero_image_template** and choose **Duplicate Addon**.
3. Name the copy in lowercase with no spaces, for example `hazeicons`.
4. Right-click your new addon and choose **Explore Content Folder**.
5. Open `panorama/images/heroes/`. It holds the template's sample images for Grey Talon.
6. Delete the sample images. If you keep them, your mod also changes Grey Talon's icons.

{/* SCREENSHOT: deadlock-ui-portraits-and-icons-3.webp, the CSDK 12 launcher with Duplicate Addon on hero_image_template */}

{/* NEEDS HANDS-ON TEST: launcher menu labels and the template's exact contents in the current CSDK 12 zip. */}

</Step>
<Step>

### Make your images

1. Create a new image at the exact size you wrote down, with a transparent background.
2. Draw your art.
3. Export it as PNG into `content/citadel_addons/hazeicons/panorama/images/heroes/`.
4. Name it like the original, without the ending. For example, `haze_card_psd.vtex_c` becomes `haze_card.png`.

Your addon's content folder now looks like this:

<Step>

### List them in image_compiler.vdata

This file in the template's `panorama` folder tells CSDK 12 which images to compile. Every image in your mod needs one line in it.

1. Open `panorama/image_compiler.vdata` in a text editor, such as Notepad.
2. Find the lines with the template's sample file names.
3. Replace each sample name with one of your file names. Include the `.png` ending.
4. Add a line for each extra image. Copy the format of an existing line.
5. Save the file.

Each line points at an image in your addon's `panorama/images` folder. The Haze card line looks like this:

```text
panorama:"file://{images}/heroes/haze_card.png"
```

For ability icons or item art, put the image in the matching folder and change the path in the line.

<Step>

### Compile

1. In the CSDK 12 launcher, select your addon and click **Launch Tools**. The Asset Browser opens.
2. Search for `image_compiler` in the Asset Browser, not for your image names.
3. Right-click `image_compiler` and choose **Recompile > Full**. This compiles every image in the list.
4. Close the tools.
5. Right-click your addon in the launcher and choose **Explore Game Folder**.
6. Open `panorama/images/heroes/`. Your compiled `.vtex_c` files are there.

{/* SCREENSHOT: deadlock-ui-portraits-and-icons-6.webp, Asset Browser right-click menu with Recompile > Full on image_compiler */}

</Step>
<Step>

### Rename to the original names

The game only loads a file with the exact original name, and the compiled files may not have it.

1. Make a staging folder, such as `hazeicons_pack`, with the path `panorama/images/heroes/` inside.
2. Copy only your compiled images into it. Leave out `image_compiler.vdata_c`.
3. Rename each file to the exact original name from Source 2 Viewer. For example, `haze_card_png.vtex_c` becomes `haze_card_psd.vtex_c`.

This rename step comes from guides made before the September 2026 update. If your files already have the original names, skip it.

### Pack and test

1. Pack your staging folder into a VPK with [Pack your mod into a VPK](/docs/deadlock/basics/pack-a-vpk).
2. Load the mod and check every image in game with [Test your mod in game](/docs/deadlock/basics/test-your-mod).

<Tab value="Quick option in the browser">

Deadlock Forge builds image mods in your browser, with no CSDK 12. Other browser tools are in [Make mods without installing tools](/docs/deadlock/tools/browser-builders).

1. Open [Texture Forge](https://deadlockforge.net/texture/) for portraits, ability icons, and minimap icons. Open [Item Forge](https://deadlockforge.net/item/) for shop item art.
2. In Texture Forge, pick the hero, then the image you want to replace. In Item Forge, pick the item from the Weapon, Vitality, or Spirit tab.
3. Upload your image as PNG, JPG, or WebP.
4. Download the VPK it builds.
5. Rename it to a name like `pak05_dir.vpk` if needed. The rules are in [Pack your mod into a VPK](/docs/deadlock/basics/pack-a-vpk).
6. Install it with [Deadlock Mod Manager](/docs/deadlock/getting-started/install-with-mod-manager) or [by hand](/docs/deadlock/getting-started/install-by-hand).

## Common problems

<Accordions>
<Accordion title="The image is stretched, cropped, or blurry">

Its size does not match the original. Check the size in Source 2 Viewer and make it again.

</Accordion>
<Accordion title="The game shows the old image">

The compiled file name or folder is wrong. Compare both with the original.

</Accordion>
<Accordion title="Grey Talon's icons changed too">

You left the template's sample images in your mod. Delete them and pack again.

</Accordion>
<Accordion title="The compile fails">

Check that every line in `image_compiler.vdata` matches a real file name. One older guide uses the `bin_server` option for this compile, which needs the optional full game files.

</Accordion>
<Accordion title="It worked before an update">

Updates can rename or move images. Check the names in Source 2 Viewer again.

</Accordion>
</Accordions>

More fixes are in [Errors when making mods](/docs/deadlock/errors/creator-errors).
