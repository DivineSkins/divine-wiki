Every Deadlock mod uses the same few ideas and steps. Learn them once here, then use them for sounds, textures, icons, and models. No tools yet? Start with [Set up your creator tools](/docs/deadlock/getting-started/creator-setup).

## What do you want to do?

- [How Deadlock mods work](/docs/deadlock/basics/how-mods-work): what a VPK is, why file paths matter, and which mod wins.
- [Hero names and file paths](/docs/deadlock/basics/hero-codenames): look up any hero's model, skeleton, portrait, and sound paths.
- [Pack your mod into a VPK](/docs/deadlock/basics/pack-a-vpk): turn your compiled files into a `pakNN_dir.vpk` the game loads.
- [Test your mod in game](/docs/deadlock/basics/test-your-mod): load your mod on a private map and check every part of it.
- [Deadlock file types](/docs/deadlock/basics/file-types): what each file type holds, which tool makes it, and whether you ship it.
