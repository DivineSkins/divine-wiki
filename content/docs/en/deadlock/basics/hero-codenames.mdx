Deadlock's files do not use the hero names you see in game. They use Valve's internal codenames, and one hero can have several. This page lists the file paths for every hero. To look inside the files yourself, install Source 2 Viewer with [Set up your creator tools](/docs/deadlock/getting-started/creator-setup).

## What you need

- Source 2 Viewer, to check paths in the game files.
- Deadlock, updated to the latest version.

## Why codenames matter

A mod only replaces a file at the exact same path ([How Deadlock mods work](/docs/deadlock/basics/how-mods-work) explains why). Those paths use codenames. Billy's model, for example, is in `models/heroes_wip/punkgoat/`.

- **One hero, several names.** Codenames differ by file type. Lady Geist's model folder is `geist`, her skeleton is `ghost`, and her portraits start with `spectre`.
- **Names change.** Valve moves and renames files in updates. Old guides often show paths that no longer exist.
- **Two hero folders.** Hero models are in `models/heroes_wip/` or `models/heroes_staging/`. Some older docs say `models/heroes/`, but that folder now holds only camera files.

How to read each column:

- **Model:** add `models/` before the path and `.vmdl_c` after it. Example: `models/heroes_wip/inferno/inferno.vmdl_c`.
- **Skeleton:** add `models/` before the path and `.vnmskel_c` after it.
- **Graph:** the hero's animation graph is `animgraphs/animgraph2/hero/hero.vnmgraph+<graph>.vnmgraph_c`.
- **Portrait:** the start of the hero's interface images, such as `panorama/images/heroes/<portrait>_card_psd.vtex_c`.
- **Sounds:** the hero's sound event file, `soundevents/hero/<sounds>.vsndevts_c`.

## Heroes with special cases

- **Haze.** Her body model is in `heroes_staging/haze/`. Her knife material is in `models/heroes_wip/haze/materials/`, and her gun material is in `models/heroes_staging/haze_v2/materials/`. Some guides list Haze under `heroes_wip` because of the knife.
- **Pocket.** His model is in `heroes_wip/pocket/`, but his skeleton, portraits, and briefcase use the old name `synth`. The briefcase material is `models/heroes_staging/synth/materials/pocket_suitcase.vmat_c`.
- **Ivy.** Her model folder is `ivy`. Her skeleton, portraits, and sounds use her old name `tengu`.
- **Kelvin and Viscous.** They share one skeleton: `heroes_staging/kelvin_v2/maya/kelvin`. Viscous's graph is `viscous_v1`.
- **Lady Geist.** She has three names. Her model and sounds use `geist`, her skeleton uses `ghost`, and her portraits use `spectre`.
- **Grey Talon.** His model is `archer`, but his sound file is `orion`. His owl has its own skeleton: `heroes_staging/grey_talon/grey_talon_owl`.
- **Silver.** The wolf form has its own files in `heroes_wip/werewolf/transform/`, with its own skeleton.
- **Graves.** He has extra rigs in a `shambler` folder inside his `necro` folder.
- **Mo & Krill.** The model is `digger`, the skeleton is `mo_krill`, and the sound file is `krill`.
- **Rem.** The model file is `familiar_wip`, but the skeleton is `familiar`.
- **Yamato.** Her model is in `heroes_staging/yamato_v2/`, but her skeleton is in `heroes_wip/yamato/`.
- **Vyper.** Her portraits start with `kali`, an old codename.
- **Wraith.** Her hero data picks material group 1 for her model. Check which materials that group uses before you edit them.
- **Violet and Nurse Harrow.** Build 6779 has no main animation graph and no sound event file for them under the usual names. They may still use an older animation system. {/* NEEDS HANDS-ON TEST: open Violet's and Nurse Harrow's vmdl_c Data tab in Source 2 Viewer and check which animation graph and sound files they use (gap G05) */}
- **The newest heroes.** Nurse Harrow, Rat King, Solomon, Deadman Danny, Baba, and Violet arrived with the "City Never Sleeps" update. They unlock through about 2026-10-20. Baba is still marked as in development in build 6779. Expect their paths to change.

Ability effects are in `particles/abilities/<codename>/`, and ability icons in `panorama/images/hud/abilities/<codename>/`. Those folder names can differ again from the table. Check them in Source 2 Viewer.

Hero model swaps need every column of this table. A full guide is coming. {/* LINK LATER: /docs/deadlock/models/hero-model-swap */}

## Old names you will still see

Old guides, forum posts, and the game's own data still use older names. These all point to the same heroes:

| Hero       | Older or internal names                 |
| ---------- | --------------------------------------- |
| Abrams     | `hero_atlas`, `atlas_detective`, `bull` |
| Calico     | `nano`                                  |
| Dynamo     | `sumo`                                  |
| Grey Talon | `hero_orion`, `orion`, `archer`         |
| Holliday   | `astro`                                 |
| Ivy        | `hero_tengu`, `tengu`                   |
| Lady Geist | `hero_ghost`, `ghost`, `spectre`        |
| McGinnis   | `hero_forge`, `forge`, `engineer`       |
| Mo & Krill | `digger`                                |
| Paradox    | `chrono`                                |
| Pocket     | `hero_synth`, `synth`                   |
| Seven      | `gigawatt`                              |
| Vindicta   | `hornet`                                |

- Names that start with `hero_` are the keys in Valve's hero data file, `scripts/heroes.vdata`.
- Old guides may show old model folders. Abrams was in `heroes_staging/atlas_detective_v2/`, McGinnis in `heroes_staging/engineer/`, and Infernus in `heroes_staging/inferno_v4/`. Mods at those paths no longer work.
- A hero can have several folders, such as `haze` and `haze_v2`. Old folders often stay in the game files unused.
- The game files also list unreleased heroes, such as Raven and Wrecker. Most point to a placeholder model. Ignore them.

## Check paths yourself after a patch

Do this after every big update, or when a path in this table does not work.

1. Open Source 2 Viewer.
2. Open `game/citadel/pak01_dir.vpk` from your Deadlock folder.
3. Press **Ctrl+F** and search for the hero's codename.
4. Open the hero's `.vmdl_c` file in `models/heroes_wip/` or `models/heroes_staging/`.
5. Click the **References** tab. It lists the real paths of the model's materials.
6. Click the **Data** tab. It shows the skeleton and animation graph paths.
7. Compare what you see with the table. If a path moved, move your mod's files to match.
