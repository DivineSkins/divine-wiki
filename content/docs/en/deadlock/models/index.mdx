Model swaps change the shape of a prop or a hero, not only its colors. Keep every model the same size and shape as the original. [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) explains why.

## Start here

New to models? Start with the soul container. It teaches the tools on a small model.

<ToolCard
  name="Your first model swap: a soul container"
  href="/docs/deadlock/models/prop-swap"
  badge="Recommended"
>
  Replace the soul container with your own 3D model. Fit it to one bone, swap
  the mesh in ModelDoc, and add one material.
</ToolCard>
<ToolCard
  name="Import a Deadlock model into Blender"

>
  Get a hero or prop into Blender to edit it or use it as a reference.
