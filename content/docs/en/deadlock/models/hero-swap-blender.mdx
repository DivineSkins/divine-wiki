## Rig and export

<Steps>
<Step>

### Export the hero

Use the hero you picked in the overview. This guide uses Vyper, whose model sits at `models/heroes_staging/viper/viper.vmdl_c`. Other heroes are in [Hero names and file paths](/docs/deadlock/basics/hero-codenames).

You need the hero twice: as a model file for ModelDoc, and as a glTF for Blender.

1. Open Source 2 Viewer and open `Deadlock/game/citadel/pak01_dir.vpk`.
2. Go to `models/heroes_staging/viper/`.
3. Right-click `viper.vmdl_c` and choose **Decompile & export**.
4. Pick the model format (`.vmdl`). Save it into your addon at the same path: `content/citadel_addons/<addon>/models/heroes_staging/viper/`.
5. Export the glTF as [Import a Deadlock model into Blender](/docs/deadlock/models/import-into-blender) shows. Save it in a work folder outside your addon.

The decompile writes a `.vmdl` file plus DMX files for the hero's meshes. Part 2 opens that `.vmdl`.

{/* NEEDS HANDS-ON TEST: the format choice for a .vmdl decompile in the current Source 2 Viewer save dialog. */}

</Step>
<Step>

### Load the hero in Blender

1. Import and clean the glTF with the same Blender import guide. Follow route 1 up to and including **Fix size and facing**.
2. Check the result. The hero faces +X, has no animations and no `$cloth` bones, and the armature is in rest pose.
3. Scale the hero to Source 2 size. Select the armature and every mesh, press S, type `39.37`, and press Enter.
4. Press Ctrl+A and choose **All Transforms**.
5. Save the `.blend` file.

The 39.37 scale turns meters into inches, the unit the Source 2 tools use. Do it once, here. Then you fit your character at the final size.

{/* NEEDS HANDS-ON TEST: whether the 39.37 scale step is still needed with Source 2 Viewer 20.0+ glTF exports, and whether the bone rescale numbers apply (conflict C32). This page does not print a bone scale number on purpose. */}

**Doing the dry run?** The overview suggests one full run with the unchanged hero first. Skip to [Sort meshes into collections](#sort-meshes-into-collections), export the hero's own meshes, and follow parts 2 to 4. Come back here once the plain hero works in game.

</Step>
<Step>

### Fit your model to the hero

<Callout type="danger" title="Keep the hero's size and shape">
  Do not make the hero smaller, thinner, or harder to see. You also see your
  skin on enemies who play this hero. Its size changes how easy they are to see
  and aim at. Players treat that as an unfair mod. See [What's allowed and how
  to stay safe](/docs/deadlock/getting-started/stay-safe).
</Callout>

1. Import your character into the same Blender file.
2. Delete your character's own armature. Your mesh uses the hero's skeleton from now on.
3. Move and scale your mesh until it lines up with the hero's body: head, shoulders, elbows, hips, and knees.
4. Keep the overall height and width close to the hero's.
5. Select your mesh, press Ctrl+A, and choose **All Transforms**.

**Never edit the hero's bones.** Do not move, rename, or delete them. The game plays the hero's animations on those exact bones. You may add new bones for cloth chains, such as a tail or long hair.

{/* SCREENSHOT: deadlock-models-hero-swap-blender-2.webp, the hero armature and an original test mesh lined up in Blender, front view */}

</Step>
<Step>

### Rig your mesh to the skeleton

1. Select your mesh, then Shift-click the hero's armature.
2. Press Ctrl+P and choose **Armature Deform**.
3. Copy the weights from the hero's body mesh to your mesh. Use Blender's **Data Transfer** modifier, or the Mesh Data Transfer add-on.
4. Switch to Pose Mode and rotate a few bones. Your mesh should follow them.
5. Fix the bad spots with weight painting. Strange bending in game almost always comes from weights.
6. Move the hero's original meshes into a separate collection. You do not export them.

Rigid parts, such as a helmet or an armor plate, should follow one bone only. In Edit Mode, select the part's vertices, pick that bone's vertex group, and click **Assign**. Weight small accessories to the nearest bone.

{/* SCREENSHOT: deadlock-models-hero-swap-blender-4.webp, a Data Transfer modifier on the new mesh with the hero's body mesh as the source and vertex groups selected */}

{/* NEEDS HANDS-ON TEST: the Data Transfer modifier settings that work best for hero weights (the notes give the tool, not the settings). */}

</Step>
<Step>

### Limit weights to 4 per vertex

Keep each vertex at four bone weights or fewer. The exporter warns you when a vertex has more.

1. Select your mesh.
2. Switch to Weight Paint mode.
3. Choose **Weights > Limit Total**. Check that the limit is 4.

{/* SCREENSHOT: deadlock-models-hero-swap-blender-5.webp, Weight Paint mode with the Weights menu open and Limit Total highlighted */}

</Step>
<Step>

### Sort meshes into collections

The exporter writes one DMX file per collection. In ModelDoc, each DMX file becomes one mesh.

1. Make one collection for each mesh the original hero has. Vyper has a body and a gun, so make `viper` and `gun`.
2. Put your meshes into the matching collection.
3. Put the armature in the body collection.
4. Move everything else out of these collections: the hero's old meshes, reference objects, and lights.

Keep these names the same on every export. ModelDoc finds each DMX file by its name.

/>

{/* SCREENSHOT: deadlock-models-hero-swap-blender-7.webp, the Outliner with the viper and gun collections and the Source Engine Exportables list with animations unticked */}

</Step>
<Step>

### Check before you export

- Every mesh is parented to the armature and weighted to at least one bone.
- No name ends in `.001`. Check meshes, materials, and vertex groups.
- Every face has a material. Use short, plain material names. Part 2 matches them by name.
- All transforms are applied.
- The armature is in rest pose.
- The file has exactly one armature.
- No `$cloth` bones are left.

</Step>
<Step>

### Export DMX

1. Open **Scene Properties** and find the **Source Engine Export** panel.
2. Set **Export Format** to **DMX**.
3. Set the DMX version to **Binary 9** and the model format to **Model 22**, the ModelDoc format.
4. Set **Export Path** to a `dmx` folder inside the hero folder of your addon: `content/citadel_addons/<addon>/models/heroes_staging/viper/dmx/`.
5. In **Source Engine Exportables**, untick the animations. Leave only your mesh collections ticked.
6. Click **Export** and choose **Scene Export**.
7. Read the warnings. Fix missing materials and too many weights. Most other warnings are harmless.

The separate `dmx` folder keeps your files apart from the decompiled ones. Heroes use DMX, not FBX: DMX keeps the scale and supports cloth.

## Common problems

<Accordions>
<Accordion title="&quot;Faces don't have a material.&quot;">

Give every mesh a material, then export again.

</Accordion>
<Accordion title="A warning about more than four weights">

Run **Weights > Limit Total** on that mesh again.

</Accordion>
<Accordion title="&quot;Non-uniform scale&quot; warning">

Apply all transforms on the armature and every mesh. Pugzilla skips this warning in his demo but calls it important.

</Accordion>
<Accordion title="The export writes nothing and shows no clear error">

One guide says the armature then needs an action in the Dope Sheet. This may differ on current versions.

{/* NEEDS HANDS-ON TEST: the "armature needs an action" note from Neutraldrift's guide (one source). */}

</Accordion>
<Accordion title="The mesh is tiny or turned in ModelDoc">

The size or facing fix was skipped. Fix it in Blender and export again.

</Accordion>
</Accordions>

More fixes are in [Model and skin problems](/docs/deadlock/errors/model-problems).
