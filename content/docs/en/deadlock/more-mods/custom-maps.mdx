Play a community-made map on your own PC. You put the map file in the right folder, load it from the console, and take it out before normal matches.

## What you need

<Requirements>
  <Requirement icon="Deadlock">Deadlock</Requirement>
  <Requirement icon="Terminal">The dev console on</Requirement>
  <Requirement icon="Map" note="downloaded or your own">
    A map mod
  </Requirement>
</Requirements>

You load maps from the dev console. [Test your mod in game](/docs/deadlock/basics/test-your-mod#turn-on-the-console) shows how to turn it on.

## What custom maps exist

Valve has released no map tools for Deadlock, and the game has no Steam Workshop. Community maps are VPK files, and only a few dozen exist as of October 2026.

| Type              | Examples                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------- |
| Movement training | Jump and parkour maps, such as Jump School Map by 1Lomi.                                                |
| Other lane maps   | Smaller 6v6 maps, such as dl_express by BestNameExisting and dl_harbor by OhSeismic (work in progress). |
| Fun maps          | Party modes, such as kart racing.                                                                       |

This guide covers playing alone. Playing a custom map with friends needs a community server or console tricks, and this wiki does not cover them.

Want to build your own map? Map makers use Hammer from [CSDK 12](/docs/deadlock/tools/csdk-12) with the full game files. This wiki does not cover mapping yet.

## Play a map

<Steps>
<Step>

### Install a map

1. Pick a map mod you downloaded, or one you made.
2. Unpack it if it came as an archive, and find the `.vpk` file. A map never needs an `.exe` file. [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) shows what a real mod looks like.
3. In Steam, right-click **Deadlock** and choose <MenuPath path="Manage > Browse local files" />.
4. Open `game/citadel/maps/`. Valve's own maps are in this folder too.
5. Copy the map `.vpk` into `maps`. Do not put it in `addons`.
6. Keep the file name as it is. The file name is the map name you type later.

Leave Valve's map files alone. Some maps install through Deadlock Mod Manager instead. Follow the map's page if it says so.

<Step>

### Load it from the console

1. Start Deadlock.
2. Press **F7** to open the console.
3. Type `map` and the file name without `.vpk`, then press **Enter**. For `dl_harbor.vpk`, type `map dl_harbor`.
4. Pick your team and hero.

Read the map's page before you play. Some maps need extra console settings to work. Some, like Jump School, need the `map` command twice.

{/* SCREENSHOT: deadlock-more-mods-custom-maps-3.webp, the console with map dl_harbor typed in */}

</Step>
<Step>

### Remove it before matchmaking

<Callout type="warning" title="Take maps out before a normal match">
  Custom maps don't work in Valve's matches. With a map installed, the normal
  map may fail to load, or you may not get into matchmaking. One map author also
  warns of desyncs and crashes.
</Callout>

<Tabs items={["By hand", "Deadlock Mod Manager"]}>
<Tab value="By hand">

1. Close Deadlock.
2. Move your custom map VPKs out of `game/citadel/maps/` into a folder outside the Deadlock folder.
3. Start Deadlock and queue.

To play a map again later, copy it back in.

</Tab>
<Tab value="Deadlock Mod Manager">

It warns you before launch when map mods are installed. Click **Disable Map Mods & Launch** before a normal match.

</Tab>
</Tabs>

</Step>
</Steps>

## Common map problems

<Accordions>
<Accordion title="The map does not load">

Check that the file is in `maps`, not `addons`. Check the spelling: the command uses the file name without `.vpk`.

</Accordion>
<Accordion title="You get teleported or killed for no reason">

Deadlock maps have a fixed play area. Read the map's page for the settings it needs.

</Accordion>
<Accordion title="The map is black">

Another mod can cause this. QOL Lock is a known cause. Move your other mods out of `addons` while you play the map.

</Accordion>
<Accordion title="Bots don't work">

Custom maps usually lack the data bots need to move around.

</Accordion>
<Accordion title="The minimap is wrong">

Custom maps show the main map's minimap, so pings land in the wrong place.

</Accordion>
<Accordion title="It worked before an update">

Game updates break maps. Check the map's page for a new version.

</Accordion>
<Accordion title="Normal matches crash after you played a map">

Remove the map VPK, as shown in the last stage above.

</Accordion>
</Accordions>
