Swap Deadlock's mouse cursor for your own image. You replace a few files in the game folder. You need no modding tools, only an image editor.

## What you need

- Deadlock, installed.
- An image editor, such as GIMP.
- Your cursor image. Use art you made or have permission to use.

## Where cursor files live

Cursor mods are not VPKs. They are loose files that replace the game's own cursor files in this folder:

To open the folder:

1. Open your Steam **Library**.
2. Right-click **Deadlock**.
3. Choose **Manage > Browse local files**.
4. Open `game`, then `citadel`, then `resource`, then `cursors`.

{/* SCREENSHOT: deadlock-more-mods-cursors-2.webp, the game/citadel/resource/cursors/ folder with its files listed */}

A mod from 2024 replaced a file named `cursor.bmp`. The names may be different on the current build. Check what is in your folder.

Source 2 Viewer also shows a cursor image, `panorama/images/cursors/arrow_png.vtex_c`, inside `game/core/pak01_dir.vpk`. Cursor mods don't use it. They replace the loose files.

## Make and install your cursor

<Steps>
<Step>

### Back up the originals

1. Copy the whole `cursors` folder.
2. Paste it outside the Deadlock folder, for example on your desktop.

You need this copy to undo your cursor later.

</Step>
<Step>

### Make your cursor image

1. Open the original cursor file in your image editor.
2. Note its size and file format.
3. Draw your cursor at the same size.
4. Export it in the same format, with the same file name as the original.

{/* NEEDS HANDS-ON TEST: whether the image must match the original size, whether transparency works, and where the click point sits on the image */}

To make the cursor bigger or smaller, use the game's cursor size setting. You don't need a new image for that.

{/* NEEDS HANDS-ON TEST: the exact label and settings tab of the cursor size option */}

If you share your cursor, keep the art your own and free of anything offensive.

</Step>
<Step>

### Replace the files

1. Close Deadlock.
2. Copy your new cursor file into `game/citadel/resource/cursors/`.
3. Let it replace the original file.
4. Start Deadlock and move the mouse in the main menu.

{/* SCREENSHOT: deadlock-more-mods-cursors-3.webp, the custom cursor in the main menu */}

Someone else's cursor mod installs the same way. GameBanana has a [Cursors](https://gamebanana.com/mods/cats/49794) category for Deadlock. These mods come as loose files, not a VPK, so copy them in by hand. Follow the steps on the mod's page.

</Step>
</Steps>

## Undo it

1. Close Deadlock.
2. Copy the files from your backup back into `resource/cursors/`.

You can also run **Verify integrity of game files** in Steam. It restores Valve's cursor files. It also replaces `gameinfo.gi`, so your other mods stop loading until you set them up again. [Install mods by hand](/docs/deadlock/getting-started/install-by-hand) shows how.

## Why updates undo it

A game update can put Valve's cursor files back. **Verify integrity of game files** does the same. Your cursor is then gone, with no error.

1. Keep a copy of your cursor files outside the Deadlock folder.
2. After each game update, check the cursor in the main menu.
3. If it is back to normal, copy your files in again.

If an update renames the cursor files, your old files do nothing. Look in the folder again and rename your files to match.

## Common problems

- **Nothing changes.** Your file name or format is different from the original. Compare it with your backup.
- **The cursor went back to normal.** A game update or Verify restored Valve's files. Copy yours in again.
- **You lost the original files.** Run **Verify integrity of game files**, then redo your mod setup.
