## Tools

Valve has not released modding tools for Deadlock. These community tools fill the gap.

<ToolCard
  name="Source 2 Viewer"
  href="/docs/deadlock/tools/source-2-viewer"
  badge="Required"
  icon={<Icon name="Source2Viewer" />}
>
  Opens the game's files. Preview, export, and decompile them.
</ToolCard>

<ToolCard
  name="CSDK 12"
  href="/docs/deadlock/tools/csdk-12"
  badge="Unofficial"
  icon={<Icon name="Wrench" />}

</ToolCard>

<ToolCard
