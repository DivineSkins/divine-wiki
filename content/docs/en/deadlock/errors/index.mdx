Pick the problem you see. Each guide puts the exact error text first, so you can match it to your screen. After a game update, start with the first two.

## Playing with mods

<ToolCard name="Mods not loading" href="/docs/deadlock/errors/mods-not-loading">
  Pick this if the game starts fine, but your skins, sounds, or icons do not
  show.
</ToolCard>
<ToolCard
  name="Crashes and matchmaking blocks"
  href="/docs/deadlock/errors/game-crashes"
>
  Pick this if you see a `FATAL ERROR`, the game closes at launch, or
  matchmaking refuses to start.
</ToolCard>
<ToolCard
  name="Deadlock Mod Manager problems"
  href="/docs/deadlock/errors/mod-manager-problems"
>
  Pick this if the app will not start, antivirus flags it, downloads get stuck,
  or it cannot find the game.
</ToolCard>
<ToolCard
  name="Linux and Steam Deck"
  href="/docs/deadlock/errors/linux-steam-deck"
  badge="Untested"
>
  Pick this if you cannot find the game folder, or the mod manager window stays
  grey.
</ToolCard>

## Making mods

<ToolCard
  name="Errors when making mods"
  href="/docs/deadlock/errors/creator-errors"

  shows in game.

<ToolCard
  name="Model and skin problems"
