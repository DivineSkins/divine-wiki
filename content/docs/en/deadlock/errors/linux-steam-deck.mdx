<LevelPill level="beginner" />

Deadlock has no Linux version. It runs through Proton, Steam's compatibility layer, so mods go in the same game folders as on Windows. This page shows where those folders are, which name rules matter, and how to fix mod manager problems. The install steps themselves are in [Install mods by hand](/docs/deadlock/getting-started/install-by-hand).

<Callout type="info" title="Mostly untested">
  We have not tested these steps on a Linux PC or a Steam Deck with the current
  game build yet. The paths come from Deadlock Mod Manager's source code, and
  the fixes come from its docs.
</Callout>

## What you need

- Deadlock, installed through Steam.
- A file manager. On a Steam Deck, switch to Desktop Mode first.
- A plain text editor, if you install mods by hand.
- Optional: a mod manager with a Linux build, such as Deadlock Mod Manager (DMM).

## Find the game folder

<Tabs items={["Through Steam", "Type the path"]}>
<Tab value="Through Steam">

This way works on every system.

1. Open your Steam **Library**.
2. Right-click **Deadlock**.
3. Choose **Manage > Browse local files**.
4. Open `game`, then `citadel`. Your `addons` folder goes here.

</Tab>
<Tab value="Type the path">

These are the default Deadlock folders. `~` means your home folder.

| Steam install | Deadlock folder                                                                    |
| ------------- | ---------------------------------------------------------------------------------- |
| Native Steam  | `~/.local/share/Steam/steamapps/common/Deadlock/`                                  |
| Flatpak Steam | `~/.var/app/com.valvesoftware.Steam/.local/share/Steam/steamapps/common/Deadlock/` |
| Snap Steam    | `~/snap/steam/common/.local/share/Steam/steamapps/common/Deadlock/`                |

- Native Steam also reaches the same folder through `~/.steam/steam` and `~/.steam/root`.
- Flatpak Steam can use `.../data/Steam/...` instead of `.../.local/share/Steam/...`.
- Is Deadlock on a microSD card or another drive? Open Steam's **Settings > Storage** to see every library.

</Tab>
</Tabs>

Proton changes where saves and settings live. It does not move the game files.

## Use lowercase names

Linux file names are case-sensitive. `Addons` and `addons` are two different folders there. Mod managers write to `addons` in lowercase, so match them.

<img
  src="/wiki-images/deadlock-errors-linux-steam-deck-2.webp"
  alt="Folder tree: use addons, pak01_dir.vpk and pak02_dir.vpk in lowercase; avoid Addons, Pak01_Dir.vpk and pak02_dir.VPK"
/>

1. Name the folder `addons`, all in lowercase.
2. Name every mod `pak01_dir.vpk` to `pak99_dir.vpk`, all in lowercase.
3. Check the ending too. It must be `.vpk`, not `.VPK`.

We have not tested whether the game itself, running under Proton, cares about capitals. Lowercase works either way.

## Mod managers on Linux

Both big mod managers have Linux builds. Use only one of them. On SteamOS, players use either the DMM Flatpak or the Grimoire Flatpak. Both work for them.

<Tabs items={["Deadlock Mod Manager", "Grimoire"]}>
<Tab value="Deadlock Mod Manager">

**Builds:** Flatpak, AppImage, `.deb`, `.rpm`, an APT repository, the AUR, nixpkgs, and a Gentoo overlay.

The DMM team calls its Linux support "best-effort". Follow its [installation guide](https://docs.deadlockmods.app/using-mod-manager/installation).

<img
  src="/wiki-images/deadlock-errors-linux-steam-deck-3.webp"
  alt="The Linux Installation section of the Deadlock Mod Manager docs, with the best-effort support note and the Flatpak install commands"
/>

If DMM feels slow on Linux, install its CEF build. It bundles its own browser engine, which runs faster for most people.

</Tab>
<Tab value="Grimoire">

**Builds:** AppImage, `.deb`, Flatpak, the AUR, an APT repository, and a Nix flake.

Get it from [grimoiremods.com](https://grimoiremods.com) or its [GitHub page](https://github.com/Slush97/grimoire).

</Tab>
</Tabs>

### Play from Game Mode on a Steam Deck

1. Set up your mods in DMM in Desktop Mode.
2. Click **Launch Modded** once. This edits `gameinfo.gi` so Deadlock loads your mods.
3. Return to Game Mode and start Deadlock as usual.

Deadlock should keep loading your mods, because the edit stays in `gameinfo.gi`. After a game update, repeat step 2. We have not tested this on a Deck yet.

## DMM fixes on Linux

<Accordions type="multiple">
<Accordion title="DMM crashes when you pick the game folder" id="dmm-crashes-when-you-pick-the-game-folder">

**What you see:** On a Steam Deck or another Linux PC, you open the folder picker in **Settings > Game**. A dialog flashes, then DMM crashes. DMM may also fail to find the game on its own.

**Why:** The Flatpak sandbox cannot see your Steam library.

<Tabs items={["Flatseal", "Terminal"]}>
<Tab value="Flatseal">

1. Quit DMM fully, including its tray icon.
2. On a Steam Deck, switch to Desktop Mode.
3. Open Flatseal, a Flatpak permissions app. Select **Deadlock Mod Manager**.
4. Under **Filesystem > Other files**, add the full path of your Steam library. Add any library on a microSD card too.
5. Start DMM and pick the game folder again.

</Tab>
<Tab value="Terminal">

1. Quit DMM fully, including its tray icon.
2. On a Steam Deck, switch to Desktop Mode.
3. Run this in a terminal. Replace the example path with your own library path:

   ```bash
   flatpak override --user --filesystem="/home/you/.local/share/Steam" dev.stormix.deadlock-mod-manager
   ```

4. Start DMM and pick the game folder again.

</Tab>
</Tabs>

Still crashing? DMM's docs list a broader fix as a last resort. It gives DMM access to most of your files, not only the Steam library:

```bash
flatpak override --user --filesystem=host dev.stormix.deadlock-mod-manager
```

To take that access back later, quit DMM and run:

```bash
flatpak override --user --nofilesystem=host dev.stormix.deadlock-mod-manager
```

</Accordion>
<Accordion title="DMM opens to a grey window" id="dmm-opens-to-a-grey-window">

**What you see:** The DMM Flatpak opens, but the window stays grey or blank. This happens most with NVIDIA graphics cards.

1. Quit DMM fully, including its tray icon.
2. Run this in a terminal:

   ```bash
   flatpak override --user --env=WEBKIT_DISABLE_DMABUF_RENDERER=1 dev.stormix.deadlock-mod-manager
   ```

3. Start DMM again. The setting stays for future launches.

Still grey? Check that your NVIDIA driver and the Flatpak NVIDIA runtime have the same version. Run `flatpak update` to update the runtimes.

To undo the setting, quit DMM and run:

```bash
flatpak override --user --unset-env=WEBKIT_DISABLE_DMABUF_RENDERER dev.stormix.deadlock-mod-manager
```

</Accordion>
<Accordion title="The AppImage does not start" id="the-appimage-does-not-start">

Make it executable. Replace the file name with yours:

```bash
chmod +x ~/Downloads/Deadlock-Mod-Manager.AppImage
```

</Accordion>
<Accordion title="Glitches on Wayland with an NVIDIA card" id="glitches-on-wayland-with-an-nvidia-card">

Start DMM with this setting in front of the command:

```bash
WEBKIT_DISABLE_COMPOSITING_MODE=1 deadlock-modmanager
```

</Accordion>
</Accordions>

## Creator tools are Windows only

You can install and play mods on Linux. Making most mods is a different story.

| Tool                                              | On Linux                                                                                                                                  |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| CSDK 12                                           | Windows only. It compiles sounds, materials, and models. We know of no tested way to run it on Linux.                                     |
| Source 2 Viewer                                   | The window app is Windows only. Its command-line version runs on Linux. It can open game files and pack a folder into a VPK.              |
| Browser tools, such as Deadlock Forge and DeadMod | They run in a web browser, so they should work on Linux. See [Make mods without installing tools](/docs/deadlock/tools/browser-builders). |

For anything that needs a compile step, use a Windows PC.
