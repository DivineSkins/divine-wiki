Stuck on a mod? Ask in Divine's Discord, check the error pages on this wiki, or read the Deadlock Mod Manager docs for problems with the app.

Looking for mods? Divine is adding Deadlock mods. When they arrive, you'll find them in Explore mods, and you'll publish yours from the Creator Panel.

## Ask on Discord

Still have questions? Hit us up on Discord. We're always around.

<GlowCTA href="https://discord.gg/divineskins">Join Discord</GlowCTA>

When you ask, include:

- The exact error text, or a screenshot of it.
- What changed last: a new mod, a game update, or a file you edited.
- How you install mods: with Deadlock Mod Manager or by hand.

You can also ask other Deadlock creators for help in the Deadlock Modding server:

<PremiumCard
  title="Deadlock Modding"
  href="https://discord.gg/P2PCCtYt2B"
  icon={<Icon name="Discord" />}
>
  A big creator server, with 21,000+ members. Ask here for help with tools and
  errors.
</PremiumCard>

To see the Deadlock Modding server's channels, you may need to be in Valve's official Deadlock Discord first. That server is invite-only, and players get the invite from inside the game. If you cannot get into the modding server, ask in Divine's Discord.

## Lookalike sites to skip

- **`steamdb.com`.** It is not SteamDB. The real SteamDB is `steamdb.info`.
- **`deadlockmodmanager.com`.** It is an unofficial lookalike of Deadlock Mod Manager's site.

[Download safely](/docs/deadlock/getting-started/stay-safe#download-safely) lists more fakes to watch for.
