Deadlock Mod Manager (DMM) is the easiest way to install Deadlock mods. It downloads mods from GameBanana, edits the game's config for you, and fixes your setup after updates. Read [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) first.

<Callout type="info" title="Looking for Celestial?">
  Celestial, Divine's own launcher, does not install Deadlock mods yet, so this
  guide uses Deadlock Mod Manager.
</Callout>

## What you need

- Deadlock, installed through Steam and updated to the latest version. The setup cannot find the game otherwise.
- A Windows 10 or 11 PC (64-bit), or a Linux PC.

## Download Deadlock Mod Manager

1. Open [deadlockmods.app](https://deadlockmods.app) in your browser.
2. Check the address bar. It must say `deadlockmods.app`.
3. Click **Download for Windows**.
4. Run the installer.
5. Click **Next** until you see **Finish**, then click it.

On Linux, follow the [official install guide](https://docs.deadlockmods.app/using-mod-manager/installation). It lists Flatpak, AppImage, `.deb`, `.rpm`, and other packages.

<Callout type="warning" title="Only download DMM from the official site">
  Get DMM only from `deadlockmods.app` or its [GitHub
  page](https://github.com/deadlock-mod-manager/deadlock-mod-manager).
  `deadlockmodmanager.com` is an unofficial lookalike site. Never install DMM
  from anywhere else.
</Callout>

## Set up on first launch

The first time you open DMM, a short setup wizard starts. You can skip it, but the wizard checks your setup for you.

1. Open Deadlock Mod Manager.
2. Read the notice that mods are third-party content. Tick the box and click **Next**.
3. Check that DMM found your Deadlock folder. Click **Next**.
4. Choose **Automatic** on the download server screen. Click **Next**.
5. Read the screen carefully if DMM says it found existing mods. This happens when you installed mods before. Then click **Next**.
6. Choose whether to share anonymous usage data. Click **Finish**.
7. Look at the status bar. It should show the API as online and the game as ready.

The wizard may also ask about match data sharing. Read [Privacy: Match Data Sharing](#privacy-match-data-sharing) below before you choose.

If DMM did not find the game, open **Settings > Game**. Set the path to your `Deadlock` folder itself, not the `game` or `citadel` folder inside it. The default path is `C:\Program Files (x86)\Steam\steamapps\common\Deadlock`.

## Find mods

You can find mods inside DMM or on the GameBanana website. Both show GameBanana's mods.

Check when a mod was last updated. Mods older than the City Never Sleeps update (September 29, 2026) may be broken.

### In the app

1. Open **Mod Store** in the sidebar.
2. Search for a hero or a mod name.
3. Turn off **Show outdated**. This hides mods that likely broke after a game update.
4. Keep adult (18+) mods hidden. Check that the 18+ option is turned off.
5. Open a mod and click **Download Mod**.
6. Pick the files you want if the mod has several versions. Click **Download Selected**.

### From GameBanana

1. Open the [Deadlock section on GameBanana](https://gamebanana.com/games/20948).
2. Open a mod page.
3. Click the 1-Click install button next to the file. GameBanana sends the mod to DMM.

DMM is the only 1-Click installer GameBanana supports for Deadlock.

DMM can also import a `.vpk`, `.zip`, `.rar`, or `.7z` file you downloaded yourself.

## Turn mods on and set the order

1. Open **Mods Library**.
2. Turn on each mod you want to use. New downloads start switched off.
3. Read the warning if DMM says two mods change the same hero. Choose which one to keep, or keep both.
4. Open **Change Mods Order** to pick which mod wins when two mods change the same file.

Mods that change different files all work together, in any order.

DMM also has profiles. Each profile is a separate set of mods, and you can switch between them.

## Launch with or without mods

1. Click **Launch Modded**.
2. Click **Continue** on the prompt.

The first time you do this, DMM edits the game's `gameinfo.gi` file so Deadlock loads your mods. After that, Deadlock starts with mods even when you launch it from Steam.

To play without mods, open DMM and click **Launch without mods**. You can also use **Disable all mods**.

If you have custom map mods, DMM warns you before launch. Map mods can stop you from loading the normal map or joining matchmaking. Use **Disable Map Mods & Launch** before a normal match.

## After a game update

Game updates often replace `gameinfo.gi` with Valve's original copy. Your mods then stop loading, with no error.

1. Close Deadlock.
2. Open DMM.
3. Click **Launch Modded**. DMM writes its changes into the new file.

DMM also has an **Auto-Reapply Mods** setting that does this for you.

{/* NEEDS HANDS-ON TEST: where Auto-Reapply Mods sits in the current stable DMM, and its exact label. */}

Big updates also break some mods, most of all HUD mods. If the game crashes after an update:

1. Click **Disable all mods**.
2. Launch the game once to check that it works.
3. Turn your mods back on one at a time, and launch after each one.
4. Turn off the mod that crashes the game.
5. Check that mod for an update in DMM or on its GameBanana page.

The errors guide will cover more fixes for mods that stop loading. {/* LINK LATER: /docs/deadlock/errors/mods-not-loading */}

## Privacy: Match Data Sharing

DMM has a feature called Match Data Sharing. It fetches your own match data for you. To do this, it reads your Steam login token from a Steam file on your PC.

Open **Settings > Privacy** and check this setting. Turn it off if you do not want it.

## Switch managers or uninstall

<Callout type="warning" title="Never run two mod managers">
  Use one mod manager per Deadlock install. Two managers both rewrite
  `gameinfo.gi`, so mods vanish or load twice.
</Callout>

Grimoire is the main alternative to DMM. Get it only from [grimoiremods.com](https://grimoiremods.com) or its [GitHub page](https://github.com/Slush97/grimoire). We recommend DMM because GameBanana supports it for 1-Click installs.

To switch from DMM to Grimoire:

1. Close Deadlock.
2. Install Grimoire and use its DMM import. It finds your DMM mods for you.
3. Uninstall DMM.

To switch from Grimoire to DMM:

1. Close Deadlock.
2. Open DMM and choose **Mods Library > Import from other mod managers**.
3. Uninstall Grimoire.

To stop using mods completely:

1. Click **Disable all mods** in DMM.
2. Uninstall DMM like any other app.
3. Follow [Remove mods completely](/docs/deadlock/getting-started/install-by-hand#remove-mods-completely) to delete leftover mod files and restore the original game file.

The tools section will compare mod managers in more detail. {/* LINK LATER: /docs/deadlock/tools/mod-managers */}

## Common problems

| Problem                              | Fix                                                                                                                                                                                       |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DMM cannot find the game             | Open **Settings > Game** and set the path to your `Deadlock` folder.                                                                                                                      |
| `Access is denied. (os error 5)`     | `gameinfo.gi` or the `addons` folder is read-only. In `game/citadel`, right-click `gameinfo.gi`, choose **Properties**, untick **Read-only**, and click **OK**. Do the same for `addons`. |
| Antivirus flags DMM after an update  | The developer says these alerts are false alarms. Download DMM again from `deadlockmods.app` only.                                                                                        |
| Downloads fail                       | Check that GameBanana opens in your browser, then try again later. GameBanana blocks downloads in some countries.                                                                         |
| Mods stopped working after an update | Click **Launch Modded** again.                                                                                                                                                            |
| Mods vanish or load twice            | You have two mod managers installed. Uninstall one.                                                                                                                                       |
