Deadlock Mod Manager (DMM) adds the mod files you downloaded, edits the game's config, and redoes that edit after updates. Read [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) first.

<Callout type="info" title="Looking for Celestial?">
  Celestial, Divine's own launcher, does not install Deadlock mods yet, so this
  guide uses Deadlock Mod Manager. Divine is adding Deadlock mods. When they
  arrive, you'll find them in Explore mods, and you'll publish yours from the
  Creator Panel.
</Callout>

### Set up on first launch

The first time you open DMM, a setup wizard checks your setup. You can skip it.

1. Open Deadlock Mod Manager.
2. Read the notice that mods are third-party content. Tick the box and click **Next**.
3. Check that DMM found your Deadlock folder. Click **Next**.
4. Choose **Automatic** on the download server screen. Click **Next**.
5. If DMM says it found existing mods, read that screen carefully. Then click **Next**.
6. Choose whether to share anonymous usage data. Click **Finish**.
7. Look at the status bar. It should show the API as online and the game as ready.

If the wizard asks about match data sharing, read [Privacy: Match Data Sharing](#privacy-match-data-sharing) first.

If DMM did not find the game, open <MenuPath path="Settings > Game" /> and set the path to the `Deadlock` folder itself, not `game` or `citadel`. The default is `C:\Program Files (x86)\Steam\steamapps\common\Deadlock`.

</Step>
<Step>

### Add a mod

Download the mod's file first. It is a `.vpk` file, or a `.zip`, `.rar`, or `.7z` archive with a `.vpk` inside. Mods not updated since the City Never Sleeps update (September 29, 2026) may be broken.

1. Open **Mods Library** in the sidebar.
2. Click **Add Local Mod**.
3. Drop the mod's file into the upload area, or click the area to pick the file.
4. Type a name for the mod. Only the name is required.
5. Add the mod to your library.

Look inside an archive before you add it. A real mod never holds an `.exe`, `.dll`, `.bat`, `.ps1`, or `.scr` file. If yours does, delete the download.

{/* NEEDS HANDS-ON TEST: where the local import button sits in the current stable DMM, and its exact label. The DMM docs call it Add Local Mod in Mods Library. Check the label of the button that adds the mod to the library, and whether an added mod starts switched off. */}

</Step>
<Step>

### Turn mods on and set the order

1. Open **Mods Library**.
2. Turn on each mod you want to use. New mods start switched off.
3. Read the warning if DMM says two mods change the same hero. Choose which one to keep, or keep both.
4. Open **Change Mods Order** to pick which mod wins when two mods change the same file.

Mods that change different files work together in any order. DMM also has profiles: separate sets of mods you can switch between.

</Step>
<Step>

### Launch with or without mods

1. Click **Launch Modded**.
2. Click **Continue** on the prompt.

The first time, DMM edits the game's `gameinfo.gi` file so Deadlock loads your mods. After that, Deadlock starts with mods even from Steam.

To play without mods, click **Launch without mods** in DMM, or use **Disable all mods**.

Custom map mods can stop you from loading the normal map or joining matchmaking. DMM warns you before launch. Use **Disable Map Mods & Launch** before a normal match.

## After a game update

Game updates often replace `gameinfo.gi` with Valve's copy, and your mods stop loading with no error.

1. Close Deadlock.
2. Open DMM.
3. Click **Launch Modded**. DMM writes its changes into the new file.

The **Auto-Reapply Mods** setting does this for you.

{/* NEEDS HANDS-ON TEST: where Auto-Reapply Mods sits in the current stable DMM, and its exact label. */}

Big updates also break some mods, most of all HUD mods. If the game crashes after an update:

1. Click **Disable all mods** and launch once to check that the game works.
2. Turn your mods back on one at a time, and launch after each one.
3. Turn off the mod that crashes the game, and wait for a newer version of it.

[Mods not loading](/docs/deadlock/errors/mods-not-loading) has more fixes.

## Privacy: Match Data Sharing

Match Data Sharing fetches your own match data. To do this, DMM reads your Steam login token from a Steam file on your PC. Open <MenuPath path="Settings > Privacy" /> and turn it off if you do not want it.

## Switch managers or uninstall

<Callout type="warning" title="Never run two mod managers">
  Use one mod manager per Deadlock install. Two managers both rewrite
  `gameinfo.gi`, so mods vanish or load twice.
</Callout>

Grimoire is the main alternative to DMM. We recommend DMM because far more players use it. [Mod managers compared](/docs/deadlock/tools/mod-managers) has the details.

<ToolCard
  name="Grimoire"
  href="https://grimoiremods.com"
  badge="Alternative"
  icon={<Icon name="Grimoire" />}
>
  Get it only from grimoiremods.com or its GitHub page, Slush97/grimoire.
</ToolCard>

To switch from DMM to Grimoire, close Deadlock, install Grimoire, and use its DMM import. Then uninstall DMM.

To switch from Grimoire to DMM, close Deadlock and choose <MenuPath path="Mods Library > Import from other mod managers" /> in DMM. Then uninstall Grimoire.

To stop using mods completely:

1. Click **Disable all mods** in DMM.
2. Uninstall DMM like any other app.
3. Follow [Remove mods completely](/docs/deadlock/getting-started/install-by-hand#remove-mods-completely) to delete leftover mod files and restore the original game file.

## Common problems

| Problem                             | Fix                                                                                                                                                                                       |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Access is denied. (os error 5)`    | `gameinfo.gi` or the `addons` folder is read-only. In `game/citadel`, right-click `gameinfo.gi`, choose **Properties**, untick **Read-only**, and click **OK**. Do the same for `addons`. |
| Antivirus flags DMM after an update | The developer says these alerts are false alarms. Download DMM again from `deadlockmods.app` only.                                                                                        |

{/* SCREENSHOT: the gameinfo.gi Properties window with the Read-only box. File: deadlock-getting-started-install-with-mod-manager-10.webp */}

More fixes are in [Deadlock Mod Manager problems](/docs/deadlock/errors/mod-manager-problems) and the [DMM troubleshooting docs](https://docs.deadlockmods.app/using-mod-manager/troubleshooting).
