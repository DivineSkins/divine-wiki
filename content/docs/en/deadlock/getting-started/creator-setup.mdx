This guide installs the two tools almost every Deadlock mod needs and creates your first addon. Set up mods on your PC first, so you can test what you make: use [Deadlock Mod Manager](/docs/deadlock/getting-started/install-with-mod-manager) or [install mods by hand](/docs/deadlock/getting-started/install-by-hand).

## What you need

- A Windows PC. The creator tools run on Windows only.
- Deadlock on Steam, updated to the latest version.
- Steam open whenever you use CSDK 12.
- Free disk space for the tools. {/* NEEDS HANDS-ON TEST: measure the size of the unzipped Reduced CSDK 12 folder and add a real number here */}

## What you will install

Valve has not released modding tools for Deadlock, so creators use two free community tools. [Tools overview](/docs/deadlock/tools) lists the others.

## Install the tools

<Steps>
<Step>

### Install Source 2 Viewer

Source 2 Viewer is free and open source (MIT), made by the ValveResourceFormat team.

1. Open [s2v.app](https://s2v.app/) in your browser.
2. Click **Download dev build**, the small link under the main download button. Deadlock fixes land in the dev build first, and current guides use it. If you pick the normal release, use version 20.0 or newer.
3. Put the download in its own folder. Source 2 Viewer has no installer.
4. Open `Source2Viewer.exe`.

<img
  src="/wiki-images/deadlock-getting-started-creator-setup-3.webp"
  alt="The s2v.app home page with the main Download button and the Download dev build link under it"
/>

{/* NEEDS HANDS-ON TEST: whether the dev build downloads as a zip or a single exe */}

</Step>
<Step>

### Install CSDK 12

<Callout type="warning" title="CSDK 12 is an unofficial community tool">
  Valve did not make CSDK 12 and does not support it. It repackages files from
  Valve's Counter-Strike 2 Workshop Tools with community fixes. Download it only
  from the community page linked below.
</Callout>

1. Open the [CSDK 12 page](https://deadlockmodding.pages.dev/modding-tools/csdk-12) on the Deadlock Modding Notes site.
2. Click **Download** in the **Installation** section. You get Reduced CSDK 12, which leaves out the full game files. You do not need them for sounds, textures, icons, or models.
3. Unzip it to a short path, such as `C:\Reduced_CSDK_12`.
4. Skip the **Full Game Files** steps on that page. Beginners do not need them.

<img
  src="/wiki-images/deadlock-getting-started-creator-setup-4.webp"
  alt="The Installation section of the CSDK 12 page on Deadlock Modding Notes, with the Download link and a warning about OneDrive folders"
/>

Never unzip it on your Desktop or in Documents. OneDrive often syncs those folders, and that breaks the tools. Keep it out of the Deadlock game folder too: a reinstall can delete it, and it gets mixed up with real game files.

{/* NEEDS HANDS-ON TEST: CSDK 12 still opens and compiles against game build 6779 (gap G02) */}

</Step>
<Step>

### First launch

1. Start Steam. CSDK 12 does not open without it.
2. Open `csdkcfg.exe` in your `Reduced_CSDK_12` folder. This is the launcher, also called the Configuration Tool. {/* NEEDS HANDS-ON TEST: launcher exe name in the current zip (conflict C22). Older guides open game\bin\win64\Deadlock_with_tools.exe instead */}
3. Leave the binary picker in the top left on `bin`.

Older downloads used a different launcher name. If `csdkcfg.exe` is missing, check the CSDK 12 page.

The binary picker has four choices:

| Choice       | What it does                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------------- |
| `bin`        | The normal tools. Use this one.                                                                         |
| `bin_tools`  | Previews some particle effects that crash `bin`, but crashes on some model compiles. Switch back after. |
| `bin_server` | Needs the full game files you skipped. It will not start without them.                                  |
| `bin_cs2`    | Only for compiling maps.                                                                                |

Leave the **No Addon** launch option off. That mode can overwrite the tool's own base files.

{/* NEEDS HANDS-ON TEST: whether the "Fix Models" checkbox is in the current launcher, and whether running bin_tools once as admin makes the tools start faster (one source says yes) */}

</Step>
<Step>

### Create your first addon

An addon is the project folder for one mod.

1. Click **Create New Addon** in the launcher.
2. Type a name in lowercase, with no spaces or special characters. Example: `firstmod`.
3. Select your addon in the list.
4. Click **Launch Tools**. A console window opens first, then the Asset Browser.

{/* SCREENSHOT: the CSDK 12 launcher with the Create New Addon button and the addon list. File: deadlock-getting-started-creator-setup-5.webp */}

{/* SCREENSHOT: the Asset Browser right after Launch Tools. File: deadlock-getting-started-creator-setup-6.webp */}

Right-click an addon in the launcher to see its menu:

| Menu item                  | What it does                                                                                                   |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Explore Content Folder** | Opens the folder for your source files.                                                                        |
| **Explore Game Folder**    | Opens the folder for your compiled files.                                                                      |
| **Duplicate**              | Copies an addon, such as a template.                                                                           |
| **Compile All Assets**     | Compiles every file in the addon.                                                                              |
| **Create VPK**             | Packs the addon. [Pack your mod into a VPK](/docs/deadlock/basics/pack-a-vpk) uses a different, tested method. |
| **Delete**                 | Removes the addon.                                                                                             |

CSDK 12 also ships template addons, such as a Billy audio template and a hero image template. The first-mod guides show when to use them.

{/* SCREENSHOT: the addon right-click menu in the launcher. File: deadlock-getting-started-creator-setup-7.webp */}

</Step>
</Steps>

## Content folder and game folder

Every addon has two folders inside `Reduced_CSDK_12`: `content/citadel_addons/<addon>/` for the source files you edit, and `game/citadel_addons/<addon>/` for the compiled `_c` files that go in your mod.

<img
  src="/wiki-images/deadlock-getting-started-creator-setup-8.webp"
  alt="The content folder holds source files such as example_sound.wav. CSDK 12 compiles them into the game folder at the same path, as example_sound.vsnd_c."
/>

Three rules:

- Put each file at the same folder path it has in the game. A file the game keeps in `sounds/vo/` goes in `content/citadel_addons/<addon>/sounds/vo/`.
- The tools watch the content folder and compile new files into the game folder on their own.
- When you pack a mod, copy from the game folder, never the content folder.

{/* SCREENSHOT: File Explorer with content/citadel_addons/firstmod next to game/citadel_addons/firstmod. File: deadlock-getting-started-creator-setup-9.webp */}

## Quick check

Test both tools before you start a mod.

1. Open Source 2 Viewer and click **File > Open**.
2. Open `game/citadel/pak01_dir.vpk` in your Deadlock folder. In Steam, **Manage > Browse local files** opens that folder.
3. Open only `pak01_dir.vpk`. Source 2 Viewer reads the numbered `pak01_000.vpk` files with it.
4. Expand `sounds` or `panorama` and double-click a file to preview it.
5. Open the CSDK 12 launcher, select your addon, and click **Launch Tools**.
6. Wait until the Asset Browser opens.

If both tools open, you are ready for your first mod.

## Common problems

- **Your addon is missing from the launcher.** The name has a capital letter, a space, or a special character. Rename the folder in both `content/citadel_addons` and `game/citadel_addons`. Then click **Refresh addons list**.
- **The tools do not start.** Start Steam first. Move the `Reduced_CSDK_12` folder out of OneDrive folders.
- **The game will not find a match.** Valve blocks matchmaking while tools mode runs. Close CSDK 12 before you queue.

[Errors when making mods](/docs/deadlock/errors/creator-errors) has more fixes.
