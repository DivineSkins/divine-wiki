To install Deadlock mods without a mod manager, you edit one game file, create one folder, and rename your mods. Read [What's allowed and how to stay safe](/docs/deadlock/getting-started/stay-safe) first.

## When to install by hand

[Deadlock Mod Manager](/docs/deadlock/getting-started/install-with-mod-manager) does every step on this page for you, so most players should use it. Install by hand to see exactly what changes, to test your own VPK, when a mod's readme says so, or when a manager does not work on your PC.

Pick one method. If you use a mod manager, let it handle `gameinfo.gi` and the `addons` folder. Never run two managers, such as Deadlock Mod Manager and Grimoire, on one install.

You need the archive tool only if Windows cannot open your mod download. Get mods from the Deadlock section on GameBanana.

## How it works

The file `gameinfo.gi` lists the folders the game reads. You add an `addons` folder to that list, above the game's own files, so your mod files win.

## Install a mod by hand

<Steps>
<Step>

### Find your Deadlock folder

1. Open your Steam **Library**.
2. Right-click **Deadlock**.
3. Choose <MenuPath path="Manage > Browse local files" />. A window opens in the `Deadlock` folder.
4. Open the `game` folder, then the `citadel` folder.

Newer Steam versions also have <MenuPath path="Properties > Installed Files > Browse" />.

The default Windows path is `C:\Program Files (x86)\Steam\steamapps\common\Deadlock\`. In another Steam library, look in `<Library>\steamapps\common\Deadlock\`.

<Accordion title="Linux and Steam Deck paths">

Deadlock runs through Proton on Linux. The game files sit in your normal Steam library:

| Steam install | Deadlock folder                                                                    |
| ------------- | ---------------------------------------------------------------------------------- |
| Native Steam  | `~/.local/share/Steam/steamapps/common/Deadlock/`                                  |
| Flatpak Steam | `~/.var/app/com.valvesoftware.Steam/.local/share/Steam/steamapps/common/Deadlock/` |
| Snap Steam    | `~/snap/steam/common/.local/share/Steam/steamapps/common/Deadlock/`                |

Linux file names are case-sensitive. Name the folder `addons` and your files `pakNN_dir.vpk`, all in lowercase.

We have not tested these steps on a Steam Deck with the current game build yet. [Linux and Steam Deck](/docs/deadlock/errors/linux-steam-deck) has known problems and fixes.

</Accordion>

</Accordions>

</Step>
<Step>

### Edit gameinfo.gi

<Callout type="warning" title="Edit only the SearchPaths block">
  Change nothing else in this file. Edits to other sections can block
  matchmaking for your whole party. Never paste a "performance" `gameinfo.gi`
  from the internet.
</Callout>

Before the edit, Valve's block looks like this. The real file also has a few comment lines that start with `//`.

```text
		SearchPaths
		{
			Game_UILanguage		citadel_*LANGUAGE*
			Game_LowViolence	citadel_lv
			Game				citadel
			Game				core
		}
```

1. Close Deadlock.
2. Copy `gameinfo.gi` to your desktop as a backup. Use it only to undo a mistake today.
3. Open `gameinfo.gi` in your text editor.
4. Find the line that says `SearchPaths`. It sits inside the `FileSystem` block.
5. Select everything from `SearchPaths` down to its closing `}`.
6. Paste this block in its place:

```text
		SearchPaths
		{
			Game_UILanguage		citadel_*LANGUAGE*
			Game_LowViolence	citadel_lv
			Game				citadel/addons
			Mod					citadel
			Write				citadel
			Game				citadel
			Mod					core
			Write				core
			Game				core
		}
```

7. Leave the two `UserSettingsPathID` lines below the block as they are.
8. Save the file.

If Windows will not save the file, right-click `gameinfo.gi` and choose **Properties**. Untick **Read-only**, click **OK**, and save again.

<Accordions>
<Accordion title="What each line does">

- `Game citadel/addons` reads your `addons` folder. It must sit above `Game citadel`, so your mod files win.
- The `Mod` and `Write` lines stop a launch crash: `Unable to read default keybinding configuration`.
- `Game_UILanguage` and `Game_LowViolence` are Valve's lines. Without them, hero name art can go missing in other languages.

Older guides show lines you should not add:

- `Game_Language`. Valve renamed it to `Game_UILanguage` in the City Never Sleeps update (September 29, 2026).
- `AddonRoot`, `OfficialAddonRoot`, or an `AddonConfig` block. These come from the creator tools' config, not the game's.

</Accordion>
</Accordions>

A typo stops the game from starting with `Failed to parse KeyValues`. Check that every `{` has a matching `}`.

{/* NEEDS HANDS-ON TEST: with this manual block, replays may save to citadel/addons/replays and fail with citadel_replay_manager_error_partial_decompression_failure (C10). Test before adding a fix to this page. */}

</Step>
<Step>

### Create the addons folder

1. Open the `game/citadel` folder.
2. Create a new folder.
3. Name it `addons`, all in lowercase.

Put mods straight into this folder. The game ignores subfolders.

</Step>
<Step>

### Add a mod

1. Open the mod's page on [GameBanana](https://gamebanana.com/games/20948). Under **Files**, click **Manual Download**.
2. Open the archive and find the `.vpk` file inside.
3. Check that the archive holds no `.exe`, `.dll`, `.bat`, `.ps1`, or `.scr` files. A real mod never needs them.
4. Extract the `.vpk` file.
5. Rename it to a free number: `pak01_dir.vpk`, `pak02_dir.vpk`, and so on, up to `pak99_dir.vpk`.
6. Move it into `game/citadel/addons/`.
7. Read the mod's readme. Some mods need extra steps.
8. Start Deadlock and check the mod in the hideout or a bot match.

</Step>
</Steps>

## File names that work

| File name                                      | Does it load? |
| ---------------------------------------------- | ------------- |
| `pak01_dir.vpk` to `pak99_dir.vpk`             | Yes           |
| `pak1_dir.vpk` (one digit)                     | No            |
| `pak00_dir.vpk` or `pak100_dir.vpk`            | No            |
| `cool_skin.vpk` (any other name)               | No            |
| `addons/my_mod/pak01_dir.vpk` (in a subfolder) | No            |

{/* SCREENSHOT: the addons folder holding pak01_dir.vpk and pak02_dir.vpk. File: deadlock-getting-started-install-by-hand-7.webp */}

### Mods with more than one file

Big mods can come as a set, such as `pak01_dir.vpk` with `pak01_000.vpk` and `pak01_001.vpk`. Give every file in the set the same new number. For example, rename `pak03_dir.vpk` and `pak03_000.vpk` to `pak05_dir.vpk` and `pak05_000.vpk`:

<Files>
  <Folder name="addons" defaultOpen>
    <File name="pak05_dir.vpk" />
    <File name="pak05_000.vpk" />
  </Folder>
</Files>

{/* NEEDS HANDS-ON TEST: confirm that renaming only the _dir file of a multi-part set breaks it. */}

## Choose the load order

When two mods change the same file, the lower number wins: `pak01_dir.vpk` beats `pak05_dir.vpk`. Give the mod you care about most the lowest number, and swap numbers if the wrong mod shows in game.

Mods that change different files all work, in any order. Skins and sounds for the same hero often clash. You can load up to 99 mods this way.

## After a game update

Steam replaces `gameinfo.gi` whenever an update ships a new copy, about once a month, and whenever you run **Verify integrity of game files**. Your mods then stop loading with no error. The `addons` folder stays on disk.

1. Close Deadlock.
2. Open `game/citadel/gameinfo.gi`. If `citadel/addons` is missing, Steam replaced the file.
3. Redo [Edit gameinfo.gi](#edit-gameinfogi) on the new file.

<Callout type="warning" title="Never paste an old backup over a new file">
  The new file may hold other changes from Valve. Always redo the edit on the
  fresh copy.
</Callout>

Big updates also break some mods, most of all HUD mods. A crash like `FATAL ERROR: Unable to find child '...' in layout file '...'` means an outdated HUD mod. To find the broken mod:

1. Move all your VPK files out of `addons` and start the game once.
2. Add the mods back one at a time, and start the game after each one.
3. Leave out the mod that crashes the game, and check its GameBanana page for an update.

[Mods not loading](/docs/deadlock/errors/mods-not-loading) and [Crashes, launch errors, and matchmaking blocks](/docs/deadlock/errors/game-crashes) have more fixes.

## Turn all mods off

To play the normal game but keep your mod files:

1. Right-click **Deadlock** in your Steam library.
2. Choose <MenuPath path="Properties > Installed Files > Verify integrity of game files" />.

Steam restores Valve's `gameinfo.gi`, so the game stops reading `addons`. Redo the edit to turn mods back on. Renaming `addons` to `addons_off` should also work, but we have not tested it on the current build.

## Remove mods completely

1. Close Deadlock.
2. Delete everything inside `game/citadel/addons/`.
3. Delete any extra folders a mod manager made in `game/citadel/`. Look for `addons` plus a number, such as `addons2`, and a `grimoire` folder.
4. Run **Verify integrity of game files** in Steam. This restores Valve's `gameinfo.gi`.
5. Delete the empty `addons` folder if you want.

Uninstalling Deadlock does not delete files you added. Old mods can survive a reinstall and keep crashing the game.

## Common problems

<Accordions>
<Accordion title="Mods do nothing after an update">

Steam replaced `gameinfo.gi`. Redo the edit.

</Accordion>
<Accordion title="Failed to parse KeyValues at launch">

A `{` or `}` is missing. Fix it, or verify game files and start over.

</Accordion>
<Accordion title="A crash with Unable to read default keybinding configuration">

The `Mod` and `Write` lines are missing. Paste the full block again.

</Accordion>
<Accordion title="Hero name art shows as plain text in other languages">

The `Game_UILanguage` line is missing, or you used the old `Game_Language`. Paste the full block again.

</Accordion>
<Accordion title="FATAL ERROR: Unable to find child '...'">

A HUD mod is outdated. Remove it and wait for an update.

</Accordion>
<Accordion title="Unable to enter matchmaking while any party member...">

Someone in your party changed a blocked section or has creator tools open. Close every creator tool, run **Verify integrity of game files**, and redo only the `SearchPaths` edit.

</Accordion>
</Accordions>
