The `.modpkg` is the file you upload to Divine and players install. Creator Hub packs your [mod project](/docs/lol/mod-format/mod-project), with every [layer](/docs/lol/mod-format/layers), into it.

Before you export:

- Repath champion mods. [Repath your mod](/docs/lol/getting-started/repath-your-mod) shows how.
- Fill in your mod info, and raise the **Version** if you're posting an update.
- Test the mod in game from Creator Hub.

## Export it

1. Right-click the mod's card.
2. Under **Export**, click **Modpkg**.
3. Check the list: each WAD shows its layer, file count and size.
4. Click **Export** and pick where to save the file.

The file name suggests your mod's name, version and author. Upload this file to Divine.

<img
  src="/wiki-images/lol-mod-format-3.webp"
  width={560}
  alt="The Export .modpkg window listing Aatrox.wad.client in the base layer with 257 files, and the Export button ringed"
/>

**Add another project to this package** merges another Creator Hub project into the same file.

## Install a .modpkg

Players install mods from Divine with Celestial. To install a file by hand:

1. Open the **Library** in Celestial.
2. Drag the file onto the Library, or click **Import**, then **Import Files**.

<img
  src="/wiki-images/lol-mod-format-4.webp"
  width={360}
  alt="The Library's Import menu open, with Import Files ringed"
/>

Only the `base` layer starts on. Click the layers badge on the mod's card to switch layers on and off.
