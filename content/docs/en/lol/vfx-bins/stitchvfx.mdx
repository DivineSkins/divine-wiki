## Open the Port tool

Open Quartz and select **Port** on the home screen.

<img
  src="/wiki-images/quartzre.webp"
  alt="Quartz home screen with the Port tool highlighted"
/>

## Load your target BIN

Click **Open Bin** on the left and open your custom skin's VFX `.bin` file, usually in the `data` folder.

<img
  src="/wiki-images/DEDXC.webp"
  alt="Port tool with the target BIN panel on the left and donor BIN panel on the right"
/>

## Choose a donor

Click the game controller icon on the right to browse donor BINs from in-game champions and skins.

<img
  src="/wiki-images/cxvcvx.webp"
  alt="Target VFX loaded in Quartz with the donor game controller icon highlighted"
/>

<Callout type="info" title="Effect name shortcuts">

- **Mis**: missile, the projectile a champion fires.
- **Tar**: target, the
  effect that plays when it hits someone.

</Callout>

## Port the effect

Find the donor effect you want to use. Select the target effect, then click the arrow on the donor effect to port it over.
