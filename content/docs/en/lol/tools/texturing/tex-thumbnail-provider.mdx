Tex Thumbnail Provider by **RitoShark** shows `.tex` files as real thumbnails in
Windows Explorer. In the file list, the preview pane, and large-icon view, you
see the texture instead of a blank icon. It decodes the file itself, so no app
has to be open.

---

## Install

You install and uninstall with a single PowerShell command. No download, no admin
rights. Registration is per user.

1. Close any Explorer windows that are showing `.tex` files.
2. Open PowerShell. A normal window is fine.
3. Paste this and press Enter:

   ```powershell
   iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1 | iex
   ```

The script grabs the latest `TexThumbnailProvider.dll`, drops it in
`%LOCALAPPDATA%\RitoShark\TexThumbnailProvider`, and registers it for your user.
Open any folder with `.tex` files and the thumbnails appear.

<Callout type="info" title="Pin a specific version">
  Want a set version instead of the latest? Run:

```powershell
& ([scriptblock]::Create((iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1))) -Version v1.1.0
```

</Callout>

## Uninstall

```powershell
iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/uninstall-thumbnail-handler.ps1 | iex
```

This removes the handler and its registry entries.

## What it handles

It decodes the `.tex` compression formats Riot ships:

| Format               | `.tex` code |
| -------------------- | ----------- |
| DXT1 / BC1           | `0x0A`      |
| DXT5 / BC3           | `0x0C`      |
| BC7                  | `0x0D`      |
| BC5                  | `0x0E`      |
| BGRA8 (uncompressed) | `0x14`      |

Mipmapped textures work too. The largest mip is decoded for the thumbnail.

<Callout type="info" title="Wins even over Photoshop">
  If Photoshop or the RitoTex plugin is installed, it registers itself as the
  `.tex` thumbnail handler and would normally take over. This installer writes
  its handler under your user account, which overrides the machine-wide one.
  Your `.tex` thumbnails keep showing. It only touches the thumbnail entry, so
  double-clicking a `.tex` still opens whatever app you set.
</Callout>

## Troubleshooting

### Thumbnails don't show

Restart Windows Explorer. Open Task Manager, find **Windows Explorer**,
right-click, and pick **Restart**. Open the folder again.

### Old thumbnails still look like generic icons

Windows caches thumbnails per file. A `.tex` repaints only after its modified
time changes or after you clear the cache. Open **Disk Cleanup**, tick
**Thumbnails**, click **OK**, then reopen the folder.

### Still nothing after a restart

Run the install command again. It re-downloads and re-registers the DLL.

## Alternative: LTK Tex Thumb Handler

The **LeagueToolkit** team has its own `.tex` thumbnail handler
([ltk-tex-utils](https://github.com/LeagueToolkit/ltk-tex-utils)). It does the
same basic job, but two things hold it back:

- It does not decode every compression format Riot uses, so some `.tex` files
  stay blank.
- If another program (Photoshop, the RitoTex plugin, and so on) has already
  claimed the `.tex` type, it cannot produce a preview at all. It does not
  override the existing handler the way this tool does.

For most people, Tex Thumbnail Provider from RitoShark is the better choice: it
covers more formats and wins over other handlers. Run only one thumbnail handler
at a time. If you had the LTK one installed, remove it before you install this.
