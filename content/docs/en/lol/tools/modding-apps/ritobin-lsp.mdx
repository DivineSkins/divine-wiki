ritobin-lsp is an LSP/VS Code extension by [alanpq](https://github.com/alanpq) that can open League's `.bin`/`.rito` files as readable text you can edit.

The latest builds are on GitHub: [ritobin-lsp releases](https://github.com/alanpq/ritobin-lsp/releases).

<Callout type="info" title="Consider Jade if you are new to modding">
  `ritobin-lsp` is designed to give you drop in support for common text editors, ideal for modders who *already* use them for modding.

If you don't already have an editor like VS Code installed, consider trying Jade.

</Callout>

## Install & Usage

See the [README](https://github.com/alanpq/ritobin-lsp/#ritobin-lsp)

## Troubleshooting

### Ritobin has hashed names instead of words

Use the `Unhash File` command available in the command palette (`Ctrl/Cmd + P`).
