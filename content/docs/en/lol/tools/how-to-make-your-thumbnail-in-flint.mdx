Make a thumbnail for your custom skin with [Flint](/docs/lol/tools/modding-apps/flint).
Use its thumbnail editor to arrange your model and text, then export an image to share with your mod.

## Before you start

- Open your skin project in Flint.
- Find the model's `.skn` file in the project file tree.

## Create your thumbnail

1. Right-click the model's `.skn` file.
2. Select **Create Thumbnail…** to open the thumbnail editor.
3. Choose **Riot style** or **Divine style** from the preset menu.
4. Select a model layer in the **Layers** panel.
5. Adjust its position and size on the canvas to frame your skin.
6. Select each text layer to edit the mod name and champion name.
7. Choose **WebP**, **PNG**, or **JPG** from the output format menu.
8. Click **Export**.
9. Choose a file name and save location in the dialog.
10. Open the exported image to check that the model and text are clear.

<Callout type="info" title="Save a layout for later">
  **Save** stores your layout as a local preset. Use **Export** to save the
  finished image.
</Callout>
