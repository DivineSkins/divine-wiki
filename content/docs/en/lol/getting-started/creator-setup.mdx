<LevelPill level="beginner" />

This guide sets up the tools almost every League mod needs. Install mods first, so you can test what you make: [Install mods](/docs/lol/getting-started/install-mods).

<Requirements>
  <Requirement icon="Monitor">Windows PC</Requirement>
  <Requirement icon="LeagueOfLegends" note="latest patch">
    League of Legends
  </Requirement>
</Requirements>

The creator tools run on Windows.

<Steps>
<Step>

### Set up Celestial's Creator Hub

Creator Hub is where you test, repath and export your mods.

1. Install [Celestial](https://divineskins.gg/install-mods).
2. Open **Settings**, then **Creator Hub**. Under **Import Defaults**, type your **Creator Name**. Celestial adds it to every mod you import.
3. Open **Creator Hub** from the icon at the top. The **?** button opens the Creator Hub Guide.

</Step>
<Step>

### Pick an extractor

An extractor pulls a champion's files out of the game, so you can edit them. Pick one. All three can extract a skin already repathed.

<ToolCard
  name="Flint"
  href="/docs/lol/tools/modding-apps/flint"
  badge="Recommended"
  icon={<Icon name="Flint" />}
>
  All-in-one: extract, preview, edit BIN files and pack. Repaths every new skin
  project for you.
</ToolCard>

<ToolCard
  name="Quartz"
  href="/docs/lol/tools/modding-apps/quartz"
  icon={<Icon name="Quartz" />}
>
  VFX-focused suite with an Asset Extractor. Use its Repath button to extract
  repathed.
</ToolCard>

<ToolCard
  name="Jade"
  href="/docs/lol/tools/modding-apps/jade"
  icon={<Icon name="Jade" />}
>
  BIN editor with an extractor that can repath as it extracts.
</ToolCard>

</Step>
<Step>

### Add a 3D app and an image editor

You need these once you change models or textures.

- **3D app:** [Blender](/docs/lol/blender) is free. [Maya](/docs/lol/maya) has the most League tooling.
- **Image editor:** [Paint.NET](/docs/lol/tools/texturing/paint-net), [GIMP](/docs/lol/tools/texturing/gimp) or [Photoshop](/docs/lol/tools/texturing/photoshop), each with its TEX plugin.

[Tools](/docs/lol/tools) lists every tool on this wiki.

</Step>
<Step>

### Start your first skin repathed

Extract your champion with a prefix from day one. Your mod never clashes with other mods, and you never repath at the end. [Repath your mod](/docs/lol/getting-started/repath-your-mod#best-practice-start-repathed) shows how in each extractor.

</Step>
</Steps>
