This guide shows you how to reduce a model's joint and vertex count in Maya while preserving most of its skin weights.

If you only want to make a 3D model swap and do not plan to edit animations, skip to [Reduce mesh geometry](#3-reduce-mesh-geometry).

## 1. Reduce the joint count

<YouTube id="cfLxL4gFCcg" title="Transfer skin weights between joints" />

Use this script to move skin weights from one or more source joints to matching target joints.

1. Copy the block below into Maya's Script Editor.
2. Replace the example names in `source_joints` and `target_joints`. Each source joint must line up with the target joint in the same list position.
3. Select the skinned mesh and run the script.

```python
import maya.cmds as cmds

def transfer_weights_multi(source_joints, target_joints):
    if len(source_joints) != len(target_joints):
        cmds.error("Source and target joint lists must be the same length.")

    # Get selected mesh
    sel = cmds.ls(sl=True, type="transform")
    if not sel:
        cmds.error("Select the skinned mesh first.")
    mesh = sel[0]

    # Find skinCluster
    skin_cluster = None
    history = cmds.listHistory(mesh)
    for node in history:
        if cmds.nodeType(node) == "skinCluster":
            skin_cluster = node
            break

    if not skin_cluster:
        cmds.error("No skinCluster found on selected mesh.")

    # Get all vertices once
    verts = cmds.ls(mesh + ".vtx[*]", fl=True)

    for source_joint, target_joint in zip(source_joints, target_joints):
        # Ensure target joint is an influence
        influences = cmds.skinCluster(skin_cluster, q=True, inf=True)
        if target_joint not in influences:
            cmds.skinCluster(skin_cluster, e=True, ai=target_joint, lw=False, wt=0)

        for v in verts:
            src_w = cmds.skinPercent(skin_cluster, v, q=True, t=source_joint)
            if src_w > 0:
                tgt_w = cmds.skinPercent(skin_cluster, v, q=True, t=target_joint)
                cmds.skinPercent(
                    skin_cluster,
                    v,
                    tv=[
                        (target_joint, tgt_w + src_w),
                        (source_joint, 0)
                    ]
                )

        print("Transferred weights from {} to {}".format(source_joint, target_joint))

    print("All joint transfers complete.")


# ===== USAGE =====
# 1. Select the skinned mesh
# 2. Replace joint names below

source_joints = [
    "_Bone_Hair045_L",

]

target_joints = [
    "_Bone_Hair044_L",

]

transfer_weights_multi(source_joints, target_joints)
```

Move each source joint after the script finishes. It should no longer deform the mesh. Move the target joint as well to confirm that it now carries the transferred weight.

<Callout type="info" title="Important">
  One joint can influence several meshes. Select each affected mesh and run the
  script again before removing that joint.
</Callout>

The script transfers weights but does not delete joints. Process every affected mesh first. Then check each source joint's descendants and delete only the joints you have confirmed are no longer needed.

Run this script to check the scene's total joint count:

```python
import maya.cmds as cmds

# Find all joint nodes in the entire scene
joints = cmds.ls(type='joint') or []
print(f"Total Joints in Scene: {len(joints)}")

```

If the count is still above the export limit, repeat the transfer with another safe source and target pair.

## 2. Split meshes and copy skin weights

<YouTube id="trdkUoEdaiQ" title="Split a mesh and copy its skin weights" />

1. Select your mesh and press `Ctrl+D` to duplicate it.
2. Select the duplicated group, then use **Separate Mesh by Material** on the Lemon 3D shelf.
3. Select every separated mesh in the group and bind them to the original SKL. In the Bind Skin options, choose **Closest Distance** for the fastest result.
4. Select the original mesh, then a separated mesh, and copy the skin weights. Repeat this for every material.
5. Divide the mesh group into smaller groups. Drag the SKL into each group, then export it. You can remove any material you do not want to include at this point.
6. Open a new Maya scene, then drag all the SKL and SKN files you exported back into it.

## 3. Reduce mesh geometry

<YouTube id="v4YBd4xBMlU" title="Remove hidden geometry from a mesh" />

<Callout type="info" title="Remove hidden geometry first">
  Start with geometry inside the character's clothing. League's top-down camera
  usually will not show it in game.
</Callout>

1. Select the mesh. Hide the other meshes to make the next steps easier.
2. Press `F11`, then double-click the faces you want to remove.
3. Hold the right mouse button, drag down to assign a new material, and choose any material in the menu.
4. Open Hypershade and confirm the new material's name.
5. Return to the skin group, export it, then import it again.
6. Find the new geometry or material group in the Outliner. Unbind the unwanted geometry from the skin, then delete it.

Alternatively, use Maya's **Reduce** tool to lower the mesh quality, then bind the reduced mesh back to its original SKL.

<Callout type="info" title="Order matters">
  If the scene exceeds the joint limit, finish reducing the joint count before
  you split or export the mesh. Otherwise, the model cannot export. For a simple
  3D model swap that does not change animations, you can go directly to section
  3.
</Callout>
