The wiki has a small set of components you can drop into any guide. The
draft editor's toolbar inserts them for you. This page is the full
reference. Each section shows the component first, then the code that
makes it.

## Which component to use

Each component has one job. Pick by what you are showing, not by how it
looks.

| You want to show                             | Use                                                   |
| -------------------------------------------- | ----------------------------------------------------- |
| The one page a reader should open first      | [PremiumCard](#premiumcard) with `featured`           |
| A set of guides or sections to pick from     | [CardGrid](#cardgrid) of [PremiumCards](#premiumcard) |
| A list of tools                              | [ToolCard](#toolcard) rows, with the tool's logo      |
| The summary at the top of a tool's own page  | [ToolHeader](#toolheader)                             |
| What a reader needs before they start        | [Requirements](#requirements)                         |
| A task with several stages                   | [Steps](#steps)                                       |
| Two or more ways to do the same thing        | [Tabs](#tabs)                                         |
| Where files go                               | [Files](#files)                                       |
| A menu path inside a step                    | [MenuPath](#menupath)                                 |
| Problems and fixes, FAQs, optional detail    | [Accordion](#accordion)                               |
| Names with descriptions (settings, commands) | [ParameterList](#parameterlist) or a [table](#table)  |
| A warning or a tip                           | [Callout](#callout)                                   |
| The single action a page asks for            | [GlowCTA](#glowcta)                                   |

Two rules keep pages readable:

- **Don't use ToolCard for guides.** It is for tools. Guides go in PremiumCards.
- **Link each page once.** If a card already points to a page, don't link it again in the text.

## Callout

A colored box for warnings, tips, and the Korea/China safety note. Use
`type="danger"` for real risk, `info` for tips, `warning` for "this can
go wrong", and `success` for confirmation.

<Callout type="info" title="Tip">
  You can skip this step if you already installed the tool.
</Callout>

<Callout type="warning" title="Heads up">
  Saving over the original file cannot be undone. Make a copy first.
</Callout>

<Callout type="danger" title="Don't use custom skins in Korea or China">
  The anti-cheat there blocks all mods. Accounts get banned.
</Callout>

<Callout type="success" title="Done">
  A green checkmark appears when the skin is ready.
</Callout>

```mdx
<Callout type="danger" title="Don't use custom skins in Korea or China">
  The anti-cheat there blocks all mods. Accounts get banned.
</Callout>
```

Props:

- `type` is `info`, `warning`, `danger`, or `success`. Defaults to `info`.
- `title` is optional. Each type has a default title.

There are also three level types for marking difficulty inside a page:
`lvl_beginner`, `lvl_intermediate`, and `lvl_advanced`. For a small
difficulty badge at the top of a guide, use [LevelPill](#levelpill)
instead.

## Tabs

Alternative paths. Use tabs for operating-system-specific steps or
tool-specific workflows. Every `<Tabs>` needs a closing `</Tabs>`, and
every `<Tab>` a closing `</Tab>`.

<Tabs items={["Windows", "macOS"]}>

<Tab value="Windows">Windows steps here.</Tab>

<Tab value="macOS">macOS steps here.</Tab>

</Tabs>

```mdx
<Tabs items={["Windows", "macOS"]}>
  <Tab value="Windows">Windows steps here.</Tab>
  <Tab value="macOS">macOS steps here.</Tab>
</Tabs>
```

## Accordion

Collapsible sections. Good for FAQs and optional detail.

<Accordions>

<Accordion title="Do I need Maya to make a skin?">
  No. Blender works for the full workflow, and many edits need no 3D tool at
  all.
</Accordion>

<Accordion title="How big can my mod file be?">
  There is no hard limit, but keep textures small so the mod loads fast.
</Accordion>

</Accordions>

```mdx
<Accordions>
  <Accordion title="Question here">Answer here.</Accordion>
</Accordions>
```

## Steps

Numbered stages for a longer task. Give each stage a `###` heading.
Inside a stage, use a normal numbered list for the small steps. Leave
a blank line after `<Step>` and before `</Step>`.

<Steps>
<Step>

### Find the file

Open the game files and note the path.

</Step>
<Step>

### Edit and compile it

Change the file, then compile it.

</Step>
</Steps>

```mdx
<Steps>
<Step>

### Find the file

Open the game files and note the path.

</Step>
<Step>

### Edit and compile it

Change the file, then compile it.

</Step>
</Steps>
```

## Files

A folder tree. Use it to show where files go. Add `defaultOpen` to
folders that should start open.

<Files>
  <Folder name="game" defaultOpen>
    <Folder name="citadel" defaultOpen>
      <File name="gameinfo.gi" />
      <Folder name="addons" defaultOpen>
        <File name="pak01_dir.vpk" />
      </Folder>
    </Folder>
  </Folder>
</Files>

```mdx
<Files>
  <Folder name="game" defaultOpen>
    <Folder name="citadel" defaultOpen>
      <File name="gameinfo.gi" />
      <Folder name="addons" defaultOpen>
        <File name="pak01_dir.vpk" />
      </Folder>
    </Folder>
  </Folder>
</Files>
```

## Image

A screenshot. `alt` text is required. Reviewers reject images without
it. Keep files under 500 KB and put them in `public/wiki-images/`.
Readers can click any image to zoom it.

<img
  src="/wiki-images/1767019072359-dfx5or.webp"
  alt="LtMAO with the maya tab open, showing the lemon3d install steps"
/>

```mdx
<img
  src="/wiki-images/your-screenshot.png"
  alt="Short description of the image"
/>
```

## ToolCard

A single tool row with a name, a link, and a one-line description. Use
it on tool list pages.

<ToolCard
  name="Flint"
  href="/docs/lol/tools/modding-apps/flint"
  badge="Recommended"
>
  All-in-one skin creation tool.
</ToolCard>

```mdx
<ToolCard
  name="Flint"
  href="/docs/lol/tools/modding-apps/flint"
  badge="Recommended"
>
  All-in-one skin creation tool.
</ToolCard>
```

Props:

- `name` and `href` are required. External links open in a new tab.
- `badge` is optional. It renders as a small pill on the right.
- `icon` is optional. Pass the tool's logo: `icon={<Icon name="Flint" />}`.
  See [Icon](#icon) for the logos we have.
- Use it for tools only. For guides, use [PremiumCard](#premiumcard).

## LevelPill

A difficulty marker. Put it at the top of a guide, right under the
title. `level` is `beginner`, `intermediate`, or `advanced`.

<LevelPill level="beginner" /> <LevelPill level="intermediate" />
<LevelPill level="advanced" />

```mdx
<LevelPill level="beginner" />
```

Use the optional `label` prop to change the text:
`<LevelPill level="advanced" label="Expert" />`.

    { name: "skin_id", description: "The numeric id of the base skin." },
  ]}
/>

```mdx
<ParameterList
  parameters={[
    { name: "champion", description: "The champion the skin belongs to." },
    { name: "skin_id", description: "The numeric id of the base skin." },
  ]}

```

## PremiumCard

A card that links to a guide or a section. Use one with `featured` for
the most important next page, or several in a [CardGrid](#cardgrid) for
a set of choices.

<PremiumCard
  title="Getting started"
  href="/docs/lol/getting-started"
  icon={<Icon name="Compass" />}
  featured
>
  Start here if you are new. One path from empty folder to finished skin.
</PremiumCard>

```mdx
<PremiumCard
  title="Getting started"
  href="/docs/lol/getting-started"
  icon={<Icon name="Compass" />}
  featured
>
  Start here if you are new.
</PremiumCard>
```

Props:

- `title` and `href` are required.
- `icon` is optional: `icon={<Icon name="Compass" />}`.
- `featured` adds a purple frame. Use it once per page at most.
- `level` adds a small difficulty tag: `beginner`, `intermediate`, or
  `advanced`.

## CardGrid

PremiumCards side by side. Use it for the sections of a category, or for
two or three real choices at the end of a guide.

<CardGrid>
  <PremiumCard
    title="Maya"
    href="/docs/lol/maya"
    icon={<Icon name="Maya" />}
    level="intermediate"
  >
    Rigging, skinning, and exporting for League.
  </PremiumCard>
  <PremiumCard
    title="Blender"
    href="/docs/lol/blender"
    icon={<Icon name="Blender" />}
    level="intermediate"
  >
    The same workflow in Blender.
  </PremiumCard>
</CardGrid>

```mdx
<CardGrid>
  <PremiumCard title="Maya" href="/docs/lol/maya" icon={<Icon name="Maya" />}>
    Rigging, skinning, and exporting for League.
  </PremiumCard>
  <PremiumCard
    title="Blender"
    href="/docs/lol/blender"
    icon={<Icon name="Blender" />}
  >
    The same workflow in Blender.
  </PremiumCard>
</CardGrid>
```

`cols={3}` fits three narrow cards per row on wide screens.

## ToolHeader

The summary at the top of a tool's own page: its logo, what it does,
short facts, and the download button. Use it once, right under the
title.

<ToolHeader
  name="Flint"
  icon="Flint"
  badge="Recommended"
  facts={["Free", "Windows"]}
  primary={{
    label: "Download",
    href: "https://github.com/RitoShark/Flint/releases",
  }}
>
  All-in-one modding app. Extract, preview, edit, and pack in one window.
</ToolHeader>

```mdx
<ToolHeader
  name="Flint"
  icon="Flint"
  badge="Recommended"
  facts={["Free", "Windows"]}
  primary={{
    label: "Download",
    href: "https://github.com/RitoShark/Flint/releases",
  }}
  links={[{ label: "GitHub", href: "https://github.com/RitoShark/Flint" }]}
>
  All-in-one modding app.
</ToolHeader>
```

Props:

- `name` is required. `icon` takes an [Icon](#icon) name.
- `facts` is a short list: price, license, platforms, version.
- `primary` is the main download. `links` adds smaller buttons, such as
  GitHub or docs.

## Requirements

The "What you need" list, as chips. Give each tool its logo and a link
to its page. Things that aren't tools (an account, a file) go in as
plain chips.

<Requirements>
  <Requirement icon="Flint" href="/docs/lol/tools/modding-apps/flint">
    Flint
  </Requirement>
  <Requirement icon="GIMP" note="or Photoshop">
    GIMP
  </Requirement>
  <Requirement icon="FileImage">Your texture as a PNG</Requirement>
</Requirements>

```mdx
<Requirements>
  <Requirement icon="Flint" href="/docs/lol/tools/modding-apps/flint">
    Flint
  </Requirement>
  <Requirement icon="GIMP" note="or Photoshop">
    GIMP
  </Requirement>
  <Requirement icon="FileImage">Your texture as a PNG</Requirement>
</Requirements>
```

Keep each label short. Put longer notes in a sentence under the chips.

## MenuPath

A menu path inside a step. It shows each menu item as a key, with arrows
between them.

1. Right-click the file and choose <MenuPath path="Recompile > Full" />.

```mdx
1. Right-click the file and choose <MenuPath path="Recompile > Full" />.
```

## GlowCTA

A glowing call-to-action button. Use it for the one action you want
the reader to take. One per page at most.

<GlowCTA href="/docs/lol">Browse the guides</GlowCTA>

```mdx
<GlowCTA href="/docs/lol">Browse the guides</GlowCTA>
```

Props:

- `variant` is `primary` (purple glow, default), `solid`, `secondary`,
  or `ghost`.
- `size` is `md` (default) or `lg`.

## YouTube

An embedded YouTube video. Pass the video id, not the full URL. The id
is the part after `watch?v=` or `youtu.be/`.

<YouTube
  id="xqB84ga55hI"
  title="Custom skin walkthrough for League of Legends"
/>

```mdx
<YouTube id="xqB84ga55hI" title="What the video shows" />
```

Props:

- `id` is required.
- `title` describes the video for screen readers.
- `start` is optional. It starts playback at that second.

Shortcut: paste a plain YouTube link on its own line and the wiki turns
it into an embed for you.

## Icon

An inline icon. Use any [Lucide icon name](https://lucide.dev/icons/),
or one of the logos below. The same names work for the `icon` prop of
ToolHeader and Requirement, and inside `icon={<Icon name="..." />}`.

| Group          | Names                                                                                          |
| -------------- | ---------------------------------------------------------------------------------------------- |
| Games          | `LeagueOfLegends`, `Deadlock`                                                                  |
| League tools   | `Flint`, `Jade`, `Quartz`, `Ruby`, `LtMAO`                                                     |
| Deadlock tools | `Source2Viewer`, `DeadlockModManager`, `Grimoire`                                              |
| Apps           | `Maya`, `Blender`, `GIMP`, `Audacity`, `Wwise`, `NotepadPlusPlus`                              |
| Platforms      | `Steam`, `Valve`, `SteamDeck`, `Linux`, `GameBanana`, `GitHub`, `Discord`, `YouTube`, `Reddit` |

<Icon name="Wrench" /> <Icon name="Sparkles" /> <Icon name="Blender" />
<Icon name="Discord" />

```mdx
<Icon name="Wrench" />
```

`className="size-4"`.
