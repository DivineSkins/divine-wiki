Zenless Zone Zero and XXMI Launcher are made for Windows. Some players run both on Linux or a Steam Deck through Wine or Proton, which translate the Windows game. This page says what is known to work, what breaks, what is not known yet, and where to ask for help.

<Callout type="warning" title="Unofficial, and not tested here">
  XXMI Launcher's author offers Linux support "as is", in the hope that Wine and
  Proton do the job. The launcher's issue tracker does not take Linux bug
  reports. Nobody has tested the steps on this page with Zenless Zone Zero 3.3
  for this wiki.
</Callout>

## The risk is the same as on Windows

Mods break the Terms of Service of Zenless Zone Zero. HoYoverse can suspend or permanently ban any account that uses third-party software. The game's kernel anti-cheat runs under Wine and Proton too, and since about June 2026 it has crashed the game for some Linux players who use XXMI. Linux is not a way around the anti-cheat or the rules. Use mods only on an account you can afford to lose.

[What's allowed and how to stay safe](/docs/zenless-zone-zero/getting-started/stay-safe) explains the risk in full.

## What is known to work

<img
  src="/wiki-images/zenless-zone-zero-errors-linux-steam-deck-1.webp"
  alt="A Wine prefix folder tree that holds both the official HoYoPlay launcher with Zenless Zone Zero and the portable XXMI Launcher with its ZZMI Mods folder, next to four rules for Linux"
/>

One rule matters most: XXMI Launcher must run in the same Wine or Proton prefix as the game. A prefix is the folder where Wine keeps one fake Windows install.

Run the official HoYoPlay launcher and the portable XXMI Launcher in one prefix. A Wine manager such as Lutris makes this easier.

1. Install HoYoPlay into a Wine prefix, then install Zenless Zone Zero through it. Start the game once.
2. In HoYoPlay, leave the **DX12** box under **Start Game** unticked. Mods only work in DirectX 11.
3. Download `XXMI-Launcher-Portable-vX.X.X.zip` from the [XXMI Launcher releases](https://github.com/SpectrumQT/XXMI-Launcher/releases/latest) on GitHub.
4. Extract it to a folder inside the same prefix. Keep it out of `Program Files`, and use no `{` or `}` in the path.
5. Install the Microsoft Visual C++ Redistributable (x64) in that prefix. The portable build needs it.
6. Add `Resources\Bin\XXMI Launcher.exe` as a second program in the same prefix. In Lutris, duplicate the HoYoPlay entry and change its executable.
7. Start XXMI Launcher, pick Zenless Zone Zero, and install ZZMI. If it does not find the game, set **Game Folder** to the `ZenlessZoneZero Game` folder, the one that holds `ZenlessZoneZero.exe`.
8. Put your mods in `ZZMI\Mods` inside the launcher folder. Start the game from XXMI Launcher.

The steps after the install are the same as on Windows: [Install mods with XXMI Launcher](/docs/zenless-zone-zero/getting-started/install-with-xxmi-launcher).

This video is from early 2025 and shows XXMI Launcher 1.3.4, so the labels differ today. It puts the launcher in `Program Files`: the launcher's own README says to avoid those folders. The creator's pinned comment updates the Wine advice: Wine Staging-Tkg 10.0, not Wine 10.1. In the video, Zenless Zone Zero works with this route without extra steps. That was before version 3.0, which added the DX12 option and the Steam version, and before the crash reports below. The video also turns VKD3D and NVAPI on: turn them off only if you see the entry-point error below.

## Steam version and Steam Deck

Zenless Zone Zero is on Steam since version 3.0. XXMI Launcher's Steam option is documented for Windows. On Linux, we found no confirmed way to use mods with the Steam version. The video above does not cover Steam copies either.

On a Steam Deck, switch to Desktop Mode and use the route above. The video above runs on a Steam Deck and adds shortcuts you can start from Game Mode. One player who tried the Steam version with XXMI on a Steam Deck got "unable to connect to steam servers".

XXMI's folder picker does not show hidden folders, such as `.local`. Type the path into the picker's address bar instead.

## Common problems

<Accordions type="multiple">
<Accordion title="The game crashes right after login" id="crash-after-login">

**Cause:** since about June 2026, some players see the game close right after login when XXMI runs under Wine or Proton. The log points at the game's anti-cheat driver.

**Fix:** none is confirmed. XXMI Launcher's author treats it as outside the launcher's scope. Never use a tool or setting that works around the anti-cheat. Ask in the AGMG Discord's Linux channel.

</Accordion>
<Accordion title='"d3d11.dll is missing expected entry point"' id="entry-point">

**Cause:** on Linux, this error comes from the graphics layers of Wine or Proton, VKD3D or NVAPI. It was reported with the portable XXMI Launcher in plain Wine and the Steam version of the game.

**Fix:** turn off VKD3D and NVAPI in your Wine runner's settings, then start again. If it stays, ask in the AGMG Discord's Linux channel.

{/* NEEDS HANDS-ON TEST: that turning off VKD3D and NVAPI clears this error for ZZMI on Linux */}

</Accordion>
<Accordion title="XXMI Launcher cannot find the game" id="game-not-found">

1. Check that the launcher and the game run in the same prefix.
2. In the launcher settings, set **Game Folder** to the folder that directly holds `ZenlessZoneZero.exe`.
3. If the folder sits under a hidden folder such as `.local`, type its path by hand.

</Accordion>
<Accordion title="The game starts, but mods do not show" id="no-mods">

Check that the **DX12** box is unticked, then go through [Mods not loading](/docs/zenless-zone-zero/errors/mods-not-loading). Its checks, such as the two graphics options, apply on Linux too.

</Accordion>
</Accordions>
