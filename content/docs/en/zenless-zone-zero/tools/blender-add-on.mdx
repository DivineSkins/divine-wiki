XXMI Tools is the Blender add-on for Zenless Zone Zero model mods. It reads a dump of an agent, lets you edit it in Blender, and writes the mod folder that ZZMI loads. This page explains each menu, panel, and option. The step-by-step guides are in the models section.

Written for the XXMI Tools 1.8.2 code. The game preset for this game is `Zenless Zone Zero`.

<Accordions>
<Accordion title="Coming from another game?">

- **Genshin Impact or Honkai: Star Rail:** same add-on, but this game has its own `Zenless Zone Zero` preset with other axes, and one extra export option, `Outline gate divergence`. See the [Genshin Impact section](/docs/genshin-impact) and the [Honkai: Star Rail section](/docs/honkai-star-rail).
- **Wuthering Waves:** uses a different add-on, WWMI Tools. Nothing on this page applies there. See the [Wuthering Waves section](/docs/wuthering-waves).
- **Deadlock or League of Legends:** nothing is packed or compiled. The add-on writes buffers and an `.ini`, ZZMI swaps them in while the game draws, and `F10` reloads them in game.

</Accordion>
</Accordions>

## Install it

1. Remove old plugins first. In <MenuPath path="Edit > Preferences > Add-ons" />, search for `3dmigoto`, `LeoTools`, and `XXMI`, and remove what you find. Restart Blender.
2. Download `XXMITools_v1.8.2.zip` from the GitHub releases page. Do not unzip it.
3. Open <MenuPath path="Edit > Preferences > Add-ons" /> again.
4. In Blender 4.2 or newer, click the small down arrow in the top-right corner and choose **Install from Disk...**. In Blender 3.6 to 4.1, click **Install...**.
5. Pick the `.zip` file.
6. Tick the checkbox next to `XXMI_Tools`.
7. Restart Blender.

To check it worked, open <MenuPath path="File > Import" />. You should see `XXMI Dump(vb.txt + ib.txt)`. Press `N` in the 3D Viewport: the sidebar has an **XXMI Tools** tab with `v1.8.2` in its header.

## Menu entries

XXMI Tools adds these entries to the File menu.

| Menu                              | Entry                                                        | Use it for                                                                    |
| --------------------------------- | ------------------------------------------------------------ | ----------------------------------------------------------------------------- |
| <MenuPath path="File > Import" /> | `XXMI Dump(vb.txt + ib.txt)`                                 | Importing a dump. The current importer, with game presets.                    |
| <MenuPath path="File > Import" /> | `3DMigoto frame analysis dump (vb.txt + ib.txt)`             | The older importer that most tutorials show. It still works.                  |
| <MenuPath path="File > Import" /> | `3DMigoto raw buffers (.vb + .ib)`                           | Raw binary buffers with a `.fmt` file. Rarely needed.                         |
| <MenuPath path="File > Import" /> | `Apply 3DMigoto vertex group map to current object (.vgmap)` | Renumbering vertex groups from a `.vgmap` file.                               |
| <MenuPath path="File > Import" /> | `3DMigoto pose (.txt)`                                       | Building an armature from dumped bone data.                                   |
| <MenuPath path="File > Export" /> | `Exports Mod Folder`                                         | The older way to export. The sidebar **Export Mod** button does the same job. |
| <MenuPath path="File > Export" /> | `3DMigoto raw buffers (.vb + .ib)`                           | Writing one object's buffers with no `.ini`.                                  |

Older guides show other labels, such as **Copy textures** or **Use foldername when exporting**. They came from earlier versions. This page uses the 1.8.2 labels.

## The import dialog

`XXMI Dump(vb.txt + ib.txt)` opens a file browser with options on the right. Select the files in the dump folder, the one that holds `hash.json`.

`Simple mode` is on by default. It hides the technical options and asks you to pick a game. Set **Game preset** to `Zenless Zone Zero`. The preset sets the rest for you: it flips the UVs and the mesh, uses `Y` forward and `Z` up, and loads `.buf` files.

| Option                 | Default            | What it does                                                                                      |
| ---------------------- | ------------------ | ------------------------------------------------------------------------------------------------- |
| **Game preset**        | `None`             | Picks the game. A red "You must select a game" box shows until you do.                            |
| **Flip Mesh**          | on with the preset | Mirrors the mesh so it faces the right way.                                                       |
| **Create Materials**   | off                | Adds a material per part with its diffuse texture, so you see colors in Material Preview.         |
| **Create Collections** | off                | Adds one collection per in-game part. Objects inside a collection merge into that part on export. |
| **Merge Vertices**     | off                | Merges duplicate vertices.                                                                        |
| **Tris to Quads**      | off                | Turns triangles into quads, keeping UVs and colors.                                               |
| **Clean Loose**        | off                | Deletes loose geometry.                                                                           |

If you change an axis or flip option by hand, the preset quietly switches back to `None`. Untick `Simple mode` to see the advanced panels: related files, bone buffers, semantic remap, and orientation. You rarely need them.

The older `3DMigoto frame analysis dump` importer does not have this preset, and its default axes are for other games. Keep **Flip TEXCOORD V** on and set **Orientation** to Forward `Y` and Up `Z`. LOD meshes import with other axes.

## The XXMI Tools sidebar

Press `N` in the 3D Viewport and open the **XXMI Tools** tab. The `?` button in the header opens the official guide.

| Field             | What to set                                                                                                    |
| ----------------- | -------------------------------------------------------------------------------------------------------------- |
| **Dump Folder**   | The folder you imported from, with `hash.json`. Filled in on import.                                           |
| **Output Folder** | Where the finished mod goes. Can be a folder inside `Mods`. Empty, it writes `<DumpName>Mod` next to the dump. |
| **Game to mod**   | `Zenless Zone Zero`. Filled in from the import preset.                                                         |

The **Export Settings** panel is folded by default:

| Option                                           | Default | What it does                                                                                                                                        |
| ------------------------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ignore hidden objects**                        | on      | Hidden objects are not exported. Keep spare meshes hidden.                                                                                          |
| **Only export selected**                         | off     | Exports only the selected objects.                                                                                                                  |
| **Apply modifiers and shapekeys**                | on      | Applies modifiers on a copy before export. Your scene stays as it is.                                                                               |
| **Normalize weights to format**                  | on      | Keeps at most 4 weights per vertex and normalizes them.                                                                                             |
| **Mod textures**                                 | on      | Writes texture lines into the `.ini` and copies missing textures from the dump. It does not overwrite a texture you edited with the same file name. |
| **Ignore shadow ramps/metal maps/diffuse guide** | on      | Skips helper textures from other games. Zenless Zone Zero dumps do not have them.                                                                   |
| **Ignore duplicated textures**                   | off     | Skips textures whose hash is already copied.                                                                                                        |
| **Write buffers**                                | on      | Writes the `.buf` and `.ib` files.                                                                                                                  |
| **Write ini**                                    | on      | Writes the `.ini`. Untick it to keep an `.ini` you edited by hand.                                                                                  |
| **Use custom template**                          | off     | Uses your own `.ini` template.                                                                                                                      |
| **Credit**                                       | empty   | Your name. The game shows "Created by" with it when the mod loads.                                                                                  |
| **Outline Optimization**                         | on      | Rebuilds the outline data for this game. Slow, so some creators turn it off until the final export.                                                 |
| **Outline decimal rounding precision**           | `8`     | How close vertices must be to share one outline vertex.                                                                                             |
| **Outline gate divergence**                      | `10.0`  | Only for Zenless Zone Zero. Below this angle, in degrees, the outline data is set to zero. The game uses the same hard cut.                         |
| **Use custom normals for outlines**              | off     | Builds outlines from your own normals.                                                                                                              |

Keep **Outline Optimization** on with XXMI Tools 1.8.2. Switch it off if outlines or shading look wrong. Guides from before mid-2025 say off: that applied to older versions.

{/* NEEDS HANDS-ON TEST: export one Zenless Zone Zero agent with Outline Optimization on and off in XXMI Tools 1.8.2 and compare outlines and shading in game. */}

Below the settings sit **Export Mod** and **Start Batch export**. Batch export writes one mod per timeline frame into numbered folders, using a pattern such as `name_###`. [Export your mod from Blender](/docs/zenless-zone-zero/models/export-your-mod) walks through a full export.

Keep every part of a component you export. To remove a part, empty its mesh instead of deleting the object. Components you did not touch can be left out. Older guides say every component in `hash.json` must stay in the scene, or tell you to edit `hash.json`: you no longer need to. Keep the object name prefix, such as `EllenBodyA`.

{/* NEEDS HANDS-ON TEST: that XXMI Tools 1.8.2 exports a Zenless Zone Zero agent with one untouched component left out of the scene, and fails when one part of an exported component is deleted. */}

The Zenless Zone Zero template drives the mesh through the Blend hash with a `DRAW_TYPE` check, never the Position hash. It writes textures in the SlotFix form: `Resource\ZZMI\Diffuse = ref ...` lines, then `run = CommandList\ZZMI\SetTextures`.

## The XXMI Toolbox

The **XXMI Toolbox** panel, folded by default, cleans up meshes before export. Vertex groups are bone numbers. They must count up from `0` with no gaps.

| Button                                                 | What it does                                                                                |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------- |
| **Remove unused Vertex Groups**                        | Deletes groups that no vertex uses.                                                         |
| **Merge shared name Vertex Groups**                    | Merges `12`, `12.001`, and `12.002` into `12`, then sorts the groups.                       |
| **Merge shared name VGs with the active Vertex Group** | The same, for the active group only.                                                        |
| **Fill gaps in Vertex Groups**                         | Adds empty groups for missing numbers, for example `1` and `2` when only `0` and `3` exist. |
| **Clean UV Names**                                     | Renames the UV maps by their order: `TEXCOORD.xy`, `TEXCOORD1.xy`, and so on.               |
| **Reset Vertex Colors**                                | Replaces the `COLOR` attribute on the selected meshes with one flat color.                  |

Hold `Alt` while you click a vertex group button to run it on every selected object.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check on a Zenless Zone Zero agent that vertex groups must run from 0 with no gaps and that the toolbox buttons behave as described. */}

Before you use **Reset Vertex Colors**, try copying the colors from the original mesh with Blender's Data Transfer modifier instead. In this game, vertex color red sets the outline thickness and blue is used for hair shadows, so keep the original's values where you can.

{/* NEEDS HANDS-ON TEST: whether Reset Vertex Colors writes byte 128 or 188 */}

Two more panels sit below. **XXMI Object's Custom properties** lists the `3DMigoto:` properties of the selected object: do not edit them. **Updater** checks for new versions of the add-on.

## What it cannot do

- **Import a finished mod.** It imports dumps only. Keep your `.blend` file for every mod.
- **Add bones.** You can only use the bones the agent already has.
- **Export shape keys.** Shape-key export for Zenless Zone Zero is in development. It is not in version 1.8.2.
- **Edit face meshes.** Face mods change textures only. The asset repo has no face meshes, and a changed face mesh breaks the face animations.

## Common problems

<Accordions type="multiple">
<Accordion title="Menus show up twice or exports throw odd errors" id="two-plugins">

An old plugin is still on next to XXMI Tools. Remove every old 3DMigoto or LeoTools add-on, then restart Blender.

</Accordion>
<Accordion title='"Please select a valid game before continuing."' id="select-game">

Set **Game to mod** to `Zenless Zone Zero` in the sidebar, then export again.

</Accordion>
<Accordion title='"Destination path not set, defaulting to ..."' id="destination">

**Output Folder** is empty. The mod went to `<DumpName>Mod` next to the dump. Set an output folder to choose the place.

</Accordion>
<Accordion title="The model does not stand upright or face you" id="axes">

You imported with the wrong axes. Import again with the `Zenless Zone Zero` preset, or set Forward `Y` and Up `Z` in the older importer.

</Accordion>
<Accordion title="The add-on does not import at all" id="old-blender">

Your Blender is older than 3.6. Install Blender 4.5 LTS.

</Accordion>
</Accordions>

More export and import errors are on [Blender export and import errors](/docs/zenless-zone-zero/errors/creator-errors).
