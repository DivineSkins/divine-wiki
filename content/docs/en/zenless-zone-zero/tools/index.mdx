A Zenless Zone Zero mod needs a few free tools. Each row below says what a tool does. Click it for the full guide.

**New here?** Install XXMI Launcher first. It is the only tool a player needs.

<Callout type="info" title="Every tool here is community-made">

HoYoverse makes no modding tools for Zenless Zone Zero. The tools on these pages come from community creators, and all of them are free. XXMI Launcher is free too: never pay for it.

</Callout>

## How the tools fit together

<img
  src="/wiki-images/zenless-zone-zero-tools-index-1.webp"
  alt="Five stages of a Zenless Zone Zero mod: get the original from the asset repo or a frame dump, edit it in Paint.NET or Blender, export with XXMI Tools, put it in the ZZMI Mods folder, and press F10 in game"

Every mod passes through the same stages. A texture-only mod skips Blender: you write its short `.ini` by hand. [How Zenless Zone Zero mods work](/docs/zenless-zone-zero/basics/how-mods-work) explains what ZZMI does with these files.

## Tools to skip

| Skip this                                                             | Why                                             | Use instead                               |
| --------------------------------------------------------------------- | ----------------------------------------------- | ----------------------------------------- |
| Standalone ZZMI (2024)                                                | Deprecated. It gets no updates.                 | XXMI Launcher                             |
| Separate SlotFix downloads, or SlotFix copies inside mods             | ZZMI ships SlotFix. Extra copies cause crashes. | Nothing. Delete stray copies from `Mods`. |
| Old Blender plugins (`blender_3dmigoto` scripts, LeoTools scripts)    | Replaced, and they clash with XXMI Tools.       | XXMI Tools                                |
| The 2024 "Zenless Zone Zero Asset Library"                            | Stale dumps from early versions.                | ZZ-Model-Importer-Assets                  |
| Fix tools for old versions                                            | Outdated. Old fixers break newer mods.          | The current ZZZ Mod Fixer                 |
| A `d3d11.dll` from any source but the launcher                        | Real fixes never swap XXMI files.               | XXMI Launcher's **Repair ZZMI**           |
| GitHub "mod menus", "mod launchers", and skin packs with farmed stars | Tools for unfair play, or malware.              | Nothing. Never download them.             |
| Lookalike 3DMigoto download sites                                     | Not official.                                   | XXMI Launcher                             |

## How to spot a real tool

- Real tools come from known community authors, most often on GitHub. GameBanana's upload bot has blocked some fix tool `.exe` files, so current Zenless Zone Zero fix tools link to GitHub.
- Download each tool from the link on its wiki page, not from a search result or a video comment.
- A tool can be an `.exe`. A mod never is: it holds `.ini`, `.buf`, `.ib` and `.dds` files. [What's allowed and how to stay safe](/docs/zenless-zone-zero/getting-started/stay-safe) explains how to check a mod download.
