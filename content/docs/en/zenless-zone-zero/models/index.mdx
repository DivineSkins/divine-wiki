Model mods change the shape of an agent. You edit the original model in Blender with XXMI Tools, then export it as a mod that ZZMI loads.

No tool can replace animations or add bones. A model mod changes the mesh that the agent's own skeleton moves. Faces cannot be edited in this game: only face textures can change.
