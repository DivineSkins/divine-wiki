<Callout type="warning" title="Play in DirectX 11">
  Mods only load when Zenless Zone Zero runs in DirectX 11. Since version 3.0
  the game also has a DirectX 12 mode: leave the **DX12** box under **Start
  Game** in the official launcher unticked. Mods also need **Character Quality**
  at **High** and **High-Precision Character Animation** at **Disable**. XXMI
  Launcher sets both each time it starts the game. The install guide, under the
  Install mods button, shows each setting.
</Callout>

## Tools

HoYoverse has not released modding tools for Zenless Zone Zero. These community tools fill the gap.

<ToolCard
  name="XXMI Launcher"
  href="/docs/zenless-zone-zero/tools/xxmi-launcher"
  badge="Required"
  icon={<Icon name="XXMILauncher" />}
>
  Installs and updates ZZMI, starts the game with mods, sets the graphics
  options mods need, and opens your Mods folder.
</ToolCard>

<ToolCard
  name="XXMI Tools for Blender"
  href="/docs/zenless-zone-zero/tools/blender-add-on"
  badge="Models"
  icon={<Icon name="Blender" />}
>
  Imports Zenless Zone Zero models into Blender and exports your edits as a mod.
</ToolCard>

<ToolCard
  name="Paint.NET"
  href="/docs/zenless-zone-zero/tools/texture-editors"

  icon={<Icon name="PaintNET" />}
