<LevelPill level="beginner" />

Every Honkai: Star Rail mod is a folder inside SRMI's `Mods` folder. This page shows how to add more, turn them off, reload them in game, and clean up. Written for XXMI Launcher 2.5.0 and SRMI 2.4.3.

## What you need

<Requirements>
  <Requirement
    icon="XXMILauncher"
    href="/docs/honkai-star-rail/getting-started/install-with-xxmi-launcher"
    note="with SRMI installed"
  >
    XXMI Launcher
  </Requirement>
  <Requirement icon="FileArchive" note="such as 7-Zip">
    An archive tool
  </Requirement>
</Requirements>

Your `Mods` folder is here:

```text
%AppData%\XXMI Launcher\SRMI\Mods
```

To open it, click the 3-dots button next to **Start** in XXMI Launcher, then **Open Mods Folder**.

## How SRMI reads your Mods folder

<img
  src="/wiki-images/honkai-star-rail-getting-started-manage-mods-1.webp"
  alt="A Mods folder tree: mod folders and one RabbitFX load, a DISABLED folder and a DISABLED .ini are skipped, a .zip is ignored, and a second RabbitFX and a stray d3dx.ini are marked for deletion"
/>

- SRMI loads every `.ini` file in `Mods` and in every folder inside it, at any depth.
- A file or folder whose name starts with `DISABLED` is skipped, with everything inside it.
- A `.zip`, `.7z` or `.rar` file does nothing. Always extract it.

So you can sort mods into folders however you like, for example `Mods\Acheron\Acheron Outfit`.

## Add a mod

1. Open the mod you downloaded with your archive tool. Check that it holds only `.ini`, `.buf`, `.ib` and `.dds` files, and sometimes `.hlsl`.
2. Extract the mod's folder into `Mods`. You should get `Mods\<mod name>\<something>.ini`.
3. If the archive holds several versions in separate folders, keep only the one you want. The others load too unless you turn them off.
4. Turn off any other mod for the same character outfit.
5. If the mod page says it needs RabbitFX, check that you have exactly one copy (see below).
6. In game, switch to a different character so the modded one is off screen.
7. Press `F10`. Switch back to see the mod.

If the character looks collapsed or stretched after `F10`, it was on screen during the reload. Hide it, press `F10` again, teleport, or restart the game.

### One mod per character outfit

Only one mod per character outfit can be on at a time. Two mods for the same outfit fight each other and you get a mix of both, sometimes with warning text. A merged mod counts as one: it switches between several mods with a key.

Each official outfit, such as March 7th's or Ruan Mei's, is a separate model. A mod for a character's default look does not change their other outfits. The Trailblazer also has a separate model for each Path, so a Trailblazer mod may only work on some Paths. Some Trailblazer mods need a small helper called Path Detection. The mod page says so.

## Turn a mod off or on

<Tabs items={["Turn one mod off", "Turn all mods off"]}>
<Tab value="Turn one mod off">

1. Rename the mod's folder so its name starts with `DISABLED`, for example `DISABLED_Kafka Recolor`.
2. Press `F10` in game.

To turn it back on, remove `DISABLED` from the name and press `F10`.

You can do the same to one `.ini` file inside a mod, for example `DISABLED_Hat.ini`, to drop only that part.

</Tab>
<Tab value="Turn all mods off">

- Press `F6` to turn all mods off. Press it again to turn them back on.
- Hold `F9` to see the original game while the key is down.

Neither key changes any files. Your mods come back as they were.

</Tab>
</Tabs>

Turning a mod off with `DISABLED` also forgets the options you picked in it, such as which outfit part was showing.

## Keys you will use

| Key                  | What it does                                                 |
| -------------------- | ------------------------------------------------------------ |
| `F10`                | Reload all mods and save their settings                      |
| `F6`                 | Turn all mods off or on                                      |
| `F9` (hold)          | Show the original game while held                            |
| `F12`                | Show or hide the SRMI user guide                             |
| `Ctrl+Alt+F10`       | Reset the saved settings of every mod, then reload           |
| `Ctrl+Alt+Shift+End` | Turn all mod keys off or on, so typing does not trigger them |

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check on Honkai: Star Rail 4.7 with XXMI DLL 1.3.2 that Ctrl+Alt+Shift+End turns mod keys off and on. */}

Many mods add their own keys to switch parts, colors or outfits. The mod's page lists them. SRMI saves your choices when you press `F10`. On a laptop, you may need to hold `Fn` with the F keys.

To give a mod different keys, see [Change a mod's keys and saved settings](/docs/honkai-star-rail/ini/change-mod-keys).

## Keep your Mods folder clean

### Keep one copy of RabbitFX

Some Star Rail mods need **RabbitFX**, a helper library by caverabbit for glow and stable textures. It is not part of SRMI: you add it yourself, once.

The Star Rail version is called **RabbitFX (SRMI)**. A mod that needs it says so on its page. Add it only then.

1. Extract RabbitFX into its own folder, for example `Mods\RabbitFX`.
2. Keep only that one copy anywhere in `Mods`.
3. If a mod came with its own RabbitFX inside its folder, delete that copy.
4. When a new RabbitFX version comes out, replace your copy with it. Do not add a second one.

<Callout type="warning" title="Two copies of RabbitFX break mods">
  The RabbitFX author warns that more than one copy causes odd behaviour and
  game crashes. An old copy can also turn newer characters pink during their
  skills. RabbitFX can clash with other shader mods.
</Callout>

### Remove files that do not belong

1. Delete any `d3dx.ini` or `d3d11.dll` that came with a mod. XXMI Launcher refuses to start with a `d3dx.ini` in `Mods`.
2. Never copy files from `SRMI\Core` into `Mods`. SRMI's own skinning files stay in `Core`.
3. Never put mod files into `SRMI\ShaderFixes`. SRMI keeps its own files there. If you added files there, remove them, then click the 3-dots button next to **Start** and run **Repair SRMI**.

### Optimize Mods

Each time you click **Start**, XXMI Launcher checks `Mods` for common problems. It offers to turn off stray `d3dx.ini` files and `.ini` lines that cost a lot of FPS. It turns off a file by adding `DISABLED_` to its name, and a heavy line by making it a comment.

To run the same check by hand, click the 3-dots button next to **Start**, then **Optimize Mods**. The details go to `XXMI Launcher Log.txt` in the launcher folder.

{/* NEEDS HANDS-ON TEST: on a test SRMI Mods folder with a d3dx.ini and a heavy ShaderRegex mod, record exactly what Optimize Mods changes and the wording of each prompt in XXMI Launcher 2.5.0. */}

### Many mods

Each mod that is on makes `F10` and the first load slower. Keep on only the mods you use, and turn the rest off with `DISABLED`. A few badly made mods also lower your FPS: **Optimize Mods** finds the worst of them.

Zip your whole `Mods` folder before every game update. Star Rail updates break mods often, and fix tools change files. With a backup, you can always go back.

## Use a mod manager or not

You do not need a mod manager. Folders and the `DISABLED` prefix do everything above, and fix tools expect this plain setup.

If you want buttons instead of renaming folders, two maintained managers support Honkai: Star Rail. Both are source available.

<ToolCard
  name="Integrated Mod Manager"
  href="https://github.com/jpbhatt21/integrated-mod-manager/releases"
  icon={<Icon name="GitHub" />}
>
  By jpbhatt21. A desktop app that lists your mods and tracks updates.
</ToolCard>
<ToolCard
  name="No Reload Mod Manager"

  icon={<Icon name="GitHub" />}
>
  By Aglglg. Switches mods from inside the game without pressing F10.
</ToolCard>

Use one manager at most on a `Mods` folder. Managers can edit mod `.ini` files, so restore your mods with the manager before you share one or run a fix tool. [Mod managers compared](/docs/honkai-star-rail/tools/mod-managers) has the details.

## Remove all mods

To play without mods for a while, start Honkai: Star Rail from HoYoPlay or Epic Games instead of XXMI Launcher. Nothing in the game folder changes.

To remove everything:

1. Uninstall XXMI Launcher from <MenuPath path="Settings > Apps" /> in Windows. If you used the portable version, delete its folder.
2. Delete the desktop shortcuts `XXMI Launcher` and `SRMI Quick Start` if they are still there.
3. Delete `%AppData%\XXMI Launcher\SRMI` if you no longer want your mods.

XXMI Launcher changes no Star Rail graphics settings, so there is nothing to set back in game.

## Common problems

<Accordions type="multiple">
<Accordion title="Orange text about a possible mod conflict" id="mod-conflict">

Two mods change the same character outfit. The text names the `.ini` files. Turn one of them off and press `F10`. You only see this text when **Mute Warnings** is off in the launcher's SRMI settings.

</Accordion>
<Accordion title="A mod's options reset after a restart" id="options-reset">

The mod does not save that option. This is a choice of the mod's creator. Pick the option again after each start.

</Accordion>
<Accordion title="A character turns pink during skills" id="pink-skills">

Your RabbitFX is out of date, or another effect mod clashes with it. Replace RabbitFX with the current version. If that does not help, turn off other effect mods one at a time.

</Accordion>
<Accordion title="The game crashes after you add RabbitFX" id="rabbitfx-crash">

Search `Mods` for a second RabbitFX folder and delete it. Then replace your one copy with the current version. If it still crashes, turn off other shader mods to find the one that clashes.

</Accordion>
</Accordions>

More fixes are in [Mods not loading](/docs/honkai-star-rail/errors/mods-not-loading) and [Mods look broken](/docs/honkai-star-rail/errors/mods-look-broken).
