This page sets up everything you need to make your own Honkai: Star Rail mods. Install the texture kit first. Add Blender when you want to change a model's shape. You need a working XXMI Launcher with SRMI before you start.

## The texture kit

<Steps>
<Step>

### Turn on hunting mode in XXMI Launcher

Hunting mode lets you find the hash of a part on screen and save a frame dump. It is off by default.

1. Open XXMI Launcher and click the SRMI icon.
2. Click the gear icon to open the settings.
3. Open the **SRMI** tab.
4. Tick **Enable Hunting** in the **Shader Hunting** section. Leave **Dump Shaders** off.
5. Start the game from XXMI Launcher.

In game, these keys now work:

| Key        | What it does                             |
| ---------- | ---------------------------------------- |
| `Numpad 0` | Turn hunting mode on or off (green text) |
| `Ctrl+F12` | Show or hide the hunting guide           |
| `F8`       | Save a frame dump                        |

No numpad? `d3dx.ini` in the SRMI folder explains how to move the hunting keys. [Find a hash with hunting mode](/docs/honkai-star-rail/basics/find-a-hash) shows how to use them.

{/* NEEDS HANDS-ON TEST: in XXMI Launcher 2.5.0, confirm the SRMI settings tab name and that Enable Hunting sits under Shader Hunting. Also confirm that the hunting guide opens with Ctrl+F12 (the GameBanana page says Ctrl+F1). */}

{/* SCREENSHOT: honkai-star-rail-getting-started-creator-setup-3.webp, XXMI Launcher 2.5.0 settings, SRMI tab, with Enable Hunting ticked. No source has a current screenshot of this tab. */}

</Step>
<Step>

### Install a texture editor

Honkai: Star Rail textures are `.dds` files. Paint.NET is free and opens and saves them without a plugin: DDS FileType Plus is built in since Paint.NET 4.2.2.

<ToolCard
  name="Paint.NET"
  href="https://www.getpaint.net/download.html"
  badge="Recommended"
  icon={<Icon name="PaintNET" />}
>
  Free, Windows. Use the classic installer from getpaint.net.
</ToolCard>

1. Download the classic installer from getpaint.net.
2. Run it and follow the steps.
3. Open any `.dds` file to check that it works.

Photoshop with Intel Texture Works, or GIMP, also work. [Texture editors and DDS plugins](/docs/honkai-star-rail/tools/texture-editors) compares them, and [Save DDS textures the right way](/docs/honkai-star-rail/textures/save-dds-files) has the save settings.

</Step>
<Step>

### Install a code editor

A mod's `.ini` file is plain text. A code editor with colors for `.ini` files makes mistakes easier to spot.

1. Install [Visual Studio Code](https://code.visualstudio.com/).
2. Add syntax colors for 3DMigoto `.ini` files from [3dmigoto-ini-extensions](https://github.com/lupomikti/3dmigoto-ini-extensions) by lupomikti. It works in several editors.

Save every `.ini` as UTF-8.

{/* NEEDS HANDS-ON TEST: how to install 3dmigoto-ini-extensions in VS Code (marketplace entry or manual install), its exact name in the editor, and whether it colors SRMI-specific lines such as $\SRMI\vertex_count. */}

</Step>
</Steps>

That is all you need for your first texture mod.

## The model kit

<Steps>
<Step>

### Install Blender

<ToolCard
  name="Blender"
  href="https://www.blender.org/download/lts/"
  icon={<Icon name="Blender" />}
>
  Free, open source. Use Blender 4.5 LTS.
</ToolCard>

1. Download Blender 4.5 LTS from blender.org.
2. Install it.

XXMI Tools needs Blender 3.6 or newer. Users report it working on Blender 4.4, 4.5 and 5.1. Nobody has reported testing it on Blender 5.2 yet, so stay on 4.5 LTS for now.

{/* NEEDS HANDS-ON TEST: import and export one Honkai: Star Rail character with XXMI Tools 1.8.2 on Blender 4.5 LTS and on 5.2 LTS (tests MD01). Update the pinned version if 5.2 works. */}

</Step>
<Step>

### Remove old 3DMigoto add-ons

XXMI Tools replaces the older Blender scripts. Two versions at once cause errors.

1. In Blender, open <MenuPath path="Edit > Preferences > Add-ons" />.
2. Search for `3dmigoto`, then `LeoTools`, then `XXMI`.
3. Remove every old version you find, such as `blender_3dmigoto_srmi.py` from the 2023 standalone SRMI.
4. Restart Blender.

</Step>
<Step>

### Install XXMI Tools

<ToolCard
  name="XXMI Tools"
  href="https://github.com/leotorrez/XXMITools/releases"
  badge="Required"
  icon={<Icon name="GitHub" />}
>
  By LeoTorreZ. Free. Imports Honkai: Star Rail models into Blender and exports
  them as a mod.
</ToolCard>

1. Download `XXMITools_v1.8.2.zip` from the latest release. Do not unzip it.
2. In Blender, open <MenuPath path="Edit > Preferences > Add-ons" />.
3. Click the small down-arrow at the top right, then **Install from Disk...**.
4. Pick the `.zip` file.
5. Tick the box next to `XXMI_Tools` if it is not ticked.
6. Restart Blender.

To check it worked, open <MenuPath path="File > Import" />. You should see `XXMI Dump(vb.txt + ib.txt)`. Press `N` in the 3D view: the sidebar now has an **XXMI Tools** tab.

On Blender 3.6 to 4.1, step 3 is the **Install...** button instead. When you import, pick the game preset `Honkai Star Rail`. It writes the Star Rail `.ini` layout when you export. [XXMI Tools for Blender](/docs/honkai-star-rail/tools/blender-add-on) explains every option.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check on Honkai: Star Rail that the File > Import entry reads XXMI Dump(vb.txt + ib.txt) in XXMI Tools 1.8.2 (one note calls it 3DMigoto frame analysis dump). */}

{/* SCREENSHOT: honkai-star-rail-getting-started-creator-setup-4.webp, Blender 4.5 Preferences > Add-ons with the down-arrow menu open on Install from Disk..., and XXMI_Tools ticked in the list. */}

</Step>
<Step>

### Get the original models

You start every model mod from the game's original model data. For most characters, it is already in a public GitHub repo.

<img
  src="/wiki-images/honkai-star-rail-getting-started-creator-setup-2.webp"
  alt="The PlayerCharacterData folder of the SR-Model-Importer-Assets repo on GitHub, listing one folder per character such as Acheron, Aglaea and Anaxa"
/>

1. Open [SR-Model-Importer-Assets](https://github.com/SilentNightSound/SR-Model-Importer-Assets) and go into `PlayerCharacterData`.
2. Find your character's folder, such as `Kafka` or `SilverWolf`. Outfits have their own folder.
3. Sign in to GitHub. In the address bar, change `github.com` to `github.dev` and press Enter.
4. Wait for the web editor to open. Right-click the character's folder and choose **Download**.
5. Allow the site to save files, and pick a work folder on your PC.

Never clone or download the whole repo. Keep the folder's name and its `hash.json` file as they are. XXMI Tools needs both to export.

{/* NEEDS HANDS-ON TEST: the github.dev right-click Download flow in a current browser, and where the folder lands. */}

This repo stops at version 3.8 (December 2025). Characters and outfits from 4.0 onward, such as Sparxie, Evanescia and Silver Wolf LV.999, are in a copy of the repo kept by Astute4533. That copy is not merged into the main repo, but it is updated for 4.7.

<ToolCard
  name="SR-Model-Importer-Assets (Astute4533)"
  href="https://github.com/Astute4533/SR-Model-Importer-Assets"
  icon={<Icon name="GitHub" />}
>
  The same folder layout, with characters from 4.0 to 4.7. Download one folder
  the same way.
</ToolCard>

The repos do not always have the newest hashes, and some lack MaterialMap hashes. For a character that is missing or out of date, make your own frame dump with gui_collect.

<ToolCard
  name="gui_collect"
  href="https://github.com/Petrascyll/gui_collect"
  icon={<Icon name="GitHub" />}
>
  By Petrascyll. Free, needs Python 3.9 or newer. Turns a frame dump into a
  folder that XXMI Tools can import.
</ToolCard>

In gui_collect, pick **Honkai: Star Rail** as the game. [Make a frame dump](/docs/honkai-star-rail/basics/frame-dump) shows the whole process.

</Step>
</Steps>

Get original models only from these repos or from your own frame dump. Tools that unpack the game's files are not covered here.

## Common problems

<Accordions type="multiple">
<Accordion title="XXMI Tools does not show in File > Import" id="no-import-entry">

Check that `XXMI_Tools` is ticked in the add-on list, then restart Blender. If it still does not show, remove every old 3DMigoto add-on and install XXMI Tools again.

</Accordion>
<Accordion title="The add-on will not install on my Blender" id="old-blender">

XXMI Tools needs Blender 3.6 or newer. Install Blender 4.5 LTS. You can keep an older Blender next to it.

</Accordion>
<Accordion title="Export fails with an error about the dump folder" id="export-hash-json">

The dump folder was renamed, or its `hash.json` is missing. Download the character folder again and do not rename it. [Blender export and import errors](/docs/honkai-star-rail/errors/creator-errors) has more fixes.

</Accordion>
</Accordions>
