After a Honkai: Star Rail update, some mods stop working. Since version 3.2, most fixes arrive inside SRMI updates, which XXMI Launcher installs for you. For the rest, a few community tools help: one for old mods, one for a format change, and small scripts for single characters. This page explains which one each mod needs, how to make sure you have the real tool, and what no tool can fix.

Written for Honkai: Star Rail 4.7 with SRMI 2.4.3. As of November 19, 2026, no break had been reported for version 4.7.

## Most breaks need no tool

Many "all my mods broke" moments fix themselves. Check these two things first:

1. **SRMI is up to date.** Open XXMI Launcher and let it update. The game's load banner should read `SRMI 2.4.3 (PRESS F12 TO SHOW GUIDE)`. Fixed mods need SRMI 2.0.0 or newer, or every character shows only a floating head.
2. **Character Quality is High.** Some mods stay unmodded on lower settings. Swap characters after you change it.

Since 3.2, the SRMI team fixes changes in how the game draws characters inside SRMI itself. SRMI 2.3.0 fixed version 4.1, and SRMI 2.4.0 fixed the new skinning in 4.2. What SRMI cannot fix is a character whose hashes changed. Most versions change a few characters, and those need a script.

The v3.3 fix mainly covers playable characters. It also does not fix a mod that was already edited by hand or by another script.

## Run them in this order

1. Back up: zip your whole `Mods` folder.
2. Update the game, then let XXMI Launcher update SRMI. Set **Character Quality** to **High**.
3. Press `F10` in game and see which mods are still broken.
4. Run Another v3.3 HSR Fix on old mods only. Put `hsr_fix33d.exe` in the broken mod's folder and run it. It fixes that folder and every folder inside it.
5. Run the Pipeline Convert Fix only on mods that glitch with two copies on screen. Put it in that mod's folder, not in the main `Mods` folder.
6. Run sora\_'s script, or the Mortenax script, only on mods for the character it names.
7. Press `F10` and test again.

{/* NEEDS HANDS-ON TEST: run hsr_fix33d.exe inside one broken pre-3.2 mod folder with SRMI 2.4.3 on Honkai: Star Rail 4.7, and confirm it fixes that mod and leaves other folders alone. Also confirm how sora_'s per-character scripts are run (folder, command, Python version). */}

Three rules keep this from going wrong:

- **Use only the newest fixer.** The Pipeline Convert Fix author warns that an outdated copy breaks every mod.
- **Fix only broken mods.** Running a fixer on working mods can cause conflicts.
- **Never run a fixer twice** on the same mod. Start again from your backup instead.

If you use a mod manager that edits `.ini` files, restore your mods in it first. Fix them, then add them back.

## What no tool can fix

- **Every 4.x character at once.** No all-character fixer has come out since the v3.3 fix in June 2025. Each 4.x break gets its own small script, or none.
- **NPC, enemy, and weapon mods.** The fix scripts mostly cover playable characters.
- **Complex and merged mods.** Scripts often miss parts of them. Expect a fix by hand or a creator update.
- **Textures tied to slot numbers.** Some older mods show wrong textures on low settings or in new maps. The creator must move them to hash-based textures or to [stable textures](/docs/honkai-star-rail/textures/stable-textures).
- **Old mods on Intel graphics.** Since a hotfix after 3.7, Intel cards need a draw branch that only current XXMI Tools exports write. The creator must export the mod again.

If a tool cannot fix a mod, check the mod's page for an update from its creator. Creators who fix their own mods use [Update your mod after a game update](/docs/honkai-star-rail/publishing/update-your-mod).

## Spot a fake fixer

<Callout type="danger" title="Fake fixers have carried malware">

In September 2025, after Genshin Impact 6.0, a new account uploaded a fake copy of a well-known Genshin fix tool under the real title. Its script asked for admin rights and downloaded a malicious program. Fake fixers show up after game updates, when players are in a hurry.

</Callout>

Before you run any fixer, check:

1. **The link.** Use the links on this page, or the one in the SRMI team's news post for that version. Not a link from a video comment or a search result.
2. **The author.** The real v3.3 page lists petrascyll as the author, with LeoMods\_, SinsOfSeven, SilentNightSound, Gustav0\_, SpectrumQT and sora\_ as key authors. It has a long update log and about 190,000 downloads.

/>

3. **The checksum.** GameBanana shows an MD5 checksum and a scan result for each file. Compare the MD5 of your download with it.
4. **The source.** Prefer the version you can read, such as the `.py` script or source `.zip`. For sora\_'s fixes, use the `.py` files on GameBanana.

Red flags: a "fix" that replaces `d3d11.dll` or other XXMI files, asks for admin rights, comes in a password-protected archive, or comes from a new account with one upload. Also a "fix" that appears before the community has announced one.

Antivirus apps sometimes flag the `.exe` versions of real fixers, because they rewrite many files at once. Use the `.py` version of the tool instead. Never turn your antivirus off.

## Tools to skip

| Skip this                                         | Why                                                                                                                    |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Fix pages for 2.x and 3.0                         | Outdated. The v3.3 fix includes all of them.                                                                           |
| Any old fixer version                             | It breaks mods that a newer fixer already fixed.                                                                       |
| Universal HSR Mod Fixer                           | Not recommended. It downloads its code from the internet each time it runs, so what it does can change without notice. |
| The slot-to-RabbitFX converter                    | Not from a trusted fix author. Creators should move textures by hand.                                                  |
| The Intel compatibility script                    | Unofficial and untested. It also edits SRMI's `d3dx.ini`.                                                              |
| A `d3d11.dll` "fix" from anyone but XXMI Launcher | Real fixes never replace XXMI files.                                                                                   |

## Common problems

<Accordions type="multiple">
<Accordion title="Every character is a floating head" id="floating-heads">

Your mods were fixed for 3.2, but SRMI is older than 2.0.0. Update XXMI Launcher. If the banner still shows an old version, click the 3-dots button next to **Start** and run **Repair SRMI**.

</Accordion>
<Accordion title="Every mod broke after I ran a fixer" id="all-broke">

An outdated fixer, or a fixer run twice, can do this. Restore your `Mods` backup and follow the order above with the newest fixer.

</Accordion>
<Accordion title="The fixer says No changes have been applied" id="no-changes">

The v3.3 fix found nothing it knows how to change, so it left the mod as it was. The break may be one that needs another tool from the table, or a creator update.

</Accordion>
</Accordions>
