A Honkai: Star Rail mod needs a few free tools. Each row below says what a tool does. Click it for the full guide.

**New here?** Install XXMI Launcher first. It is the only tool a player needs.

<Callout type="info" title="Every tool here is community-made">

HoYoverse makes no modding tools for Honkai: Star Rail. The tools on these pages come from community creators, and all of them are free. XXMI Launcher is free too: never pay for it.

</Callout>

## How the tools fit together

<img
  src="/wiki-images/honkai-star-rail-tools-index-1.webp"
  alt="Five stages of a Honkai: Star Rail mod: get the original from the asset repo or a frame dump, edit it in Paint.NET or Blender, export with XXMI Tools, put it in the SRMI Mods folder, and press F10 in game"

Every mod passes through the same stages. A texture-only mod skips Blender: you write its short `.ini` by hand. [How Honkai: Star Rail mods work](/docs/honkai-star-rail/basics/how-mods-work) explains what SRMI does with these files.

## Tools to skip

| Skip this                                                                | Why                                                           | Use instead                            |
| ------------------------------------------------------------------------ | ------------------------------------------------------------- | -------------------------------------- |
| Standalone SRMI (2023)                                                   | Deprecated. It cannot run mods made for version 3.2 or later. | XXMI Launcher                          |
| A second copy of RabbitFX, or one inside a mod                           | Copies clash with each other.                                 | One current copy in `Mods`             |
| Old Blender plugins (`blender_3dmigoto_srmi.py`, LeoTools scripts)       | Replaced, and they clash with XXMI Tools.                     | XXMI Tools                             |
| Fix pages for old versions, and fixers that download their code when run | Outdated or not trusted. Old fixers break newer mods.         | The tools on the update fix tools page |
| A `d3d11.dll` from any source but the launcher                           | Real fixes never swap XXMI files.                             | XXMI Launcher's **Repair SRMI**        |
| GitHub "mod menus", "mod launchers", and skin packs with farmed stars    | Tools for unfair play, or malware.                            | Nothing. Never download them.          |
| Lookalike 3DMigoto download sites                                        | Not official.                                                 | XXMI Launcher                          |

## How to spot a real tool

- Real tools come from known community authors, most often on GitHub. A few fix tools and RabbitFX live only on their GameBanana page.
- Download each tool from the link on its wiki page, not from a search result or a video comment.
- A tool can be an `.exe`. A mod never is: it holds `.ini`, `.buf`, `.ib` and `.dds` files. [What's allowed and how to stay safe](/docs/honkai-star-rail/getting-started/stay-safe) explains how to check a mod download.
