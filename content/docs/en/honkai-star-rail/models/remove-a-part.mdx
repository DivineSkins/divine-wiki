<LevelPill level="intermediate" />

In this guide you make your first model mod: you remove one small piece from a character, such as an ornament on the hair or a buckle on the clothes. You delete it in Blender, export the mod, and load it in game. The example uses Kafka, but the same steps work for any character. Written for XXMI Tools 1.8.2 on Blender 4.5 LTS and SRMI 2.4.3.

This guide uses the steps from [Get a model into Blender](/docs/honkai-star-rail/models/import-into-blender) and [Export your mod from Blender](/docs/honkai-star-rail/models/export-your-mod) in short form. You can start here and open those pages when you want the details.

## The plan

1. Import Kafka into Blender.
2. Find the object that holds your piece.
3. Select the piece and delete its vertices.
4. Export the mod into your `Mods` folder.
5. Reload in game and look.

Kafka comes into Blender as eight objects: `KafkaHairA`, `KafkaHeadA`, `KafkaHeadB`, and `KafkaBodyA` to `KafkaBodyE`. Your piece sits inside one of them, together with other pieces. You delete only the piece's vertices from that object. The object itself must stay: export finds each part by its object.

<img
  src="/wiki-images/honkai-star-rail-models-remove-a-part-1.webp"
  alt="Four steps on Kafka's eight objects: hide objects one by one to find the piece, select it with L in Edit Mode, delete its vertices with X, and keep every object. Deleting or hiding a whole object makes the export fail with Cannot find object in the scene"
/>

Pick a piece that is small and separate from the rest. Do not start with the face. It is the `Head` component, and its shading depends on its UV layout.

## Make the mod

<Steps>
<Step>

### Import Kafka

1. Download the `Kafka` folder from `PlayerCharacterData` in the asset repo. Do not rename it.
2. Open Blender, select everything in the empty scene with `A`, and delete it with `X`.
3. Open <MenuPath path="File > Import > XXMI Dump(vb.txt + ib.txt)" />.
4. Go into the `Kafka` folder and select every file shown.
5. Leave **Simple mode** ticked, set **Game preset** to `Honkai Star Rail`, and import.
6. Save the file as `KafkaEdit.blend`.

You now see Kafka standing in the scene, as eight objects in the Outliner.

Want a character from version 4.0 or newer? Take the folder from the [Astute4533 copy](https://github.com/Astute4533/SR-Model-Importer-Assets) of the repo instead. The steps stay the same.

</Step>
<Step>

### Find the object that holds your piece

1. In the Outliner, click the eye icon next to one object to hide it.
2. Look at the model. If your piece disappeared, it is in that object. Note the object's name.
3. Click the eye icon again to show the object.
4. Repeat with the next object until you find the piece.

Show every object again before you go on.

</Step>
<Step>

### Select the piece

1. Click the object you found in the Outliner.
2. Press `Tab` to go into Edit Mode.
3. Press `Alt+A` to deselect everything.
4. Press `Alt+Z` to turn on X-ray, so you can see pieces behind other pieces.
5. Hover the mouse over the piece and press `L`. The bit under the mouse turns orange.
6. Hover over each bit of the piece that is not orange yet and press `L` again, until the whole piece is orange.

If you select something else by mistake, hover over it and press `Shift+L` to deselect it.

{/* SCREENSHOT: honkai-star-rail-models-remove-a-part-2.webp, Blender 4.5 in Edit Mode with X-ray on, one small piece of Kafka selected in orange, and the Delete menu open with Vertices highlighted */}

</Step>
<Step>

### Delete the piece's vertices

1. Press `X` and choose **Vertices**.
2. Turn the view with the middle mouse button and check the model from all sides. Delete any bit you missed the same way.
3. Press `Tab` to go back to Object Mode.
4. Save with `Ctrl+S`.

Deleted too much? Press `Ctrl+Z` to undo.

If the piece sat on top of another surface, there may be a hole under it. Select the edges around the hole and press `F` to fill it.

<Callout type="warning" title="Delete vertices, never the object">
  Keep all eight objects in the scene, visible, even the one you edited. If a
  part's object is missing, the export stops with "Cannot find object ... in the
  scene".
</Callout>

</Step>
<Step>

### Export into your Mods folder

1. Press `N` in the 3D Viewport and open the **XXMI Tools** tab.
2. Check that **Dump Folder** points to your `Kafka` folder.
3. Set **Output Folder** to a new folder: `%AppData%\XXMI Launcher\SRMI\Mods\KafkaEdit`.
4. Check that **Game to mod** says `Honkai Star Rail`.
5. Leave the **Export Settings** at their defaults.
6. Click **Export Mod**.

The status bar says `Exported Kafka to ...` when it works. The new folder holds `Kafka.ini`, a set of `.buf` files for each of `Hair`, `Head` and `Body`, one `.ib` file per part, and Kafka's textures.

{/* NEEDS HANDS-ON TEST: export Kafka with one piece removed, using XXMI Tools 1.8.2 defaults, into a folder inside SRMI\Mods, and confirm the exact status bar text and file list */}

</Step>
<Step>

### Check it in game

1. Turn off any other Kafka mod: rename its folder so it starts with `DISABLED`.
2. Start the game from XXMI Launcher.
3. Switch to another character, press `F10` to reload mods, then switch back to Kafka.
4. Look at her in the character screen, then walk around and fight a battle, to check the piece is gone in motion too.

That is your first model mod. To compare, hold `F9` to see the original Kafka.

{/* SCREENSHOT: honkai-star-rail-models-remove-a-part-3.webp, Kafka in the Honkai: Star Rail 4.7 character screen with the removed piece gone, next to the original for comparison */}

{/* NEEDS HANDS-ON TEST: on Honkai: Star Rail 4.7 with SRMI 2.4.3, that a Kafka mod exported from the asset repo folder loads, and that the removed piece stays gone in the overworld and in battle */}

</Step>
</Steps>

## Remove other parts the same way

| You want to remove                              | What to do                                                                                      |
| ----------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| One piece inside a part (an ornament, a buckle) | Select it with `L` in Edit Mode, then `X` > **Vertices**.                                       |
| A whole part, like `KafkaBodyE`                 | In Edit Mode press `A`, then `X` > **Vertices**. Keep the empty object.                         |
| Something on the face                           | Leave it for later. The face is the `Head` component, and its shading depends on its UV layout. |

Hidden objects are skipped on export. Before you export, show every part object again.

{/* NEEDS HANDS-ON TEST: that a fully emptied Honkai: Star Rail part (for example KafkaBodyE) exports with XXMI Tools 1.8.2 and loads in SRMI 2.4.3. A 2023 Star Rail guide said every part needs at least one face. */}

## Common problems

<Accordions type="multiple">
<Accordion title="The piece is still there in game" id="piece-still-there">

- Check that the `KafkaEdit` folder is inside `%AppData%\XXMI Launcher\SRMI\Mods`.
- Check that no other Kafka mod is on. Two mods for one character both load, and the result is a mess.
- Switch away from Kafka, press `F10`, and switch back. A mod loaded while she is on screen can show only partly.
- If none of that helps, the game may have changed Kafka's hashes since the asset repo folder was made. [Make a frame dump](/docs/honkai-star-rail/basics/frame-dump) to get current ones.

</Accordion>
<Accordion title="The export stops with an error" id="export-error">

Most errors come from a missing, renamed or extra object. Check that all eight Kafka objects exist, are visible, and that the folder is still called `Kafka`. [Blender export and import errors](/docs/honkai-star-rail/errors/creator-errors) lists every message.

</Accordion>
<Accordion title="Too much is gone, or there is a hole" id="too-much-deleted">

You deleted more than the piece. Press `Ctrl+Z` in Blender until it is back, or import the `Kafka` folder again. Then select the piece again and export.

</Accordion>
</Accordions>
