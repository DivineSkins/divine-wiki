<LevelPill level="beginner" />

You will swap a 2D image in Honkai: Star Rail, like a character icon or portrait, for your own art, with a small texture-only mod. No 3D work: you dump the screen, find the image, edit it and write a short `.ini`. Written for XXMI Launcher 2.5.0 and SRMI 2.4.3 on Honkai: Star Rail 4.7.

## What you can replace

Any image the game draws from a texture can be swapped by its hash. Star Rail creators make three kinds of UI mods:

- **Character icons and portraits.** Each screen draws its own image, so dump the screen that shows the one you want. One texture can also appear on more than one screen.
- **Phone wallpapers.** The background of the in-game phone. See [Phone wallpapers](#phone-wallpapers).
- **Light cone card art.** A tool builds these for you. See [Light cone art](#light-cone-art).

Text cannot be changed unless the game draws it as an image.

## Make the icon mod

<Steps>
<Step>

### Set up

1. In XXMI Launcher, click the gear, open the **SRMI** tab and tick **Enable Hunting**. [Find a hash with hunting mode](/docs/honkai-star-rail/basics/find-a-hash) shows the setting.
2. Turn off any mod that already changes these images: rename its folder so it starts with `DISABLED`.
3. In your `Mods` folder, make a folder such as `KafkaIcons`.
4. Inside it, make a text file and rename it `KafkaIcons.ini`. Delete the `.txt` ending.

</Step>
<Step>

### Dump the screen

1. Start the game and open the screen that shows the image.
2. Check for the green hunting text. If it is missing, press `Numpad 0`.
3. Press `F8`. The game freezes for a moment while SRMI saves a `FrameAnalysis-...` folder in `%AppData%\XXMI Launcher\SRMI`.
4. Rename that folder after the screen, like `FrameAnalysis-Portrait`, so you can find it later.
5. Repeat for each screen you want.

Full dumps take several gigabytes. Keep the screen simple, and delete the folders when you are done. [Make a frame dump](/docs/honkai-star-rail/basics/frame-dump) shows how to dump less, and how to make a dump save `.dds` files when it does not.

</Step>
<Step>

### Find the image

1. Open the dump folder, then `deduped`.
2. Search for `BC7`.
3. Look through the results for your image. It is upside down.
4. Read the file name, which looks like `<hash>-BC7_UNORM.dds`. The start is the hash. The end is the format.
5. Copy the file into your mod folder and give it a clear name, like `KafkaPortrait.dds`.

Keep the exact width and height of the file you found.

If `deduped` holds no `.dds` file of your image, the dump did not save it as DDS. Add `dds` to the dump options for that image, as the frame dump guide shows, and dump again.

{/* NEEDS HANDS-ON TEST: whether a plain F8 dump with SRMI 2.4.3's shipped analyse_options (no dds option, jps_dds default) saves Honkai: Star Rail BC7 UI textures as <hash>-<FORMAT>.dds in deduped, or only as .jpg, so that this step needs the targeted dds dump */}

</Step>
<Step>

### Edit the image

1. Open the copied `.dds` in Paint.NET.
2. Flip your own art vertically with <MenuPath path="Image > Flip Vertical" />, then paste it in. The file must stay upside down.
3. Keep the alpha: transparent corners and edges must stay transparent.
4. Save in the format from the file name: `BC7_UNORM` is `BC7 (Linear, DX 11+)`, `BC7_UNORM_SRGB` is `BC7 (sRGB, DX 11+)`. Tick **Generate Mip Maps**.

Many guides say every UI image is Linear. Follow the file name instead: it is always right. [Save DDS textures the right way](/docs/honkai-star-rail/textures/save-dds-files) has every option.

</Step>
<Step>

### Write the .ini

Add one pair of sections per image. Put in the hash from your file name, and your own file name:

```ini
[TextureOverrideKafkaPortrait]
hash = <hash from the file name>
this = ResourceKafkaPortrait

[ResourceKafkaPortrait]
filename = KafkaPortrait.dds
```

The hash is the 8 characters before the dash. Never write a note after the hash on the same line. Each section name must be unique in the file.

<Files>
  <Folder name="Mods" defaultOpen>
    <Folder name="KafkaIcons" defaultOpen>
      <File name="KafkaIcons.ini" />
      <File name="KafkaPortrait.dds" />
      <File name="KafkaIcon.dds" />
    </Folder>
  </Folder>
</Files>

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check on Honkai: Star Rail 4.7 that a hash and this = override replaces a character icon or portrait */}

</Step>
<Step>

### Test it

1. Press `F10` in game.
2. Open each screen and check your art. It should be the right way up.
3. Untick **Enable Hunting** when you are done.

</Step>
</Steps>

## Phone wallpapers

One guide, from 2024, covers a phone wallpaper for one background. Its settings:

- The image is 1320x2048.
- It is flipped vertically, like every Star Rail UI image.
- It is saved as `BC7 (Linear, DX 11+)`.

Other backgrounds may use another size or format. Read both from your own dump.

## Common problems

<Accordions type="multiple">
<Accordion title="My art is upside down in game" id="upside-down">

The file was saved the normal way up. Flip it vertically and save again.

</Accordion>
<Accordion title="Nothing changed" id="nothing-changed">

Check the hash and the `filename =` line. Make sure no other mod for that image is on. If the hash is right and nothing shows, the game may not check that texture on this screen. Hunt the pixel shader that draws the image, then add `checktextureoverride = ps-t0` in a `[ShaderOverride...]` section with that shader's hash.

{/* NEEDS HANDS-ON TEST: whether any Honkai: Star Rail 4.7 UI image needs the checktextureoverride line */}

</Accordion>
<Accordion title="Colors look too dark or washed out" id="wrong-colors">

The file was saved as sRGB when the original was Linear, or the other way round. Check the end of the dumped file name and save again.

</Accordion>
<Accordion title="Error text after F10" id="error-text">

SRMI could not load the file. Check the file name, and keep the original width and height. SRMI hides warnings by default: untick **Mute Warnings** in the SRMI tab to see them.

</Accordion>
<Accordion title="The image broke after a game update" id="after-update">

UI hashes can change with an update. Dump the screen again and put the new hash in your `.ini`.

</Accordion>
</Accordions>
