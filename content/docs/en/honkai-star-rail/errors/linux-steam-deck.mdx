Honkai: Star Rail and XXMI Launcher are made for Windows. Some players run both on Linux or a Steam Deck through Wine or Proton, which translate the Windows game. This page says what is known to work for Star Rail, what is not known yet, and where to ask for help.

<Callout type="warning" title="Unofficial, and not tested here">
  XXMI Launcher's author offers Linux support "as is", in the hope that Wine and
  Proton do the job. The launcher's issue tracker does not take Linux bug
  reports. Nobody has tested the steps on this page with Honkai: Star Rail 4.7
  for this wiki.
</Callout>

## The risk is the same as on Windows

Mods break HoYoverse's Terms of Service. HoYoverse can ban any account that uses third-party software. Linux does not change that, and it is no way around the game's rules. In a 2023 forum thread about short bans, some Star Rail players named Linux as a possible cause. Nothing proved it either way. Use mods only on an account you can afford to lose.

[What's allowed and how to stay safe](/docs/honkai-star-rail/getting-started/stay-safe) explains the risk in full.

## What is known to work

<img
  src="/wiki-images/honkai-star-rail-errors-linux-steam-deck-1.webp"
  alt="Two boxes: what Twintail does to start Honkai: Star Rail with XXMI and SRMI in one prefix, and four rules for any Linux setup"
/>

One rule matters most: XXMI and SRMI must run in the same Wine or Proton prefix as the game. A prefix is the folder where Wine keeps one fake Windows install. For Star Rail, one route has a working report.

### Twintail Launcher

Twintail Launcher installs and starts the game on Linux and has a built-in XXMI option. It downloads XXMI and SRMI itself and starts them in the game's prefix.

1. Install Twintail from Flathub (`app.twintaillauncher.ttl`), or from Copr, Terra, AUR or Nix.
2. Install or import Honkai: Star Rail inside Twintail.
3. Turn on the game's XXMI option.
4. Keep a runner whose name does not start with `dw`. Twintail refuses mods with "dw" runners.
5. Put your mods in the `SRMI\Mods` folder that Twintail made, and start the game from Twintail.

{/* NEEDS HANDS-ON TEST: Twintail 2.5.3 menu labels for the XXMI option, where it puts SRMI\Mods, and whether its XXMI copy is the official package. */}

In September 2026 a player reported a Star Rail mod loading under Twintail on Linux. The steps after the install are the same as on Windows: [Install mods with XXMI Launcher](/docs/honkai-star-rail/getting-started/install-with-xxmi-launcher).

### The official launcher in plain Wine

This route is not covered here. PCGamingWiki notes a check inside Star Rail that stops the game under plain Wine. A 2025 video guide says the game crashes on start this way unless you add an extra launch command, which the video does not show. This wiki does not know what that command does.

## Steam Deck

Honkai: Star Rail is not on Steam. On a Steam Deck, switch to Desktop Mode and use the Twintail route above. No report shows Star Rail mods working on a Steam Deck yet.

XXMI's folder picker does not show hidden folders, such as `.local`. If you must pick a folder, type the path into the picker's address bar instead.

## What is not known

- Whether mods load on Linux with Honkai: Star Rail 4.7. The one report is from before 4.7.
- Whether the portable XXMI Launcher build works with Star Rail. It runs under Wine 9.22 or newer, in the same prefix as the game, but no report shows it with Star Rail.
- Which Wine or Proton runner works best.
- Twintail's exact labels, and whether its copy of XXMI is the official package.
- A full Steam Deck setup, from install to a mod in game.

Tested it? Tell us on Discord, and we will update this page.

## Common problems

<Accordions type="multiple">
<Accordion title='"d3d11.dll is missing expected entry point"' id="entry-point">

**Cause:** on Linux, this error comes from the graphics layers of Wine or Proton, VKD3D or NVAPI.

**Fix:** turn off VKD3D and NVAPI in your runner's settings, then start again. If it stays, ask in the AGMG Discord's Linux channel.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check on Honkai: Star Rail that turning off VKD3D and NVAPI clears this error */}

</Accordion>
<Accordion title="XXMI Launcher cannot find the game" id="game-not-found">

1. Check that the launcher and the game run in the same prefix.
2. In the launcher settings, set **Game Folder** to the folder that holds `StarRail.exe` and `StarRail_Data`.
3. If the folder sits under a hidden folder such as `.local`, type its path by hand.

</Accordion>
<Accordion title="The SRMI guide box does not close" id="guide-box">

On the first start, SRMI opens its guide box. `F10` hides it and `F12` toggles it. On a laptop, hold `Fn` with the key. One Linux player could close it only with `Fn+F12`.

</Accordion>
</Accordions>
