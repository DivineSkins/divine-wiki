You will change the colors of one character's outfit or hair, save the texture the way the game expects, and see it in game. No 3D work. SRMI must already load your mods. Written for XXMI Launcher 2.5.0 and SRMI 2.4.3 on Honkai: Star Rail 4.7.

## How a recolor works

Each character part uses a few textures. Only the **diffuse** holds the colors you see. SRMI swaps the game's diffuse for your edited copy while the game draws the character. No game file changes.

| Texture file                | What it holds                          | Edit it for a recolor?       |
| --------------------------- | -------------------------------------- | ---------------------------- |
| `KafkaBodyADiffuse.dds`     | The colors. Its alpha is the glow mask | Yes                          |
| `KafkaHairADiffuse.dds`     | The hair colors                        | Yes, for a hair recolor      |
| `KafkaBodyALightMap.dds`    | Shine, shadows and material types      | No                           |
| `KafkaBodyAStockingMap.dds` | Stocking shading                       | No                           |
| `KafkaHeadADiffuse.dds`     | The face colors                        | Only if you change skin tone |

The part names come from the game: `Hair` is the hair, `Head` is the face, and `Body` is the rest. Each one splits into lettered parts, `A`, `B` and so on. [Character names and parts](/docs/honkai-star-rail/basics/character-names-and-parts) explains every name.

<Callout type="warning" title="The alpha is the glow mask">
  In a Honkai: Star Rail diffuse, the alpha channel is not see-through. It marks
  the areas that glow. Black means no glow. That is why the file can look mostly
  transparent in Paint.NET. Lose the alpha and the whole part glows.
</Callout>

## Make the recolor

<Steps>
<Step>

### Get the texture

Pick one route. The paint steps after this are the same for both.

<Tabs items={["Practice on a mod you have", "Make your own mod"]}>

<Tab value="Practice on a mod you have">

The fastest first project. You change a texture inside a mod you downloaded.

1. Open your `Mods` folder: in XXMI Launcher, click the 3-dots button next to **Start**, then **Open Mods Folder**.
2. Copy the mod's whole folder to your desktop as a backup.
3. In the mod folder, find the diffuse of the part you want, for example `KafkaBodyADiffuse.dds`. If the names differ, open the mod's `.ini` and look for the `filename =` lines.

Keep the result for yourself. The mod is someone else's work, so never share your edited copy.

</Tab>

<Tab value="Make your own mod">

You start from the game's original texture and write a tiny `.ini` yourself.

1. Open [SR-Model-Importer-Assets](https://github.com/SilentNightSound/SR-Model-Importer-Assets) on GitHub, then `PlayerCharacterData`, then your character's folder.
2. Download only two files: the diffuse you want, for example `KafkaBodyADiffuse.dds`, and `hash.json`. Do not clone the repository.
3. Open `hash.json` in a text editor. Find your component, such as `"component_name": "Body"`. Under `texture_hashes`, the parts are listed in the same order as `object_classifications` (`A`, `B`, `C`...). Copy the 8-character hash after `"Diffuse", ".dds"` for your part.
4. In your `Mods` folder, make a folder named `MyFirstRecolor` and put the `.dds` in it.
5. In that folder, make a text file and rename it `MyFirstRecolor.ini`. Paste this, with your own hash and file name:

```ini
[TextureOverrideKafkaBodyADiffuse]
hash = 207c0559
this = ResourceKafkaBodyADiffuse

[ResourceKafkaBodyADiffuse]
filename = KafkaBodyADiffuse.dds
```

<Files>
  <Folder name="Mods" defaultOpen>
    <Folder name="MyFirstRecolor" defaultOpen>
      <File name="MyFirstRecolor.ini" />
      <File name="KafkaBodyADiffuse.dds: your edited texture" />
    </Folder>
  </Folder>
</Files>

The hash above is Kafka's body diffuse in the asset repository. A hash override changes every part that uses that texture. Kafka's body parts `A` and `B` share one diffuse, so this file recolors both. This is the same `this =` form the XXMI Tools export writes.

Never write a note after the hash on the same line. In a `.ini`, `;` starts a comment only at the start of a line. Old mods sometimes put textures on numbered slots, like `ps-t2 = ...`. Do not copy that: Star Rail moves textures between slots on low settings and in new maps.

The repository stops at version 3.8. For characters from 4.0 on, such as Sparxie or Evanescia, use the [4.x copy by Astute4533](https://github.com/Astute4533/SR-Model-Importer-Assets), which has the same layout. The repositories do not always have the newest hashes. If a hash does not work, get the texture and its hash from a [frame dump](/docs/honkai-star-rail/basics/frame-dump).

Check that the hash still matches and that the recolor shows in the overworld, in battle, on the character screen and on low graphics settings. */}

<Step>

### Split off the glow mask

Work on a copy: keep a backup of the original `.dds`.

1. Open the `.dds` in Paint.NET.
2. Choose <MenuPath path="Layers > Duplicate Layer" />.
3. With the top layer selected, open <MenuPath path="Adjustments > Modify Channels" />.
4. Set line 1 to `Greyscale`, `Identity`, source `Alpha`. Click `+` and set line 2 to `Alpha`, `Constant`, `255`. Tick `Enabled`, then click **OK**. The top layer is now your glow mask in black and white.
5. Hide the top layer: untick its box in the Layers panel.
6. Select the bottom layer and open **Modify Channels** again. Use one line: `Alpha`, `Constant`, `255`. Now you see every color, with nothing transparent.

{/* NEEDS HANDS-ON TEST: the Modify Channels plugin labels and these two settings in the current Paint.NET 5.x release */}

</Step>
<Step>

### Recolor the part

1. Select the bottom layer and pick the **Magic Wand**. Set **Tolerance** to about 20%, never above 25%.
2. Hold `Shift` and click a color. This selects that color everywhere on the image. Hold `Ctrl` and click to add more colors.
3. Choose <MenuPath path="Adjustments > Black and White" />. Only the selected area turns grey.
4. Choose <MenuPath path="Layers > Add New Layer" />.
5. Pick your new color as the primary color, then press `Backspace` to fill the selection on the new layer.
6. Double-click the new layer and set **Blend mode** to **Overlay**. The grey shading shows through your color.
7. Repeat for each color you want to change.

Use a dark grey instead of pure black: black does nothing in Overlay mode. Select areas that looked empty before, too. The game can show them at the edges.

  title="Magic Wand, Black and White and Overlay recolor in Paint.NET, by Proxy Index"
/>

This video uses Zenless Zone Zero files and is in Spanish, with an English audio track. Watch the clothing recolor, from 19:55 to about 24:00. The Paint.NET steps are the same in Honkai: Star Rail.

</Step>
<Step>

### Put the glow mask back

1. Show the glow mask layer, select it, then press `Ctrl+A` and `Ctrl+C`.
2. Choose <MenuPath path="Layers > Delete Layer" /> to remove the mask layer. It stays on your clipboard.
3. Choose <MenuPath path="Image > Flatten" />.
4. Choose <MenuPath path="Effects > Object > Paste Alpha" />. This comes from BoltBait's Plugin Pack.

The image can look mostly transparent again. That is correct.

{/* NEEDS HANDS-ON TEST: the menu location of Paste Alpha from BoltBait's Plugin Pack in the current Paint.NET 5.x release */}

</Step>
<Step>

### Save as DDS

1. Choose <MenuPath path="File > Save As" />. Keep the exact file name and the `.dds` ending.
2. In the DDS window, pick `BC7 (sRGB, DX 11+)`.
3. Tick **Generate Mip Maps**.
4. Click **OK** and replace the old file.

{/* NEEDS HANDS-ON TEST: mipmaps on a Star Rail diffuse. Dumped originals hold one mip level; check that a file saved with Generate Mip Maps and one saved without both load and look the same in game */}

[Save DDS textures the right way](/docs/honkai-star-rail/textures/save-dds-files) explains every option.

</Step>
<Step>

### Test it in game

1. Swap to another character.
2. Press `F10` to reload mods.
3. Swap back and look at your recolor.
4. Hold `F9` to see the original, then let go to compare.
5. Check the overworld, battle, the character screen, and day and night areas.

{/* NEEDS HANDS-ON TEST: carried over from the shared XXMI workflow, check on Honkai: Star Rail which in-game moments make the diffuse glow mask light up, so the test list can name them */}

</Step>
</Steps>

Changed the skin color? Recolor the face too, `KafkaHeadADiffuse.dds`, with the same steps and settings. In your own mod it needs its own `[TextureOverride...]` and `[Resource...]` pair. In `hash.json` it sits under the component named `Head`, part `A`. Otherwise the face will not match the body.

## Common problems

<Accordions type="multiple">
<Accordion title="The whole part glows or looks very bright" id="part-glows">

The alpha was lost or filled. Start again from your backup and paste the glow mask back before you save.

</Accordion>
<Accordion title="Colors look washed out, too dark or too strong" id="wrong-colors">

The file was saved in the wrong format. A diffuse must be `BC7 (sRGB, DX 11+)`. Save again.

</Accordion>
<Accordion title="Nothing changed in game" id="nothing-changed">

Check that the `filename =` line matches your file name exactly. Turn off other mods for that character: rename their folders so they start with `DISABLED`. Check that **Character Quality** is on **High**. Then check the hash. It may have changed since the asset repository was made. Get the current one from a frame dump.

</Accordion>
<Accordion title="Error text after F10, or the texture is missing" id="error-text">

SRMI could not load the texture. A typo in the file name, a missing file, or a size that is not a power of two causes this. Keep the original width and height. SRMI hides warnings by default: untick **Mute Warnings** in the SRMI tab of XXMI Launcher to see them.

</Accordion>
<Accordion title="The outline keeps its old color" id="old-outline">

Outline colors come from the light map alpha, not the diffuse. [What each texture map does](/docs/honkai-star-rail/textures/texture-maps) shows where they live.

</Accordion>
<Accordion title="A downloaded mod shows wrong textures on low settings" id="low-settings">

That mod puts its textures on numbered slots, and Star Rail moves them. Your own hash-based mod avoids this. [Make textures survive game updates](/docs/honkai-star-rail/textures/stable-textures) shows a sturdier method.

</Accordion>
</Accordions>

More symptoms and fixes are in [Mods look broken](/docs/honkai-star-rail/errors/mods-look-broken).
