Tex Thumbnail Provider od **RitoSharka** pokazuje pliki `.tex` jako prawdziwe
miniatury w Eksploratorze Windows. Na liście plików, w panelu podglądu i w
widoku dużych ikon widzisz teksturę zamiast pustej ikony. Sam dekoduje plik,
więc żadna aplikacja nie musi być otwarta.

---

## Instalacja

Instalujesz i odinstalowujesz jednym poleceniem PowerShell. Bez pobierania, bez
praw administratora. Rejestracja jest per użytkownik.

1. Zamknij wszystkie okna Eksploratora, które pokazują pliki `.tex`.
2. Otwórz PowerShell. Zwykłe okno wystarczy.
3. Wklej to i naciśnij Enter:

   ```powershell
   iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1 | iex
   ```

Skrypt pobiera najnowszy `TexThumbnailProvider.dll`, wrzuca go do
`%LOCALAPPDATA%\RitoShark\TexThumbnailProvider` i rejestruje dla twojego
użytkownika. Otwórz dowolny folder z plikami `.tex`, a miniatury się pojawią.

<Callout type="info" title="Przypnij konkretną wersję">
  Chcesz konkretną wersję zamiast najnowszej? Uruchom:

```powershell
& ([scriptblock]::Create((iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1))) -Version v1.1.0
```

</Callout>

## Odinstalowanie

```powershell
iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/uninstall-thumbnail-handler.ps1 | iex
```

To usuwa handler i jego wpisy w rejestrze.

## Co obsługuje

Dekoduje formaty kompresji `.tex`, których używa Riot:

| Format               | Kod `.tex`  |
| -------------------- | ----------- |
| DXT1 / BC1           | `0x0A`      |
| DXT5 / BC3           | `0x0C`      |
| BC7                  | `0x0D`      |
| BC5                  | `0x0E`      |
| BGRA8 (nieskompresowany) | `0x14`  |

Tekstury z mipmapami też działają. Do miniatury dekodowany jest największy mip.

<Callout type="info" title="Wygrywa nawet z Photoshopem">
  Jeśli masz zainstalowany Photoshop albo plugin RitoTex, rejestruje się on jako
  handler miniatur `.tex` i normalnie by to przejął. Ten instalator zapisuje swój
  handler pod twoim kontem użytkownika, co wygrywa z tym na poziomie całej
  maszyny. Twoje miniatury `.tex` pokazują się dalej. Rusza tylko wpis miniatur,
  więc dwuklik na `.tex` nadal otwiera aplikację, którą ustawiłeś.
</Callout>

## Rozwiązywanie problemów

### Miniatury się nie pokazują

Zrestartuj Eksplorator Windows. Otwórz Menedżer zadań, znajdź **Eksplorator
Windows**, kliknij prawym i wybierz **Uruchom ponownie**. Otwórz folder ponownie.

### Stare miniatury nadal wyglądają jak zwykłe ikony

Windows buforuje miniatury per plik. Plik `.tex` przerysowuje się dopiero po
zmianie czasu modyfikacji albo po wyczyszczeniu bufora. Otwórz **Oczyszczanie
dysku**, zaznacz **Miniatury**, kliknij **OK**, potem otwórz folder ponownie.

### Nadal nic po restarcie

Wykonaj polecenie instalacji jeszcze raz. Pobiera i rejestruje bibliotekę DLL od
nowa.

## Alternatywa: LTK Tex Thumb Handler

Zespół **LeagueToolkit** ma własny handler miniatur `.tex`
([ltk-tex-utils](https://github.com/LeagueToolkit/ltk-tex-utils)). Robi tę samą
podstawową robotę, ale dwie rzeczy go blokują:

- Nie dekoduje każdego formatu kompresji, którego używa Riot, więc niektóre pliki
  `.tex` zostają puste.
- Jeśli inny program (Photoshop, plugin RitoTex itd.) już zajął typ `.tex`, w
  ogóle nie wytworzy podglądu. Nie nadpisuje istniejącego handlera tak, jak robi
  to to narzędzie.

Dla większości osób Tex Thumbnail Provider od RitoSharka to lepszy wybór:
obsługuje więcej formatów i wygrywa z innymi handlerami. Uruchamiaj tylko jeden
handler miniatur naraz. Jeśli miałeś zainstalowany ten od LTK, usuń go przed
instalacją tego.
