ritobin-lsp to rozszerzenie LSP/VS Code autorstwa [alanpq](https://github.com/alanpq), które otwiera pliki `.bin`/`.rito` League'a jako czytelny tekst, który możesz edytować.

Najnowsze wersje są na GitHubie: [wydania ritobin-lsp](https://github.com/alanpq/ritobin-lsp/releases).

<Callout type="info" title="Rozważ Jade, jeśli dopiero zaczynasz modding">
  `ritobin-lsp` daje gotowe wsparcie dla popularnych edytorów tekstu, idealne
  dla modderów, którzy *już* z nich korzystają przy moddingu.

Jeśli nie masz jeszcze zainstalowanego edytora takiego jak VS Code, rozważ wypróbowanie Jade.

</Callout>

## Rozwiązywanie problemów

### Ritobin pokazuje zahashowane nazwy zamiast słów

Użyj polecenia `Unhash File` dostępnego w palecie poleceń (`Ctrl/Cmd + P`).
