## Otwórz swój BIN w Paint

Otwórz Quartz i kliknij ikonę pędzla na górze paska bocznego, żeby otworzyć **Paint**. Kliknij **Open Bin** i otwórz plik `.bin` z VFX swojego skina.

  src="/wiki-images/uno.webp"

/>

## Znajdź efekty, które chcesz zmienić

Gdy BIN się wczyta, Quartz pokaże każdy system partikli razem z jego emiterami. Wpisz kod w **Filter systems**, żeby zostawić tylko jedną umiejętność.

| Wpisz to | Żeby znaleźć           |
| -------- | ---------------------- |
| `_Q_`    | VFX umiejętności Q     |
| `_W_`    | VFX umiejętności W     |
| `_E_`    | VFX umiejętności E     |
| `_R_`    | VFX umiejętności R     |
| `_BA_`   | VFX podstawowego ataku |
| `_Z_`    | VFX idle               |

Zaznacz checkbox przy każdym systemie albo emiterze, który chcesz przekolorować.

## Wybierz kolory

Kliknij pasek koloru na górze, żeby otworzyć color picker, i wybierz kolor. Chcesz gradient? Przesuń suwak **Colors**, żeby dodać więcej kolorów.

## Przekoloruj i zapisz

Kliknij **Recolor Selected** w prawym dolnym rogu, a potem **Save Bin**.

## Przetestuj zmiany

Podejrzyj efekt w [Ruby](/docs/lol/tools/modding-apps/ruby) albo spakuj moda i sprawdź go w grze. Ruby jest szybsze, bo nie musisz odpalać meczu.
