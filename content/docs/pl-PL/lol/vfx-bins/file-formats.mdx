## Pliki .bin: dane i logika

Pliki `.bin` przechowują **całą logikę** w League: systemy partikli, definicje skinów, animacje, dźwięki i więcej.

| Zawiera            | Przykłady                  |
| ------------------ | -------------------------- |
| Dane partikli      | Kolory, rozmiary, timing VFX |
| Definicje skinów   | Ścieżki modeli i tekstur   |
| Konfiguracje animacji | Nazwy animacji, blendowanie |
| Konfiguracje dźwięku | Triggery audio, głośność  |

### Jak to zrobić

1. Wypakuj `.bin` przez [Flint](/docs/lol/tools/modding-apps/flint)
2. Skonwertuj do `.py` przez [Ritobin](/docs/lol/tools/modding-apps/ritobin) (albo edytuj od razu w [Jade](/docs/lol/tools/modding-apps/jade))
3. Edytuj w edytorze tekstu, np. VS Code lub Notepad++
4. Skonwertuj z powrotem do `.bin`
5. Dodaj do folderu swojego moda

> 💡 Pliki `.py` są czytelne dla człowieka. Możesz je przeszukiwać i edytować.

## Pliki .dds: tekstury

`.dds` (DirectDraw Surface) to **standardowy format tekstur** używany do:

| Zastosowanie      | Przykłady             |
| ----------------- | --------------------- |
| Modele bohaterów  | Tekstury skinów, twarze |
| Partikle          | Sprite'y VFX, poświaty |
| UI/HUD            | Ikony, panele umiejętności |

### Narzędzia do edycji

<ToolCard name="Photoshop" href="https://www.adobe.com/products/photoshop.html">
  Najlepsza opcja z wtyczką NVIDIA DDS.
</ToolCard>

<ToolCard name="GIMP" href="https://www.gimp.org/">
  Darmowa alternatywa z obsługą DDS.
</ToolCard>

<ToolCard name="Paint.NET" href="https://www.getpaint.net/">
  Lekki program z wtyczką DDS.
</ToolCard>

### Ustawienia eksportu

| Ustawienie  | Wartość        |
| ----------- | -------------- |
| Format      | `.dds`         |
| Kompresja   | **BC3 / DXT5** |
| Mipmapy     | ✅ Włączone     |

> ⚠️ Zła kompresja = zepsute tekstury w grze!

## Pliki .tex: format Riot

`.tex` to **własny format tekstur** Riot, spotykany w plikach `.wad.client`.

| Status                      | Info                       |
| --------------------------- | -------------------------- |
| ❌ Nie edytujesz bezpośrednio | To skompilowany format   |
| ✅ Najpierw konwertuj       | Użyj tex2dds               |
| ✅ Potem konwertuj z powrotem | Przed ponownym importem   |

Masz dwa sposoby pracy z `.tex`:

1. **Otwórz od razu** wtyczką TEX w swoim edytorze grafiki. Bez konwersji.
2. **Skonwertuj** `.tex` na `.dds` i z powrotem przez Flint lub LtMAO.

## Pełna tabela pracy

| Zadanie                     | Plik   | Narzędzie                          | Wynik           |
| --------------------------- | ------ | ---------------------------------- | --------------- |
| Edycja VFX/partikli         | `.bin` | Jade (lub Ritobin)                 | `.bin`          |
| Edycja skina bohatera       | `.dds` | Photoshop/GIMP                     | `.dds`          |
| Edycja tekstury bezpośrednio | `.tex` | RitoTex, Paint.NET lub wtyczka GIMP | `.tex`         |
| Konwersja tekstury          | `.tex` | Flint lub LtMAO                    | `.dds`          |
| Ponowny import tekstury     | `.dds` | Flint lub LtMAO                    | `.tex`          |
| Przeglądanie plików gry     | `.wad` | Flint                              | Wypakowane pliki |
