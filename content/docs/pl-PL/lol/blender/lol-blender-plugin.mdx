## Najważniejsze funkcje

| Funkcja         | Opis                                          |
| --------------- | --------------------------------------------- |
| **SKL + SKN**   | Import/eksport modeli postaci ze szkieletem   |
| **ANM**         | Import/eksport animacji                        |
| **SCB / SCO**   | Import/eksport obiektów statycznych            |
| **Bone Limit**  | Ogranicza do maks. 4 wpływów na wierzchołek   |
| **UV Tools**    | Narzędzia do przyciągania narożników UV        |
| **Drag & Drop** | Łatwa obsługa plików                           |

## Wymagania

| Wymaganie   | Szczegóły                             |
| ----------- | ------------------------------------- |
| Blender     | **4.0+** (tylko Windows)              |
| Ustawienie FPS | **30 FPS** zalecane dla animacji   |

## Instalacja

1. Pobierz [`Aventurine.zip`](https://github.com/RitoShark/Aventurine-League-Tools/releases). **Nie rozpakowuj!**
2. Otwórz Blender → `Edit` → `Preferences` → `Add-ons` → `Install…`
3. Wybierz plik `.zip` → Kliknij **Install Add-on**
4. Włącz **Aventurine: League Tools**

> ✅ **Sprawdź:** Opcje importu/eksportu powinny pojawić się w menu **File**, a zakładka **Aventurine LoL** w bocznym panelu (klawisz `N`)

---

### Instrukcja użycia

<Tabs items={["Import", "Eksport"]}>
<Tab value="Import">

### Import modeli

1. Przejdź do `File → Import → LoL SKN+SKL`
2. Wybierz swój plik `.skn` (upewnij się, że `.skl` jest w tym samym folderze)
3. Ustaw skalę (domyślnie: `0.01`) → Kliknij **Import**

### Import animacji

1. Najpierw zaimportuj model (SKL+SKN)
2. Przejdź do `File → Import → LoL ANM Animation`
3. Wybierz swój plik `.anm`

</Tab>
<Tab value="Eksport">

### Eksport modeli

1. Zaznacz **mesh + armature** w widoku
2. Przejdź do `File → Export → LoL SKN+SKL`
3. Użyj **Limit to 4 Influences**, jeśli trzeba, przed eksportem

### Eksport animacji

1. Zaznacz **armature** z animacją
2. Przejdź do `File → Export → LoL ANM Animation`
3. Wybierz miejsce zapisu

</Tab>
</Tabs>

## Panel boczny LoL Tools

Naciśnij `N`, aby otworzyć panel boczny, potem znajdź zakładkę **LoL Tools**:

| Narzędzie             | Funkcja                     |
| --------------------- | --------------------------- |
| Import/Export         | Szybkie skróty              |
| Limit to 4 Influences | Poprawia wagi kości do eksportu |
| UV Corners            | Przyciąga wierzchołki UV     |

---

## 💡 Szybkie porady

- Domyślna skala importu = **0.01** (jednostki League są duże)
- Do eksportu wymagane jest maks. **4 wpływy kości** na wierzchołek
- Zawsze ustawiaj FPS = **30** dla animacji
- Trzymaj pliki `.skl` i `.skn` w **tym samym folderze**
