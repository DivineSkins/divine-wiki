---

## Zainstaluj plugin

1. Wypakuj zawartość pliku `.zip`.
2. Skopiuj wszystkie pliki pluginu do folderu Mayi.

Umieść te foldery w:

```text
Documents\maya\2023\
```

- `plug-ins`
- `prefs`
- `scripts`

---

## Włącz plugin w Mayi

1. Otwórz **Mayę**
2. Przejdź do:
   **Windows → Settings/Preferences → Plug-in Manager**
3. Znajdź **lol_maya** na liście
4. Włącz oba:
   - **Loaded**
   - **Auto Load**

5. Kliknij **Close**, potem zrestartuj Mayę

Jeśli się udało, zobaczysz zakładki **LoLMaya** i **LoLMaya_MAPGEO** na głównym pasku narzędzi Mayi.

### Rozwiązywanie problemów

<Tabs items={["Plugin się nie pokazuje", "Brak zakładek", "Kompatybilność z Mayą"]}>
<Tab value="Plugin się nie pokazuje">

### Plugin nie pojawia się w Plug-in Manager

**Przyczyny:**

- Pliki nie są w odpowiednim folderze
- Zły folder wersji Mayi

**Naprawa:**

1. Sprawdź, czy pliki są w `Documents\maya\[TWOJA_WERSJA]\`
2. Upewnij się, że wszystkie trzy foldery (`plug-ins`, `prefs`, `scripts`) są na miejscu
3. Zrestartuj Mayę do końca

</Tab>
<Tab value="Brak zakładek">

### Zakładki nie pojawiają się po wczytaniu

**Przyczyny:**

- Plugin wczytany, ale UI nie odświeżone
- Maya wymaga restartu

**Naprawa:**

1. Zamknij Mayę do końca
2. Otwórz Mayę ponownie
3. Sprawdź jeszcze raz Plug-in Manager
4. Upewnij się, że **Loaded** i **Auto Load** są oba włączone

</Tab>
<Tab value="Kompatybilność z Mayą">

W przypadku **Mayi 2024+** standardowy plugin może mieć problemy ze zgodnością.
