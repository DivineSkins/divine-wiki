ritobin-lsp, [alanpq](https://github.com/alanpq) tarafından yapılan bir LSP/VS Code eklentisidir. League'in `.bin`/`.rito` dosyalarını düzenleyebileceğin okunabilir metin olarak açar.

En yeni yapılar GitHub'da: [ritobin-lsp sürümleri](https://github.com/alanpq/ritobin-lsp/releases).

<Callout type="info" title="Modlamaya yeniysen Jade'i düşün">
  `ritobin-lsp`, yaygın metin düzenleyiciler için hazır destek sunmak üzere
  tasarlandı. Bu düzenleyicileri modlama için *zaten* kullananlar için ideal.

VS Code gibi bir düzenleyicin henüz yoksa, Jade'i denemeyi düşün.

</Callout>

Komut paletindeki (`Ctrl/Cmd + P`) `Unhash File` komutunu kullan.
