## Öne Çıkan Özellikler

| Özellik         | Açıklama                                       |
| --------------- | --------------------------------------------- |
| **SKL + SKN**   | İskeletli karakter modellerini import/export et |
| **ANM**         | Animasyonları import/export et                 |
| **SCB / SCO**   | Statik objeleri import/export et               |
| **Bone Limit**  | Vertex başına en fazla 4 etkiyle sınırla       |
| **UV Tools**    | UV köşe hizalama araçları                      |
| **Drag & Drop** | Kolay dosya yönetimi                           |

---

## Gerekenler

| Gereksinim  | Detay                                 |
| ----------- | ------------------------------------- |
| Blender     | **4.0+** (Sadece Windows)             |
| FPS Ayarı   | Animasyonlar için **30 FPS** önerilir |

---

## Kurulum

1. [`Aventurine.zip`](https://github.com/RitoShark/Aventurine-League-Tools/releases) dosyasını indir. **Zip'ten çıkarma!**
2. Blender'ı aç → `Edit` → `Preferences` → `Add-ons` → `Install…`
3. `.zip` dosyasını seç → **Install Add-on**'a tıkla
4. **Aventurine: League Tools**'u etkinleştir

> ✅ **Doğrula:** Import/Export seçenekleri **File menüsünde**, **Aventurine LoL** sekmesi ise kenar çubuğunda (`N` tuşu) görünmeli

### Kullanım Rehberi

<Tabs items={["Import", "Export"]}>
<Tab value="Import">

### Model Import Etme

1. `File → Import → LoL SKN+SKL` yolunu izle
2. `.skn` dosyanı seç (`.skl`'nin aynı klasörde olduğundan emin ol)
3. Ölçeği ayarla (varsayılan: `0.01`) → **Import**'a tıkla

### Animasyon Import Etme

1. Önce modelini import et (SKL+SKN)
2. `File → Import → LoL ANM Animation` yolunu izle
3. `.anm` dosyanı seç

</Tab>
<Tab value="Export">

### Model Export Etme

1. Viewport'ta **mesh + armature**'ını seç
2. `File → Export → LoL SKN+SKL` yolunu izle
3. Gerekiyorsa export öncesi **Limit to 4 Influences**'ı kullan

### Animasyon Export Etme

1. Animasyonun olduğu **armature**'ı seç
2. `File → Export → LoL ANM Animation` yolunu izle
3. Çıktı konumunu seç

</Tab>
</Tabs>

## LoL Tools Kenar Çubuğu

Kenar çubuğunu açmak için `N`'ye bas, sonra **LoL Tools** sekmesini bul:

| Araç                  | İşlevi                      |
| --------------------- | --------------------------- |
| Import/Export         | Hızlı erişim kısayolları    |
| Limit to 4 Influences | Export için bone weight'leri düzelt |
| UV Corners            | UV vertex'lerini hizala     |

---

## 💡 Hızlı İpuçları

- Varsayılan import ölçeği = **0.01** (League birimleri büyüktür)
- Export için vertex başına en fazla **4 bone influence** gerekli
- Animasyonlar için FPS'i her zaman **30** yap
- `.skl` ve `.skn` dosyalarını **aynı klasörde** tut
