## .bin Dosyaları: Veri ve Mantık

`.bin` dosyaları League'deki **tüm mantığı** tutar: partikül sistemleri, skin tanımları, animasyonlar, sesler ve daha fazlası.

| İçerir              | Örnekler                     |
| ------------------- | ---------------------------- |
| Partikül verisi     | VFX renkleri, boyutlar, zamanlama |
| Skin tanımları      | Model yolları, doku yolları  |
| Animasyon config'leri | Animasyon adları, blending |
| Ses config'leri     | Ses tetikleyicileri, sesler  |

### Workflow

1. `.bin` dosyasını [Flint](/docs/lol/tools/modding-apps/flint) ile çıkar
2. [Ritobin](/docs/lol/tools/modding-apps/ritobin) ile `.py` formatına dönüştür (ya da doğrudan [Jade](/docs/lol/tools/modding-apps/jade) içinde düzenle)
3. VS Code veya Notepad++ gibi bir metin editöründe düzenle
4. Tekrar `.bin` formatına dönüştür
5. Mod klasörüne ekle

> 💡 `.py` dosyaları insan tarafından okunabilir. Arama yapıp düzenleyebilirsin.

## .dds Dosyaları: Dokular

`.dds` (DirectDraw Surface), şunlar için kullanılan **standart doku formatıdır**:

| Kullanım        | Örnekler              |
| --------------- | --------------------- |
| Şampiyon modelleri | Skin dokuları, yüzler |
| Partiküller     | VFX sprite'ları, parıltılar |
| UI/HUD          | İkonlar, yetenek panelleri |

## .tex Dosyaları: Riot'un Formatı

`.tex`, `.wad.client` dosyalarında bulunan Riot'un **özel doku formatıdır**.

| Durum                     | Bilgi                  |
| ------------------------- | ---------------------- |
| ❌ Doğrudan düzenlenemez  | Derlenmiş bir format   |
| ✅ Önce dönüştürmelisin   | tex2dds kullan         |
| ✅ Sonra geri dönüştür    | Yeniden import etmeden önce |

`.tex` ile çalışmanın iki yolu var:

1. Resim editörün için bir TEX plugin ile **doğrudan aç**. Dönüştürme adımı yok.
2. `.tex` dosyasını Flint veya LtMAO ile `.dds` formatına ve geri **dönüştür**.

## Tam Workflow Tablosu

| Görev                    | Dosya  | Araç                               | Çıktı           |
| ------------------------ | ------ | ---------------------------------- | --------------- |
| VFX/partikül düzenle     | `.bin` | Jade (veya Ritobin)                | `.bin`          |
| Şampiyon skin'i düzenle  | `.dds` | Photoshop/GIMP                     | `.dds`          |
| Bir dokuyu doğrudan düzenle | `.tex` | RitoTex, Paint.NET veya GIMP plugin | `.tex`         |
| Bir dokuyu dönüştür      | `.tex` | Flint veya LtMAO                   | `.dds`          |
| Bir dokuyu yeniden import et | `.dds` | Flint veya LtMAO               | `.tex`          |
| Oyun dosyalarına göz at  | `.wad` | Flint                              | Çıkarılmış dosyalar |
