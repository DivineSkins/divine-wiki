<Callout type="info" title="CTRL+5 ile açıp kapama">
  Yalnızca Jade kullanarak bir moda CTRL+5 ile açıp kapama ekle.
</Callout>

Bu rehber, aşağıdaki videodaki gibi bir CTRL+5 açıp kapama işlevini nasıl ekleyeceğini gösteriyor:

<YouTube id="AeuXesgfyIc" title="CTRL+5 ile açıp kapama örneği" />

Önce `skinMeshProperties` içine `initialSubmeshToHide` ekle. `YourSubmesh`
değerini varsayılan olarak gizlemek istediğin submesh ile değiştir.

```py
initialSubmeshToHide: string = "YourSubmesh"
```

<img
  src="/wiki-images/screenshot-2026-08-25-104212.png"
  alt="skinMeshProperties içinde Skirt olarak ayarlanmış initialSubmeshToHide"
/>

`AnimationGraphData` içinde aşağıdaki kayıtları `mClipDataMap` alanına ekle.
`mCascadeBlendValue` ve `mClipDataMap` satırları, kayıtları nereye ekleyeceğini
gösteriyor. Alan zaten varsa ikinci bir `mClipDataMap` oluşturma.

```py
      mCascadeBlendValue: f32 = 0
            mClipDataMap: map[hash,pointer] = {
                "Toggle" = ConditionBoolClipData {
                    Updater: pointer = LogicDriverBoolParametricUpdater {
                        driver: pointer = SubmeshVisibilityBoolDriver {
                            Submeshes: list[hash] = {
                                "Skirt"
                            }
                            VISIBLE: bool = false
                        }
                    }
                    mTrueConditionClipName: hash = 0xbe8683f0
                    mFalseConditionClipName: hash = 0x8aa48b13
                }
                0xbe8683f0 = ParallelClipData {
                    mFlags: u32 = 14
                    mClipNameList: list[hash] = {
                        0x43191761
                    }
                }
                0x43191761 = AtomicClipData {
                    mFlags: u32 = 14
                    mTrackDataName: hash = "Toggle"
                    mMaskDataName: hash = "Default"
                    mEventDataMap: map[hash,pointer] = {
                        "Fade" = ParticleEventData {
                            mEffectKey: hash = 0xcef6c126
                            mParticleEventDataPairList: list[embed] = {
                                ParticleEventDataPair {
                                    mBoneName: hash = "C_Buffbone_GLB_Layout_Loc"
                                }
                            }
                            mIsLoop: bool = false
                            mIsKillEvent: bool = false
                        }
                        0x38503e10 = SubmeshVisibilityEventData {
                            mShowSubmeshList: list[hash] = {
                                "Skirt"
                            }
                            mHideSubmeshList: list[hash] = {
                                0x8ba930d1
                            }
                        }
                    }
                    mAnimationResourceData: embed = AnimationResourceData {
                        mAnimationFilePath: string = "ASSETS/cosmic/0/bum/Characters/camille/Skins/Base/Animations/camille_Taunt.anm"
                    }
                }
                0x8aa48b13 = ParallelClipData {
                    mFlags: u32 = 14
                    mClipNameList: list[hash] = {
                        0x04acc354
                    }
                }
                0x04acc354 = AtomicClipData {
                    mFlags: u32 = 14
                    mTrackDataName: hash = "Toggle"
                    mMaskDataName: hash = "Default"
                    mEventDataMap: map[hash,pointer] = {
                        "FadeOut" = ParticleEventData {
                            mEffectKey: hash = 0xe271f27c
                            mParticleEventDataPairList: list[embed] = {
                                ParticleEventDataPair {
                                    mBoneName: hash = "C_Buffbone_GLB_Layout_Loc"
                                }
                            }
                            mIsLoop: bool = false
                            mIsKillEvent: bool = false
                        }
                        "Hide_Mesh" = SubmeshVisibilityEventData {
                            mHideSubmeshList: list[hash] = {
                                "Skirt"
                            }
                            mShowSubmeshList: list[hash] = {
                                0x8ba930d1
                            }
                        }
                    }
                    mAnimationResourceData: embed = AnimationResourceData {
                        mAnimationFilePath: string = "ASSETS/cosmic/0/bum/Characters/camille/Skins/Base/Animations/camille_taunt.anm"
                    }
                }
            }
```

Her `"Skirt"` metnini açıp kapatmak istediğin submesh ile değiştir. Örnek,
`0x8ba930d1` hash'li submesh'i de diğerinin tersine açıp kapatıyor. Bu hash'i
ikinci submesh'inin adı ya da hash'iyle değiştir. Yalnızca bir submesh'i
gösterip gizleyeceksen ikinci submesh'e ait bu kayıtları kaldır.

<Callout type="warning" title="Geçerli bir animasyon yolu kullan">
  Her iki `mAnimationFilePath` değerini de şampiyonunda bulunan bir animasyonla
  değiştir. Geçersiz bir yol, CTRL+5 işlevinin çalışmamasına ya da oyunun
  çökmesine yol açabilir.
</Callout>

Son olarak `mTrackDataMap` içine şu kaydı ekle:

```py
"Toggle" = TrackData {
    mPriority: u8 = 1
}
```
