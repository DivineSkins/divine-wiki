## Bind Weight

**`bindWeight`** contrôle à quel point la particule suit le mouvement du bone auquel elle est attachée.

- `1` → suit totalement le bone
- `0` → reste en place
  <img src="/wiki-images/1769132679719-x7qanf.webp" alt="Image" width={500} />

```rust
bindWeight: embed = ValueFloat {
    constantValue: f32 = 1
}
```

---

## Rate

**`rate`** contrôle combien de particules l'emitter fait apparaître par seconde.

<img src="/wiki-images/1769132701264-5grdr.webp" alt="Image" width={500} />

### Exemple : 1 particule

```rust
rate: embed = ValueFloat {
    constantValue: f32 = 1 // 1 particle in emitter
}
```

### Exemple : 20 particules

```rust
rate: embed = ValueFloat {
    constantValue: f32 = 20 // 20 particles spawning in 1 emitter
}
```

## Particle Lifetime

- **`particleLifetime`** définit combien de temps chaque particule vit après avoir été émise.
- **`lifetime`** définit combien de temps l'emitter lui-même dure avant de disparaître.

<img src="/wiki-images/1769132720262-0d010j.webp" alt="Image" width={500} />

### Durée de vie finie

```rust
particleLifetime: embed = ValueFloat {
    constantValue: f32 = 1
}
```

### Durée de vie infinie

```rust
particleLifetime: embed = ValueFloat {
    constantValue: f32 = -1 // infinity
}
```

### Durée de vie de l'emitter

```rust
lifetime: option[f32] = {
    1
}
```

## Particle Linger

**`particleLinger`** retarde la disparition des particules après la fin de l'emitter. Elles restent visibles pendant une durée fixée (en secondes).

<img src="/wiki-images/1769132745363-l0cm4s.webp" alt="Image" width={500} />

```rust
particleLinger: option[f32] = {1}
```

## Emitter Position

**`EmitterPosition`** définit où les particules apparaissent par rapport à l'emitter.

- **Y** plus haut → monte
- **Y** plus bas → descend

<img src="/wiki-images/1769132826453-dvots5.webp" alt="Image" width={500} />

### Exemples de position

```rust
EmitterPosition: embed = ValueVector3 {
    constantValue: vec3 = { 0, 100, 0 } // higher
}
```

```rust
EmitterPosition: embed = ValueVector3 {
    constantValue: vec3 = { 0, -100, 0 } // lower
}
```

```rust
EmitterPosition: embed = ValueVector3 {
    constantValue: vec3 = { 100, 0, 0 } // right
}
```

```rust
EmitterPosition: embed = ValueVector3 {
    constantValue: vec3 = { -100, 0, 0 } // left
}
```

```rust
EmitterPosition: embed = ValueVector3 {
    constantValue: vec3 = { 0, 0, 100 } // forward
}
```

```rust
EmitterPosition: embed = ValueVector3 {
    constantValue: vec3 = { 0, 0, -100 } // backward
}
```

## Translation Override

**`translationOverride`** déplace le système de particules indépendamment des réglages de l'emitter et décale tout le système de façon globale.

<img src="/wiki-images/1769132846178-bcemql.webp" alt="Image" width={500} />

```rust
translationOverride: vec3 = { 0, 100, 0 } // higher
translationOverride: vec3 = { 0, -100, 0 } // lower
translationOverride: vec3 = { 100, 0, 0 } // right
translationOverride: vec3 = { -100, 0, 0 } // left
translationOverride: vec3 = { 0, 0, 100 } // forward
translationOverride: vec3 = { 0, 0, -100 } // backward
```

## Eye Candy

**`mEyeCandy`** active ou désactive l'option **Hide Eye Candy** dans les réglages vidéo.

> À placer tout en bas d'un système de particules.

<img src="/wiki-images/1769132889330-6y5jzd.webp" alt="Image" width={500} />

```rust
mEyeCandy: bool = true // or false
```

## Pass (ordre de dessin)

**`Pass`** contrôle l'ordre de dessin, comme les calques dans Photoshop.

<img src="/wiki-images/1769132912369-jb8tlr.webp" alt="Image" width={500} />

- `Pass = 0` → calque du bas (dessiné en premier)
- `Pass = 16` → calque du haut (dessiné en dernier, s'affiche au-dessus des autres)

```rust
Pass: i16 = 0
```

---

## Blend Mode

**`blendMode`** définit comment la particule se fond visuellement.

```rust
blendMode: u8 = 1
```

### Valeurs de Blend Mode

- **1** : pas de transparence
  - Safe à recolorer en noir ou en blanc

- **3 / 4 (SCB)** : transparence standard
  ⚠️ Ne recolore pas trop foncé, sinon la particule peut devenir invisible en jeu

## Navmesh Mask

**`useNavmeshMask`** contrôle si le système de particules utilise le terrain comme masque.

### Activé (utilise le terrain comme masque)

<img src="/wiki-images/1769133429180-hdk1d.webp" alt="Image" width={500} />

```rust
useNavmeshMask: flag = true
```

> La particule sera masquée par le terrain.

---

### Désactivé (pas de masque terrain)

<img src="/wiki-images/1769133650731-8zdz6u.webp" alt="Image" width={500} />

```rust
useNavmeshMask: flag = false
```

> La particule ignorera le masquage par le terrain.
