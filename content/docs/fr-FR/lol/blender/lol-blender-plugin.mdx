## Fonctionnalités clés

| Fonctionnalité  | Description                                    |
| --------------- | --------------------------------------------- |
| **SKL + SKN**   | Importe/Exporte les modèles avec squelettes   |
| **ANM**         | Importe/Exporte les animations                |
| **SCB / SCO**   | Importe/Exporte les objets statiques          |
| **Bone Limit**  | Limite à 4 influences max par vertex          |
| **UV Tools**    | Utilitaires de snap des coins UV              |
| **Drag & Drop** | Gestion facile des fichiers                   |

## Prérequis

| Prérequis   | Détails                                  |
| ----------- | ---------------------------------------- |
| Blender     | **4.0+** (Windows uniquement)            |
| Réglage FPS | **30 FPS** recommandés pour les animations |

## Installation

1. Télécharge [`Aventurine.zip`](https://github.com/RitoShark/Aventurine-League-Tools/releases) : **Ne le dézippe pas !**
2. Ouvre Blender → `Edit` → `Preferences` → `Add-ons` → `Install…`
3. Sélectionne le fichier `.zip` → Clique sur **Install Add-on**
4. Active **Aventurine: League Tools**

> ✅ **Vérifie :** les options Import/Export doivent apparaître dans le **menu File**, et l'onglet **Aventurine LoL** dans la barre latérale (touche `N`)

---

### Guide d'utilisation

<Tabs items={["Import", "Export"]}>
<Tab value="Import">

### Importer des modèles

1. Va dans `File → Import → LoL SKN+SKL`
2. Sélectionne ton fichier `.skn` (assure-toi que le `.skl` est dans le même dossier)
3. Ajuste l'échelle (par défaut : `0.01`) → Clique sur **Import**

### Importer des animations

1. Importe d'abord ton modèle (SKL+SKN)
2. Va dans `File → Import → LoL ANM Animation`
3. Sélectionne ton fichier `.anm`

</Tab>
<Tab value="Export">

### Exporter des modèles

1. Sélectionne ton **mesh + armature** dans le viewport
2. Va dans `File → Export → LoL SKN+SKL`
3. Utilise **Limit to 4 Influences** si besoin avant l'export

### Exporter des animations

1. Sélectionne ton **armature** avec l'animation
2. Va dans `File → Export → LoL ANM Animation`
3. Choisis l'emplacement de sortie

</Tab>
</Tabs>

## Barre latérale LoL Tools

Appuie sur `N` pour ouvrir la barre latérale, puis trouve l'onglet **LoL Tools** :

| Outil                 | Fonction                        |
| --------------------- | ------------------------------- |
| Import/Export         | Raccourcis d'accès rapide       |
| Limit to 4 Influences | Corrige les poids de bones pour l'export |
| UV Corners            | Snap les vertices UV            |

---

## 💡 Astuces rapides

- Échelle d'import par défaut = **0.01** (les unités de League sont grandes)
- Max **4 influences de bones** par vertex requis pour l'export
- Règle toujours les FPS = **30** pour les animations
- Garde les fichiers `.skl` et `.skn` dans le **même dossier**
