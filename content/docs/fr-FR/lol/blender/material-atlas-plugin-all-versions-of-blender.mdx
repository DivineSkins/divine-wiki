Un material atlas regroupe toutes les textures de ton modèle dans une seule image, pour que League n'ait qu'une texture à charger. La [version CATS de ce guide](/docs/lol/blender/material-atlas) ne marche que sur Blender 5.0. Celle-ci utilise l'add-on Material Combiner, qui marche sur toutes les versions de Blender.

## Installer l'add-on

1. Installe le `.zip` :
   - **Blender 4.2 et plus récent :** glisse-dépose le `.zip` dans la fenêtre de Blender.
   - **Versions plus anciennes :** va dans **Edit → Preferences → Add-ons**, clique sur **Install**, choisis le `.zip` et active **Material Combiner**.
2. Appuie sur `N` dans le viewport pour ouvrir la barre latérale et ouvre l'onglet **MatCombiner**.
3. Clique sur **Install Pillow** pour télécharger la bibliothèque dont l'add-on a besoin, puis redémarre Blender.

## Créer l'atlas

1. Sélectionne ton modèle et rouvre l'onglet **MatCombiner**.
2. Clique sur **Generate Material List**. Tous les matériaux du modèle apparaissent dans la liste. Décoche ceux que tu veux laisser de côté.

<img
  src="/wiki-images/atyayaya.png"
  alt="L'onglet MatCombiner dans la barre latérale de Blender avec le bouton Generate Material List souligné"
/>

3. Clique sur **Save Atlas to..** (appelé **Generate Texture Atlas** dans les versions plus récentes) et choisis un dossier. L'add-on y enregistre la texture combinée et passe ton modèle sur un seul matériau.

C'est tout. Ton modèle utilise maintenant une seule texture au lieu d'une par matériau.

<Callout type="info" title="Il manque des textures dans l'atlas ?">

- Si tes textures sont intégrées au `.blend`, enregistre le fichier et utilise d'abord **File → External Data → Unpack Resources**.
- L'add-on cherche les nodes par leur nom anglais. Passe Blender en anglais et réimporte le modèle si l'atlas sort vide.

</Callout>

Tu préfères te passer d'add-on ? Consulte [Material Atlas (No Plugin)](/docs/lol/blender/material-atlas-no-plugin).
