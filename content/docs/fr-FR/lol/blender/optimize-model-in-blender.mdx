<LevelPill level="intermediate" />

Les modèles de League of Legends peuvent dépasser 65 000 vertices, tant que chaque submesh reste sous la limite. Tu peux avoir un submesh à 65 000 vertices et un autre à 65 000 vertices, le modèle s'exportera quand même.

Le souci, c'est que trop de vertices peuvent faire baisser tes FPS. Sur une grosse config, la différence peut être énorme, parfois autour de 100 FPS. Sur une petite config, ça se verra sûrement moins.

Ce guide te montre comment réduire ton nombre de vertices pour que ton modèle pèse moins sur les FPS.

<img
  src="/wiki-images/optimize-model-1.webp"
  alt="Un modèle de 2B dans Blender avec l'overlay de statistiques affichant 219 906 vertices"
/>

Ce modèle de 2B a **219 906 vertices**, plus de trois fois la limite de 65 000 pour un seul submesh.

<Callout type="info" title="Tu ne vois pas le nombre de vertices ?">
  Ouvre le menu **Overlays** en haut à droite du viewport et active
  **Statistics**.
</Callout>

## Fusionner par distance

La plupart des modèles importés contiennent plein de vertices en double, empilés les uns sur les autres. Tu peux les fusionner sans changer l'apparence du modèle. Ça peut supprimer une énorme partie des vertices.

<Steps>
<Step>

### Sélectionne le modèle

1. Sélectionne ton modèle.
2. Appuie sur `Tab` pour passer en **Edit Mode**.

<img
  src="/wiki-images/optimize-model-2.webp"
  alt="Le modèle en Edit Mode avec tout le mesh sélectionné"
/>

</Step>
<Step>

### Sélectionne tous les vertices

Appuie sur `A` pour sélectionner tous les vertices.

</Step>
<Step>

### Fusionne les vertices

1. Appuie sur `M` pour ouvrir le menu **Merge**.
2. Choisis **By Distance**.

<Callout type="warning" title="Utilise toujours By Distance">
  Les autres options écrasent tout ce que tu as sélectionné en un seul point.
</Callout>

<img
  src="/wiki-images/optimize-model-3.webp"
  alt="Le menu Merge ouvert avec At Center, At Cursor, Collapse et By Distance"
/>

</Step>
</Steps>

Blender affiche en bas de la fenêtre le nombre de vertices supprimés. Dans cet exemple, il en a supprimé 188 335. Le modèle est tombé à **31 571 vertices**, bien sous la limite.

<img
  src="/wiki-images/optimize-model-4.webp"
  alt="Après Merge by Distance, le modèle a 31 571 vertices et Blender indique 188 335 supprimés"
/>

Si le nombre est encore trop élevé, augmente un peu **Merge Distance** dans le panneau en bas à gauche. Essaie par exemple `0.001`.

N'exagère pas, sinon les détails proches risquent de se fondre entre eux.

## Decimate

Si la fusion ne suffit pas, utilise le modificateur **Decimate** pour simplifier le mesh.

<Steps>
<Step>

### Ouvre l'onglet Modifiers

1. Appuie sur `Tab` pour revenir en **Object Mode**.
2. Sélectionne ton modèle.
3. Ouvre l'onglet **Modifiers** dans le panneau Properties à droite. Cherche l'icône de clé bleue.

<img
  src="/wiki-images/optimize-model-5.webp"
  alt="L'onglet Modifiers, une icône de clé bleue, entouré dans le panneau Properties"
/>

</Step>
<Step>

### Ajoute le modificateur Decimate

1. Clique sur **Add Modifier**.
2. Cherche `Decimate`.

</Step>
<Step>

### Règle les options du modificateur

1. Passe le mode sur **Planar**.
2. Augmente **Angle Limit** petit à petit.
3. Surveille le nombre de vertices jusqu'à obtenir ce que tu veux.
4. Active **UVs** sous **Delimit** pour que les textures ne soient pas étirées.

<img
  src="/wiki-images/optimize-model-6.webp"
  alt="Le modificateur Decimate en mode Planar avec Angle Limit et les options Delimit"
/>

</Step>
<Step>

### Applique le modificateur

1. Ouvre la flèche du menu déroulant du modificateur.
2. Clique sur **Apply** pour appliquer le changement au mesh avant l'export.

</Step>
</Steps>

<Callout type="info" title="Combine les deux">
  Sur les modèles très high-poly, fusionne par distance d'abord, puis décime ce
  qui reste. Vise moins de 60 000 vertices par submesh pour garder de la marge.
  Pour plus d'étapes de préparation du modèle, consulte le [guide 3D Model
  Swap](/docs/lol/blender/3d-model-swap).
</Callout>
