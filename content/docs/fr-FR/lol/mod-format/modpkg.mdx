Le `.modpkg`, c'est le fichier que tu uploades sur Divine et que les joueurs installent. Le Creator Hub y packe ton [projet de mod](/docs/lol/mod-format/mod-project), avec chaque [couche](/docs/lol/mod-format/layers).

Avant d'exporter :

- Repathe les mods de champion. [Repath ton mod](/docs/lol/getting-started/repath-your-mod) te montre comment.
- Remplis les infos de ton mod, et augmente la **Version** si tu publies une mise à jour.
- Teste le mod en jeu depuis le Creator Hub.

## Exporte-le

1. Fais un clic droit sur la carte du mod.
2. Sous **Export**, clique sur **Modpkg**.
3. Vérifie la liste : chaque WAD affiche sa couche, son nombre de fichiers et sa taille.
4. Clique sur **Export** et choisis où enregistrer le fichier.

Le nom de fichier proposé reprend le nom, la version et l'auteur de ton mod. C'est ce fichier que tu uploades sur Divine.

<img
  src="/wiki-images/lol-mod-format-3.webp"
  width={560}
  alt="La fenêtre Export .modpkg qui liste Aatrox.wad.client dans la couche base avec 257 fichiers, et le bouton Export entouré"
/>

**Add another project to this package** fusionne un autre projet du Creator Hub dans le même fichier.

## Installe un .modpkg

Les joueurs installent les mods de Divine avec Celestial. Pour installer un fichier à la main :

1. Ouvre la **Bibliothèque** dans Celestial.
2. Glisse le fichier sur la Bibliothèque, ou clique sur **Importer**, puis **Import Files**.

<img
  src="/wiki-images/lol-mod-format-4.webp"
  width={360}
  alt="Le menu Importer de la Bibliothèque ouvert, avec Import Files entouré"
/>

Seule la couche `base` est active au départ. Clique sur le badge de couches de la carte du mod pour activer ou désactiver les couches.
