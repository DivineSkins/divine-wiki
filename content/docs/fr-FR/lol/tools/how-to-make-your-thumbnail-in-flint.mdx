Crée une miniature pour ton skin personnalisé avec [Flint](/docs/lol/tools/modding-apps/flint).
Dans l'éditeur de miniatures, place ton modèle et ton texte, puis exporte une image à partager avec ton mod.

## Avant de commencer

- Ouvre ton projet de skin dans Flint.
- Repère le fichier `.skn` du modèle dans l'arborescence du projet.

## Tuto vidéo

Regarde la vidéo pour suivre les manipulations dans l'éditeur de miniatures.

<YouTube id="ANyByMlxGGg" title="Créer une miniature de skin personnalisé dans Flint" />

## Crée ta miniature

1. Fais un clic droit sur le fichier `.skn` du modèle.
2. Choisis **Create Thumbnail…** pour ouvrir l'éditeur de miniatures.
3. Choisis **Riot style** ou **Divine style** dans le menu des presets.
4. Sélectionne un calque de modèle dans le panneau **Layers**.
5. Ajuste sa position et sa taille sur le canevas pour bien cadrer ton skin.
6. Sélectionne chaque calque de texte pour modifier le nom du mod et du champion.
7. Choisis **WebP**, **PNG** ou **JPG** dans le menu du format de sortie.
8. Clique sur **Export**.
9. Choisis un nom de fichier et un dossier de destination dans la fenêtre qui s'ouvre.
10. Ouvre l'image exportée pour vérifier que le modèle et le texte sont bien lisibles.

<Callout type="info" title="Garde ta mise en page pour plus tard">
  **Save** enregistre ta mise en page comme preset local. Utilise **Export**
  pour enregistrer l'image finale.
</Callout>
