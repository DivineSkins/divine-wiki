Tex Thumbnail Provider par **RitoShark** affiche les fichiers `.tex` en vraies
miniatures dans l'Explorateur Windows. Dans la liste des fichiers, le volet d'aperçu
et la vue en grandes icônes, tu vois la texture au lieu d'une icône vide. Il décode
le fichier lui-même, donc aucune appli n'a besoin d'être ouverte.

---

## Installation

Tu installes et désinstalles avec une seule commande PowerShell. Pas de
téléchargement, pas de droits admin. L'enregistrement est par utilisateur.

1. Ferme toutes les fenêtres de l'Explorateur qui affichent des fichiers `.tex`.
2. Ouvre PowerShell. Une fenêtre normale suffit.
3. Colle ceci et appuie sur Entrée :

   ```powershell
   iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1 | iex
   ```

Le script récupère le dernier `TexThumbnailProvider.dll`, le dépose dans
`%LOCALAPPDATA%\RitoShark\TexThumbnailProvider` et l'enregistre pour ton
utilisateur. Ouvre un dossier avec des fichiers `.tex` et les miniatures
apparaissent.

<Callout type="info" title="Épingle une version précise">
  Tu veux une version fixe plutôt que la dernière ? Lance :

```powershell
& ([scriptblock]::Create((iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1))) -Version v1.1.0
```

</Callout>

## Désinstallation

```powershell
iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/uninstall-thumbnail-handler.ps1 | iex
```

Ceci retire le handler et ses entrées de registre.

---

## Ce qu'il gère

Il décode les formats de compression `.tex` que Riot livre :

| Format                   | code `.tex` |
| ------------------------ | ----------- |
| DXT1 / BC1               | `0x0A`      |
| DXT5 / BC3               | `0x0C`      |
| BC7                      | `0x0D`      |
| BC5                      | `0x0E`      |
| BGRA8 (non compressé)    | `0x14`      |

Les textures mipmappées marchent aussi. Le plus grand mip est décodé pour la
miniature.

<Callout type="info" title="Gagne même contre Photoshop">
  Si Photoshop ou le plugin RitoTex est installé, il s'enregistre comme handler de
  miniatures `.tex` et prendrait normalement le dessus. Cet installeur écrit son
  handler sous ton compte utilisateur, ce qui l'emporte sur celui de toute la
  machine. Tes miniatures `.tex` continuent de s'afficher. Il ne touche qu'à l'entrée
  de miniature, donc double-cliquer sur un `.tex` ouvre toujours l'appli que tu as
  définie.
</Callout>

## Dépannage

### Les miniatures ne s'affichent pas

Redémarre l'Explorateur Windows. Ouvre le Gestionnaire des tâches, trouve
**Windows Explorer**, fais un clic droit et choisis **Restart**. Rouvre le dossier.

### Les anciennes miniatures ressemblent encore à des icônes génériques

Windows met les miniatures en cache par fichier. Un `.tex` ne se repeint qu'après un
changement de sa date de modification ou après un vidage du cache. Ouvre le
**Nettoyage de disque**, coche **Miniatures**, clique sur **OK**, puis rouvre le
dossier.

### Toujours rien après un redémarrage

Relance la commande d'installation. Elle re-télécharge et ré-enregistre le DLL.

## Alternative : LTK Tex Thumb Handler

L'équipe **LeagueToolkit** a son propre handler de miniatures `.tex`
([ltk-tex-utils](https://github.com/LeagueToolkit/ltk-tex-utils)). Il fait le même
travail de base, mais deux choses le freinent :

- Il ne décode pas tous les formats de compression que Riot utilise, donc certains
  fichiers `.tex` restent vides.
- Si un autre programme (Photoshop, le plugin RitoTex, etc.) a déjà revendiqué le
  type `.tex`, il ne peut produire aucun aperçu. Il ne l'emporte pas sur le handler
  existant comme le fait cet outil.

Pour la plupart des gens, le Tex Thumbnail Provider de RitoShark est le meilleur
choix : il couvre plus de formats et gagne contre les autres handlers. Ne lance qu'un
seul handler de miniatures à la fois. Si tu avais installé celui de LTK, retire-le
avant d'installer celui-ci.
