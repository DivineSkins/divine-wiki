Tex Thumbnail Provider par **RitoShark** te permet de voir les fichiers `.tex` en
miniatures dans l'Explorateur Windows. Fini de deviner ce qu'il y a dedans.

[Télécharger la dernière version](https://github.com/RitoShark/TexThumbnailProvider/releases/latest)

Dernière version : **v1.1.0**.

---

## Ce qu'il fait

- Affiche les fichiers `.tex` en aperçu image dans l'Explorateur Windows.
- Fonctionne dans n'importe quel dossier avec des textures `.tex` (fichiers du jeu, exports, assets de mod).
- Tourne comme une DLL COM enregistrée. Aucune appli à ouvrir. Aucun processus en arrière-plan.

{/* SCREENSHOT: Windows Explorer showing a folder of .tex files with image thumbnails instead of generic icons */}

---

## Avant de commencer

- Windows 10 ou 11.
- PowerShell. Aucun droit administrateur requis. L'installateur enregistre la DLL pour ton utilisateur seulement.

---

## Installation

1. Ferme toutes les fenêtres de l'Explorateur Windows qui affichent des fichiers `.tex`.
2. Ouvre PowerShell. Une fenêtre normale suffit. Tu n'as pas besoin de le lancer en tant qu'administrateur.
3. Colle cette commande et appuie sur Entrée :

   ```powershell
   iwr -useb https://raw.githubusercontent.com/RitoShark/TexThumbnailProvider/master/scripts/install-thumbnail-handler.ps1 | iex
   ```

4. Attends que l'installateur finisse. Il télécharge `TexThumbnailProvider.dll`, le copie dans `%LOCALAPPDATA%\RitoShark\TexThumbnailProvider`, et l'enregistre pour ton utilisateur.
5. Ouvre n'importe quel dossier avec des fichiers `.tex`. Les miniatures apparaissent à la place des icônes génériques.

{/* SCREENSHOT: PowerShell window showing the install script output with a success message */}

<Callout type="info">
  L'installateur enregistre la DLL pour l'utilisateur courant. C'est pour ça qu'il n'a
  pas besoin de droits admin. Garde le dossier d'installation. Si tu le supprimes, les aperçus
  arrêtent de marcher.
</Callout>

---

## Si tu utilises aussi RitoTex

Le plugin Photoshop [RitoTex](/docs/lol/tools/texturing/photoshop-tex-plugin)
enregistre lui aussi un gestionnaire de miniatures `.tex`. Deux gestionnaires pour un même type de fichier
se gêneraient normalement.

Cet installateur écrit son gestionnaire sous ton compte utilisateur, ce qui l'emporte sur celui
de la machine. Donc tes miniatures `.tex` continuent de s'afficher même avec RitoTex
installé. Tu n'as pas à choisir entre les deux.

## Dépannage

### Les miniatures ne s'affichent pas

1. Redémarre l'Explorateur Windows :
   - Ouvre le Gestionnaire des tâches.
   - Trouve **Windows Explorer**.
   - Fais un clic droit. Choisis **Redémarrer**.
2. Ouvre à nouveau le dossier.

### Les anciennes miniatures ressemblent toujours à des icônes génériques

Windows met les miniatures en cache. Un fichier `.tex` ne se rafraîchit qu'après un changement de sa date
de modification ou après que tu vides le cache.

1. Ouvre le **Nettoyage de disque**.
2. Coche **Miniatures**.
3. Clique sur **OK**.
4. Ouvre à nouveau le dossier.

### Toujours rien après un redémarrage

Relance la commande d'installation. Elle retélécharge et réenregistre la DLL.

## Alternatives

[LTK Tex Thumb Handler](/docs/lol/tools/texturing/ltk-tex-thumb-handler) par
l'équipe LeagueToolkit fait le même travail. Choisis un seul outil, pas les deux. Lancer deux
gestionnaires de miniatures pour le même type de fichier peut causer des conflits.
