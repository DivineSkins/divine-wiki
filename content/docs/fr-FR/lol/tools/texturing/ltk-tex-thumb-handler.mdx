LTK Tex Thumb Handler est l'extension shell Windows de l'équipe
**LeagueToolkit**. Il affiche les fichiers `.tex` en aperçu image dans l'Explorateur Windows.

Il fait le même travail que [Tex Thumbnail Provider](/docs/lol/tools/texturing/tex-thumbnail-provider)
de RitoShark. Choisis-en un, pas les deux.

[Télécharger la dernière version](https://github.com/LeagueToolkit/ltk-tex-utils/releases)

---

## Ce qu'il fait

- Affiche les fichiers `.tex` en aperçu miniature dans l'Explorateur Windows.
- Fonctionne sur n'importe quel dossier avec des textures `.tex` (fichiers du jeu, exports, assets de mod).
- Tourne comme une DLL COM enregistrée. Aucune appli à ouvrir. Aucun processus en arrière-plan.

---

## Avant de commencer

- Windows 10 ou 11.
- Accès administrateur (l'installateur enregistre une DLL système).
- PowerShell.

---

## Installer

1. Ferme toutes les fenêtres de l'Explorateur Windows qui affichent des fichiers `.tex`.
2. Fais un clic droit sur PowerShell et choisis **Exécuter en tant qu'administrateur**.
3. Colle cette commande et appuie sur Entrée :

   ```powershell
   iwr -useb https://raw.githubusercontent.com/LeagueToolkit/ltk-tex-utils/main/scripts/install-thumbnail-handler.ps1 | iex
   ```

4. Attends que l'installateur finisse. Il télécharge `ltk-tex-thumb-handler.dll`,
   le copie dans `%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler`, et
   l'enregistre auprès de Windows.
5. Redémarre l'Explorateur Windows (ou redémarre ton PC).

{/* SCREENSHOT: PowerShell window showing the install script output with success message */}

---

## Comment vérifier que ça marche

Ouvre n'importe quel dossier avec des fichiers `.tex`. Les icônes deviennent des aperçus image. Si
elles ressemblent toujours à des icônes vides, redémarre l'Explorateur ou reboote.

---

## Désinstaller

1. Fais un clic droit sur PowerShell et choisis **Exécuter en tant qu'administrateur**.
2. Lance :

   ```powershell
   regsvr32.exe /u "%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler\ltk_tex_thumb_handler.dll"
   ```

3. Supprime le dossier `%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler`.

---

## Quand utiliser celui-ci plutôt que Tex Thumbnail Provider

Les deux outils font la même chose : afficher les aperçus `.tex` dans l'Explorateur. N'en lance qu'un
seul à la fois.

| Outil                      | Créé par      | Méthode d'installation          |
| -------------------------- | ------------- | ------------------------------- |
| **LTK Tex Thumb Handler**  | LeagueToolkit | Ligne unique PowerShell (admin) |
| **Tex Thumbnail Provider** | RitoShark     | Ligne unique PowerShell (par utilisateur) |

Choisis LTK Tex Thumb Handler si tu utilises déjà d'autres outils LeagueToolkit.
Choisis la version RitoShark si tu veux une installation par utilisateur sans droits admin.

> **Attention.** N'installe pas les deux. Deux gestionnaires de miniatures pour le même
> type de fichier peuvent se gêner et te laisser sans aucun aperçu.
> Désinstalle l'un avant d'installer l'autre.

---

## Dépannage

### Les miniatures n'apparaissent pas

Redémarre l'Explorateur Windows. Ouvre le Gestionnaire des tâches, trouve **Windows Explorer**,
fais un clic droit, et choisis **Redémarrer**. Ouvre à nouveau le dossier.

### Toujours pas de miniatures après un redémarrage

Vérifie que la DLL est bien à
`%ProgramFiles%\LeagueToolkit\ltk-tex-thumb-handler\ltk_tex_thumb_handler.dll`.
Si elle manque, relance la commande d'installation.

### L'ancienne DLL de Tex Thumbnail Provider est encore enregistrée

Désinstalle d'abord l'autre gestionnaire de miniatures. Consulte la
[page Tex Thumbnail Provider](/docs/lol/tools/texturing/tex-thumbnail-provider)
pour ses étapes d'installation et de suppression.

### Le script d'installation échoue

Assure-toi que PowerShell tourne en tant qu'administrateur. Le script a besoin des droits
admin pour enregistrer la DLL auprès de Windows.
