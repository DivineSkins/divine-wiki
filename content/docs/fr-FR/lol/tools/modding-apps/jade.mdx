Jade est un éditeur BIN ciblé signé **RitoShark**. C'est le point de départ
conseillé si tu travailles surtout avec des fichiers `.bin`.

[Télécharge la dernière version](https://github.com/RitoShark/Jade-League-Bin-Editor/releases)

> Jade est encore en développement actif. Attends-toi à quelques
> imperfections et signale les bugs sur GitHub si tu en croises un.

---

## Ce qu'il fait

- **Éditeur BIN visuel** avec coloration syntaxique (l'éditeur Monaco, le
  même que VS Code).
- **Deux moteurs de parsing** : celui de Jade (Rust) et le parser LTK.
  Bascule de l'un à l'autre dans les réglages.
- **Gestion des fichiers de hash** avec téléchargement automatique depuis
  CommunityDragon, pour que tu n'aies pas à suivre les fichiers toi-même.
- **Aperçu des textures** au survol. Vois à quoi ressemble vraiment une
  texture référencée.
- **Éditeur de particules** pour ajuster les systèmes de particules
  visuellement.
- **Onglets** avec glisser-déposer. Édite plusieurs fichiers côte à côte.
- **Intégration Quartz**. Jade remarque quand Quartz modifie un fichier que
  tu es en train d'éditer.

---

## Installation

1. Va sur la [page des releases](https://github.com/RitoShark/Jade-League-Bin-Editor/releases).
2. Télécharge l'installateur Windows.
3. Lance-le. C'est fait.

Après l'installation, un double-clic sur un fichier `.bin` l'ouvre dans Jade.

---

## Quand utiliser Jade plutôt qu'un autre outil

- **Utilise Jade** si l'édition de .bin est ton travail principal. C'est le
  chemin le plus rapide : ouvrir le fichier, éditer, enregistrer.
- **Utilise [Flint](/docs/lol/tools/modding-apps/flint)** si tu as aussi
  besoin de l'extraction, de l'aperçu et du packing dans la même app.
- **Utilise [RitoBin](/docs/lol/tools/modding-apps/ritobin)** s'il te faut
  un outil en ligne de commande pour des scripts ou des traitements par lots.

<Callout type="info" title="Jade à l'intérieur de Flint">
  [Flint](/docs/lol/tools/modding-apps/flint) peut utiliser le moteur BIN de
  Jade directement. Choisis-le dans les réglages de Flint. À l'intérieur de
  Flint, les hashs viennent d'une base LMDB récupérée automatiquement, donc il
  n'y a aucun dossier de hashs à gérer. Jade en version autonome utilise
  toujours le modèle de dossier CommunityDragon décrit plus haut.
</Callout>

## Raccourcis clavier

| Action              | Raccourci          |
| ------------------- | ------------------ |
| Ouvrir un fichier   | `Ctrl + O`         |
| Enregistrer         | `Ctrl + S`         |
| Enregistrer sous    | `Ctrl + Shift + S` |
| Rechercher          | `Ctrl + F`         |
| Remplacer           | `Ctrl + H`         |
| Comparer deux fichiers | `Ctrl + D`      |
| Éditeur de particules | `Ctrl + P`       |
| Onglet suivant      | `Ctrl + Tab`       |
| Fermer l'onglet     | `Ctrl + W`         |

---

## Astuces

- Les fichiers de hash se trouvent dans
  `%APPDATA%\LeagueToolkit\Requirements\Hashes`. Tu peux les précharger au
  démarrage dans les réglages.
- Active la réduction dans la barre des tâches si tu gardes Jade ouvert
  pendant tes tests en jeu.
