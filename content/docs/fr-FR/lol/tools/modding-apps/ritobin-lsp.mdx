ritobin-lsp est une extension LSP/VS Code signée [alanpq](https://github.com/alanpq) qui ouvre les fichiers `.bin`/`.rito` de League sous forme de texte lisible que tu peux éditer.

Les dernières builds sont sur GitHub : [releases de ritobin-lsp](https://github.com/alanpq/ritobin-lsp/releases).

<Callout type="info" title="Pense à Jade si tu débutes dans le modding">
  `ritobin-lsp` est conçu pour te donner un support clé en main dans les
  éditeurs de texte courants, idéal pour les moddeurs qui les utilisent *déjà*
  pour modder.

Si tu n'as pas encore d'éditeur comme VS Code installé, pense à essayer Jade.

</Callout>

- [VS Code](https://code.visualstudio.com/Download).

## Dépannage

### Ritobin affiche des noms hashés au lieu de mots

Utilise la commande `Unhash File` disponible dans la palette de commandes (`Ctrl/Cmd + P`).
