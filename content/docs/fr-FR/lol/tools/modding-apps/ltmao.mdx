**LtMAO** est un pack d'outils pour le modding de League of Legends signé tarngaina. Il ajoute un menu contextuel au clic droit pour convertir des fichiers et l'associe à un jeu d'outils graphiques pour le packing WAD, les fichiers 3D, l'audio, les textures et plus encore.

<Callout type="info" title="Pack d'outils historique">
  LtMAO fonctionne toujours et couvre beaucoup de terrain. Les apps plus
  récentes de RitoShark font maintenant la plupart de ces tâches avec moins de
  configuration. Utilise
  [Flint](/docs/lol/tools/modding-apps/flint) pour extraire, éditer et packer,
  [Quartz](/docs/lol/tools/modding-apps/quartz) pour les VFX et l'audio, et
  [Jade](/docs/lol/tools/modding-apps/jade) pour l'édition de BIN. Garde LtMAO
  comme solution de secours pour les traitements en masse, le builder no-skin
  et le travail complet sur les banques de sons.
</Callout>

## Ce que fait le menu clic droit

LtMAO ajoute un menu contextuel au clic droit dans l'Explorateur Windows. Depuis là, tu peux :

### Convertir des fichiers

| De     | Vers   | Ce que ça fait                                |
| ------ | ------ | --------------------------------------------- |
| `.dds` | `.tex` | Convertir des textures pour un usage en jeu   |
| `.tex` | `.dds` | Extraire des textures pour les éditer         |
| `.wem` | `.wav` | Convertir des fichiers audio en format éditable |
| `.bin` | `.py`  | Convertir des fichiers binaires en Python lisible |
| `.py`  | `.bin` | Repacker des fichiers Python édités en binaire |

### Travailler avec les fichiers WAD

- Décompacter des fichiers `.wad.client` avec des hashes extraits sur mesure.
- Ouvrir des WAD de mods repathés ou lourdement modifiés.
- Extraire un seul fichier ou toute une archive WAD.

### Afficher les infos d'un fichier

Afficher les détails de :

- fichiers `.bin` : structure et propriétés.
- fichiers `.skn` : données de mesh du skin.
- fichiers `.skl` : données de squelette et de rig.

## Installation

1. Télécharge [LtMAO-hai.zip](https://github.com/tarngaina/LtMAO/archive/refs/heads/hai.zip).
2. Extrais le zip.
3. Lance `LtMAO-hai/start.bat`. L'app s'ouvre.

## Mises à jour

LtMAO-hai vérifie s'il existe une nouvelle version à chaque ouverture de l'app. Quand une sort, un message de mise à jour apparaît dans la barre de titre.

Pour mettre à jour complètement :

1. Re-télécharge l'app depuis GitHub.
2. Extrais-la au même endroit, en écrasant les anciens fichiers.

Pour mettre à jour vite fait :

1. Ouvre l'app.
2. Va sur la page des paramètres.
3. Clique sur **Redownload LtMAO**. Ce n'est pas la méthode recommandée, mais ça marche souvent.

### Thème

Tu peux créer ton propre thème. Ajoute un nouveau dossier dans `LtMAO-hai/res/themes`.

Règles :

- La taille de tes images doit garder le même ratio que les images d'origine.
- La couleur d'accent de l'app vient de la couleur dominante de ton `background.gif`.
- Si le nom du thème contient un `_`, la couleur d'accent est un dégradé entre les deux couleurs les plus dominantes.

### hash_helper

<img
  src="https://i.postimg.cc/7Y0W2XX0/screenshot-1.png"
  alt="Interface hash_helper"
  width={700}
/>

<Callout type="warning">
  Attends que la synchronisation, la mise à jour et le chargement des hashes
  soient finis avant de lancer une autre fonction de `LtMAO`.
</Callout>

Trois sources de hashes alimentent LtMAO :

1. **CDTB Hashes** : synchronisés automatiquement depuis [CommunityDragon](https://github.com/CommunityDragon/CDTB/tree/master/cdragontoolbox). Tu peux aussi les télécharger à la main depuis le même lien.
2. **Extracted Hashes** : les hashes que tu extrais toi-même. Tu peux les extraire depuis :
   - binentries :
     - VfxSystemDefinitionData → particlePath dans le BIN.
     - StaticMaterialDef → name dans le BIN.
   - binhashes :
     - Joint hashes → noms de joints dans le SKL.
     - Submesh hashes → noms de submesh dans le SKN.
   - game :
     - Les chemins de fichiers commençant par `assets/` ou `data/` dans le BIN. Si le type de fichier est `.dds`, les dds 2x et 4x sont extraits aussi.
3. **Custom Hashes** : le jeu de hashes que toutes les fonctions de LtMAO utilisent (ritobin, wad_tool, no_skin et d'autres).
   - Custom Hashes = CDTB Hashes + Extracted Hashes + les hashes que tu ajoutes à la main.

`hash_helper` a aussi un générateur de hashes WAD et BIN. Tu peux pousser les hashes générés dans Custom Hashes d'un seul bouton.

### no_skin

Crée un mod NO SKIN qui remet **presque** tous les skins de League à leur look par défaut.

<img
  src="https://i.imgur.com/AfQyzFN.png"
  alt="Interface de l'outil no_skin"
  width={700}
/>

`SKIPS.json` est une liste des skins qui font planter League quand on les remet à la base. L'outil la lit et saute ces skins.

Il y a deux modes :

1. **Full** : construit un `NO SKIN.fantome` complet à partir de tous les champions dans `League of Legends/Game/DATA/FINAL/Champions`.

   <img
     src="https://i.postimg.cc/ht0ZCjkG/screenshot-4.png"
     alt="Sortie du mode Full de no_skin"
     width={700}
   />

2. **Lite** : transforme chaque `skinx.bin` sélectionné en `skin0.bin`.

   <img
     src="https://i.postimg.cc/c18DpTp2/screenshot-7.png"

### lemon3d

Travaille avec les fichiers 3D de League.

1. **fbx** :

   <img

     alt="Workflow FBX de lemon3d"

   Supporte : SKN, SKL, ANM. Prévu : SCO, SCB, MAPGEO.

2. **maya** :

   <img
     src="https://i.postimg.cc/L6Ky2LRX/screenshot-9.png"

   />

   <img
