## Fichiers .bin : données et logique

Les fichiers `.bin` stockent **toute la logique** de League : systèmes de particules, définitions de skins, animations, sons, et plus encore.

| Contient          | Exemples                   |
| ----------------- | -------------------------- |
| Données de particules | Couleurs, tailles, timing des VFX |
| Définitions de skins  | Chemins des modèles, chemins des textures |
| Configs d'animation | Noms d'animations, blending |
| Configs de son    | Déclencheurs audio, volumes |

### Workflow

1. Extrais le `.bin` avec [Flint](/docs/lol/tools/modding-apps/flint)
2. Convertis-le en `.py` avec [Ritobin](/docs/lol/tools/modding-apps/ritobin) (ou édite-le directement dans [Jade](/docs/lol/tools/modding-apps/jade))
3. Édite-le dans un éditeur de texte comme VS Code ou Notepad++
4. Reconvertis-le en `.bin`
5. Ajoute-le à ton dossier de mod

> 💡 Les fichiers `.py` sont lisibles par un humain. Tu peux les chercher et les éditer.

## Fichiers .dds : les textures

Le `.dds` (DirectDraw Surface) est le **format de texture standard** utilisé pour :

| Usage           | Exemples              |
| --------------- | --------------------- |
| Modèles de champions | Textures de skins, visages |
| Particules       | Sprites de VFX, glows |
| UI/HUD          | Icônes, panneaux de compétences |

### Outils d'édition

<ToolCard name="Photoshop" href="https://www.adobe.com/products/photoshop.html">
  La meilleure option avec le plugin DDS de NVIDIA.
</ToolCard>

<ToolCard name="GIMP" href="https://www.gimp.org/">
  Alternative gratuite avec support du DDS.
</ToolCard>

<ToolCard name="Paint.NET" href="https://www.getpaint.net/">
  Léger, avec un plugin DDS.
</ToolCard>

### Réglages d'export

| Réglage     | Valeur          |
| ----------- | -------------- |
| Format      | `.dds`         |
| Compression | **BC3 / DXT5** |
| Mipmaps     | ✅ Activés      |

> ⚠️ Une mauvaise compression = des textures cassées en jeu !

## Fichiers .tex : le format de Riot

Le `.tex` est le **format de texture propriétaire** de Riot, présent dans les fichiers `.wad.client`.

| Statut                  | Info                   |
| ----------------------- | ---------------------- |
| ❌ Édition directe impossible | C'est un format compilé |
| ✅ Convertir d'abord    | Utilise tex2dds        |
| ✅ Reconvertir après    | Avant de réimporter    |

Tu as deux façons de travailler le `.tex` :

1. **L'ouvrir directement** avec un plugin TEX pour ton éditeur d'image. Aucune étape de conversion.
2. **Convertir** le `.tex` en `.dds` et inversement avec Flint ou LtMAO.

## Tableau complet du workflow

| Tâche                   | Fichier | Outil                              | Sortie          |
| ----------------------- | ------ | ---------------------------------- | --------------- |
| Éditer les VFX/particules | `.bin` | Jade (ou Ritobin)                  | `.bin`          |
| Éditer un skin de champion | `.dds` | Photoshop/GIMP                     | `.dds`          |
| Éditer une texture directement | `.tex` | RitoTex, Paint.NET, ou plugin GIMP | `.tex`          |
| Convertir une texture   | `.tex` | Flint ou LtMAO                     | `.dds`          |
| Réimporter une texture  | `.dds` | Flint ou LtMAO                     | `.tex`          |
| Parcourir les fichiers du jeu | `.wad` | Flint                              | Fichiers extraits |
