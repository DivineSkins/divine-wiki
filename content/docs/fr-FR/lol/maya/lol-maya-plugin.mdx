## Installer le plugin LoL-Maya

Pour commencer à travailler les modèles de League dans Maya, tu auras besoin du **plugin LoL-Maya** de **Tarngaina**.

> ⚠️ Pour les versions récentes de Maya, tu peux aussi utiliser **Lemon 3D** avec **LtMAO** (aussi de Tarngaina) pour assurer la compatibilité.

## Télécharger le plugin

Télécharge **LoL-Maya (dernière version)**
Vérifie que tu utilises bien la version la plus récente.

---

## Installer le plugin

1. Extrais le contenu du fichier `.zip`.
2. Copie tous les fichiers du plugin dans ton dossier Maya.

Place les dossiers suivants dans :

```text
Documents\maya\2023\
```

- `plug-ins`
- `prefs`
- `scripts`

---

## Activer le plugin dans Maya

1. Ouvre **Maya**
2. Va dans :
   **Windows → Settings/Preferences → Plug-in Manager**
3. Repère **lol_maya** dans la liste
4. Active les deux options :
   - **Loaded**
   - **Auto Load**

5. Clique sur **Close**, puis redémarre Maya

Si tout s'est bien passé, tu verras les onglets **LoLMaya** et **LoLMaya_MAPGEO** dans la barre d'outils principale de Maya.

### Dépannage

<Tabs items={["Plugin Not Showing", "Tabs Missing", "Maya Compatibility"]}>
<Tab value="Plugin Not Showing">

### Le plugin n'apparaît pas dans le Plug-in Manager

**Causes :**

- Les fichiers ne sont pas dans le bon dossier
- Mauvais dossier de version de Maya

**Solution :**

1. Vérifie que les fichiers sont dans `Documents\maya\[TA_VERSION]\`
2. Vérifie que les trois dossiers (`plug-ins`, `prefs`, `scripts`) sont présents
3. Redémarre complètement Maya

</Tab>
<Tab value="Tabs Missing">

### Les onglets n'apparaissent pas après le chargement

**Causes :**

- Le plugin est chargé mais l'interface n'a pas été rafraîchie
- Maya a besoin d'un redémarrage

**Solution :**

1. Ferme complètement Maya
2. Rouvre Maya
3. Revérifie le Plug-in Manager
4. Vérifie que **Loaded** et **Auto Load** sont bien activés

</Tab>
<Tab value="Maya Compatibility">

### Problèmes avec les versions récentes de Maya

Pour **Maya 2024+**, le plugin standard peut avoir des soucis de compatibilité.

**Solution :** utilise **Lemon 3D + LtMAO** ensemble :
