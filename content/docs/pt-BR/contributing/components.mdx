O wiki tem um pequeno conjunto de componentes que você pode inserir em qualquer guia. A barra de ferramentas do editor de rascunho os insere para você. Esta página é a referência completa. Cada seção mostra primeiro o componente e depois o código que o gera.

## Callout (Aviso/Nota)

Uma caixa colorida para avisos, dicas e a nota de segurança da Coreia/China. Use `type="danger"` para risco real, `info` para dicas, `warning` para “isso pode dar errado” e `success` para confirmação.

<Callout type="info" title="Dica">
  Você pode pular esta etapa se já instalou a ferramenta.
</Callout>

<Callout type="warning" title="Atenção">
  Salvar sobre o arquivo original não pode ser desfeito. Faça uma cópia primeiro.
</Callout>

<Callout type="danger" title="Não use skins personalizadas na Coreia ou China">
  O sistema anti-cheat lá bloqueia todos os mods. Contas são banidas.
</Callout>

<Callout type="success" title="Concluído">
  Um visto verde aparece quando a skin está pronta.
</Callout>

```mdx
<Callout type="danger" title="Não use skins personalizadas na Coreia ou China">
  O sistema anti-cheat lá bloqueia todos os mods. Contas são banidas.
</Callout>
```

Propriedades:

- `type` é `info`, `warning`, `danger` ou `success`. O padrão é `info`.
- `title` é opcional. Cada tipo tem um título padrão.

Existem também três tipos de nível para marcar a dificuldade dentro de uma página:
`lvl_beginner`, `lvl_intermediate` e `lvl_advanced`. Para um pequeno
selo de dificuldade no topo de um guia, use [LevelPill](#levelpill).

## Tabs

Caminhos alternativos. Use abas para etapas específicas de cada sistema operacional ou
fluxos de trabalho específicos de cada ferramenta. Todo `<Tabs>` precisa de um `</Tabs>` de fechamento, e
todo `<Tab>` de um `</Tab>` de fechamento.

<Tabs items={["Windows", "macOS"]}>

<Tab value="Windows">Etapas do Windows aqui.</Tab>

<Tab value="macOS">Etapas do macOS aqui.</Tab>

</Tabs>

```mdx
<Tabs items={["Windows", "macOS"]}>
  <Tab value="Windows">Etapas do Windows aqui.</Tab>
  <Tab value="macOS">Etapas do macOS aqui.</Tab>
</Tabs>
```

## Accordion

Seções recolhíveis. Boas para perguntas frequentes e detalhes opcionais.

<Accordions>

<Accordion title="Preciso do Maya para fazer uma skin?">
  Não. O Blender funciona para todo o fluxo de trabalho, e muitas edições não precisam de
  nenhuma ferramenta 3D.
</Accordion>

<Accordion title="Qual o tamanho máximo do meu arquivo de mod?">
  Não há um limite rígido, mas mantenha as texturas pequenas para o mod carregar rápido.
</Accordion>

</Accordions>

```mdx
<Accordions>
  <Accordion title="Pergunta aqui">Resposta aqui.</Accordion>
</Accordions>
```

## Image

Uma captura de tela. O texto `alt` é obrigatório. Os revisores rejeitam imagens sem
ele. Mantenha os arquivos abaixo de 500 KB e coloque-os em `public/wiki-images/`.
Os leitores podem clicar em qualquer imagem para ampliá-la.

/>

## ToolCard

Uma única linha de ferramenta com um nome, um link e uma descrição de uma linha. Use-a
em páginas de lista de ferramentas.

<ToolCard
  name="Flint"
  href="/docs/lol/tools/modding-apps/flint"
  badge="Recommended"
>
  Ferramenta completa de criação de skins.
</ToolCard>

```mdx
<ToolCard
  name="Flint"
  href="/docs/lol/tools/modding-apps/flint"
  badge="Recommended"
>
  Ferramenta completa de criação de skins.
</ToolCard>
```

Propriedades:

- `name` e `href` são obrigatórios. Links externos abrem em uma nova aba.
- `badge` é opcional. Ele aparece como uma pequena pílula à direita.

## LevelPill

Um marcador de dificuldade. Coloque-o no topo de um guia, logo abaixo do
título. `level` é `beginner`, `intermediate` ou `advanced`.

<LevelPill level="beginner" /> <LevelPill level="intermediate" />
<LevelPill level="advanced" />

```mdx
<LevelPill level="beginner" />
```

Use a propriedade opcional `label` para mudar o texto:
`<LevelPill level="advanced" label="Expert" />`.

## ParameterList

Uma tabela de duas colunas com nome/descrição para páginas de referência.

<ParameterList
  parameters={[
    { name: "champion", description: "O campeão ao qual a skin pertence." },
    { name: "skin_id", description: "O id numérico da skin base." },
  ]}
/>

```mdx
<ParameterList
  parameters={[
    { name: "champion", description: "O campeão ao qual a skin pertence." },
    { name: "skin_id", description: "O id numérico da skin base." },
  ]}
/>
```

## PremiumCard

Um cartão em destaque com borda em gradiente para um link em evidência. Use-o
para apontar aos leitores a próxima página mais importante.

<PremiumCard title="Tutorial guiado" href="/docs/lol/guided-walkthrough">
  Comece por aqui se você é novo. Um caminho da pasta vazia até a skin pronta.
</PremiumCard>

```mdx
<PremiumCard title="Tutorial guiado" href="/docs/lol/guided-walkthrough">
  Comece por aqui se você é novo.
</PremiumCard>
```

## GlowCTA

Um botão de chamada para ação brilhante. Use-o para a única ação que você quer
que o leitor faça. No máximo um por página.

<GlowCTA href="/docs/lol">Explorar os guias</GlowCTA>

```mdx
<GlowCTA href="/docs/lol">Explorar os guias</GlowCTA>
```

Propriedades:

- `variant` é `primary` (brilho roxo, padrão), `solid`, `secondary`
  ou `ghost`.
- `size` é `md` (padrão) ou `lg`.

## YouTube

Um vídeo do YouTube incorporado. Passe o id do vídeo, não a URL completa. O id
é a parte após `watch?v=` ou `youtu.be/`.

<YouTube
  id="xqB84ga55hI"
  title="Tutorial de skin personalizada para League of Legends"
/>

```mdx
<YouTube id="xqB84ga55hI" title="O que o vídeo mostra" />
```

Propriedades:

- `id` é obrigatório.
- `title` descreve o vídeo para leitores de tela.
- `start` é opcional. Ele inicia a reprodução naquele segundo.

Atalho: cole um link simples do YouTube em sua própria linha e o wiki o transforma
em um vídeo incorporado para você.

## Icon

Um ícone em linha. Use qualquer [nome de ícone do Lucide](https://lucide.dev/icons/),
ou um dos nomes de marca: `Maya`, `Blender`, `Discord`,
`LeagueOfLegends`.

<Icon name="Wrench" /> <Icon name="Sparkles" /> <Icon name="Blender" />
<Icon name="Discord" />

```mdx
<Icon name="Wrench" />
```

Use a propriedade opcional `className` para mudar o tamanho, por exemplo
`className="size-4"`.
