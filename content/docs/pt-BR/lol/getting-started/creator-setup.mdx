<LevelPill level="beginner" />

Este guia configura as ferramentas que quase todo mod de League precisa. Instale mods primeiro, assim você consegue testar o que criar: [Instale mods](/docs/lol/getting-started/install-mods).

<Requirements>
  <Requirement icon="Monitor">PC com Windows</Requirement>
  <Requirement icon="LeagueOfLegends" note="patch mais recente">
    League of Legends
  </Requirement>
</Requirements>

As ferramentas de criador rodam no Windows.

<Steps>
<Step>

### Configure o Creator Hub do Celestial

O Creator Hub é onde você testa, faz o repath e exporta os seus mods.

1. Instale o [Celestial](https://divineskins.gg/install-mods).
2. Abra **Configurações** e depois **Hub de Criadores**. Em **Padrões de Importação**, digite o seu **Nome do Criador**. O Celestial coloca esse nome em todo mod que você importar.
3. Abra o Creator Hub pelo ícone **Hub de Criadores** no topo. O botão **?** abre o Guia do Creator Hub.

</Step>
<Step>

### Escolha um extrator

Um extrator tira os arquivos de um campeão de dentro do jogo para você editar. Escolha um. Os três conseguem extrair uma skin já com repath.

<ToolCard
  name="Flint"
  href="/docs/lol/tools/modding-apps/flint"
  badge="Recomendado"
  icon={<Icon name="Flint" />}
>
  Tudo em um: extrai, visualiza, edita arquivos BIN e empacota. Faz o repath de
  todo projeto de skin novo para você.
</ToolCard>

<ToolCard
  name="Quartz"
  href="/docs/lol/tools/modding-apps/quartz"
  icon={<Icon name="Quartz" />}
>
  Suíte focada em VFX, com um Asset Extractor. Use o botão Repath dele para
  extrair já com repath.
</ToolCard>

<ToolCard
  name="Jade"
  href="/docs/lol/tools/modding-apps/jade"
  icon={<Icon name="Jade" />}
>
  Editor de BIN com um extrator que faz o repath enquanto extrai.
</ToolCard>

</Step>
<Step>

### Adicione um app 3D e um editor de imagem

Você vai precisar deles quando for mexer em modelos ou texturas.

- **App 3D:** o [Blender](/docs/lol/blender) é gratuito. O [Maya](/docs/lol/maya) tem mais ferramentas feitas para o League.
- **Editor de imagem:** [Paint.NET](/docs/lol/tools/texturing/paint-net), [GIMP](/docs/lol/tools/texturing/gimp) ou [Photoshop](/docs/lol/tools/texturing/photoshop), cada um com o seu plugin de TEX.

[Ferramentas](/docs/lol/tools) lista todas as ferramentas desta wiki.

</Step>
<Step>

### Comece sua primeira skin já com repath

Extraia o seu campeão com um prefixo desde o primeiro dia. Seu mod nunca bate com outros mods, e você nunca precisa fazer o repath no final. [Faça o repath do seu mod](/docs/lol/getting-started/repath-your-mod#boa-prática-comece-já-com-repath) mostra como fazer em cada extrator.

</Step>
</Steps>
