> Este guia leva você do primeiro install das ferramentas até uma skin final publicada. Siga as partes em ordem.

<Callout type="warning" title="Segurança primeiro">
  Skins personalizadas são seguras fora da Coreia e China. Não há banimentos desde 2014 quando você usa ferramentas confiáveis. Elas são apenas client-side: só você vê e não dão vantagem no jogo. Nunca use skins na Coreia ou China. O anti-cheat lá bloqueia todos os mods.
</Callout>

<Callout type="info" title="Vídeos podem estar desatualizados">
  Alguns vídeos abaixo usam ferramentas antigas. Novas ferramentas foram lançadas desde então, e cada uma tem seu próprio guia na seção [Ferramentas](/docs/lol/tools). Os vídeos ainda ajudam a entender o fluxo geral. Para uso diário, prefira as ferramentas mais recentes.
</Callout>

## Como o pipeline funciona

A criação de skins segue um fluxo único. O [Flint](/docs/lol/tools/modding-apps/flint) cobre quase tudo em uma única interface.

1. **Extrair** arquivos do jogo.
2. **Pré-visualizar** modelo, texturas e VFX.
3. **Editar** o que quiser: modelo, texturas, partículas ou áudio.
4. **Validar** o mod e corrigir bugs com [Hematite](/docs/lol/tools/modding-apps/hematite).
5. **Empacotar** o mod em `.fantome` ou `.modpkg`. Esses são os formatos de pacote de mod que um gerenciador de skins instala.
6. **Instalar** via gerenciador de skins para testar no jogo.

Cada parte abaixo corresponde a uma dessas etapas.

## Começando

### Ferramentas necessárias

Comece com estas três. Elas cobrem a maior parte do trabalho:

- **[Flint](/docs/lol/tools/modding-apps/flint)**: extrair, editar, validar e empacotar.
- **[Jade](/docs/lol/tools/modding-apps/jade)**: editor de BIN.
- **[Quartz](/docs/lol/tools/modding-apps/quartz)**: VFX e ajustes visuais.

Você também vai querer:

- A visão geral de [Ferramentas](/docs/lol/tools) para todo o resto.

Opcional:

- **[LtMAO](/docs/lol/tools/modding-apps/ltmao)**: ferramenta antiga, usada como fallback para trabalhos em lote e soundbanks completas.

#### Notas importantes

- **Instale o LoL Maya primeiro**
- **Não** apague faces, vértices ou arestas depois de vincular a malha
- Na primeira importação de arquivos `.skn` / `.skl`, use **Importar**, não arrastar e soltar

### Parte 10: Repath e publicação

Refaça o path do seu mod para alinhá-lo com os arquivos atuais do jogo, depois publique-o.

**Empacotar e exportar.** No Flint, exporte seu mod como um arquivo `.fantome` ou `.modpkg`.
Escolha `.modpkg` quando compat?vel, ou mantenha pastas `.wad.client` n?o empacotadas no `.fantome`.
Leia [Qual formato escolher](/docs/lol/tools/which-format-to-choose) para entender por que preservar os caminhos.

**Opções de repath.** Se um path estiver errado, ou um patch quebrou o mod, refaça o path com o [League Mod Repather](/docs/lol/tools/modding-apps/league-mod-repather) ou a página Bumpath do Quartz.

**Instalar e testar.** Carregue o mod em um gerenciador de skins como LTK Manager ou Celestial, depois teste em uma partida personalizada.

https://youtu.be/WxdHs9oauP4

## Extras

### Bones e física (cabelo, capas, etc.)

Adicione bones e movimento baseado em física à sua skin.

#### Ferramentas necessárias

| Ferramenta    | Descrição                                                            |
| ------------- | ------------------------------------------------------------------- |
| Autodesk Maya | Software 3D padrão da indústria para rigging e mapeamento de UV      |
| Jade          | Edita o `.bin` de física diretamente. Sem converter de ida e volta.  |
| RitoBin       | Fallback opcional. Converte `.bin` para `.py` e de volta (`ritobin_cli`). |

https://www.youtube.com/watch?v=ejg5IAkEDTY

---

### Exemplo de configuração

```cpp
rigPoseModifierData: list[pointer] = {
    ConformToPathRigPoseModifierData {
        mStartingJointName: hash = 0x41f70632
        mEndingJointName: hash = 0x3cf6fe53
        mDefaultMaskName: hash = 0x7136e1bc
        mMaxBoneAngle: f32 = 45
        mDampingValue: f32 = 5
        mFrequency: f32 = 3
    }
}
```
