Crie uma thumbnail para sua skin personalizada com o [Flint](/docs/lol/tools/modding-apps/flint).
Use o editor de thumbnails para posicionar o modelo e o texto, depois exporte uma imagem para compartilhar com seu mod.

## Antes de começar

- Abra o projeto da sua skin no Flint.
- Encontre o arquivo `.skn` do modelo na árvore de arquivos do projeto.

## Crie sua thumbnail

1. Clique com o botão direito no arquivo `.skn` do modelo.
2. Selecione **Create Thumbnail…** para abrir o editor de thumbnails.
3. Escolha **Riot style** ou **Divine style** no menu de presets.
4. Selecione uma camada de modelo no painel **Layers**.
5. Ajuste a posição e o tamanho dela na tela para enquadrar sua skin.
6. Selecione cada camada de texto para editar o nome do mod e do campeão.
7. Escolha **WebP**, **PNG** ou **JPG** no menu de formato de saída.
8. Clique em **Export**.
9. Escolha o nome do arquivo e onde salvar na janela que abrir.
10. Abra a imagem exportada para conferir se o modelo e o texto estão bem visíveis.

<Callout type="info" title="Guarde o layout para depois">
  **Save** salva seu layout como um preset local. Use **Export** para salvar
  a imagem final.
</Callout>
