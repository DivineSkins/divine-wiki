ritobin-lsp é uma extensão LSP/VS Code feita por [alanpq](https://github.com/alanpq) que abre os arquivos `.bin`/`.rito` do League como texto legível que você pode editar.

As builds mais recentes estão no GitHub: [releases do ritobin-lsp](https://github.com/alanpq/ritobin-lsp/releases).

<Callout type="info" title="Considere o Jade se você é novo no modding">
  O `ritobin-lsp` foi feito para dar suporte pronto aos editores de texto mais
  comuns, ideal para modders que *já* usam esses editores para modar.

Se você ainda não tem um editor como o VS Code instalado, considere testar o Jade.

</Callout>

## Solução de problemas

### O Ritobin mostra nomes com hash em vez de palavras

Use o comando `Unhash File` disponível na paleta de comandos (`Ctrl/Cmd + P`).
