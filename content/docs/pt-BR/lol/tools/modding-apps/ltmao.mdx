O **LtMAO** é um pacote de ferramentas para modding de League of Legends, criado por tarngaina. Ele adiciona um menu de contexto no botão direito para conversão de arquivos e vem acompanhado de um conjunto de ferramentas com interface gráfica para empacotamento de WAD, arquivos 3D, áudio, texturas e muito mais.

<Callout type="info" title="Pacote de ferramentas legado">
  O LtMAO ainda funciona e cobre muitos casos de uso. Os aplicativos mais novos
  da RitoShark agora fazem a maioria dessas tarefas com menos configuração. Use o
  [Flint](/docs/lol/tools/modding-apps/flint) para extrair, editar e empacotar, o
  [Quartz](/docs/lol/tools/modding-apps/quartz) para VFX e áudio, e o
  [Jade](/docs/lol/tools/modding-apps/jade) para edição de BIN. Mantenha o LtMAO como
  uma alternativa para tarefas em lote, o construtor no_skin e trabalho completo com soundbank.
</Callout>

## O que o menu do botão direito faz

O LtMAO adiciona um menu de contexto no botão direito do Windows Explorer. A partir dele você pode:

### Converter arquivos

| De     | Para   | O que faz                                       |
| ------ | ------ | ----------------------------------------------- |
| `.dds` | `.tex` | Converte texturas para uso dentro do jogo       |
| `.tex` | `.dds` | Extrai texturas para que você possa editá-las   |
| `.wem` | `.wav` | Converte arquivos de áudio para um formato editável |
| `.bin` | `.py`  | Converte arquivos binários em Python legível    |
| `.py`  | `.bin` | Reempacota arquivos Python editados de volta em binário |

### Trabalhar com arquivos WAD

- Descompacte arquivos `.wad.client` usando hashes extraídos personalizados.
- Abra WADs de mods com caminhos alterados ou fortemente modificados.
- Extraia arquivos individuais ou um arquivo WAD inteiro.

### Exibir informações de arquivos

Exiba detalhes sobre:

- arquivos `.bin`: estrutura e propriedades.
- arquivos `.skn`: dados da malha da skin.
- arquivos `.skl`: dados do esqueleto e do rig.

## Instalação

1. Baixe o [LtMAO-hai.zip](https://github.com/tarngaina/LtMAO/archive/refs/heads/hai.zip).
2. Extraia o zip.
3. Execute o `LtMAO-hai/start.bat`. O aplicativo abre.

## Atualizações

O LtMAO-hai verifica se há uma nova versão toda vez que você abre o aplicativo. Quando há uma disponível, uma mensagem de atualização aparece na barra de título.

Para atualizar por completo:

1. Baixe o aplicativo novamente no GitHub.
2. Extraia-o no mesmo local, sobrescrevendo os arquivos antigos.

Para atualizar de forma rápida:

1. Abra o aplicativo.
2. Vá para a página de configurações.
3. Clique em **Redownload LtMAO**. Este não é o caminho recomendado, mas costuma funcionar.

### Tema

Você pode criar o seu próprio tema. Adicione uma nova pasta dentro de `LtMAO-hai/res/themes`.

Regras:

- Os tamanhos das suas imagens devem usar a mesma proporção das imagens originais.
- A cor de destaque do aplicativo vem da cor dominante do seu `background.gif`.
- Se o nome do tema tiver um `_`, a cor de destaque será um gradiente entre as duas cores mais dominantes.

### hash_helper

<img
  src="https://i.postimg.cc/7Y0W2XX0/screenshot-1.png"
  alt="Interface do hash_helper"
  width={700}
/>

<Callout type="warning">
  Espere a sincronização, a atualização e o carregamento dos hashes terminarem
  antes de executar qualquer outra função do `LtMAO`.
</Callout>

Três fontes de hash alimentam o LtMAO:

1. **CDTB Hashes**: sincronizados automaticamente do [CommunityDragon](https://github.com/CommunityDragon/CDTB/tree/master/cdragontoolbox). Você também pode baixá-los manualmente no mesmo link.
2. **Extracted Hashes**: hashes que você mesmo extrai. Você pode extrair estes:
   - binentries:
     - VfxSystemDefinitionData → particlePath no BIN.
     - StaticMaterialDef → name no BIN.
   - binhashes:
     - Joint hashes → nomes de joints no SKL.
     - Submesh hashes → nomes de submeshes no SKN.
   - game:
     - Caminhos de arquivo que começam com `assets/` ou `data/` no BIN. Se o tipo do arquivo for `.dds`, os dds 2x e 4x também são extraídos.
3. **Custom Hashes**: o conjunto de hashes que toda função do LtMAO usa (ritobin, wad_tool, no_skin e outras).
   - Custom Hashes = CDTB Hashes + Extracted Hashes + hashes que você adiciona manualmente.

O `hash_helper` também tem um gerador de hashes de WAD e BIN. Você pode enviar os hashes gerados para os Custom Hashes com um botão.

### no_skin

Cria um mod NO SKIN que troca **quase** todas as skins do League de volta para a aparência padrão.

<img
  src="https://i.imgur.com/AfQyzFN.png"
  alt="Interface da ferramenta no_skin"
  width={700}
/>

O `SKIPS.json` é uma lista de skins que fazem o League travar quando trocadas de volta para a base. A ferramenta lê o arquivo e pula essas skins.

Há dois modos:

1. **Full**: cria um `NO SKIN.fantome` completo a partir de todos os campeões dentro de `League of Legends/Game/DATA/FINAL/Champions`.

   <img
     src="https://i.postimg.cc/ht0ZCjkG/screenshot-4.png"
     alt="Saída do modo Full do no_skin"
     width={700}
   />

2. **Lite**: transforma cada `skinx.bin` selecionado em `skin0.bin`.

   <img
     src="https://i.postimg.cc/c18DpTp2/screenshot-7.png"
     alt="Resultado do modo Lite do no_skin"
     width={700}
