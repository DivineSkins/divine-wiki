## 1. Preparando seus Static Materials

Você achou que era só trocar texturas? Queria que fosse tão simples assim.

Você precisa copiar o `staticmaterial` associado à textura base do mesh. Por exemplo, para o corpo da Yuumi, é `Orb_Cat_inst`. Você encontra isso pesquisando o nome da textura dentro do arquivo da skin.

<img src="/wiki-images/1767149443636-vvzsnj.webp" alt="Imagem" width={800} />

Depois disso, copie tudo, cole em outro lugar, renomeie e adicione sua textura. No exemplo, o nome será `"mine"`.

<img src="/wiki-images/1767149464084-1r81lr.webp" alt="Imagem" width={500} />

## 2. VFX

Você vai precisar deste trecho de código. Recomendo colar perto do seu staticmaterial para ter tudo em um só lugar.

```py
"Hide" = VfxSystemDefinitionData {
    timeBeforeFirstEmission: f32 = 1
    complexEmitterDefinitionData: list[pointer] = {
        VfxEmitterDefinitionData {
            rate: embed = ValueFloat {
                constantValue: f32 = 1
            }
            particleLifetime: embed = ValueFloat {
                constantValue: f32 = 1e+14
            }
            isSingleParticle: flag = true
            emitterName: string = "Override"
            meshRenderFlags: u8 = 0
            materialOverrideDefinitions: list[embed] = {
                VfxMaterialOverrideDefinitionData {
                    priority: i32 = 1
                    subMeshName: option[string] = {
                        "NomeDoSeuMaterialDoMaya"
                    }
                    material: link = "Characters/urchamp/Skins/urskin/Materials/urstaticmaterial"
                    transitionSample: f32 = 1
                }
            }
        }
    }
    particleName: string = "Hide"
    particlePath: string = "Hide"
}
```

## 3. Resource Resolver

Você também vai precisar disso no `ResourceResolver`:

```py
"Hide" = "Hide"
"Show" = "Show"
```

---

## 4. Animation Bin

Depois disso, você precisa do bin de animação. Encontre a animação que você quer usar como toggle e cole estes trechos de código assim:

<img src="/wiki-images/1767149506632-k9q8d.webp" alt="Imagem" width={700} />

```py
"Hide" = ParticleEventData {
    mEffectKey: hash = "Hide"
    mParticleEventDataPairList: list[embed] = {
        ParticleEventDataPair {}
    }
    mIsLoop: bool = false
    mIsKillEvent: bool = false
}
```

```py
"Show" = ParticleEventData {
    mEffectKey: hash = "Show"
    mParticleEventDataPairList: list[embed] = {
        ParticleEventDataPair {}
    }
    mIsLoop: bool = false
    mIsKillEvent: bool = false
}
```
